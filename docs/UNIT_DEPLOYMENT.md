# 部署与出场规则

部署分为命令等待、可选预部署、生成后部署三段；它们不是同一段计时。

| 阶段 | 当前行为 |
| --- | --- |
| 命令等待 | 正式出牌先经过 10 个固定步，即 0.5 秒缓冲 |
| 预部署（可选） | 先显示落点提示，此时没有可攻击或碰撞的单位 |
| 生成后部署 | 默认 1 秒；已有身体、可被命中和推挤，但不能自主移动、攻击或释放技能 |

网络传输时间包含在命令缓冲内。主机按点击时观察到的 Tick 加 10 排程；过晚、过旧或明显来自未来的请求被拒绝，不重新追加一整段等待。

召唤物与兵线不走手牌命令等待，兵线可以立即行动。工作台跳过通用缓冲，但保留卡牌自身两段部署时间。

## 模型与特殊情况

- 部署片段优先复活动作，其次回城结束，最后待机；多段动作总时长应匹配部署窗口。
- 群体卡只提交一次落点，生成多个独立成员；各自有生命和碰撞，共享编队身份。
- 卡牌大师先预部署 1.3 秒，再部署 0.45 秒。全图地面部署由 `deploy_zone` 配置，仍检查河道和建筑占地。
- 赵信生成时立即结算部署横扫，之后仍保持 1 秒部署锁；伤害不等待动画回调。

## 主动技能的等待

主动技能也经过命令缓冲。请求入队时检查归属、费用、次数、冷却与状态并扣金币；技能真正开始时扣使用次数、开始冷却，再推进效果执行和结束；弹体伤害另外等待真实碰撞。

因此“0.5 秒后生效”不能套用到所有卡牌的最终行动时刻：单位还可能需要预部署和部署。验证步骤见 [测试手册](../tests/README.md)。

建筑等待到场时不预留占位；真正生成前重新检查，若被先落地的建筑挡住，挪到最近合法格，不退牌不退费。活塔占地禁止部署；塔死后普通卡牌按正常地面处理（仍遵守阵营和地形规则），太阳圆盘与废墟重叠时只能位于废墟正中心并获得重建效果，也可部署在废墟之外的合法位置。
