# 交付合同：3D 地图流水与林缘升级

- **需求 / 来源**：用户对话；先调研召唤师峡谷景观，再增强河流流动感与地图外围景物。
- **完成结果**：正式水面采用从左向右持续平移的水纹、两层细波和断续岸线泡沫，侧面截面向下流动。新增分层针叶树、矮树、苔石、倒木、根系、蕨草与花丛，补足镜头可见林缘。复用已有模型和原图集，保留六座建筑与双桥的辨识度。已按素材库副本试接入、实际渲染、同步最终资源的流程完成；GLB、生成器、可编辑 Blender 源同步更新。预览工具修复旧部署接口引用，并增加 `--motion` 连续帧与真实时间记录。
- **验证**：基线提交 `4ca4f256ef7af96779e7fbb504419e04f4bd43c6`；工作区原有大量卡牌、机制和文档未提交修改，本任务未覆盖。Godot `4.7.1.stable.official.a13da4feb`、Compatibility / Apple M5；Blender 5.2.1。最终工程导入及图形渲染正常退出，无脚本/着色器错误；实际目视检查实战、全景、河道、部署提示及连续帧。核心命令 `Godot --headless --path . --script tests/mechanics_check.gd` 正常退出，54 个套件、6518 项断言全部通过。日志包含既有网络失败路径输出与水晶终局音频缺失警告，不属于地图改动。地面、桥梁、基座、道路和河面 21 组几何的顶点/索引与变换逐项比对一致。`git diff --check` 通过。
- **查看方式**：F5 启动主场景后开始单机对战，河水持续向右流动。独立检查：`Godot --path . --script tools/capture/capture_rift_arena_v2.gd -- --inspect`，按 `1/2/3` 切换实战、全景、河道。下方为本机真实渲染与视频。
- **遗留 / 未验证**：用户尚未确认主观观感；未做移动设备性能验收。相同河道预览的绘制调用为 475 → 480，绘制图元为 412,967 → 519,992（约 +26%，包含阴影等绘制），不等于模型面数或 FPS 结论。运行 GLB 为 7,094,304 → 8,593,320 字节。没有新增水流音频，本轮范围为视觉升级。

调研结论与实现依据见[竞技场特效说明](../units/effects/arena.md)：参考 [Riot 海洋峡谷环境开发](https://www.leagueoflegends.com/en-sg/news/dev/unleashing-the-elements/)的局部花草与环境分层，结合[画面辨识度原则](https://www.leagueoflegends.com/en-gb/news/dev/clarity-in-league/)保留战斗区域空隙；水面使用 [Godot Spatial Shader](https://docs.godotengine.org/en/4.6/tutorials/shaders/shader_reference/spatial_shader.html) 的世界坐标和渲染时间进行平移，避免仅原地明暗变化。源纹理未改动。
