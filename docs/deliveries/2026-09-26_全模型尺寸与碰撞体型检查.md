# 交付合同：全模型显示尺寸与碰撞体型只读检查

- **需求 / 来源**：用户对话；检查所有正式模型的显示大小与权威碰撞体型是否一致，只检查不调整。
- **完成结果**：检查 42 个去重后的单位/建筑模型与形态/阵营组合，另查 4 个系统塔/水晶组合，共 46 项。群体卡复用成员模型，不把整组编队当成一个碰撞体。未修改游戏代码、资源、模型缩放或碰撞数值；仅新增本报告和忽略目录中的检查产物。
- **验证环境**：基线 `2ecbf51`；开始时工作区已有大量未提交修改，检查以当前工作区为准。Godot 4.7.1 stable，Compatibility/OpenGL，Apple M5。

## 结论

**目前不能认为所有模型都符合“同等碰撞、看起来大小接近”的要求。** 同组存在明显差异；没有发现所有模型都统一随 radius 缩放的机制，包装场景分别决定大小。

| 优先级 | 对象 | 判断 |
| --- | --- | --- |
| 优先复核 | 潘森、超级兵（蓝/红） | 都是 R18，但本体明显比艾希、女枪、卡牌大师厚重；不是只有武器尖端越界。 |
| 优先复核 | 提莫、小纳尔 | 都是 R12，但比同组远程兵、小鬼、虚空蠕虫明显大。提莫帽子、小纳尔耳朵贡献部分差异，身体也较饱满。 |
| 优先复核 | 大纳尔 ↔ 峡谷先锋 | 同为 R27，先锋明显更大，大纳尔在该组显小。不能在没有选定体型基准前断言只应改其中哪一个。 |
| 次级复核 | 格温、冰鸟 | 身体偏小的候选；格温剪刀、冰鸟翅膀扩大宽度，整体包围盒掩盖本体偏小。 |
| 次级复核 | 剑圣、炮车 | 剑圣轮廓偏大但长剑占比很高；炮车 R15 对应的车体占屏较大。应检查本体，不能按总包围盒直接缩放。 |
| 外形差异单列 | 天使双形态、剑魔大灭、龙王、太阳圆盘、蓝红塔 | 翼展、尾巴、悬浮构件或塔身高度会显著改变整体轮廓；并不自动意味着碰撞设置错误。 |

## 测量口径

- 复用正式工作台 `WorkbenchModelPreview` 的模型加载与材质灯光；正式包装场景原尺寸加载。固定正交镜头和45°俯角，待机动作采样0.3秒，关闭逐模型自动适配后的取景差异。系统塔使用正式 `TowerModel3D` 的完好状态过滤。
- 表内尺寸为实际渲染透明轮廓的宽×高，换算到标准战场40像素/世界单位的投影尺度，约数；包括可见武器、翅膀、衣服等。**不是身体直径，不是精确蒙皮体积，不能拿高度除碰撞直径当作合格线。**
- 碰撞是2D权威战场上的圆，图中绿色圈按真实 radius 画为屏幕圆；不使用 visual_radius。3D地面在俯视投影中有压缩，不能把世界空间圆直接当成权威碰撞圆。
- 单位对照图同倍率；建筑R40使用单位图的一半倍率，系统塔使用0.35倍倍率以容纳高度。因此跨这些组看数值，不直接比较缩略图大小。空军未补实战统一离地平移，只比较尺寸；平移不改变尺寸。
- 额外完成部分模型的90°侧向复核；未覆盖全部动作、死亡、部署、转向和实战遮挡，不宣称已完成完整动态验收。
