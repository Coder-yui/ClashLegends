# 真实峡谷封面摄影台

- **需求 / 来源**：搭建可拍摄横版与竖版封面、可放置多单位并定格动作和特效的封面拍摄台；用户对话明确要求潘森冲击波定格，封面成片保存到桌面。
- **完成结果**：新增 `tools/viewers/cover_studio.gd` 与 `python3 tools/dev.py cover` 入口。摄影台加载正式晴昼峡谷地图、四座防御塔和双方水晶；支持 9:16（1080×1920）与 16:9（1920×1080）、多单位添加/删除、符合游戏内部署姿态的地面默认放置、地图任意位置放置、单位 X/Y/Z 三维位置和朝向调节、单位动作播放/暂停/时间轴定格、潘森天降/滑行冲击波及落地收尾冲击波播放/暂停/时间轴定格、透视相机 X/Y/Z 三维机位、环绕/俯仰/滚转/自由旋转 X/Y/Z、距离/目标高度/FOV，以及桌面 PNG 输出。
- **验证**：基线 `66fce26a1986c62f0b7ebb353a00ae25c96e03ea`；工作区含本任务未提交修改。Godot `4.7.1.stable.official.a13da4feb`。`Godot --headless --path . --script tools/viewers/cover_studio.gd -- --smoke` 通过；`mechanics_check.gd -- --suite=workbench_suite` 通过（64 项断言）；实际渲染生成 1080×1920 透视 PNG，并目视确认地图、塔、水晶、潘森模型可见且相机远近已产生真实构图变化；实际打开窗口确认已切换为 1280×900 横向工具窗口，预览与右侧控制面板完整显示，单位三维位置、相机三维位置和自由旋转控制已显示；`git diff --check` 通过。
- **查看方式**：运行 `python3 tools/dev.py cover`，在右侧选择比例、单位、动画和“特效定格（潘森冲击波）”，调整相机后点击“拍摄当前封面 PNG”。默认文件名为 `ClashLegends_cover_9x16.png` 或 `ClashLegends_cover_16x9.png`，写入桌面。
- **遗留 / 未验证**：`audit_project.py` 仍报告已有的 Video7 宣传素材路径缺失（2 项），与本次摄影台无关；封面摄影台是表现预览工具，不替代正式对局规则或网络验收。
