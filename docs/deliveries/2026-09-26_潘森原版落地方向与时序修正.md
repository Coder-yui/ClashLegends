# 潘森原版落地方向与时序修正

- **需求 / 来源**：用户对话；先整理落地素材、修正方向并理清播放时机，再修改实现。
- **素材整理**：已逐项列出102个原版发射器的图元、网格、贴图、出生偏移、旋转、速度、世界加速度、绑定及寿命；保留66项原版资源，不新增替代特效。见[素材、方向与时序清单](../units/effects/pantheon_arrival_resources.md)，CSV及加工源在素材库03-制作中/潘森/落地方向与时序。
- **根因 / 修正**：Ending_Shockwave的原始速度沿+X，之前误套用滑行的+Y前进矩阵，导致整组横移；现按+X前进、+Y向上播放。原始Damage_Mis含childEmitOnDeath，因此收尾波从0.77秒提前叠加改为1.3秒到点后播放。世界重力从局部变换中分离；地面四边形强制贴地；静态撞地半弧按网格+X前沿对齐。原版碎石少量随机左右散落保留。
- **顺序**：0–0.2秒长矛斜落；0.2秒插矛冲击及空中彗星；0.65秒后方三格撞地并开始滑行火光/伤害波；1.3秒到点生成潘森、播放拿矛收势及向前消散的原版收尾波。尾波通过现有只读部署表现接口播放，锚点和方向固定，不随单位转身/推挤移动；死亡、取消及池复用清理。权威生成、伤害、三格距离和中体型缩放未改。
- **音频**：六条原版TXTP解码素材保持音高和采样速度，仅把R_shockwave移动到1.3秒与收尾波一致；总长3.45秒，统一增益-4.797360dB，末0.12秒淡出，无额外拿矛撞击重播。
- **验证**：Godot 4.7.1 Compatibility / Apple M5；基线 `2ecbf5125843ac7b7e0fb42162f7ace11677146f`，工作区含其他未提交改动，已备份并只同步本任务15项文件。专项309断言通过（其后补充双方彗星尾轴断言）；正式完整回归7336项断言全部通过（含新增尾轴检查）。66项原版依赖及音频SHA-256校验通过；项目审计43卡0错误；git diff --check通过。实际渲染逐组检查双方六系统三个时间点，并检查完整流程的飞行、滑行、到点余波；战斗录音实际播放，用户观感/听感未确认。
- **查看方式**：F5进入卡牌开发工作台选择潘森，实战下牌检查完整流程。已有复核脚本支持 `--arrival-materials`逐组显示和`--clean-arrival`完整流程。[截图、录音及修改前备份](../../ClashLegends-开发素材库/04-中间产物/潘森落地方向与时序/20260926/)。
- **遗留 / 未验证**：热浪仍为原版法线纹理高光近似，未实现LoL完整屏幕折射、软深度和导航遮罩。收尾余波仅表现，不另加伤害；未进行移动端性能认证。素材朝向已按当前项目镜头校准，不宣称逐像素复刻LoL渲染器。
