# 交付合同：潘森简化预部署与落地

- **需求 / 来源**：用户对话。按项目规格简化潘森R落地，前段只有特效，到达部署点才生成真正单位。
- **完成结果**：沿用卡牌大师的预部署队列。0.6秒星火、橙红残影和拖痕，从己方后侧斜降、短滑到格心；此前没有单位、碰撞、受击或沿途伤害。到期生成潘森，结算一次半径90、伤害100的落地攻击，再播放1秒Spell4_Hit→Spell4_Hit_ToIdle。方向适配双方；清场与生成回收残影。预部署使用原版R_buffactivate，实体落地使用R_impact，替换误用的先行长矛R_land声音。
- **接入边界**：新增通用视觉域visual_pre_deploy_scene及场景接口，补齐读取方、schema、资源加载、类型/时长校验。特效只读队列；复用原协议，不由动画驱动单位生成和伤害。残影复用正式模型首帧和已有原版纹理，采用一模型、四平面的简化组合。
