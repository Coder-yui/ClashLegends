# 交付合同：峡谷先锋原版节点映射与蠕虫爆出

- **需求 / 来源**：用户对话。普攻2秒、按LoL比例映射前后摇；旋转拳3秒/210伤害，命中和第11/31帧声音按原片缩放；复核冲撞消耗/空撞/拦截/沿途声音，蠕虫从撞击处爆出。
- **时长结果**：原角色BIN的AttackSlotData总时间2、前摇0.5，比例25%，新普攻**2.00秒，前摇0.50秒，后摇1.50秒**。原GLB全片2.666667秒映射2秒，声音不变调，出手/真实命中分别对应。旋转拳原片107帧/30fps映射**3.00秒**；第11/31帧声音分别映射**0.31/0.87秒**；以原动画表第56帧打击特效作为接触节点，映射**1.57秒命中，210伤害**。
- **音频结果**：新增通用audio事件action_time字段及形状/语义校验，声音根据只读动作进度启动。起手vox与release恢复为两个原声，release在0.87秒启动，不在命中点重复；取消/死亡不留下待播声音，控制暂停，同序号回退不重播，晚到动作不补过去节点。真正命中仍派发hit。沿途碰撞地面Unit使用原银行charge_hit_minion四变体；建筑使用dash_hit，普攻/技能各用原对应事件，均只在有效命中播放。
