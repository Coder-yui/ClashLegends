# 交付合同：潘森三格滑行冲击波

- **需求 / 来源**：用户对话。长矛斜落在下牌点，彗星落在己方侧后方3格，带冲击波滑到长矛；波及时伤害，到点才生成单位拿矛。
- **完成结果**：0–0.2秒长矛从己方侧按世界45°斜线落至下牌点；0.2–0.65秒彗星斜落到后方3格（120像素）；0.65–1.3秒带原版火光、掀土和冲击波滑向长矛。权威20Hz按相同轨迹连续扫掠，保留半径90、100点伤害，每名地面敌人含建筑一次，友军与空军不受伤。长矛插地无伤害，单位生成不重复结算。到达长矛才生成通用Unit，并开始Spell4_Hit（0.3秒）→Spell4_Hit_ToIdle（0.7秒）的1秒部署；此时可受伤、不能自主行动。前段没有单位碰撞或受击目标。
- **声音**：六个原版事件合成一条登场音轨；冲击从实体生成前移到0.65秒后方着地，余震0.77秒。拿矛时不再重复爆炸音。总长3.45秒含自然尾音，统一-5.064025dB，无变调变速，最高约-1dBFS、无截顶；36个运行WAV来源哈希一致。旧独立落地音轨及爆炸包装已移至本轮备份。
