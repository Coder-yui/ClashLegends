# 交付合同：通用单位回血特效

- **需求 / 来源**：用户对话；复用恕瑞玛卫队的回复光，让所有实际回血在受疗单位身上显示低调反馈；治疗术大面积施法提示保持原样。
- **完成结果**：沿用现有回复光绘制与可靠 RPC，统一普通治疗（治疗术、技能、凯隐入地形等）、命中回血、吸血、回复盾到期回血。采用 0.7 秒淡绿细环和三个小型上浮十字，连续回血合并为当前脉冲，满血、死亡或无实际增量不触发。去除原先双重绘制。表现不影响权威结算；形态变化带来的生命上限调整不算治疗。保留旧 restoration 命名以兼容现有调用与网络入口。
- **验证**：基线 `2ecbf51`，工作区开始时已有大量未提交改动，均保留。Godot `4.7.1.stable.official.a13da4feb`；核心机制回归通过 7067 项断言；实际工作台脚本检查满血、普通治疗、连续治疗、普攻回血、吸血、回复盾与死亡边界，并完成模型上特效的渲染目视检查。治疗术绘制文件最终无差异。
