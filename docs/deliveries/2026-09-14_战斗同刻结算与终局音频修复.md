# 交付合同：战斗同刻结算与终局音频修复

- **需求 / 来源**：用户对话；定向修复近战遍历偏置、剑圣三段连击及攻速时序、双水晶平局和爆炸后的本地结果播报。
- **完成结果**：五项代码修复及对应回归已完成。保留 20Hz、阶段先后、卡牌数值、寻路、素材和工作台预览定位；规则协议由 19 提升为 20，快照载荷形状不变。
- **基线 / 工作区**：`f2d1d9b1e022ce46698b63e9a63f0e17bd380697`；Godot `4.7.1.stable.official.a13da4feb`，Apple M5 / Compatibility 实际渲染。起始交付索引及部署音频报告未提交修改已保留；工作期间出现的提莫/龙王部署音频、关联卡牌定义及 `tests/demo_xin_sweep.tscn` 等并行改动也未覆盖，不计本任务修改。本次未创建提交。

| 修复单元 | 根因、修改位置与规则 |
| --- | --- |
| 同刻命中 | 旧 `Unit.sim_tick` → 即时命中 → `take_damage/_die` 会取消后遍历来源。`Main._sim_step` 为技能影响、区域、技能命令、法术区域、单位/塔和弹体分别开启/提交批次；`CombatResolver`、`BattleNumbers`、`BattleContext` 和 Unit/Tower 伤害入口收集固定命中记录，再逐刀扣盾扣血，最后提交控制、存活收益和死亡。每次死亡只生成一次召唤/替身，新生实体不进入已收集批次。真实早一 Tick 仍获先手。 |
| 剑圣循环 | 累计主攻击计数越过三项数组后直接返回。`Unit._queue_extra_attack_hits` 改为循环段索引，同时选择倍率及延迟；取消重播的动画/音效序号也重新对齐权威段。第 3、6、9 次正常主攻击均实际产生追加刀，追加刀不推进主攻击周期。 |
| 追加刀时序 | 原延迟只用主动加速且下限为 1，未纳入减攻速或剩余进度缩放。改用 `_effective_attack_speed_multiplier`，在 `_rescale_attack_phase` 按旧/新速率比例调整剩余时间；目标失效即清理，冻结期间也会清理失效目标。冻结/眩晕暂停，移动、击退和出手后施法不撤销连击；来源更早死亡取消未来刀。 |
| 双水晶 | `MatchRules.advance` 原先先判红方水晶。现在先检查双方同时归零，以 `winner_team=-1, reason=nexus` 返回平局；仍在 Tick 全部战斗阶段完成后调用，复用可靠终态及本地阵营显示；正式终局保持幂等。 |
| 终局音频 | `Main._end_game` 原先停止短音池中的爆炸并立即播报。水晶死亡改用 `GameAudioManager.play_nexus_destruction` 的本局独占实例；可靠最终塔状态补足触发，已有实例不重播。`finish_match_audio` 清理常规战斗声、保留本次爆炸，全部实例自然 `finished` 后立即播本地结果。无固定延时；界面、禁操作、终态同步及停止战斗仍立即发生。菜单/重开/释放取消旧代次回调；缺配置/加载失败/无法启动记录诊断并兜底。平局没有胜败语音，非水晶终局不制造爆炸，断线不新增内容。 |

必要规则变化：同批实际掉血与盾吸收按各刀有效伤害比例归属，分配保留小数，吸血仍按实际生命损失及既有治疗取整计算。例如 90 血、30 盾同时受 120/60 伤害，掉血归属为 60/30。全批血量确定后才给存活来源收益；共同致死的有效参与来源各至多获得一次击杀资源，零伤害不分走击杀。保留逐刀致盲、逐次命中/回血和音效去重，不把多刀合成一次普攻。普通受伤无通用硬直、施法暂停恢复、锁普攻施法显式重置、强化普攻不重置时刻等既有规则均保留。
