# 凯隐三形态部署语音

- **需求 / 来源**：用户指定九句部署语音，普通与蓝凯如台词/归属错误不得直接接入；核对出两句归属相反后，用户明确回复“交换到另一形态”。
- **完成结果**：三形态各3条独立中文部署池，Voice总线，每次部署随机一条，重复绑定不重播。千年兵刃→蓝凯，恐惧吧→普通凯隐；其余按原清单。复用现有部署消费者，没有新增语音驱动的游戏逻辑。

- **核对方式**：使用[中文台词目录](https://api.buguoguo.cn/lol-voice/v1/champions/141/000?GameVersion=latest)定位事件，随后解码本地`Kayn.zh_CN.wad.client`，追踪Wwise形态开关与随机分支，并进行本地MLX Whisper转写。客户端选人语音单独从本地中文LCU WAD提取。网站键未当作本地媒体ID使用，没有下载网站音频。
- **加工**：原事件浮点解码，转44.1kHz PCM16，统一-6dB储存余量，运行+3dB，净增益-3dB；不变速、不截断整句。九个文件没有满幅采样；哈希与来源在[事件清单](../../assets/audio/units/kayn/event_manifest.json)。本地候选、TXTP、ASR和选择表在素材库`03-制作中/凯隐/voice-selection/`。
- **验证**：基线`2ecbf51`，保留既有未提交改动；Godot `4.7.1.stable.official.a13da4feb`。专项216项断言、完整回归7,010项断言全部通过；审计43卡/3,512文件零错误，diff检查通过。三形态双方6次实际部署均发出一次正确形态deploy:voice；38.21秒录音无满幅采样。新增回归覆盖每形态3句、Voice总线和重复绑定不重播；全部54个凯隐音频文件哈希核对通过。
- **查看方式**：F5→卡牌开发工作台，切换三形态并重复部署；每次只从当前形态的三句中随机选择。
- **遗留 / 限制**：没有把ASR当作人工听写，短句会出现明显同音识错；本次依据台词目录、事件定位、形态分支及本地转写交叉核对。实际录音与事件验证不等于用户最终听感确认；本轮未运行双进程联机。
