# 交付合同：剑魔背剑移动与部署语音

> 本文记录当次迭代，后续修订以[当前剑魔手册](../units/aatrox.md)及[动画说明](../units/animations/aatrox.md)为准。

- **需求 / 来源**：用户对话；首次攻击前背剑移动、确认大灭击杀刷新规则、从本地源库加入三句指定部署语音并提供可复用工具。
- **完成结果**：Respawn 后移动使用 `Aatrox_sheath_run01_anm`（原表 Sheathe_Run_Slow），首次攻击动作开始后采用 Run_Base 或 Passive_Run；移除部署后的独立拔剑路线，保留已有动作混合。击杀只刷新至5秒、1秒30%加速和下一击被动；回归确认最大生命不变、当前生命仅有实际伤害吸血。两形态部署随机播放“让我带来终结。”“我回来了。”“你无法摧毁我。”之一，完整原长约5.945/2.452/3.015秒，统一-6dB余量。
- **来源与工具**：台词/事件用[网站公开目录](https://voice.buguoguo.cn/#/voice)核对，音频全部提取自本机中文源包。第一句为客户端 champion-ban-vo/266.ogg；后两句为 GuardianAngelR 第13/10变体，媒体345039076/123782949。来源哈希见 [选择记录](../../ClashLegends-开发素材库/03-制作中/剑魔/voice-selection/selected.json)。新增 [find_lol_voice.py](../../tools/audio/find_lol_voice.py)，支持台词目录、查找事件、本地解码、本地转写；[使用说明](../../tools/audio/README.md)。网站编号不冒充本地媒体编号；未采用的14条候选已归档中间产物。
- **验证**：Godot 4.7.1；基线 `d938a9aed9301bcbb6d268cb11d05e18338cc9a6`，保留全部既有未提交修改。完整机制3698项、联网、资源审计、导入及差异检查通过；专项86项，工具7项。工具实际解析16条事件变体，Small本地转写核对三句全文。实机渲染顺序为 Respawn → Sheathe_Run_Slow → Attack1/2/3 → Run_Base，已目视检查截图。实际战斗录音记录 deploy:voice，三条最终WAV均逐条播放，51条音频峰值均无PCM削波。详细结果见 [验证记录](../../ClashLegends-开发素材库/04-中间产物/预览与验证/剑魔/deploy-revision/verification/result.json) 和 [渲染/音频日志目录](../../ClashLegends-开发素材库/04-中间产物/预览与验证/剑魔/deploy-revision/)。
- **查看方式**：F5进入卡牌开发工作台，选择剑魔进行部署与攻击；[音频试听台](http://127.0.0.1:18769/)已更新51条，搜索“部署语音”可分别试听三句。
