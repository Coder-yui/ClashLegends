# 交付合同：3D 卡面摄影棚工具

- **需求 / 来源**：用户对话；希望能自行调整相机拍摄 3D 卡面，而不是只靠文字描述让 Agent 固定构图。
- **完成结果**：新增 `python3 tools/dev.py studio` 独立 Godot 工具。支持项目卡牌/形态/蓝红模型与外部 `.tscn/.glb`，动画选择、暂停、时间定位；预览区拖拽环绕相机、滚轮推拉，默认自动朝向主体，也可直接调整相机朝向的水平偏移、垂直偏移和滚转角；可调相机俯仰、目标高度、模型朝向、透视/正交投影、FOV/正交画幅；可调三点灯光、环境光、背景色、透明背景。摄影灯关闭阴影，地面默认可见但可手动关闭；支持把多个卡牌模型加入同一组合，逐成员调位置/纵深/朝向/缩放/动画，并提供可调整间距的横排、三角、环绕起始编队。界面改为卡面比例预览和可滚动完整参数栏，方案会保存摄影参数和成员布局，PNG 固定按项目卡面规格 `308×560` 输出到 `ClashLegends-开发素材库/04-中间产物/3D摄影棚/shots/`，不覆盖已有文件。
- **验证**：基线提交 `a19e310`；工作区原有超小兵相关未提交修改已保留。Godot `4.7.1.stable.official.a13da4feb`。全量机制回归 `4368` 项断言、0 失败；工作台套件 `16` 项断言、0 失败；项目审计 `34 cards / 2669 files / 0 errors`；工具单测 `7` 项通过；`git diff --check` 通过。实际窗口已目视确认横向工具布局、参数滚动栏和无黑边内容画布；实际渲染验证已生成并目视检查带地面、无影、无侧边黑条 PNG：单模型 `card-spec-check-20260918-v2.png`、多模型横排 `card-group-spec-check-20260918.png`，均位于本地开发素材库的 `04-中间产物/3D摄影棚/shots/`，尺寸为 `308×560`。
- **查看方式**：运行 `python3 tools/dev.py studio --card garen`；包含多个部署成员的重装部队可运行 `python3 tools/dev.py studio --card heavy_minion_squad`，然后使用横排、三角、环绕和编队间距重新布局；也可运行 `python3 tools/dev.py studio --card gnar --form 1 --team 1` 或 `python3 tools/dev.py studio --scene /绝对路径/model.glb`。工具说明见 [工具展台说明](../../tools/viewers/README.md)。
- **遗留 / 未验证**：不同模型/动作的最终卡面审美仍需人工在摄影棚内选机位；工具不自动写入正式 `assets/cards/`，正式接入仍按美术流程人工确认。
