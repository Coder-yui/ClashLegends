# 交付合同：剑魔拔剑修正与大灭计时加速

> 本文记录当次迭代，后续修订以[当前剑魔手册](../units/aatrox.md)及[动画说明](../units/animations/aatrox.md)为准。

- **需求 / 来源**：用户对话；死亡取前0.8秒，核对Unsheath上下层，大灭动画后计5秒，开启/击杀刷新获得1秒30%加速，并改善混合。
- **完成结果**：两形态死亡源裁剪及播放时长均为0.8秒。解码原表确认Unsheath_Lower/Upper同指Aatrox_unsheath.anm，替换此前错误的Unsheath_run01；配置更柔和的局部与通用动作混合。5秒寿命从开启动画权威窗口结束后起算；开启瞬间获得1秒30%移速，击杀同时刷新寿命、被动及加速。继续允许移动，仅锁攻击；死亡声音沿用既有时长。
- **验证**：Godot 4.7.1，基线d938a9a，保留既有未提交修改。80项专项断言、完整3692项机制断言、审计、导入、diff及联网验证全部通过。隔离联调副本实际渲染检查拔剑衔接、升降、计时/加速和死亡裁剪；记录显示开启动画剩余0.4秒时寿命仍为5.0、移速倍率1.3，动画结束后寿命开始减少且倍率还原1.0。协议28。
- **查看方式**：卡牌开发工作台选择剑魔，实战部署并开启大灭；模型页选择Aatrox_unsheath_anm查看正确源片段。
- **遗留 / 未验证**：用户主观连贯度待体验。当前使用上下层共同引用的全身导出片段，未单独重建LoL上下身独立播放速率。
