# 交付合同：图奇隐身与穿透射程修订

- **需求 / 来源**：用户澄清，隐身只让敌方场上单位无法看到/索敌，双方玩家都能看到虚化模型；大招弹体直线飞行且固定行程长于攻击射程。
- **完成结果**：分离玩家视图与单位感知。双方模型、血条、队伍环和隐身文字均保留；敌方单位与塔仍无法索敌。隐身使用保留原纹理的冷绿半透明材质（alpha 0.42），关闭实体阴影，破隐/死亡/模型池回收还原；凝滞金身优先，冻结仍保留虚化及冻结提示。每实例持有独立材质，不修改共享模型资源。
- **射程规则**：普通攻击射程170，大招攻击射程260；大招每支弩箭从权威发射点固定飞行420，方向在出手瞬间固定，不追踪、不转弯。沿途每名敌人各命中一次，可击中攻击射程外的后排，高速横移可躲避；出手后来源死亡、技能到期、目标位移/消失不缩短已发射行程。2金币、一次、5秒、攻速提升50%不变。
- **实现边界**：新增主动字段piercing_distance，包含读取、数值类型与正数/能力校验；行程由权威弹体推进，材质不参与战斗。协议77提升规则版本，快照字段布局不变，客户端只从隐身布尔状态显示虚化。双方玩家拥有公开视图，因此无需对图奇裁剪位置数据。
- **验证**：Godot 4.7.1；基线b079c0c，工作区已有上一轮图奇、凝滞与卑尔维斯等未提交改动，均保留。核心回归8215项断言零失败；图奇33项与网络生命周期99项专项通过；双进程host/join冒烟通过，图奇专属感知/可见性往返由单进程快照测试覆盖。新增覆盖固定行程、远处后排、射程外终止、横移落空、不转向、材质独立/还原/金身优先。最终仅将虚化alpha由0.36调至0.42并重新渲染，未改机制。
- **实际画面**：[双阵营隐身与实体对照](../../ClashLegends-开发素材库/04-中间产物/预览与验证/图奇隐身修订-20260930/ghost_blue_red.png)、[破隐还原](../../ClashLegends-开发素材库/04-中间产物/预览与验证/图奇隐身修订-20260930/revealed.png)、[冻结中的隐身](../../ClashLegends-开发素材库/04-中间产物/预览与验证/图奇隐身修订-20260930/frozen_ghost.png)。实际Compatibility渲染已目视检查；用户尚未确认最终观感。
- **查看方式**：F5进入卡牌开发工作台，选择图奇，蓝红任一方部署即可看到虚化；攻击或主动起手后恢复实体。玩法见[图奇](../units/twitch.md)。
- **遗留 / 未验证**：项目审计仅剩已有璐璐旧交付的需求文档断链，本轮未修改；联调副本首次导入提示既有盖伦动画重名，图奇渲染及主工程导入无该错误。本轮未改音频文件，上一轮主观混音/原版R专用攻击音未单独切换的限制保持。未进行双端图奇专属人工对战。
