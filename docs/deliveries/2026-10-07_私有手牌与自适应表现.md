# 交付合同：私有手牌与自适应表现

- **需求 / 来源**：用户对话；执行服务端牌序核对中的全部建议，玩家仅需知道下一张牌。
- **完成结果**：服务器独占完整八张牌轮转，客户端仅保留自己的四张手牌、下一张、镜像所需历史与版本/请求序号；移除客户端临时洗牌。初始洗牌使用独立随机源，服务器日志记录会话、种子、卡组和初始牌序，便于复现牌序，不消耗战斗随机序列。旧状态和不对应的回执不能回拨手牌或清除新请求。协议升为98，双方须使用相同版本。
- **操作与表现**：点击立即显示本方待确认落点、卡牌/技能等待状态，服务器仍决定扣费、补牌、生成与完整战斗。根据到包延迟/抖动自适应调整50–200毫秒的表现缓冲，时间轴不倒退；保留20Hz权威模拟和出牌/技能0.5秒排程。单机继续复用权威战斗核心及CardCycle。
- **验证**：基线6998fd64，工作区包含此前未提交修改，未覆盖或提交。Godot 4.7.1；`python3 tools/dev.py verify --network-boundaries`通过，63个套件、10328项断言、正常三进程联机和10类边界场景通过；审计、导入、事实核对、验证器测试及diff检查通过。专项覆盖种子复现、随机隔离、最少下发字段、旧回执、新请求关联、客户端无权威牌序、缓冲上下限与单调时间轴。完整结果位于[验证记录](../../ClashLegends-开发素材库/04-中间产物/构建与验证/verification/20261007-163823-730917/result.json)。
