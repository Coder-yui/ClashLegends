# 交付合同：攻城部队与炮车部队

- **需求 / 来源**：用户对话；新增6金币“攻城部队”和7金币“炮车部队”，分别部署超级兵横排与炮车兵三角形编队，并复用成员男爵之力。
- **完成结果**：新增`super_minion_squad`（攻城部队）和`siege_minion_squad`（炮车部队）两张卡。攻城部队为2只超级兵横向并排、中心间隔60像素（1.5格），主动技能消耗2金币、可用1次；炮车部队为3只炮车兵三角形顶点、三边均为60像素（1.5格），主动技能消耗3金币、可用1次。两张卡均共享本次部署的主动资格，并只给同次部署中仍存活的成员施加成员自身男爵之力。
