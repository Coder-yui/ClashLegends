## 完成结果

| 职责 | 最终所有者与边界 |
| --- | --- |
| 排程 | `CommandSchedule` 私有管理四类队列及部署编号，提供类型化入队、重复检查、到期取出、取消和结算；保留 `CommandPayment` 原付款者、原金额与一次性结算。分段效果继续关联 Unit 的施法代次、取消代次和命中状态。 |
| 主动技能 | `ActiveSkillRoster` 管理资格、槽位替换、编队转交、次数和冷却；Main 编排请求付款、UI 和 RPC。 |
| 部署 | `DeploymentRules` 管理吸附、奇偶占地、区域、阻挡、塔墟和最近合法落点，仅注入战场查询；生成时复核、无位置等待等规则保持。 |
| 手牌 | `CardCycle` 管理牌组、手牌和队列；UI 消费结果，客户端用明确副本入口更新。 |
| 工作台 | `ui/workbench/session.gd` 管理选择、预设、清场、暂停和模式；通过正式战场入口操作，没有验收持久化或报告导出。 |
| 强制位移 | `ForcedMovementState` 管理当前轨迹、替换、剩余时间及结束原因；实际移动、碰撞和准入仍在既有系统。 |

保留 `StatusInstances`、`ControlState`、`AttackTimeline`、`ShieldState`、`StructureRushState`、表现序列、模型资源与音轨所有权。形态和技能资源在 Unit 中已有明确生命周期，本轮没有复制一套状态管理。去掉控制刷新无效参数及带测试语义的计时 setter；正式施加、网络副本和测试夹具入口分开。

`BattleContext` 改用明确时钟/战斗服务查询；SpellSystem、ActiveSkillEffectSystem 产生表现通知，由 Main 决定本地与 RPC 派发，RPC 节点路径未移动。攻击选择、效果命中、控制/位移、治疗/护盾仍按各自领域准入，没有新增统一 `targetable` 或新状态机制。固定 20Hz、阶段顺序、费用、时序和单位平衡保持。

## 退役清理与协议

删除丝缕缠流的数据白名单、单位状态/启停、索敌与伤害过滤、专用绘制、表现/音频事件能力和网络镜像字段，不保留空壳或通用替代。格温普攻被动、充能、分段技能、命中资格和结束治疗保留。未发现可独立删除且无共享依赖的正式专属资源，因此没有误删模型、纹理或动画库。

协议从本地基线 **43 升为 44**，单位载荷 **41 项改为 40 项**，删除原字段并连续调整索引，没有保留占位。当前版本/长度只在[协议契约](../reference/NETWORK_PROTOCOL.md)集中维护并由审计核对；内容指纹关联统一版本。实际双进程验证了新版本通信和旧版本握手拒绝。
