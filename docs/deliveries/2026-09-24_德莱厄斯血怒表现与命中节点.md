# 交付合同：德莱厄斯血怒表现与命中节点

- **需求 / 来源**：用户对话；核对流血/血怒实现，改为稍大体型和自身血怒特效，按LoL原始节点映射攻速缩放后的命中时刻并沉淀流程。后续明确普通攻击不同动作使用统一近似前摇。
- **完成结果**：稍大体型半径21px，模型缩放0.013125；移除头顶血怒文字，改为附着模型的红色脉动轮廓和上升火星，仅订阅血怒。原生Attack1/Attack2映射分别0.330/0.229787秒，普通攻击统一取0.30秒；Spell4按11/40映射0.33秒，攻速同比缩放。中途武装保留原定命中时刻并定位强化动画进度；修正攻击计时浮点尾差导致额外等待Tick的问题。
- **机制核对**：每次真实命中增加1层流血，最多4层，共用最后命中起3秒到期；满层获得4秒血怒，后续命中刷新血怒并直接施加4层、攻击伤害翻倍。两种时钟独立，流血跳伤不刷新血怒；第4击先伤害后触发。断头台先按原有层数结算再加层，直接击杀才获得血怒及免费追斩；免费资格不消耗付费次数、不重启16秒后台冷却。
- **流程文档**：[新卡清单](../NEW_CARD_CHECKLIST.md)、[近战](../MELEE_3D_INTEGRATION.md)、[远程](../RANGED_3D_INTEGRATION.md)均指向[原生命中节点映射](../reference/ANIMATION_CONFIGURATION.md#原生命中节点映射)。记录原数据路径、castFrame/帧率、GLB片长、缩放公式、普通攻击公共近似值与误差、权威Tick量化及中途强化规则。逐卡依据见[德莱厄斯动画](../units/animations/darius.md)。
