# 红凯入地形镰刀混合方向

- **需求 / 来源**：用户观察 Run_Slayer→Spell3_Run 镰刀混合穿身，要求调整方向，并询问 modelviewer.lol 的混合方式。
- **完成结果**：该动作对沿身体外侧固定方向旋转；参考姿态只计算一次，按旋转轴选择四元数分支，解决接近180度时不同跑步相位会翻面的问题。仍使用原0.1秒窗口、原动画终点和原位移，不改变其他动作、三形态部署、Q或战斗判定。
- **网站核对**：公开发布脚本的普通切换采用 Three.js 的0.3秒动作交叉淡入淡出；局部骨骼旋转使用四元数球面插值，没有在该路径中发现身体避障。细节及脚本来源见[动画手册](../units/animations/kayn.md)。
- **验证**：Godot 4.7.1，基线 `2ecbf51`，已有未提交修改保留。Compatibility实际渲染对比修改前后，检查双方红凯及多个跑步相位的0/17/33/50/67/100/150毫秒帧，镰刀改从躯干外侧抬起并落到原片姿势。回归覆盖8个跑步相位的方向、冻结、结束姿态，以及现有首帧与池复用检查。完整机制回归7043项断言全部通过；项目审计43卡、3514文件、0错误。
- **查看方式**：工作台实战部署红凯，让它由地面跑入河道；也可查看本地开发素材库 `04-中间产物/凯隐/20260926红凯穿地形混合/` 的 `fixed03.jpg`、`fixed07.jpg`。
- **遗留 / 未验证**：未声称所有动画组合具备自动防穿模；本次修正针对上述动作对，用户主观观感尚待确认。
