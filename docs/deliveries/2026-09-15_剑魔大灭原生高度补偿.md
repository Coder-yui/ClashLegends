# 交付合同：剑魔大灭原生高度补偿

> 本文记录当次迭代，后续修订以[当前剑魔手册](../units/aatrox.md)及[动画说明](../units/animations/aatrox.md)为准。

- **需求 / 来源**：用户对话。背剑跑只属于部署后的初始阶段；修正大灭原生离地高度与地面版被动攻击；Spell4仅前1秒；解释技能时机。
- **完成结果**：背剑跑在攻击开始或首次变形后永久退出，未攻击便开启/结束大灭也不会恢复背剑跑；使用已有主机和客户端形态序号，支持晚加入快照。Spell4源片段裁为0–1秒。普通Idle1和ULT_Idle各120个等间隔采样，双脚Foot_end低点均值分别为-0.019225、0.979366，差0.998591。空军根高度扣除该差值；大灭地面版Passive_Attack的模型轨道补回同量，其他片段归零，随已有动画混合过渡，不影响权威位置。
- **技能时序**：开启瞬间最大生命1050→1350、当前生命+300，立即变为空军、获得1秒30%加速；起手1秒只锁攻击。起手结束允许对地对空攻击，从此开始5秒倒计时。击杀重置5秒、1秒加速、下一击被动，不再加最大或当前生命、不重播起手。到期瞬间成为地面单位、上限恢复1050（当前生命仅超限截断），收翼0.5秒只锁攻击；之后仅对地攻击。两个动画均可移动。硬控会暂停转换动作；持续阶段计时照常消耗。
- **验证**：Godot4.7.1，基线d938a9aed9301bcbb6d268cb11d05e18338cc9a6，保留全部已有未提交修改。完整机制、联网、资源审计、导入和差异检查通过，见 [完整验证](../../ClashLegends-开发素材库/04-中间产物/预览与验证/剑魔/height-revision/verification-native-lift/result.json)。已在联调副本实际渲染、目视检查浮空移动与被动攻击；日志显示空军根目标1.733778、被动模型补偿0.998591；无攻击完整换形后为Run_Base，见 [渲染日志](../../ClashLegends-开发素材库/04-中间产物/预览与验证/剑魔/height-revision/render.log)。
- **查看方式**：F5进入卡牌开发工作台，部署剑魔，先开技能不攻击并等待结束；或生成敌人查看大灭被动。现有声音不变。
- **遗留 / 未验证**：原生动画自身的上下浮动保留，校正的是待机平均离地量，不锁死脚部高度。用户主观观感待体验。
