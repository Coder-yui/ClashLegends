# 交付：剑魔被动前摇与直接转跑

- **需求 / 来源**：用户对话；被动前摇改0.4秒，第三刀不经转跑动作直接接被动跑，并稍加混合。
- **完成结果**：普通和大灭的被动前摇0.4秒，其他攻击0.25秒，连续命中间隔保持1.1秒并适配攻速。第三刀直接以0.15秒混合到Passive_Run；第二刀仍保留Attack_INTO_Run。原路线为第三刀→转跑0.03秒、转跑→被动跑0.1秒。动画源片、整段播放速度及大灭被动补高未改。
- **实现边界**：通用可选passive_first_hit字段选择被动刀前摇，附带类型/范围验证；按下一刀前摇安排待攻窗口，击杀刷新同步重算。快照复用攻击序号，无新增载荷；规则变更协议升至32。保留工作区峡谷先锋等已有改动。
- **验证**：Godot 4.7.1，基线5831b87；覆盖双形态连续命中、0.5/1/2倍攻速、击杀刷新、第三刀直连与非法配置。完整4075项断言通过，审计、导入与双进程联网通过。实机确认第三刀后直接播放Passive_Run、混合0.15秒、无转跑序列；各攻击整段播放窗口仍为1.1秒。证据在素材库04-中间产物/剑魔统一命中点/passive-verification及passive-render。
- **查看方式**：F5 → 卡牌开发工作台 → 剑魔；观察普通第三刀后的移动，以及两形态被动扣血时刻。
- **遗留 / 未验证**：用户尚未确认最终混合观感。
