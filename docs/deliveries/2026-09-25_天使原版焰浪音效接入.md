# 交付合同：天使原版焰浪音效接入

- **需求 / 来源**：用户对话；接入检查中发现缺失的原版焰浪音效。
- **完成结果**：接入 LoL 基础皮肤 `KayleEnrageConeMis_OnMissileCast` 的 4 个随机变体及 `KayleEnrageConeMis_hit`。发射事件在延迟焰浪真正创建时触发；每道焰浪首次有效命中播放一次命中声，穿过后续对象不叠加。空波不播放命中，清场取消待创建波；来源死亡后在途波仍使用出手时卡牌/形态/阵营。复用可靠卡牌音频事件与现有去重、预算消费者，近战与光剑原有音效保持现有配置。
- **素材与时序**：来自本地 Kayle 原始 WAD 的基础皮肤 BNK，经现有 WWISER TXTP 分支、vgmstream float32 解码；沿用天使 SFX 统一 -4dB 加工，再转 PCM16，不逐文件归一化。发射 WAV 保留原版 Wwise Action 的 70ms 延迟，只烘焙一次；相对光剑创建为既有 100ms 波延迟加 70ms 声音延迟。未修改战斗时序。精确事件/媒体 ID、路径、处理及 SHA256 已写入 [manifest](../../assets/audio/units/kayle/event_manifest.json)。
- **验证**：Godot 4.7.1，基线 `3905461`，保留此前未提交修改。素材库联调副本全量 54 套件、6,788 项断言通过；同步正式工程后音频/天使专项 412 项通过，导入及测试无脚本错误，`git diff --check` 通过。新增回归覆盖延迟、来源死亡、空波、穿透多目标去重及清场。蓝红双方实机共 14 次攻击，各有 14 次光剑发射/命中及焰浪发射/命中事件，无重复。5 个新增 WAV 非静音且无满幅采样；约 10.84 秒实机录音峰值 15,243/32,768，无满幅采样。
- **查看方式**：工作台选择天使远程形态攻击目标；[实机录音](../../ClashLegends-开发素材库/04-中间产物/预览与验证/kayle-wave-audio-20260925/ranged-combat.wav)、[播放日志](../../ClashLegends-开发素材库/04-中间产物/预览与验证/kayle-wave-audio-20260925/runtime.log)、[回归日志](../../ClashLegends-开发素材库/04-中间产物/预览与验证/kayle-wave-audio-20260925/mechanics.log)。
- **遗留 / 未验证**：原版还有 Upgrade_cast，但本地客户端资料不足以确认它与 16 级的具体绑定；本次采用明确对应 EnrageConeMis 的原版声音，不宣称完全复现 LoL 16 级音频脚本。每波首次命中去重是本项目混音策略。播放事件、素材及录音已验证，主观听感仍未确认。本轮未额外完成双进程联网实测；沿用现有可靠音频 RPC，无协议字段变更。
