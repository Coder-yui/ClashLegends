# 交付合同：天使满层被动怒焰特效

- **需求 / 来源**：用户对话；参考 LoL 原版，给天使满层被动添加附着特效。
- **完成结果**：近战双翼、远程六翼在真实普攻叠满4层时显示金橙色流动怒焰。0.5秒渐入，满层刷新不闪烁，被动到期或死亡后0.5秒渐出；每只天使使用独立材质，模型回池重置。原有叠层、攻速、攻击与焰浪伤害规则未调整。
- **原版依据**：本地 Kayle.wad.client 的 Skin0 `Kayle_Wings_inst` 由 `KayleEnrage` 驱动 Rage_Blend（开关各0.5秒）、Mask_Intensity、Bloom_Intensity、Rage_Gradient_Texture。`Kayle_Base_P_Enrage_Buff` 是没有发射器的空定义。复用原版怒焰渐变及 Fire_Tile 纹理，参考UV缩放(2,2)、滚动(-0.4,0.25)，将材质附着在真实翅膀表面，不额外生成无来源的环绕光环。转换无重绘，来源与哈希见 [素材清单](../../assets/units/kayle/source_manifest.json)。兼容渲染使用有上限的发光颜色混合，避免直接叠加烧白；这是Godot适配，非原着色器逐指令复现。
- **联网**：增加专属满层布尔状态，不从最终攻速反推；协议60、单位载荷48项。客户端只消费快照，其他攻速增益、减速不会伪造或抹除满层。非法类型拒绝，旧快照不重新点亮已到期状态。
- **验证**：Godot 4.7.1；基线 `2ecbf51`，开始时工作区干净。素材库副本试接入、渲染验收后同步正式工程。正式工程全量54套件、6,830项断言通过，导入无脚本错误，`git diff --check` 通过。覆盖两形态3/4层边界、原版半秒渐变、刷新、到期、死亡、实例隔离、回池重置、快照往返与乱序。双方两形态实际渲染已目视检查；双进程真实ENet约15秒检查主机与客户端均 `full=4 expired=4 success=true`，两个进程正常退出。联网fixture用命中回执推进状态，实际伤害命中叠层由机制套件覆盖。
- **查看方式**：卡牌工作台部署近战或远程天使，持续攻击直到第4次命中；停止攻击3秒后观察淡出。[近战满层](../../ClashLegends-开发素材库/04-中间产物/预览与验证/kayle-enrage-20260925/kayle-05_passive_full.png)、[远程满层](../../ClashLegends-开发素材库/04-中间产物/预览与验证/kayle-enrage-20260925/kayle_ranged-05_passive_full.png)、[客户端实机截图](../../ClashLegends-开发素材库/04-中间产物/预览与验证/kayle-enrage-20260925/client-full.png)、[回归日志](../../ClashLegends-开发素材库/04-中间产物/预览与验证/kayle-enrage-20260925/mechanics.log)。
- **遗留 / 未验证**：用户最终观感未确认。原版16级的常驻进阶条件未移植为玩法规则；按本项目要求，两种形态都只在4层被动期间出现怒焰。
