# 奥恩修复与复盘

- **需求 / 来源**：用户对话：修复模型与卡面，检查其他错误；减慢冲锋、距离3.5格，使用 Spell3 蓄力/冲锋/停顿；锤子使用橙色拖尾，到达后才增幅。
- **完成结果**：修复模型缩放及原生隐藏部件；更换原生竖版卡面；冲锋改为0.55秒蓄力、200像素/秒移动140像素、0.5秒停顿，依次使用 Spell3 / Spell3_Dash / Spell3_Hit / Spell3_hit_toIdle。碰撞提前进入停顿，伤害仍只由权威逻辑结算。锤子改为橙红渐隐弧形拖尾、火星和清晰锤头，跟随移动目标，抵达后才永久增加20%普攻伤害并显示标记，沿原规则取整。增加在途目标预留、目标死亡取消与清场清理；奥恩死亡不会撤回已发锤子。同步了技能说明、单位手册和资源来源。

## 错误原因

| 问题 | 直接原因 | 流程结论 |
| --- | --- | --- |
| 战场模型近乎不可见 | 把盖伦源模型使用的0.015缩放套给奥恩；前者原始高度约244.8，后者身体高度约1.778 | 尺寸指南早已要求核对源坐标量级、同战场对比，前次执行遗漏。自动取景展台放大模型，掩盖了错误。现在缩放1.35并同镜头比较盖伦 |
| 不应出现的道具 | 把“所有部件打包在GLB中”误解成全部显示，没有读取原生皮肤默认隐藏列表 | 原生 skin0.bin 明确隐藏 Sword、Bucket、Poro。现在仅在实例网格副本中移除对应表面，完整源GLB保持原样 |
| 卡面错误 | 使用横版 centered splash，并重命名为 loading，未查找已有原生竖版资源 | 美术流程已有优先 loading 的要求，属于选材及验收遗漏。现在使用原包 ornnloadscreen.jpg，来源与哈希已更正 |
| 冲锋太快且没有蓄力 | 原参数540像素/秒、190像素，只使用Dash片段；未建立分段时序 | 本次按用户修订建立蓄力/冲锋/停顿的权威时序，模型动作跟随 |
| 飞行前已经增幅 | 原实现先写倍率，再播放线条表现 | 权威飞行状态缺失。现在由主机计时抵达后写倍率，客户端只跟随事件与快照 |
| 原验收未发现上述问题 | 回归只验证当时写入的配置，独立展台截图不能证明战场尺寸和裁切正确 | 前次交付结论超出了证据；已添加更正说明，新增模型尺寸、子网格、竖版卡面及飞行期间未增幅等断言 |

主要原因是前次实现与验收没有落实已有文档要求。流程文档本身已包含关键要求；此次在新卡清单补充必须记录的可核对证据，避免再次用自动取景或资源加载成功代替实战验收。
