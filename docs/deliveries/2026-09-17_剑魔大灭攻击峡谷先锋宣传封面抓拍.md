# 交付合同：剑魔大灭形态攻击峡谷先锋宣传封面抓拍

- **需求 / 来源**：用户对话。为新宣传视频制作封面图，抓拍开启大灭（技能）形态的剑魔攻击峡谷先锋的画面；要求在 3D 竞技场内取景、复用项目已有防御塔与水晶摆放、不拍到无内容的黑暗边缘；输出 9:16 竖版与 16:9 横版两种比例；竖版上方预留 logo 空间；水晶取待机状态（水晶柱已升起）；横版采用从左往右斜俯视、先锋与剑魔隔河对峙；最终合成 logo；抓拍做成可复用工具。

- **完成结果**：
  1. **可复用抓拍工具** `tools/capture/capture_cover_combat.gd`（已加入 `tools/capture/README.md` 索引）。复用项目 `BattlePresentation3D` 搭建竞技场/环境/光照，复用 `Tower` + `attach_tower()` 按 `main.gd` 坐标挂 4 座公主塔与 2 座水晶（水晶强制切 `Idle1_Base` 待机态，水晶柱升起）；剑魔大灭形态取普攻命中帧、先锋取受击姿态；支持 `--ratio=9x16|16x9` 与 `--out=<路径>` 参数。
  2. **竖版构图**：斜俯视，战斗单位居中偏下，上方草地留白放 logo。
  3. **横版构图**：相机置于河流一端上方，与地面法线成约 30° 近距放大俯视，河流纵向贯穿画面居中留白，先锋（左下）与剑魔（右上）左右对峙，画面铺满竞技场草地/岩石/树木建模，无边界外黑暗。
  4. **logo 合成**：PIL 将 `clash_legends_logo_transparent.png` 合成（竖版顶部居中、横版画面居中可覆盖人物）。
