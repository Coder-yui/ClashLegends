# 潘森移除热浪与黄色线条居中

- **需求 / 来源**：用户对话；去掉自制热浪，修正黄色线条主体未居中。
- **完成结果**：移除Spear_Impact、update_missile、Update_Impact、Ending_Shockwave中的四个distot_activate发射器及自制particle_distort shader；两张不再使用的纹理及导入文件归档。当前运行98个发射器、64项原版依赖。Damage_Mis的Air Streak 1/2原始横向偏移0/+250导致整体偏侧，改为-125/+125，并减去原版网格横截面中心偏差，使两组黄色空气拖线围绕人物滑行轴对称。前后拖线长度、原版纹理颜色、生成时序、音频与权威伤害未改。
- **验证**：Godot 4.7.1 Compatibility / Apple M5；基线 `2ecbf5125843ac7b7e0fb42162f7ace11677146f`，工作区有其他未提交修改，指定文件同步前已备份。专项313项断言通过，含双方拖线世界几何中心对称检查；正式核心回归7334项断言全部通过。项目审计43卡0错误，64项资源哈希通过，git diff --check通过。在联调副本实际渲染并目视检查双方滑行过程；未修改音频，本轮未单独试听。
- **查看方式**：F5进入卡牌开发工作台选择潘森，实战下牌查看。见[截图与修改前备份](../../ClashLegends-开发素材库/04-中间产物/潘森去热浪与黄线居中/20260926/)。
- **遗留 / 未验证**：用户观感尚未确认。自制热浪已完全移除，不提供替代折射效果。
