# 交付合同：缩短开局准备

- **需求 / 来源**：用户要求恢复合理加载时间，以金币约束下的正常并发为准；确认仅准备本局可能使用的素材。
- **完成结果**：菜单加载实测由上一轮同卡组约10.2–10.3秒降至**4.86秒**，接近最初约4.7秒。只修改[模型池预热](../../scripts/presentation/match_model_pool.gd)及相关测试/说明，不改变模拟、画质、音频或单位数量。
- **原因与修复**：此前按每个动画片段强制绘制整场，590次绘制约4.86秒；现仍采样所有片段，仅网格、材质或可见性变化时重新绘制，跳过442次重复绘制。六种控制/强化材质状态均保留实际绘制，取消状态间额外等待帧，使用`force_draw(false)`避免逐次交换屏幕缓冲。最终148次绘制约0.78秒，实例动画准备约1.41秒。资源比较仅用实例ID，不序列化大型网格。
- **资源范围核实**：正常入口为双方完整卡组＋系统兵线，递归包括技能、变形、召唤、死亡替身、复生及音频，再加地图、塔、水晶和世界音频。没有加载所有英雄模型。全卡准备只用于开发工作台；选卡菜单显示全卡面属于菜单需要。男爵粒子保守保留9种相关系统，因为系统兵线可能使用这些效果；没有冒险删掉可达资源。
- **预算**：现有常规预算已是双方各两只先锋、共24只蠕虫，不再放大，也未削减这部分。模型回收、失败寻路冷却、粒子数值预编译继续保留。
- **实际图形验证**：同设备M5/16GiB、Godot4.7.1、Compatibility、同卡组和种子12345，经真实菜单加载。四只纳尔同时生成/变形短场：模型零缺货，生成2.15ms、变形2.34ms，帧P95/P99/最大17.54/17.77/32.60ms，Tick最大4.16ms。正常规模短场不等于所有玩法稳定60FPS。已目视查看[实际截图](../../ClashLegends-开发素材库/04-中间产物/构建与验证/performance/20260916-231858-095069/4-1/final.png)。[图形结果与精确内容指纹](../../ClashLegends-开发素材库/04-中间产物/构建与验证/performance/20260916-231858-095069/result.json)。
- **回归**：完整机制4167项断言通过；资源ID比较收紧后重跑表现/准备两套件192项通过，均含审计、导入、验证器测试、diff检查。最后`force_draw(false)`由上述真实图形运行验证。[完整回归](../../ClashLegends-开发素材库/04-中间产物/构建与验证/verification/20260916-231400-927540/result.json)、[最终相关回归](../../ClashLegends-开发素材库/04-中间产物/构建与验证/verification/20260916-231742-310491/result.json)。新增测试区分姿势与网格/材质/可见性，明确24只蠕虫预算。
- **命令**：`python3 tools/verify.py`；`python3 tools/verify.py --suite PresentationSuite --suite DeckBuilderSuite`；`python3 tools/performance/benchmark.py --render --case burst --counts 4`。
- **范围 / 未验证**：本次只收紧加载，未重新扩大联机和极端矩阵测试。调试中的305秒对局已中止，不作为最终完整对局证据；最终版使用上述正常并发短场验证。此前完整对局结果见[上一轮记录](2026-09-16_局中性能与资源准备.md)，不能把它写成此次最终版新测量。未降低画质或共享可变动画，无新后台线程/资源框架，保留既有未提交修改。
- **查看方式**：正常从菜单开始对局。资源真正准备完成才开战，最短展示仍为1秒。不同卡组和设备的加载时间会变化。

绘制接口依据：[Godot RenderingServer.force_draw](https://docs.godotengine.org/en/stable/classes/class_renderingserver.html#class-renderingserver-method-force-draw)；Compatibility仍需实际可见绘制，见[官方预热说明](https://docs.godotengine.org/en/stable/tutorials/performance/pipeline_compilations.html)。
