# 交付合同：卑尔维斯与虚空鱼

- **需求 / 来源**：[卑尔维斯需求](../../需求文档/已完成/卑尔维斯.md)。7费大型空中攻城单位，死亡分散生成8只虚空鱼，主动向前突进3格，仅伤害空军。
- **完成结果**：本体1500生命、90攻击、1.5秒间隔、44移速；虚空鱼110生命、26攻击、1.25秒间隔，采用小型空中近战、可对地对空。主动1费、2次、冷却6秒，路径伤害100、每目标一次。通用突进新增仅空中筛选与可关闭旋转，旧凯隐默认行为保留；死亡召唤复用通用入口。接入需求指定模型、完整普攻拼接、原版加载卡面、原版Q图标及双方攻击/命中/部署/突进/死亡音效。详情见[本体手册](../units/belveth.md)、[虚空鱼手册](../units/voidfish.md)。
- **工作区**：基线提交 `b079c0cd48a4c1d5ff3703f5cc9ffede2e81e65c`，包含用户原有及并行的图奇、凝滞等未提交工作；先在素材库联调副本制作，只按明确变更合并，未提交Git。Godot `4.7.1.stable.official.a13da4feb`。
