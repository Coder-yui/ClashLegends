# 交付合同：天使光剑创建时固定朝向

- **需求 / 来源**：用户反馈侧面地面目标的光剑横着下落，并明确要求创建时固定弹体朝向。
- **完成结果**：光剑表现首次创建时，以出手路径两端加上实际模型投影偏移计算方向，包含天使与地面目标的高度差；保存该方向，后续追踪位移、骨骼摆动和无位移的渲染帧均不旋转光剑。修复原来无位移帧退回二维平面方向的问题。改动仅在表现层，追踪与命中销毁继续由现有权威逻辑处理。通用弹体验收工具新增 `--angle` 参数，支持侧面发射检查。
- **验证**：Godot 4.7.1，基线 `3905461`，保留既有未提交修改。最终固定朝向版本天使专项 204 项、正式工程天使与弹体专项合计 1,961 项通过，覆盖左右侧地面目标初始高差方向、位移及目标移动后保持方向、20Hz Tick 间多帧稳定性。修复过程全量回归 6,792 项通过（早于用户固定朝向的最终调整；最终版本另跑上述针对性回归）。最终实际渲染已目视检查左侧地面目标：剑尖斜向目标，飞行期间保持创建方向。`git diff --check` 通过。
