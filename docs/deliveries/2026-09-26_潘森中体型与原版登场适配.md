# 潘森中体型与原版登场适配

- **需求 / 来源**：用户对话；潘森模型适配中体型，并使用 LoL 原版素材制作长矛先落、彗星后方三格着地再滑向长矛的流程。
- **完成结果**：主模型缩放1.3→1.05，缩小19.23%；Idle头骨高度约2.160，与卡牌大师2.181对齐。长矛、fly/slide人物代理及附属粒子按同一比例调整；满怒附着、死亡头部和武器继承模型缩放，血条随通用模型投影适配。中体型权威半径18、三格120px路径与伤害范围保持不变。
- **原版特效**：恢复六组原版系统、102个发射器定义与66项实际资源；修复三维出生偏移曲线读取及运动局部轴映射。原版长矛保持斜插，人物使用原版fly/slide骨骼、星空纹理和橙红色参数；原版火光、拖尾、掀土及冲击波跟随滑行。上一版程序火焰与剪影shader已归档。沿途伤害与单位到点生成继续由20Hz权威逻辑决定。
- **验证**：Godot 4.7.1 Compatibility / Apple M5；基线 `2ecbf5125843ac7b7e0fb42162f7ace11677146f`，工作区原有大量未提交修改，仅同步本任务指定文件。副本潘森专项293断言通过；正式项目完整回归7314项断言全部通过。资源清单66项SHA-256全部通过；项目审计43卡、0错误；git diff --check通过。实际渲染已目视检查蓝红双方飞行/滑行及正式项目中体型同屏、满怒效果；战斗录音已用afplay播放成功，用户听感尚未确认。
- **查看方式**：F5进入卡牌开发工作台选择潘森；实战下牌查看登场。可运行 `Godot --path . --script tools/demos/pantheon_review.gd -- --size-comparison` 查看中体型同屏。截图、录音、日志及修改前备份在[本地验证目录](../../ClashLegends-开发素材库/04-中间产物/潘森中体型与原版登场/20260926/)。
- **遗留 / 未验证**：热浪为原版法线纹理的加色高光近似，未实现屏幕折射；未完整复刻LoL软深度、导航遮罩和FlexShape。每系统最多220个存活粒子，到部署点清理预部署代理。实际观感尚待用户确认；未作移动端性能认证。本轮未修改音频时序及普攻/Q机制。
