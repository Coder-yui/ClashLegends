# 交付合同：工作台三区交互改版

- **需求 / 来源**：用户对话及逐项确认。模型、音频、实战分开；模型页不显示快捷栏；多模型编辑框上方选牌、下方移除槽位；放置 / 选择显式切换；地图默认完整适配 100%。需求梳理期间未生成报告，本报告记录实施结果。
- **完成结果**：模型页常驻全部动作列表，显示接入用途与时长，支持任意时间暂停续播，删除逐帧按钮。音频左侧事件筛选、右侧变体列表与播放器，每条显示时长。实战区分单 / 多模型，快捷栏仅多模型出现，木桩独立按当前阵营点击放置。选择模式只选单位；待放置卡和操作目标分离，黄色圈与名称 / 阵营 / 生命 / 批次标识目标。控制仅作用于点选成员，整组技能保留原作用范围；死亡不自动转移。地图默认 100%，支持缩放、拖动、复位。
- **验证**：基线 `4ca4f25`，保留原有大量未提交修改；Godot `4.7.1.stable.official.a13da4feb`。完整核心回归 6549 项通过；最后的动作列表、命中范围和镜像资格细节另做工作台、经典场景和镜像专项回归，627 项通过。项目审计与 `git diff --check` 通过。实际渲染检查模型、音频、单模型、多人选牌与显式选择，复用 `tools/demos/workbench_preview.gd`；脚本同时验证暂停恢复、控件边界与退出窗口复原。
