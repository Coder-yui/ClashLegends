# 交付合同：天使音效检查

- **需求 / 来源**：用户对话；检查近战挥剑、命中、远程光剑与焰浪音效。
- **完成结果**：核对当前配置、事件链、LoL 本地原始音频事件及实际运行录音；更新声音说明。本轮未修改播放逻辑或音频资源。

| 项目 | 检查结果 |
| --- | --- |
| 近战挥剑 | BasicAttack / BasicAttack2 各 4 个随机变体，按攻击序号交替选择；实机 7 次播放。 |
| 近战命中 | 对应两组 OnHit，各 4 个变体，成功命中才播放；实机 7 次播放。 |
| 远程出手 | BasicAttack3 / BasicAttack4 OnCast，各 4 个变体；实机 7 次播放。 |
| 光剑发射 | 对应 Attack3 / Attack4 OnMissileCast，弹体创建事件触发；实机 7 次播放，无重复发射声事件。使用一次性声音，没有持续飞行循环。 |
| 光剑命中 | 对应 Attack3 / Attack4 OnHit，由真实命中事件播放；实机 7 次播放。 |
| 焰浪 | 缺独立发射及命中声。延迟创建没有发声通知，波及伤害不计普通攻击并跳过通用 skill_hit 通知。 |

原版素材中已找到 `Play_sfx_Kayle_KayleEnrageConeMis_OnMissileCast`（4 个变体）和 `Play_sfx_Kayle_KayleEnrageConeMis_hit`，另外还有 `EnrageConeMisUpgrade_cast`。发射事件包含 Wwise 内部 70ms 延迟；后续接入需核对普通/升级事件对应形态及事件时间基准，避免与当前焰浪创建延迟重复累加。尚未确认 16 级应使用哪一组焰浪发射事件。

- **验证**：Godot 4.7.1；基线 `3905461`，工作区包含此前未提交的天使功能改动。音频与天使专项回归全部通过（398 项断言）。39 个已接入 WAV 均可读取、非静音。通过现有 `card_audio_batch_demo.gd --cards=kayle,kayle:1` 实机运行，两份主混音录音均非静音，未出现 16-bit 满幅采样。
- **查看方式**：[近战录音](../../ClashLegends-开发素材库/04-中间产物/预览与验证/1790306053-49242/clash-card-audio/kayle.wav)、[远程录音](../../ClashLegends-开发素材库/04-中间产物/预览与验证/1790306053-49242/clash-card-audio/kayle:1.wav)；[播放日志](../../ClashLegends-开发素材库/03-制作中/正义天使/audio-audit-20260925.log)。录音含场景背景声音。
- **遗留 / 未验证**：焰浪声音待接入；本轮确认配置、播放事件和录音有效性，不代表主观听感、混音平衡或与 LoL 原版逐帧听感一致已经验收。
