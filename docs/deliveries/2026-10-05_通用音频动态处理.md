# 交付合同：通用音频动态处理

- **需求 / 来源**：用户要求撤回出生、凝滞、死亡及攻击的单独并发调整，改为通用混音处理。
- **完成结果**：已完整移除 100 ms 事件分组、按数量衰减及相关测试，GameAudioManager 回到提交 `1f422d7` 的实现。默认音频总线新增 Combat 压缩（-18 dB、2:1、2 ms/160 ms）、Voice 独立压缩（-16 dB、2:1、3 ms/180 ms）、Master 硬限幅（-1 dB、100 ms）。压缩补偿与限幅预增益均为 0。单音效原增益、冰冻 -12 dB、客户端语音逐文件补偿保持不变。原有声部预算和优先级保留。
- **通用性**：同类/不同类音效、持续声音均按总线实际混合电平处理，无需卡牌或事件白名单。阈值以下不主动放大；较响单声源也可能触发压缩。Voice 独立于 Combat，但最终 Master 限幅在过载时可能作用于全部输出。
- **验证**：Godot 4.7.1 原生音频开启/旁路共 14 组录音，覆盖低电平单声源、8 声源叠加、语音、32 声源过载、单/6 份凝滞素材、8 声源跨类型混播。低电平单声源开关前后峰值均 -26 dBFS、稳定段 RMS 均 -29.02 dBFS。8 声源战斗叠加稳定段 RMS 从 -10.95 降为 -21.02 dBFS；6 份凝滞稳定段从 -10.36 降为 -26.27 dBFS（处理后单份为 -27.97）。过载样本峰值限制在 -1 dBFS，满量程样本从 100692 降为 0。这里是录音样本峰值，不是跨采样点真峰值认证。首轮压缩过重已降低比例后重新录音。核心回归 9835 项断言全部通过，`git diff --check` 通过。
- **基线 / 工作区**：`1f422d7e4a411944d98282cb58cbf1e6c64c951f`。保留期间出现的先锋冲撞机制、对应文档和测试及工具 UID 修改，未纳入撤回范围。未提交。
- **查看方式**：实战和工作台自动生效，参数集中于 `default_bus_layout.tres`；无需逐卡配置。
- **遗留 / 未验证**：实际播放和录音已验证，用户主观听感仍待确认；压缩器启动期间的短峰由最终限幅兜底。未将参数标为所有设备上的最终听感定稿。
