# 交付合同：潘森定向彗星与斜插长矛

- **需求 / 来源**：用户对话。长矛从己方朝敌方斜落并斜插，包含人物剪影的彗星砸在后方3格，依惯性带火光、热浪及冲击波滑到长矛；允许自制特效。
- **完成结果**：用同一把原版长矛贯穿下落与插地，不再切换成直立的Spear_Impact。保留原版fly/slide骨骼代理，改用深色剪影与橙红边光。火光、热浪和冲击波改成程序自制：前方半椭圆波头、后方收窄的彗星尾焰、定向热浪高光、28粒火星；双方都由己方向敌方推进，不使用四面扩散的环形余震。原版声音、1.3秒预部署、后方120像素着地、扫掠伤害以及到点才创建单位并播放1秒拿矛收势均保留。
- **倾角适配**：当前镜头几乎沿世界45°观察，严格45°会让蓝方长矛只剩一个点。此次使用高度/地面距离0.5（约26.6°）的表现倾角，保证屏幕投影从己方侧向前移动，枪柄保持向后上方斜插；地面落点与伤害路径不变。长矛开启投影以帮助判断插地姿态。
- **资源**：正式目录仅保留原版长矛网格、贴图与人物代理三项依赖，哈希已核对；旧七组粒子系统、播放器及退出运行的纹理/网格共133个文件（含导入记录）归档到本轮证据目录。新效果无需外部位图。未改动音轨。
