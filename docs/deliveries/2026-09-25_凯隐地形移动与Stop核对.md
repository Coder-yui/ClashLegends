# 凯隐地形移动与 Stop 核对

- **需求 / 来源**：用户对话：不接 Idle-In，核对 Spell1_Stop 原版用途，地形内行走使用 Spell3_Run。
- **完成结果**：移除三形态 Q 的 Idle-In 配置，结束后直接混合回各自待机；地形内移动统一循环 Spell3_Run，离开地形恢复本形态跑步。地形内 Q 保持技能动画优先，结束移动按源表 Spell1_Exit_To_Run 接回 Spell3_Run。新增 terrain_move 表现字段、schema/validator 和回归；表现层只读地形几何，不改权威状态或网络协议。保留已有工作区其他修改。
- **Stop 核对结论**：源片0.3秒，首帧与 Dash 末帧逐轨道一致，支持其为突进停步相关片段；Circle末帧与Exit_To_Run首帧一致。动画BIN仅声明Stop片段及部分出边，未发现自动进入Stop的转场；KaynQ技能BIN同样未提供其动态播放条件。不能证明它每次Q必播，也不能认定无用。本轮保留素材、不绑定、不改变技能时间。详见[动画说明及证据边界](../units/animations/kayn.md#地形内移动与-spell1_stop-核对)。
- **验证**：基线 `2ecbf51`，含本轮及此前未提交修改；Godot `4.7.1.stable.official.a13da4feb`。完整核心回归6,880项断言通过；专项114项通过；项目审计零错误，diff检查通过。复用素材库联调副本，Compatibility实际渲染检查三形态双方入地形、循环、地形内Q出口、出地形和Q直接回待机，438张记录，未见错误。新增测试覆盖桥面恢复、动画循环、不误触发回血、Q优先级和非法字段类型。
- **查看方式**：工作台实战中将凯隐部署在河道附近观察穿行；三形态都使用Spell3_Run，动作列表可独立查看Spell1_Stop。模型与音频规则延续已有配置。
- **遗留 / 未验证**：LoL的Stop实际调用条件尚未证实；未进行本轮双进程网络及性能专项测试。用户尚未确认最终观感。
