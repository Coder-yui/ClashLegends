# 凯隐音频复核及机制边界汇总

- **需求 / 来源**：用户对话：核对凯隐音频，入地形参考LoL的E，汇总此前检查过的边界。本报告采用最终规则，覆盖并替代前序报告中已废弃的“最近地面出口”“走近出口”“Q末端瞬移找空位”描述。
- **完成结果**：核对39条正式音频与源TXTP、文件哈希及三形态事件分支；入地形已使用LoL E施放短音，不是新增猜测素材。修复PCM16导出削波，统一-6dB储存余量/+6dB播放补偿；死亡声按项目通用规则保留1.5秒并淡出。部署语音继续有意留空。
- **验证基线**：`2ecbf51`，工作区已有天使、网络与凯隐等未提交修改均保留；Godot `4.7.1.stable.official.a13da4feb`。本轮完整回归和实际运行结果见下文。
- **查看方式**：F5→卡牌开发工作台→凯隐三形态；木桩贴河时从对岸接近，观察挤出后攻击。音频试听入口及文件在[凯隐音频页](../units/audio/kayn.md)。

## 验证结果与限制

- 本轮完整核心回归：**6,982项断言全部通过**；项目审计43张卡、3,480文件、零错误；diff格式检查通过。
- 三形态×双方共6组实际有声运行：每组两次进入地形，每次停留连续更新10次，只产生2次`terrain:enter`播放；离开不播放进入声。
- 另行运行三形态双方完整战斗录音，事件覆盖普攻出手、真实命中、Q施放/旋转/命中、入地形、死亡；没有脚本错误。
- 当前出口规则的前序实际木桩验证：三形态双方均能在目标岸挤出并持续攻击；最终版本是**直接挤出**，没有“先走向出口”的路径。
- 本轮证据保存在本地素材库`04-中间产物/凯隐/20260926音频边界核对/`：原文件备份、浮点源解码、修复候选、审计JSON、回归/运行日志、`terrain_mix.wav`和`battle_mix.wav`。入地形录音批次`1790360482-65403`，战斗录音批次`1790360646-65503`，均在联调副本`20260925-143517-710860`内。


未完成或不应冒充已验证的项目：独立强制位移/推拉尚无完整执行链；本轮未重新进行双进程联机测试；未穷举大量单位堵住所有出口、两个高速突进相向交叉、移动目标高速擦边及控制与命中同Tick的全部排列；未做专门性能压测。音频实际播放、录音、解码和事件计数可验证链路，但本工具环境不能据此作可靠的主观听感判断，用户最终听感仍未确认。未新增E持续音/退出音或部署语音。
