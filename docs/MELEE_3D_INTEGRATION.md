# 普通近战模型接入

适用于通用单位和简单阵营模型；双形态、组合动画等特殊情况另读对应 [单位动画页](units/README.md)。

## 四步完成

1. **检查原素材。**确认材质、骨骼、动画播放器，以及待机、移动、攻击和死亡片段；部署选片见 [部署规则](UNIT_DEPLOYMENT.md)。
2. **建立包装。**实例化原模型，只调缩放、脚底和初始朝向；不写伤害、移动或碰撞规则。
3. **配置动作。**逐卡表现域登记场景、朝向和真实动画名。多种攻击按实际攻击顺序对应；分段攻击使用已有起手、命中和收势配置。
4. **实战验证。**跑内容回归，并在工作台检查双方、连续动作与受控恢复。

动画应适配已确定的攻击间隔和命中点。不要为了让素材顺眼而改旧卡攻速或伤害，也不要由动画回调扣血。

## 重点检查

| 现象 | 优先检查 |
| --- | --- |
| 不可见 / 过大过小 | 场景路径、模型缩放 |
| 朝向反了 | 表现朝向偏移 |
| 脚底悬空 / 埋地 | 包装位置；空军按共用高度规则 |
| 攻击接跑步跳姿 | 是否使用正确收势、转跑片段 |
| 命中时刻不合拍 | 动画片段与权威前摇的映射 |
| 血条晃动 | 稳定头顶锚点，避免跟随武器最高点 |

部署期不能自主行动，但已可被命中和推挤；死亡表现不能延长战斗对象存活。

字段与衔接规则见 [动画参考](reference/ANIMATION_CONFIGURATION.md)，完整验证见 [测试手册](../tests/README.md)。

新增卡牌的攻击前摇必须按[原生命中节点映射](reference/ANIMATION_CONFIGURATION.md#原生命中节点映射)核对：原始节点→片长与帧率→按攻速缩放后的节点。普通攻击多动作统一近似前摇，记录来源和误差；远程区分离弦与弹体命中。不得直接沿用模板前摇。
