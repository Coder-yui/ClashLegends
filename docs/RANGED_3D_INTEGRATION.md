# 远程模型与弹体接入

先完成 [普通模型接入](MELEE_3D_INTEGRATION.md)，再核对发射和命中的区别。

## 普通远程攻击

攻击起手 → 到达发射时刻 → 弹体飞行 → 实际碰撞 → 结算伤害。

`first_hit` 对普通远程攻击表示发射时刻，不是伤害时刻。弹体速度影响飞行；外观高度、大小和前向偏移只改变画面，不改变权威路径或命中。

现有普通弹体包括法球、箭、针、回旋镖和冰锥。素材的离弦点应适配既定攻击时间，不能靠动画回调生成权威弹体。

普通追踪弹体的画面路径从发射者模型投影锚点过渡到目标模型投影锚点，朝向按可见路径指向目标；缺少模型锚点时使用卡牌配置的外观高度与偏移回退。模型锚点只影响绘制，权威出生点、飞行速度与命中圆不随之改变。

## 技能有两种情况

| 类型 | 伤害如何发生 |
| --- | --- |
| 直接范围结算 | 按技能的效果执行延迟判定范围；飞行效果只是表现 |
| 真实技能弹体 | 按排程发射，飞行碰撞后才伤害；不能把它当成定时范围伤害 |

艾希万箭齐发遇到首个敌人停止；卡牌大师万能牌与炮台激光会穿透。每次施法对目标的去重规则由技能系统处理。发射提示与实际路径要一致，路径间空隙不能画成可命中区域。

## 验收

分别检查出手、飞行和命中；空放不伪造命中，目标失效后正确清理。核对弹体朝向、大小、起点及双方显示；涉及网络事件时完成主客双方验证。

具体规则见 [卡牌机制](CARD_DESIGN.md)，声音节点见 [音频流程](AUDIO_INTEGRATION.md)。

新增卡牌的攻击前摇必须按[原生命中节点映射](reference/ANIMATION_CONFIGURATION.md#原生命中节点映射)核对：原始节点→片长与帧率→按攻速缩放后的节点。普通攻击多动作统一近似前摇，记录来源和误差；远程区分离弦与弹体命中。不得直接沿用模板前摇。
