# 远程角色 3D 素材与弹体接入流程

本文档以寒冰射手为首个完成样例，供后续 agent 接入普通远程英雄。近战模型的目录、
包装场景、朝向、死亡动画和通用验收仍遵循
[`MELEE_3D_INTEGRATION.md`](MELEE_3D_INTEGRATION.md)，这里只描述远程攻击的差异。

## 权威时序

```text
攻击序号产生
  → 播放完整 Attack 动画
  → first_hit 到时生成弹体（箭矢离弦）
  → 主机固定 tick 推进弹体
  → 抵达目标碰撞圈
  → 结算伤害
  → 销毁弹体
```

`first_hit` 对远程单位表示“动画开始到弹体离弦”的时间，不表示伤害命中时间。
实际命中时间还取决于射程、目标移动和 `projectile_speed`。动画回调不能创建权威弹体，
也不能直接扣血；发射和命中仍由主机固定 tick 控制。

## CardDB 字段

```gdscript
"projectile_speed": 480.0,
"projectile_visual": "arrow",
"projectile_visual_height": 30.0,
"visual_scene_path": "res://assets/units/<card_id>/<card_id>_view.tscn",
"visual_animations": {
    "deploy": "Idle1",
    "idle": "Idle1",
    "move": "Run",
    "attack": ["Attack1", "Attack2"],
    "death": "Death",
},
```

- `projectile_speed > 0`：使用主机权威追踪弹体；`0` 表示近战/即时攻击。
- `projectile_visual = "arrow"`：使用带方向和箭头的细箭；寒冰当前使用蓝色小箭。
- `projectile_visual = "needle"`：使用无箭头的短线；提莫当前使用绿色短线代替毒针。
- 未设置 `projectile_visual` 时使用普通圆形弹体 `orb`。
- `projectile_visual_height`：将屏幕绘制位置从脚底原点抬到弓、吹管或枪口高度。权威
  弹体仍在 2D 地面坐标飞行和碰撞，因此这个值不能改变射程、飞行时间或命中结果。
- 弹体颜色沿用单位 `color`；寒冰配置为浅蓝色。
- 多套射击动作按数组顺序循环。

## 离弦时刻调校

1. 在 Godot 中预览 Attack，找到弓弦释放或枪口火光出现的源动画时刻。
2. 计算 `release_ratio = source_release_time / source_animation_length`。
3. 设置 `first_hit = interval * release_ratio`。
4. 实机检查弹体是否恰好从离弦姿态出现，再按 0.05 秒固定 tick 小步调整。

寒冰 `Attack1/Attack2` 均约在源动画 44% 处释放，当前使用
`first_hit = 0.45`、`interval = 1.0`。

## 发射位置与临时弹体

本项目的 3D 模型站在 2D 权威单位的地面原点上。如果直接在 `Unit.global_position` 绘制
弹体，它会看起来从脚底射出。正确做法是保持权威弹体坐标不变，只在绘制和联机表现中
同步 `projectile_visual_height`：

- 人物统一放大 `1.5×` 后，寒冰弓部高度约为 45px；
- 提莫身形较矮，放大后的吹管口高度约为 42px；
- 新模型必须按实际渲染重新测量，不能照抄角色身高或修改 `Unit.position`；
- 前向起点可在单位碰撞圆外小幅偏移，避免弹体被自身模型完全遮住。

素材没有独立弹体时可以先做清晰、方向正确的代码占位表现。当前约定：

| 类型 | 表现 | 适用样例 |
|---|---|---|
| `arrow` | 细轴 + 三角箭头 | 寒冰蓝色箭矢 |
| `needle` | 约 16px 的短直线、无箭头 | 提莫绿色毒针 |
| `orb` | 小圆点 | 尚未定制的塔弹或法球 |

以后替换正式 3D/2D 弹体资产时，只替换绘制代理；`launch_attack`、固定 tick 飞行、命中
伤害和格温拦截逻辑必须保持不变。

## 弹体表现和联机

主机弹体保存位置、方向、速度、目标、伤害、攻击者及攻击者最后有效位置。客户端快照
同步弹体位置、方向、颜色、半径、视觉类型和绘制高度，只做平滑显示。目标死亡、弹体命中或特殊
机制令目标不可见时，主机移除弹体；客户端从后续快照中同步移除。

素材没有独立弹体模型时，不要阻塞角色接入。客户端快照还必须同步视觉类型、方向和
绘制高度，不能在客户端根据角色名猜测弹体外观。

## 与不可见/免疫机制交互

发射前必须再次确认攻击者仍能看到目标；弹体飞行期间也必须持续检查目标合法性。
格温丝缕缠流开启后：

- 圈外单位和塔不能继续锁定或发射；
- 已经在途、来源仍在圈外的弹体立即失去目标并消散；
- 攻击者在飞行途中死亡时，弹体使用其最后有效位置判定，不能穿透缠流；
- 来源进入圈内时，弹体可以继续飞行并正常命中；
- 被缠流拦截的攻击不能附带击退或触发“攻击命中”效果。

## 验收

- Attack 动画在正确离弦姿态创建弹体；
- 弹体从武器/手部高度出现，不从脚底原点出现；
- 发射时不扣血，抵达碰撞圈才扣血；
- 命中、目标死亡和失去目标时弹体都能销毁；
- 箭头始终朝飞行方向；
- 普通单位、建筑和塔均能被命中；
- 本地、主机和客户端看到一致的弹体类型、方向与绘制高度；
- 不可见/免疫机制能同时阻止索敌、发射、在途命中和附带效果；
- 运行 `tests/mechanics_check.gd` 并完成实际渲染检查。
