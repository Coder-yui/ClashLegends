# 小鬼（`imp`，系统召唤物）

小鬼由墓碑周期召唤、亡语或“亡者集结”生成，不在 `CardDB.all()` 中，不占用独立卡槽，也不是可选卡牌。数据来自 `CardDB.imp_stats()`。

## 1. 属性数据

| 属性 | 数值 |
| --- | --- |
| 类型 / 费用 | 系统召唤物 / 无 |
| 生命值 / 普攻伤害 / 攻击距离 | 55 / 25 / 24 |
| 移速 | 68 px/s（稍快） |
| 攻击间隔 / 首次命中 | 0.70 s / 0.25 s |
| 体型 / 权威半径 / 表现半径 | 极小 / 9 / 13.5 |
| 质量 / 视野 | 1 / 180 |
| 空中单位 / 仅攻击建筑 / 可攻击空中 | 否 / 否 / 否 |
| 部署时间 | 0 s |
| 阵营颜色 | `Color(0.55, 0.45, 0.80)` |

## 2. 被动

无独立被动。小鬼是基础近战地面召唤物。

## 3. 主动技能

无主动技能。小鬼不能占用主动槽。

## 4. 使用的动画

- 场景：`res://assets/units/imp/imp_view.tscn`；`visual_forward_yaw = 0`。
- 部署 / 待机 / 移动：`Spawn1` / `Idle1` / `Run1`。
- 普攻：`Yorick_ghoul_leapWindup_anm`。
- 死亡：`Death`，表现时长 `0.5 s`。
