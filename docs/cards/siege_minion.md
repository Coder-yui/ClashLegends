# 炮车兵（`siege_minion`）

## 1. 属性数据

| 属性 | 数值 |
| --- | --- |
| 类型 / 费用 / 可选 | 单位 / 3 / 是（显式配置） |
| 描述 | 远程炮击单位，攻击距离较远，适合从后方压制敌方建筑。 |
| 生命值 / 普攻伤害 / 攻击距离 | 390 / 58 / 170 |
| 移速 | 60 px/s（中） |
| 攻击间隔 / 首次命中 | 1.65 s / 0.55 s |

## 2. 被动

无独立被动字段。炮车兵是远程、可攻击空中的兵线单位，当前没有额外攻城倍率或溅射字段。

## 3. 主动技能

**超载炮击**（`kind = nova`）

- 以炮车兵为中心，半径 `180` 的范围内造成 `100` 点伤害。
- 对仍存活的敌方单位施加基础击退距离 `35`；无施法窗口和延迟。
- 没有主动专属动画。

## 4. 使用的动画

- 双阵营场景：`res://assets/units/siege_minion/siege_minion_order_view.tscn`、`res://assets/units/siege_minion/siege_minion_chaos_view.tscn`；数组顺序为 Order/蓝方、Chaos/红方；`visual_forward_yaw = 0`。
- 部署 / 待机 / 移动：`Idle1` / `Idle1` / `Run`。
- 普攻：`Attack1_BASE`、`Attack2_BASE`。
- 死亡：`Death`，表现时长 `0.5 s`。
- `超载炮击`没有 `visual_action`，范围伤害与击退由逻辑直接触发。
