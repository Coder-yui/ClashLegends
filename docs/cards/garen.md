## 2. 被动

无独立被动字段。盖伦的核心定位由高生命值和 `building_only = true` 决定：普通攻击只寻找塔和建筑，不攻击普通单位。

## 3. 主动技能

**致命打击**（`kind = empowered_attack`）

- 当前主动技能数值：消耗 `1` 金币；每个盖伦最多使用 `2` 次；每次使用后冷却 `6.0 s`。
- 强化下一次普通攻击，伤害倍率为 `2.0`，本次命中后立即消耗强化。
- 强化尚未打出且单位不在当前攻击动作中时，移速倍率为 `60 / 44 = 1.363636...`，即从 44 提升到 60 px/s（中）。攻击动作进行中才使用技能时不追加移动加速。
- 不重置、不延后当前攻击的 `attack_cd` 或 `first_hit`；技能没有施法窗口和延迟，Gameplay Impact 立即写入“下一次普攻强化”状态。

## 4. 使用的动画

- 场景：`res://assets/units/garen/garen_view.tscn`；`visual_forward_yaw = 0`。
- 部署：`Respawn_Base`。
- 待机 / 移动：`Idle1_Base` / `Run_Base`。
- 强化待机移动：`Run_Spell1`。
- 普攻：`Attack1`、`Attack2`。
- 强化普攻：`Spell1`（仍走 Attack 通道）。
- 死亡：`Death`，表现时长 `0.8 s`。
