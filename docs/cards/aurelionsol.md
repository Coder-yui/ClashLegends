## 2. 被动

### 星尘充能

- 每击杀一个敌方 `Unit` 获得 1 层资源，最多 5 层；击杀塔不增加该资源。
- 只有主动槽实际携带“星落/天瀑”时才显示并积攒资源；Cast Start 读取当前层数、清空资源并固化本次技能强度。
- 资源条最多 5 段，未满时为白色，满层为蓝紫色 `Color(0.58, 0.42, 1.0, 0.96)`。

### 持续龙息

- 普攻是持续攻击（`is_continuous_attack = true`），权威每个固定模拟步按 `55 × delta` 结算。
- 普攻命中范围带 `splash_radius = 34` 的溅射。

## 3. 主动技能

**星落/天瀑**（`kind = forward_area`）

- 主动技能规则：消耗 `2` 金币；每个龙王最多使用 `1` 次；每次使用后冷却 `10.0 s`。
- 在锁定朝向前方 `175` 的位置生成半径 `92` 的落点区域，造成 `120` 点伤害并眩晕 `1.2 s`。
- 普通资源：`impact_delay = 1.15 s`、`cast_duration = 1.9333328 s`。
- 满 5 层时伤害与眩晕各乘 `1.5`，即 `180` 点伤害和 `1.8 s` 眩晕；满层时间线为 `impact_delay = 1.12 s`、`cast_duration = 1.8999995 s`。
- 只有满层的“天瀑”在落地后生成扩散冲击波：伤害 `55`，从初始范围向半径 `1500` 扩散，持续 `1.4 s`；冲击波命中目标后减速 `2.0 s`，速度倍率 `0.60`。
- 施法期间锁定移动、普通攻击和朝向。冲击波由独立固定模拟时间线推进，不由动画结束触发。

## 4. 使用的动画

- 场景：`res://assets/units/aurelionsol/aurelionsol_view.tscn`；`visual_forward_yaw = 0`。
- 部署：`Respawn`，只播放前 `0.5` 比例；待机 `Idle1_Base`。
- 移动入口 / 循环：部署、待机和普通攻击进入移动时使用 `RunIn`（存在专用转跑片段时使用专用片段）；循环 `Run1B`、`Run1C`、`Run1D`、`Run1A`。
- 持续攻击入口：`AurelionSol_Spell1_newtst_anm`；换目标入口：`AurelionSol_Spell1_new_looptoin_anm` → `AurelionSol_Spell1_newtst_anm`；吐息循环：`AurelionSol_Spell1_loop_anm`。
- 攻击后转移动画：`Spell1_2Run`。
- 普通主动技能 `active`：`Spell4`，`1.9333328 s`。
- 满层主动技能 `active_strong`：`AurelionSol_Spell4_base_anm`，`1.8999995 s`。
- 死亡：`Death`，表现时长 `0.8 s`。
