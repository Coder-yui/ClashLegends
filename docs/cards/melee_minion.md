## 2. 被动

无独立被动字段。近战兵是基础地面近战单位，没有额外连击、资源或状态机制。

## 3. 主动技能

**列阵突击**（`kind = buff`）

- 主动技能规则：消耗 `0` 金币；每个近战兵最多使用 `2` 次；每次使用后冷却 `5.0 s`。
- 持续 `4.0 s`。
- 移速倍率 `1.35`，伤害倍率 `1.25`；不提供护盾或攻速倍率。
- 无施法窗口、无主动专属动画，效果立即生效。

## 4. 使用的动画

- 双阵营场景：`res://assets/units/melee_minion/melee_minion_order_view.tscn`、`res://assets/units/melee_minion/melee_minion_chaos_view.tscn`；数组顺序为 Order/蓝方、Chaos/红方；`visual_forward_yaw = 0`。
- 部署 / 待机 / 移动：`Idle1` / `Idle1` / `Run`。
- 普攻：`Attack1`、`Attack2`。
- 死亡：`Death`，表现时长 `0.5 s`。
- `列阵突击`没有 `visual_action`，使用逻辑 Buff 表现。
