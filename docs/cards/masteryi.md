## 2. 被动

### 双重打击

- 普攻动画循环的第三段在首刀命中后 `0.12 s` 追加一次普通攻击判定。
- 追加刀伤害倍率 `0.5`，即以基础伤害 `52` 计算为 `26` 点；追加刀也独立推进攻击计数和命中相关资源，但不会重新开启完整攻击间隔。
- 致盲等“下一次普通攻击”效果按每一刀独立消费，因此追加刀会被视为另一刀普通攻击。

## 3. 主动技能

**高原血统**（`kind = buff`）

- 持续 `5.0 s`。
- 移速倍率 `1.5`（88 → 132 px/s），伤害倍率 `1.0`（伤害数值保持基础值），攻速倍率 `1.5`（攻击间隔倍率为 `2/3`）。
- 无施法窗口、无延迟和主动专属技能动作；移动表现切换为 `haste_move`。

## 4. 使用的动画

- 场景：`res://assets/units/masteryi/masteryi_view.tscn`；`visual_forward_yaw = 0`。
- 部署 / 待机：`Respawn` / `masteryi_2013_idle1_anm`。
