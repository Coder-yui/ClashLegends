## 2. 被动

无独立被动字段。远程兵只通过普通远程攻击发挥作用。

## 3. 主动技能

**奥术齐射**（`kind = nova`）

- 主动技能规则：消耗 `1` 金币；每个远程兵最多使用 `3` 次；每次使用后冷却 `5.0 s`。
- 以远程兵为中心，半径 `150` 的范围内对敌方战斗对象造成 `48` 点伤害。
- 无施法窗口、无延迟、无击退/减速，Gameplay Impact 立即结算；没有主动专属动画。

## 4. 使用的动画

- 双阵营场景：`res://assets/units/ranged_minion/ranged_minion_order_view.tscn`、`res://assets/units/ranged_minion/ranged_minion_chaos_view.tscn`；数组顺序为 Order/蓝方、Chaos/红方；`visual_forward_yaw = 0`。
- 部署 / 待机 / 移动：`Idle1` / `Idle1` / `Run`。
- 普攻：`Attack1`、`Attack2`。
- 死亡：`Death`，表现时长 `0.5 s`。
- `奥术齐射`没有 `visual_action`，范围伤害由逻辑直接触发。
