## 2. 被动

### 丝缕缠流

- 第一次真正的普通攻击命中后开启，影响半径 `120`。
- 开启后，距离格温超过 `120` 的敌方单位/塔不能将她作为目标，也不能对她造成伤害；敌方仍可看到她，圈内攻击正常生效。
- 赵信的击退等强制位移会关闭缠流；资源条只有主动槽实际携带本技能时才启用。

## 3. 主动技能

**快刀乱剪**（`kind = frontal`，`shape = fan`）

- 主动技能规则：消耗 `3` 金币；每个格温最多使用 `2` 次；每次使用后冷却 `8.0 s`。
- 普攻命中充能，最多 `3` 层；Cast Start 固化当前层数并清空资源，施法期间获得的新资源留给下一次技能。
- 从格温前缘向前延伸 `135` 的 `78°` 圆弧扇区；外边界为半径 `135` 的圆弧，圆弧外的区域不在命中范围内。
- 扇区中央是贯穿至外弧的 `30px` 恒宽长条，命中时每一剪造成 `1.2` 倍伤害；扇区两条侧边与中央长条近端共用两个端点，`ground_only = true`。
- 范围提示使用相同的圆弧扇区与中央长条，并持续到 `Spell1_C_anm` 最后一剪结算。
- 任意层数都先由 `Spell1_0` 剪切一次、造成 `40` 伤害，最后由 `Spell1_C_anm` 剪切一次、造成 `60` 伤害；每层资源在两者之间增加一次 `Spell1_B` 和 `20` 伤害。
- 0～3 层的逐剪伤害分别为 `[40, 60]`、`[40, 20, 60]`、`[40, 20, 20, 60]`、`[40, 20, 20, 20, 60]`；总伤害为 `100 / 120 / 140 / 160`，中央区域每一剪再乘 `1.2`。
- 四档 `cast_duration` 统一为 `1.5 s`；四档剪切相对 Cast Start 的结算时刻分别为 `[0.0949367, 1.0443036]`、`[0.0949367, 0.9493669, 1.0443036]`、`[0.0949367, 0.7827002, 0.9493669, 1.0443036]`、`[0.0949367, 0.6160335, 0.7827002, 0.9493669, 1.0443036]`。满 3 层时在技能结束瞬间回复 `100` 点生命值。
- 施法期间锁定移动、普通攻击和朝向；没有弹体（`projectile_count = 0`）。

## 4. 使用的动画

- 场景：`res://assets/units/gwen/gwen_view.tscn`；`visual_forward_yaw = 0`。
- 部署 / 待机 / 移动 / 进入移动：`Respawn` / `Idle_anm` / `Run_anm` / `Into_Run`。
- 普攻：`Attack1`、`Attack2`、`Attack3`。
- 0～3 层分别选择 `active_0`～`active_3`：`Spell1_0 → Spell1_B × 层数 → Spell1_C_anm`。
- `Spell1_0 + Spell1_C_anm` 的素材动作按比例安排在 `1.5 s` 技能时槽内；每段 `Spell1_B` 使用约 `0.1667 s`，各档技能总时长均为 `1.5 s`。
- `Spell1_0 → Spell1_B`、连续 `Spell1_B`、`Spell1_B → Spell1_C_anm` 均使用素材自身的逐帧衔接，内部 `sequence_blend = 0`。
- 技能转移动画：`Spell1_C_to_Run_anm`。
- 死亡：`Death`，表现时长 `0.8 s`。
