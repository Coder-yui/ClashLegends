## 2. 被动

无独立被动字段。艾希的基础攻击通过箭形弹体攻击地面和空中目标。

## 3. 主动技能

**万箭齐发**（`kind = frontal`，`shape = fan`）

- 当前主动技能数值：消耗 `2` 金币；每个艾希最多使用 `1` 次；每次使用后冷却 `10.0 s`。
- 锁定施法开始时的朝向，在前方长度 `190`、夹角 `72°` 的环形扇区进行结算；内边界沿艾希体型外围的前半圆弧，侧边从人物左右两侧延伸到远端圆弧。
- 表现上射出 `8` 根箭矢；权威命中对每个符合范围的目标造成 `70` 点伤害。
- 命中单位减速 `1.0 s`，速度倍率为 `0.55`（保留 55% 移速）。
- `impact_delay = 0.62 s`，`cast_duration = 1.833333 s`；施法期间锁定移动、普通攻击和朝向。
