# Godot 新手速成（本项目专用）

> 只讲你运行和看懂这个项目需要的东西，全面学习请配合官方教程。

## 一、怎么运行游戏

1. 双击打开 Godot.app（首次打开 macOS 可能提示安全验证：系统设置 → 隐私与安全性 → 仍要打开）
2. 启动器界面点 **导入（Import）** → 选择本项目里的 `project.godot` → 打开
3. 进入编辑器后按 **F5**（或右上角 ▶ 播放按钮）运行游戏
4. 再按 **F8**（或右上角 ■）停止

**游戏操作**：点底部卡牌 → 我方半场（下方绿色区域，会亮起蓝色高亮）点击任意位置 → 单位出兵。金币不够时卡牌是灰的。摧毁上方金色国王塔获胜。

## 二、报错怎么看

- 运行时报错会显示在编辑器底部的 **调试器（Debugger）** 面板
- 代码语法错误在保存时就会提示，比如刚才的 `Parser Error`
- 把错误信息原文发给我即可修复，不用自己研究

## 三、看懂这个项目的 5 个核心概念

**1. 节点（Node）与场景（Scene）**
游戏里的一切都是"节点"：战场、塔、单位、按钮。节点组成树状结构叫"场景"。我们的主场景 `main.tscn` 只有一个根节点，所有内容都是代码动态创建的。

**2. 脚本（.gd 文件）**
每个节点可以挂一个脚本控制它的行为。`extends Node2D` 表示这是一个 2D 节点。

**3. 生命周期函数**
- `_ready()`：节点进入场景时执行一次（初始化）
- `_process(delta)`：每一帧执行（游戏逻辑），`delta` 是距上一帧的秒数
- `_unhandled_input(event)`：UI 没消费的输入（我们用它处理战场点击）
- `_draw()`：画图形（占位美术全靠它）

**4. 信号（Signal）**
节点间通信的方式。比如金币变化时 `changed.emit(elixir)` 发出信号，UI 里 `connect` 了 `_refresh` 就会自动刷新。

**5. 组（Group）**
给节点打标签。所有单位和塔都在 `combatants` 组里，单位找敌人就是遍历这个组。

## 四、本项目文件速查

| 想改什么 | 改哪个文件 |
|---|---|
| 卡牌数值（血量/伤害/费用） | `scripts/data/card_db.gd` |
| 金币回复速度、上限 | `scripts/elixir_manager.gd` 顶部常量 |
| 塔的血量/攻击力/位置 | `scripts/main.gd` 顶部常量 |
| 敌方出兵频率 | `scripts/main.gd` 的 `_enemy_timer = 6.0` |
| 战场尺寸 | `project.godot` 的 window 尺寸 |

## 五、改代码的正确姿势

1. 在 TRAE 里直接改（推荐，可以让我改）
2. 改完保存，Godot 编辑器会自动重载
3. 按 F5 重新运行看效果

**常见坑**：
- GDScript 用**缩进**区分代码块（和 Python 一样），且必须用 Tab，不能混空格
- `:=` 是自动类型推断，推断不了时会报错（就像刚才那个），改成 `变量名: 类型 = 值` 即可
