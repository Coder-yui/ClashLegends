## 共同边界

权威结果由[动作合同](ACTIONS.md)决定，模型和声音只消费状态与真实事件。当前可用字段见[动画配置](../reference/ANIMATION_CONFIGURATION.md)、[音频事件](../reference/AUDIO_EVENTS.md)，素材按[音频流程](../AUDIO_INTEGRATION.md)接入。以下目标规则不表示现有派发、播放器或 schema 已完整支持。

## 模型：控制命中时如何处理

| 硬控 | 普攻被实际打断 / 普通移动 | 正在技能、变形或部署 |
| --- | --- | --- |
| 眩晕 | 当前姿态短混合到 Idle 并循环 | 动作继续；结束仍眩晕才混合到 Idle |
| 击退 / 强制推拉 | 短混合到 Idle，权威位置带动模型平移 | 动作继续，位置仍受推拉影响 |
| 禁锢 | 不打断原地攻击；无圈内合法目标时 Idle | 动作继续，自主位移受限制 |
| 嘲讽 | 实际打断者混合到移动或新攻击；正在攻击嘲讽者不重播 | 动作继续，后续普攻目标受约束 |
| 冰冻 | **施加瞬间冻结当前姿势**，冰霜材质/特效 | 同样立即冻结，不允许技能/转换/部署先播完 |
| 凝滞 | **施加瞬间冻结当前姿势**，金身材质/特效 | 同样立即冻结，不允许技能/转换/部署先播完 |

冻结时不得先混合到 Idle、播放控制起手或额外推进几帧；保存当前可见姿势，但取消的逻辑动作身份立即失效。重复刷新不重新捕获导致姿势跳动，不重复播进入音。客户端收到有效权威状态后立即应用，不靠本地计时决定玩法解控。

解冻后从冻结姿势混合到**当前合法的新动作**，不续播旧 Attack/Spell/转换/部署。若还眩晕则 Idle，仍禁锢可原地攻击，另一冻结来源仍在则保持冻结；部署或转换尚未完成则保留其行动锁。混合到新动作的配置首帧，不要求回到原始素材第 0 帧。

短混合只改变姿态，不延迟新前摇、不补旧命中、不等待 `stun_exit` 才行动。Idle 是眩晕/推拉打断普攻后的统一基线，不要求新增专门受控动作。没有完整眩晕片段也必须正常表现规则。

## 优先级与清理

主骨骼动作优先级：死亡/退场 → 冰冻/凝滞姿势覆盖 → 仍合法继续的技能/变形/部署 → 眩晕或外部位移 Idle → 其他合法特殊动作 → 普攻 → 移动/待机。先锋准备/恢复按其专属规则，不冒充普通技能保护。

材质与局部标记独立叠加：冰冻 + 击退保持冻结姿势随权威位置移动；冰冻 + 眩晕先显示冻结，冰冻结束仍眩晕才转 Idle。冰冻与凝滞同时有效时，姿势持续冻结；金身与冰霜冲突的材质优先级暂取凝滞，实例结束后展示仍有效材质，不重新激活动作。

未被打断的连续普攻保留 `Attack1 → 末帧保持 → Attack2` 的原节奏；被打断后按完成段号选择新攻击，不能一律回到 Attack1。持续普攻、强化攻击也使用新的动作实例去重。

自然换形可在冻结期间到期；战斗形态立即按规则更新，表现保持冻结覆盖，不播放转换。不同模型无法复用姿势时须制作确定的冻结姿态衔接并实际目视验收，不能靠延长形态寿命规避。死亡始终解除冻结覆盖并播放正常死亡；致死复生和死亡替身同样优先于旧冻结，直接衔接复生/变蛋表现，不等待硬控到期。换模型、回收、跨局必须清理姿势、材质、速率、动作 ID 和附属特效。

眩晕回退 Idle 之前必须消费新出现且仍有效的权威技能/变形/部署动作，不能用“模型是否已经播过一帧”判断 Cast Start。首次快照同时包含动作与眩晕时也按权威经过时间定位；已结束或累计取消屏障之前的动作不从头补播。冰冻优先、形态代次和动作取消身份仍先于新动作，模型与音频使用相同身份。

身体方向与施法命中方向独立保存。眩晕、冰冻期间根节点不继续朝旧移动方向或目标方向插值；冰冻命中时保留已显示朝向及姿势，外部位移仅改变位置。眩晕中的受保护骨骼动作继续播放，不授予自主转向。解控重新读取当前合法方向，模型复用及新实体不携带旧控制锁。

## 特效：按所有者处理

冻结模型姿势不等于暂停单位下全部粒子、材质动画和特效节点。特效记录动作、命中、弹体、Buff、区域等所有者身份，但不直接套用声音的取消策略；空间挂载与播放寿命分别定义。

| 特效归属 | 对应动作被取消后 |
| --- | --- |
| 普攻挥刀拖尾、持续普攻喷吐/光束 | 对应普攻取消时停止生成并清理；不留下静止喷吐 |
| 依赖施法动作的技能特效（瑟提梯形、格温扇形、纳尔框等） | 眩晕时随受保护技能继续；冰冻/凝滞取消技能时同步取消对应范围特效，不保留待恢复 |
| 已释放的独立结果及其特效（龙王星辰、弹体、独立区域、真实命中） | 按自身生命周期继续；来源之后被晕/冻/凝滞不取消其运动、落地伤害或后续特效，仍检查目标准入 |
| 已有 Buff 附着特效 | 挂在模型上，随模型位移，按实例寿命继续播放；凝滞不因玩法贡献抑制而删除或冻结该特效 |
| 冰霜、金身、控制标记 | 按当前有效控制显示，刷新不重复创建 |

依赖动作的技能被取消时，其未释放效果和范围特效一起取消；已释放独立结果继续，Buff 特效存在不表示凝滞中的 Buff 贡献仍有效。冰冻/凝滞取消未释放技能效果、凝滞抑制 Buff 的权威规则不变；动作声音仍按声音合同取消，不能因特效继续而保留声音。独立的可交互/实时生效提示读取真实权限，不用特效是否可见判断命中。

### 空间挂载

- 随身技能范围特效（瑟提梯形、格温扇形、纳尔框）持续跟随模型显示位置，被击退/推拉时一起移动；对应尚未结算的伤害范围也以施法者当时的权威位置为起点，不能只移动图形而保留旧伤害位置。方向按本次技能既定方向，不因平移重新瞄准。
- 远程技能弹体在实际创建时确定世界起点及轨迹参数，之后独立运动，不继承施法者后续位移；这不是弹体停在创建点。尚未创建的弹体遇技能取消不再生成。
- 单位身上的 Buff 特效锚定模型/指定挂点，不残留在施加位置；模型骨骼冻结不暂停其独立特效时钟。
- 明确固定落点的地面区域保持世界坐标，不因来源位移迁移。

是否独立按效果定义的创建节点与归属判定。**龙王星辰特效一旦创建，就同时成立独立星辰结果**，不再等待龙王后续动作节点：冰冻/凝滞只冻结龙王模型动作，不暂停或取消该星辰的坠落、落地伤害及后续特效，眩晕也不影响它。此节点由权威逻辑提交，表现只消费创建事件，不能由客户端粒子生成反向驱动伤害。该规则专属于星辰这类已独立创建的结果，不让瑟提梯形等依赖动作的特效自动获得独立性。恢复 Buff 贡献不重播获得特效，迟到事件不重复创建已有特效，也不生成已被取消的后续释放特效。

## 音频：按声音归属取消，不能按整个单位静音

**普通攻击与强化攻击都区分挥舞声、真实命中声和弹体声。**只有属于被取消动作的声音被中断；命中结果、弹体及 Buff 拥有自己的生命周期。

| 声音归属 | 被控后如何处理 |
| --- | --- |
| 近战普通/强化挥舞声 | 对应攻击实际打断时停止正在播放的声音，取消待播节点；未命中只有挥舞声 |
| 远程抬手/挥舞/发射前准备声 | 对应攻击实际打断时停止，取消未到达节点 |
| 真实近战/远程命中声 | 只在真实命中时触发；不因攻击者受控而停止或漏播，未命中不伪造 |
| 已创建弹体的发射、飞行、尾音、命中声 | 不被攻击者受控打断；按弹体命中、失效、播完等实际生命周期结束 |
| 普通技能动作声（起手/蓄力/维持等） | 眩晕、击退、禁锢、强制推拉、嘲讽不中断；冰冻/凝滞取消本次技能时停止，后续节点不再播放 |
| 变形 / 部署动作声 | 前述五类硬控不中断；冰冻/凝滞时停止，解除后不续播、不重播 |
| 已成功施加 Buff 的获得声、持续声 | **不因硬控打断**，包括冰冻/凝滞；Buff 继续计时，凝滞中玩法贡献被抑制；声音按自身播放与效果生命周期管理，音轨继续不代表 Buff 生效 |
| Buff 消费、到期、移除声 | 仅在相应真实状态变化时播放；攻击被取消不伪造 Buff 结束 |
| 护盾、已落地独立区域的声音 | 随盾层/区域的生命周期，不因来源动作取消或受控暂停 |
| 控制施加/移除声 | 真实转换一次；刷新不重播，剩余控制承接不再播第二次进入音 |
| 全局暂停、死亡、清场 | 全局暂停保留有效音轨进度；死亡清理自身所有者，清场清理本局。独立结果只要仍存在就按自己的规则处理 |

“弹体声不中断”以**权威弹体已创建**为前提。动画中的假弹体、发射预备声仍归攻击动作；弹体已失效则不为了“不中断”强留循环声。来源受控与弹体自身失效是不同结束原因。

“Buff 声不中断”包括已经开始播放的获得声，即使随后取消的是施加它的技能；不能只按名字包含 `skill`、`empowered`、`start` 或 `sustain` 决定所有者。未成功施加的 Buff 没有获得音。声效播完不会强制循环，Buff 到期也不等声音播完才结束规则。

### 盖伦强化普攻示例

获得强化时，`empowered_buff:start` 是 Buff 获得声；如有 Buff 持续声也归该效果。强化挥刀的 `empowered_swing` 归本次攻击，真实命中声归命中结果。

盖伦在强化前摇中被控：挥刀声停止；已经获得的强化及其 Buff 声保留，不播放虚假的 `empowered_buff:end`。解控后若强化仍有效，重新起手播放新的挥刀声，不重播获得 Buff 的声音。已经出手消耗强化时，Buff 正常结束，不因攻击后来被控返还或重播。

### 技能声音的例外不是按卡牌区分

凝滞中的 Buff 无玩法效果，但音频仍按独立生命周期处理；离开凝滞恢复剩余贡献时不重播 Buff 获得音。

一项技能可以同时拥有动作声、Buff 声、弹体声与区域声。冰冻/凝滞取消施法，只停止它的动作声；已有 Buff 实例和音轨继续（凝滞抑制其玩法贡献），弹体与独立区域按自身规则继续。真实效果命中再播放真实命中声；取消后不播放虚假的成功释放或正常完成音。

玩家听到的命中声可以按并发预算去重/合并，但不能因为攻击者受控就删除合法命中。音频不产生伤害，也不反推攻击段完成或纳尔计数。

## 属性变化与可见性不替代动作打断

加减移速只改变允许自主移动时的步频；加减攻速只改变仍有效的普攻时间线和对应动作节奏，不影响普通技能、部署、变形、外部位移或冻结姿势。声音的未触发节点跟随所属时间线，已开始的采样默认保持原音高和播放速度，不能因倍率刷新重播节点。

增益、软控和不可选中不自行切换主骨骼或停止动作声。隐身只按观察方过滤表现，不能取消权威动作；恢复可见时显示当前状态，不补播隐藏期间的旧声音。凝滞中的玩法抑制与独立 Buff 音轨保留分别处理，真实伤害/收益反馈必须有对应回执。

## 实施所需身份与缺项

声音需能关联 `(会话, 实体代次, 所有者类型, 动作/弹体/Buff/区域实例, 声音层)`。只按单位 ID 清理会误停 Buff 和弹体；只取消待播节点又无法停止已经响起的挥舞声。事件应区分开始、释放、命中、完成、取消及自然到期，迟到或重复事件不能恢复旧动作声音。

模型冻结需先保存命中时姿势再做播放器取消，防止停止播放器将姿势重置。声音实际停止采用立即停止或极短防爆音淡出，不得保留可听见的旧动作长尾或解控后续播；最终以试听验收为准。

隐身观察阵营过滤独立于控制取消；可见性规则仍覆盖血条、阴影、附属特效和定位音源，公开弹体/区域按自身公开规则播放。

卡牌页记录动作/材质/特效、各声音的所有者与终止条件、缺素材回退、蓝红/形态覆盖、目视和试听结果。缺声音不阻止机制；未支持事件不得只填资源路径宣布接入完成。

## 通用单位附着提示

表现采用位置、形状和运动方式共同区分，硬控制的视觉优先级高于软控制；依据 [Riot 的可读性说明](https://www.leagueoflegends.com/en-au/news/dev/clarity-in-league/)中“保留信息层级、控制视觉噪声”的原则。具体配色和图形是本项目的设计选择，不表示行业统一标准。

| 状态 | 颜色与形态 | 播放条件 |
| --- | --- | --- |
| 回血 | 淡绿小十字分别上浮，辅以微弱细环 | 真实生命增量触发 0.7 秒脉冲；三个十字分别延迟 0 / 0.13 / 0.26 秒出现，各自上浮淡出 |
| 移动减速 | 黄色贴脚短拖痕，朝移动反向淡出 | 有效减速且发生自主移动时循环；静止、被挡住、眩晕、外力击退和传送不凭移动意图伪造拖痕 |
| 减攻速 | 冷灰蓝竖直刻线错落下落，位置、周期和出生相位各异；线长较初版增加 30%，固定 X 坐标，无横向摆动，平均密度为初版的 80% | 整个有效状态期间持续循环，与是否移动、攻击或眩晕无关；不逐帧随机抖动 |
| 眩晕 | 头顶紫色扁平漩涡持续旋转 | 单位和防御塔读取有效眩晕；骨骼停住时漩涡仍转动，状态到期/死亡清除 |

软控只读取仍有效、未被免疫抑制且倍率小于 1 的减益；增益把最终速度抬回 1 以上时仍保留减益身份。回血、移动减速、减攻速共用 3D 代理投影的离地平面，空军随升降；眩晕使用模型头顶投影，单位放在血条上方避开生命信息，防御塔使用模型高度锚点。无模型对象回退到自身位置与体型高度。场地倒转时符号保持屏幕直立。

所有动画只使用渲染相位和只读状态；不修改权威位置、碰撞、寻路或状态时间。刷新状态不重置循环相位。客户端通过快照读取有效减速、减攻速和眩晕，移动拖痕额外读取实际渲染位移与行动权限，不自行倒计时移除。治疗术的大面积效果仍表示施法，独立于单位受疗提示。

### 统一接入约定

当前所有回血、移动减速、眩晕、减攻速的**受影响对象提示**必须使用上述通用特效；不按英雄、技能或来源另画一套。不需要逐卡填写特效路径。

| 效果入口 | 已接入来源 | 通用表现入口 |
| --- | --- | --- |
| `Unit.heal()` / `heal_with_overflow()` | 治疗术及强化/过量治疗、天使治疗、格温满层首次命中回复、凯隐三形态入地形、红凯 Q 命中、赵信/红凯普攻回血、恕瑞玛回复盾到期 | 实际生命增加 → `_present_heal_gain()` → `restoration_heal_effect.gd` |
| `Unit._try_attack_lifesteal()` | 皮克斯授予的吸血、剑魔攻击吸血、赛恩亡魂吸血 | 实际生命增加 → 同一 `_present_heal_gain()`；支持溢出生命上限 |
| `Unit.apply_slow()` | 寒冰技能、冰鸟技能/区域、龙王冲击波、强化冰冻后续区域、工作台 | 有效状态 + 实际自主移动 → `soft_control_effect.gd` 黄色拖痕 |
| `Unit.stun()` / `Tower.stun()` | 纳尔技能、龙王落星及通用技能命中、工作台 | 有效眩晕 → `stun_effect.gd` 紫色漩涡 |
| `Unit.apply_attack_speed_slow()` | 当前工作台通用减攻速入口；新卡复用同一入口 | 有效减攻速 → `soft_control_effect.gd` 冷灰蓝垂直下落线 |

客户端回血走既有可靠表现事件；其他三类状态走快照与只读状态。`restoration` 旧名称仅为兼容调用/网络入口，不表示只供恕瑞玛使用。当前没有正式卡牌主动施加减攻速，不为展示特效而新增玩法。

治疗术的范围光效、冰冻/减速区域、技能弹道及命中特效继续承担施法或范围信息；它们不能代替对象身上的通用状态提示。复生填血条、初始化生命、变形调整生命上限不属于治疗，不伪造回血提示。新增真实回血必须进入上述通用实际增量入口，不能只修改 `hp` 而遗漏表现。
