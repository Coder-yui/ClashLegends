## 扩展未支持状态时的合同

规则正文分别由[硬控](HARD_CONTROL.md)、[动作](ACTIONS.md)、[特殊状态](SPECIAL_STATES.md)、[增益](BUFFS.md)和[表现](PRESENTATION.md)维护，此处只列扩展检查点；其中对现有攻击、纳尔和联网的要求是已有边界，不是重复迁移待办。

| 领域 | 实施要求 |
| --- | --- |
| 攻击打断 | 取消旧前后摇/间隔，按近战命中或远程创建弹体维护段号；不要重置整个循环 |
| 控制响应 | 分开眩晕与冰冻；普通技能/转换/部署对五类控制继续，对冰冻/凝滞立即冻结并按各自规则结束 |
| 嘲讽 | schema/validator 禁止空中单位/形态提供能力；运行时检查来源，到期清除强制目标并重新普通选敌，不保留强制追击路径 |
| 凝滞 | 保留碰撞且不可推动，进入不额外整理位置；下牌冲突只调整新单位到最近合法落点，结束恢复现有接触分离。拒绝选取/伤害/新 Buff，已有 Buff 抑制且照计时 |
| Buff 生命周期 | 抑制、恢复、自然到期与重新施加分开；不因解除凝滞重发加血、周期收益或获得音 |
| 纳尔 | 命中计数与攻击段分开；只在冰冻/凝滞时记录一次待变形，两者都解除即可触发，其他控制仍有效 |
| 音频所有者 | 分开动作、命中、弹体、Buff、区域；取消动作不误停独立声音，也能停止已播放的挥舞声 |
| 联网 | 同步足够的当前权限、动作身份及抑制表现，重复/晚到消息不能恢复已取消动作 |

当前尚需具体化的内容：位移技能截停后的各段归属、入场首批召唤归属、跨模型冻结姿势衔接；相关卡牌接入前须有明确规则和验证。仍标注“暂定”的数值、隐身等专题按其所属页继续评审。

动作接入还须覆盖：完整攻击周期与同目标嘲讽、技能动作与位移保护分离、转向权限、解控后的强制形态变化优先级。生命周期维护独立于可取消的战斗完成奖励；控制新增/刷新/抑制恢复事件分开。凝滞拒绝重复施加，退出不重施旧控制；净化复用恢复流程。特效与声音按所有者取消，避免冻结或清理整个单位的全部表现。对应规则见动作、特殊状态、共通规则与表现合同。

## 当前职责与扩展边界

当前所有者见[维护架构](../MAINTENANCE_ARCHITECTURE.md)：StatusInstances、ControlState、AttackTimeline、ShieldState、StructureRushState 继续复用；资格在 ActiveSkillRoster，效果排程在 CommandSchedule，普通击退轨迹在 KnockbackState（不提供强制位移能力）。Unit 汇合权限并编排形态/技能资源，不再另造 StatusState。

新增内容继续放四域定义，新增字段必须有读取方、类型/范围、能力校验及回归。未实现效果在加载时拒绝；正式施加用 freeze/stun/apply_* 等准入接口，网络使用显式副本接口。测试窗口构造在 SuiteUtils 中，不给 active_buff_timer 提供生产 setter。

旧迁移计划保存为[历史快照](../archive/2026-09-22/status_implementation_before_cleanup.md)。未来机制的待定项和目标验收仍见所属规则页与[验收清单](VALIDATION.md)，不要求新 agent 先重做已完成迁移。

## 网络与性能

权威实例只在主机推进；客户端不得根据渲染时间自行判定解除眩晕、毒伤、护盾到期或重新取得攻击资格。客户端可以插值/估计剩余时间用于显示，但玩法结果以主机状态为准。

扩展快照应传递必要的权限、表现家族、动作身份/代次、阶段进度、可见性相关视图和盾量等，而不是复制所有执行器内部字典。短暂动作取消、状态开始/结束使用现有事件通道可靠去重，快照再作状态收敛。事件过时或所属动作已取消时，不补播过期技能。

实施前读取实际协议与载荷定义；新规则/载荷同步提高协议版本、更新双方读写与内容校验，不声称旧客户端可无修改兼容。当前核对版本见[网络协议](../reference/NETWORK_PROTOCOL.md)。

图奇按用户定义区分玩家观察与单位感知：双方玩家看到公开位置及虚化模型，敌方单位/塔索敌排除他。无需对玩家裁剪图奇坐标。未来若实现玩家视野隐藏，需要另行定义数据裁剪，不沿用此公开视图语义。

性能实施原则：按来源/目标维护紧凑实例；同一区域续期同一实例而非每 Tick 分配新对象；权限/数值只在增删、强度改变、抑制改变时标脏重算；复用现有目标查询和移动几何；不让所有状态各自扫描全体单位。死亡、形态切换、清场和模型池回收及时释放引用。

验收记录状态实例峰值、每 Tick 推进耗时分布、区域目标数、网络快照字节数、音轨数与表现丢弃数。不能仅凭代码看起来更抽象就宣称性能提高；战斗过程流畅性仍优先于减少开局预加载。

## 特效挂载与控制时钟现状

`BattleEffects2D._draw_frontal_skill_effect` 对非固定范围特效读取来源模型显示位置，符合随身技能范围跟随位移的规则；`ProjectileSystem.launch_skill_fan` 保存创建位置/方向，后续独立推进；`UnitModel3D` 将 ActiveBuffVisual3D 挂为子节点并独立 advance，符合随身 Buff 挂载。

`SkillEffectPresentation.tick_visuals` 按动作身份清理依附施法的范围：眩晕继续，冰冻取消。固定独立区域和星辰按自身时间推进；`apply_frontal` 仍按每次结算的位置查询目标。凝滞未实现，不能宣称已验证。实际画面与声音的验收状态见交付记录。

奥恩的友方增幅复用 CombatInteraction 的复生/阵营判定，并读取 StatusInstances 的 stasis / untargetable 状态族作为准入边界；专项夹具覆盖此边界，不代表通用凝滞或不可选中的完整施加、权限与联网链已实现。赛恩与冰鸟致死取消依赖原有生命/实体生命周期，无新增专用转换逻辑。

## 一次性永久成长

已接入璐璐：ActiveSkillEffectSystem选择目标并施加，Unit保存一次性生命增量/体型倍率，Main按一次性退款收据回退空目标释放，当前协议74投影成长状态（该字段自73加入）。LuluSuite覆盖召唤、目标、属性、换形与退款，网络生命周期套件覆盖非法/重复载荷。规则见[增益](BUFFS.md#一次性永久成长)；不代表通用限时最大生命或凝滞抑制系统已实现。

## 图奇脱战隐身与远程增益

已实现普通单位stealth_delay：生成隐身、攻击起手破隐、开启技能不破隐、攻击施法与受伤刷新2秒窗口；敌方单位/塔索敌过滤，已释放弹体和范围结算继续。每单位独立StealthState；客户端接收布尔状态以显示虚化，双方玩家均可见。buff的range_bonus/piercing_attacks/piercing_distance由StatusInstances管理，出手固定直线轨迹、独立飞行距离和每箭命中集合，穿透保留普通攻击归属。不是通用Reveal或多来源隐身实现。

## 凝滞法术接入（2026-09-30）

此前表格中“凝滞未实施”的描述由本节更新：Unit.apply_stasis、ControlState、CombatInteraction、StatusInstances贡献抑制、MovementSystem、单位快照U_STASIS和金身材质已接入。法术仅作用Unit（含建筑卡），不作用Tower。StasisSuite覆盖到期、免伤、治疗拒绝、重复施加与部署避让；完整规则交叉场景与双机验证仍按交付列明，不能将本节理解为所有目标验收已通过。

### 空中路径突进（卑尔维斯）

通用dash_strike现支持飞行来源、仅空中命中与关闭结束旋转。默认凯隐行为不变；卑尔维斯沿当前朝向突进3格，逐次施法按目标身份去重。继承冰冻取消、眩晕不中断已开始技能、外部击退接管和场地边界终止。死亡8只召唤物复用通用死亡召唤与可靠生成事件。专项BelvethSuite覆盖双方距离、目标排除、去重、死亡单次召唤、控制与字段错误。

## 凝滞规则收敛与在途法术（2026-09-30）

保留动作取消后重新行动。先锋仅冲撞阶段拒绝双方凝滞；已建立赛恩爆炸盾、黄沙庇护恢复盾可在凝滞中自然到期结算，普通收益仍禁止。永久成长与奥恩永久增幅保留，不经普通Buff抑制；凝滞/Buff同批沿用当前顺序，其他批次规则不变。

SpellSystem以可选flight_speed（正数）和flight_min_duration（非负数，默认0）统一调度无碰撞、无追踪的在途法术；未配置者仍瞬时结算。公共出牌10Tick延迟之后才发射，抵达重新查询目标。凝滞用900px/s、最低0.4秒。表现读发射/抵达Tick，爆炸及声音由权威抵达事件驱动，协议78。DeploymentRules复用UnitLandingQuery处理凝滞占位，普通可推动和冰冻自然碰撞不变；玩家无解复用建筑等待队列，召唤/复生按全场几何。StasisSuite覆盖这些边界。

凝滞范围已包含双方防御塔，水晶免疫；塔共享硬控计时和交互准入，取消攻击后重新起手，协议79同步凝滞布尔状态。
