逻辑测试后仍需实际渲染与试听：尤其是冻结解除后的第一击、眩晕退出与新攻击混合、龙王循环声停止、先锋恢复、隐藏音源、模型池复用。这些不能只靠 headless 测试宣布通过。

## 通用打断与恢复边界

| 编号 | 场景 | 期望 |
| --- | --- | --- |
| A106 | 受保护技能的自主冲刺遇眩晕/禁锢/外部推拉 | 动作保护不保护位移；截停或被接管，解控不续冲、不补距离、未碰撞不发撞击伤害；专属保护另按声明验证 |
| A107 | 模型已待机但攻击间隔未完时受短控制 | 旧周期作废，解控完整新前摇；可早于原下一刀，刷新及解除不再次重置 |
| A108 | 正等待再次攻击同一嘲讽者时被其嘲讽 | 保留剩余攻击间隔，不通过嘲讽刷新攻击速度 |
| A109 | 已凝滞目标再次收到自身/友方/敌方凝滞或普通净化 | 请求被拒绝，不刷新延长、不解除；同批多效果按捕获视图准入，与遍历顺序无关 |
| A110 | 凝滞结束仍有其他控制，或控制被提前净化 | 重算剩余权限，不重施旧控制、不重置周期、不续旧动作/轨迹；凝滞自身不被 Buff 抑制 |
| A111 | 剑魔转换或单位部署中被冻结 | 生命周期维护和锁到期正常执行；大灭寿命正常起算，附带未释放战斗奖励依动作归属取消 |
| A112 | 解冻时纳尔待变形、技能请求与普攻同时就绪 | 先处理生命周期及权限，再待变形和行动锁，最后技能/普攻决策；无先发小形态攻击 |
