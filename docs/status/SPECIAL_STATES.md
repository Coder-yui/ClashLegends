# 特殊状态：交互保护、免控与动作保护

> 本页定义目标规则，已实现子集见 [IMPLEMENTATION](IMPLEMENTATION.md)。

[返回总览](README.md)

## 先区分这些名称

| 名称 | 本方案的精确含义 |
| --- | --- |
| 不可选中 | 必须注明敌我、锁定与命中范围；下文提供“敌方不可选中”预设 |
| 隐身 / 潜行 | 改变敌方感知与新锁定，不等于免伤 |
| 凝滞 | 保留碰撞，不可选中或受伤；已有 Buff 计时但不生效 |
| 无法控制 / 免控 | 文案统一写“控制免疫”，必须列明拒绝的控制标签 |
| 不可打断 | 指定动作的保护，不等于整个单位免控 |
| 无法阻挡 | 不是可直接配置的单一状态；按下表拆成明确能力 |
| 无敌 | 当前未定义通用预设；不可借用隐身、免控或凝滞来冒充 |

## 表现与硬控交互速查

| 特殊状态 / 能力 | 实际影响 | 动画与音频处理 |
| --- | --- | --- |
| 敌方不可选中 | 改变敌方选取和新命中准入，不自动免疫已附着效果；友方增益按原目标规则 | 本身不取消动作、不冻结模型或停音；使用独立标记，仍受已有控制 |
| 隐身 / 潜行 | 按观察阵营改变感知与锁定，按规定事件破隐；不改变碰撞 | 权威动作正常推进；敌方模型、血条、附着特效和定位音源按可见性过滤，友方表现正常；显形不重播旧动作/声音 |
| 凝滞 | 冻结姿势、隔离交互、不可推动；已有 Buff 计时且抑制 | 立即金身冻结，取消对应动作声音及普攻拖尾/喷吐；依赖施法动作的范围特效随技能取消，已释放独立结果及 Buff 附着特效继续，独立 Buff、弹体音轨按原合同，退出不续播 |
| 控制施加免疫 | 拒绝标签匹配的新增敌方控制，不净化旧控制 | 不切动作、不停旧动作声；被拒绝控制不显示成功控制标记/声音 |
| 既有控制抑制 | 实例计时但不贡献声明范围内的限制 | 按当前有效权限选择动作；已取消动作不会复活；抑制恢复不重播施加效果 |
| 净化 | 移除声明范围的已有控制，不解除部署/恢复等自身锁 | 可播放一次真实净化反馈，再按剩余控制承接；不续旧动画/声音 |
| 外部位移免疫 | 拒绝新增推拉/吸引，是否终止既有轨迹须明确组合规则 | 不自带冻结或动作保护；其他合法硬控仍照常表现 |
| 动作不可打断 | 仅保护明确的动作范围，普通技能保护不抵抗冰冻/凝滞 | 受保护动作按原时间线继续；不自动获得转向、移动、免伤或免控 |
| 自身恢复锁 | 限制新动作，按自己的计时结束，不属于敌方控制 | 正常播放该动作；硬控覆盖按动作合同，净化不提前结束恢复 |

可见性、材质、骨骼与声音所有权分别判断：例如隐身且冰冻的单位，对有权看见它的一方显示冻结姿势，对无权看见的一方仍隐藏，不能用冰霜特效泄露位置。普通 Buff/软控不会改变既定硬控骨骼优先级。

### “无法阻挡”必须写清楚

| 卡牌真正需要的能力 | 使用规则 | 不额外获得 |
| --- | --- | --- |
| 冲锋期间不吃新增控制 | 限时控制免疫，声明标签 | 不自动清除旧控制，不免伤 |
| 不被推走、拉走 | 外部位移免疫 | 不免疫眩晕、沉默等其他控制 |
| 当前技能继续释放 | 动作不可打断 | 不自动获得移动、转向权限 |
| 不被单位身体挡住 | 单独的单位碰撞例外，尚未设计/实现 | 不默认穿墙、过河、穿建筑 |

卡面可以用简短名称，机制定义必须展开。先锋冲撞以其阶段规则为准，不能把“无法阻挡”理解成四项能力全开。当前设计：眩晕、击退、禁锢、强制推拉、嘲讽不取消已开始普通技能，控制即时计时，技能完成后只承受剩余控制；冰冻/凝滞则立即冻结模型、停动作音并取消技能后段。动作继续只豁免其自身门禁，不允许开始被禁止的新动作；仍检查目标合法性和位移权限，死亡/清场始终终止自身动作。完整规则见[动作合同](ACTIONS.md)。

### 控制免疫、减速免疫与动作保护

必须区分以下能力：

| 能力 | 意义 |
|---|---|
| 控制施加免疫 | 拒绝匹配标签的新增敌方控制 |
| 既有控制抑制 | 状态实例仍计时，但临时不贡献某些限制/倍率 |
| 净化 | 移除指定已有控制 |
| 外部位移免疫 | 拒绝推、拉、吸引，不自动免疫其他控制 |
| 动作不可打断 | 保护指定动作，不自动免疫掉血或所有行动限制 |
| 自身恢复锁 | 自己做动作的代价，不属于敌方控制 |

**暂定通用“控制免疫”默认只拒绝新控制，不自动净化已有控制。**已有击退已经接管时，后来获得仅施加免疫并不会凭空撤销旧轨迹。需要立即解控的技能应明确组合净化/中止位移；不能解除后又让旧轨迹继续。

当前高原血统一类 ignore 标记还会抑制已有减速。将其表达为“拒绝新减速 + 持续抑制旧减速”，保留其特殊能力；不要因此让所有新增免控 Buff 都暗含净化。

通用敌方控制集合暂定包括：眩晕/冰冻、禁锢、嘲讽、沉默、致盲、减速、减攻速、击退、强制推拉、吸引，以及敌方施加的凝滞。中毒/流血的伤害不在集合内；一招同时有伤害和眩晕时，只拒绝其中控制部分。自身施法锁、先锋恢复锁、部署锁不在集合内。

### 净化与提前解除

净化只移除声明范围内的已有控制。提前解除与自然到期共用权限重算及动作恢复流程，不续播旧动作；剩余控制和自身行动锁继续生效。普通净化默认不能作用于凝滞目标；若需解除凝滞，必须显式定义专门的解除能力，不能绕过通用交互门禁。

## 可见性与交互

### 本方案采用的默认解释

本方案暂定：友方可治疗/增益敌方不可选中的单位，凝滞中则不接受。敌我交互因此不能共用一个 `targetable` 开关；凝滞使用下文的完整隔离规则。

“无法选中”有多种游戏解释。**本方案暂定采用较强的‘敌方不可选中’预设：禁止敌方新锁定，也拒绝新的敌方直接/范围命中，但不清除已经附着的持续效果。**它仍不是完全无敌，因为已有中毒可继续扣血、既有控制可继续限制动作。若某张卡只需要“不能被定向锁定，但仍可吃范围伤害”，用单独的锁定权限配置，不修改这个预设的统一含义。

### 当前落地：按来源与固定结界判断不可选取

“不可选取”与本页“敌方不可选中”为同一交互规则。`CombatInteraction`分别接受来源实体、阵营、备用位置和已附着标记；没有全局targetable开关。格温丝缕缠流是条件版本：仅对中心在固定圣霭外的敌方生效，圈内敌方不受限制。边界相等视为圈内，不叠加身体半径。

伤害及新增状态在收集时判断准入，被拒绝不消耗盾、不产生命中回血/资源/控制；已有附着效果可明确声明attached继续结算。已经存在的控制、Buff、护盾由各自原所有者推进，不清理或暂停。保护实例由TargetProtectionState保存固定中心、半径与20Hz窗口，建立后80Tick结束，移动出圈或死亡提前结束。主机快照同步当前状态，客户端不自行到期。

活来源按当前中心判断；法术卡以施法方水晶为来源，按水晶中心判断，落点仅决定覆盖范围；独立结果在来源消失后使用保存的来源位置。新增敌方效果调用者必须提供来源上下文，空上下文仅供自身维护、已通过批次准入的内部提交与工作台控制测试。非追踪弹体过滤、追踪永久失效、已有锁定脱离及范围效果均已接入；通用DoT仍没有生产卡牌，本次仅提供并验证已附着伤害准入接口。

### 交互矩阵

所有“允许”还要满足阵营、目标类型、范围等普通条件。

| 目标状态 | 敌方新锁定 | 敌方新的范围/非指向命中 | 进入状态前已飞出的追踪弹体 | 已附着中毒/流血 | 友方治疗/加盾/增益 | 自主行动 |
|---|---|---|---|---|---|---|
| 普通状态 | 允许 | 允许 | 正常 | 正常 | 允许 | 按其他锁决定 |
| 真隐身 | 不允许，除非合法显隐/侦测规则已揭示 | 允许 | 暂定继续命中，不凭隐身抹除 | 继续，不自动破隐 | 允许 | 可行动，攻击/施法起手破隐 |
| 受伤显形的潜行 | 同上 | 允许，受到有效伤害会破隐 | 继续；有效伤害会破隐 | 继续；有效伤害会破隐 | 允许 | 同上 |
| 敌方不可选中 | 不允许 | 拒绝新命中 | 追踪关系失效，本枚不恢复追踪 | 继续 | 允许 | 按施加者定义及其他锁决定 |
| 凝滞 | 不允许 | 拒绝 | 追踪关系失效 | 实例计时继续，本次伤害跳过 | 拒绝，包括自己造成的回血收益 | 全部禁止 |
| 仅控制免疫 | 允许 | 伤害仍允许，匹配的新增控制拒绝 | 正常 | 正常 | 允许 | 仍受既有状态与自身动作锁限制 |
| 仅伤害减免 | 允许 | 按倍率减伤，不自动拒绝控制 | 正常 | 按伤害规则减免 | 允许 | 按其他锁决定 |

非追踪技能弹体遇到不可命中的目标，应按合法目标过滤继续飞行，不能把该目标当成首个碰撞对象触发伤害爆炸；对地爆炸等独立区域依本身生命周期执行，但仍逐目标检查交互资格。

已经失去追踪资格的弹体，不在目标结束不可选中后恢复追踪。已经附着的毒与仍在地上产生新命中的伤害区域必须区分：前者可在敌方不可选中期间结算，后者每次新命中都被过滤。

### 隐身破除事件

真隐身在**真实开始攻击前摇**或**真实开始主动施法**时解除。不是按下按钮就解除，也不是等到伤害命中才解除。无效命令、等待攻击机会、寻路、单纯朝向改变不破隐。攻击开始后即使落空或被打断，也已经破隐。

嘲讽不是直接显形标记：被迫走向嘲讽者时保持隐藏；真正开始那次被迫普攻时解除。真隐身受到伤害、眩晕、禁锢等，不额外显形；未来某效果需要揭示目标，必须显式携带 Reveal 规则。

受伤显形的潜行在上述动作事件之外，还在**实际掉血或实际耗盾**时解除。完全免疫导致的零伤害不破隐；既有毒伤可以破潜行。护盾衰减、生命上限到期回收、自身技能的生命代价不当作敌方受伤事件。

赋予隐身的技能不能在赋予后马上被自己的同一次施法起手再次打破：先处理本次 `CastStarted` 的破隐，再施加本次技能授予的新隐身，或声明相同施法实例的排除关系。已经飞出的旧弹体后来命中，不属于新一次攻击起手，不因此再次破隐。

同 Tick 命中致死的潜行单位直接进入死亡表现，不必先闪现一帧存活模型再死亡。

同时携带真隐身与受伤显形潜行时，受伤只移除会被受伤打破的潜行实例，真隐身仍有效；攻击或施法起手则移除两种对应实例。破隐不是简单把一个全局 visible 标记写回真，而是先移除应失效的效果，再重新聚合可见性。


## 凝滞

凝滞属于[七类硬控](HARD_CONTROL.md)，同时隔离战斗交互。生效时立即冻结当前模型姿势并显示金身；取消普攻和技能未释放后段、停止相应动作声音，解除后不恢复旧动作。Buff 和独立弹体音轨按[表现合同](PRESENTATION.md)管理。

### 碰撞、选取与收益

| 方面 | 凝滞期间 |
| --- | --- |
| 碰撞 | 保持原有碰撞；凝滞本身不删除碰撞体、不改变半径/空地层、不使其他单位穿过 |
| 位置与行动 | 停止自主移动、普攻、技能及主动转向；终止已有外部轨迹，拒绝推拉和外力积累 |
| 战斗目标选取 | 敌方、友方均不能将它选为攻击、技能、治疗或加 Buff 的目标；范围效果也逐目标排除 |
| 伤害 | 不承受直接、弹体、范围、已附着持续伤害；拒绝的伤害不消耗护盾、不缓存 |
| 新效果与收益 | 不接受新 Buff、治疗、护盾、状态或单位资源收益，包括自我回复；拒绝不等于治疗溢出 |
| 已有 Buff | 保留实例和剩余时长，计时照走，但数值、触发、周期和依附 Buff 的光环贡献均不生效 |
| 生命周期 | 单位仍存在，不触发死亡、替身或击杀；自然寿命、状态到期和清场照常处理 |

碰撞和可选取是不同维度：其他单位仍需绕行，不能因为索敌列表排除了凝滞目标，就同时从碰撞查询中删除。**凝滞单位不可被推动**，接触推挤和部署挤位均不能移动它。

进入凝滞时直接保持当前位置，不增加位置整理或重叠修复步骤。少量已有重叠不在凝滞期间修正该单位的位置；凝滞结束后恢复现有碰撞推开规则。

下牌落点与凝滞单位占位冲突时，将新生成单位或建筑放到最近合法位置，凝滞单位不动。合法位置仍遵守原有部署范围、地形、建筑和空地碰撞规则；编队逐成员检查。只避开实际碰撞占位，不把整个凝滞法术区域视为禁放区。落点由主机在实际生成时确定；沿用现有生成与碰撞体系，不另设凝滞专属的等待、退款或无落点兜底流程。

### 凝滞自身、已有控制与重复施加

凝滞自身的冻结、交互隔离和不可推动规则始终有效，不受“已有 Buff 无效果”抑制。其他已有控制保留实例并计时；退出凝滞后，仍有效的限制继续约束，不当成重新施加，不重复打断、重播进入音或重置攻击周期。已终止的外部轨迹不恢复。

凝滞期间拒绝新增状态，也拒绝再次施加凝滞，包括自身、友方与敌方来源，因此不能在生效期间刷新或延长。多个效果在同一结算批次进入时，按该批捕获的交互视图分别准入，独立实例按各自时长结束；不以请求遍历顺序决定谁被拒绝。

### 已有 Buff：计时与效果分开

进入凝滞时抑制已有 Buff 的贡献，不删除实例；期间照常到期或衰减。加速、攻速、增伤、减伤、免控等数值/权限增益不贡献，持续治疗、触发收益和依附自身 Buff 的光环不执行。实例所拥有的护盾量、强化次数等剩余数据保留，不因为“抑制”当作消费；自然衰减/到期仍正常结算。

离开凝滞时只恢复仍未到期实例的剩余效果；不重新施加、不刷新时长、不重发获得奖励，也不补发被跳过的周期。凝滞中到期的恢复护盾不回血，之后也不补回。

已完成的一次性治疗或变形不回滚。持续最大生命修饰器同样暂停贡献；临时抑制/恢复本身不额外扣当前生命或再次增加生命，真实到期/形态到期的上限回收仍按数值规则处理。属性聚合与生命周期维护必须分开，不能将“恢复贡献”误识别为新获一次 Buff。

Buff 声音继续播放仅表示其独立音轨仍有效，**不表示 Buff 的玩法效果仍生效**。声音播完、持续层自然结束或实例到期依原音频合同处理，不在离开凝滞时重播获得音。

### 独立结果与退出

凝滞单位已发出的弹体、已建立的独立区域仍按自身生命周期影响其他合法目标；出手时已固化的结果不撤回，不在凝滞中追加来源 Buff 贡献。回流给该单位的吸血、命中回复、技能资源、触发新增益被拒绝且不延期。击杀归因及玩家级记账照常。

纳尔可以记录真实命中及一次待变形条件，但仅在**冰冻和凝滞都解除**后开始变形，不等待其他五类控制结束，见[动作合同](ACTIONS.md)。这不允许缓存其他被拒绝收益。

已有毒、控制等实例继续计时，凝滞期间不能产生伤害，错过的跳数不补发。自然维护可执行：Buff/形态自然到期、有限生命周期结束、清场均不因凝滞延后。退出后根据当前有效状态和形态重新决定行为；仍有其他控制则继续受其限制。

凝滞可由自身、友方或敌方效果提供。敌方版本检查控制免疫，自身保护版不被“拒绝敌方控制”误拦截；能否在被控时开启自保凝滞由该技能的开始资格决定，默认遵守正常门禁。

### 已落地：零血复生的双方不可选取

赛恩的死亡荣耀是专用生命周期窗口：首次致死后保留实体、生命为0，2秒内拒绝敌我双方锁定、直接/范围命中、新状态、治疗与护盾，也拒绝已附着伤害。禁止自主动作，终止旧施法及护盾；不属于凝滞，不提供金身。等待期间血条按进度从0填满，仅作表现，真实生命保持0；首次致死清除旧冰冻与眩晕。40Tick后满血恢复交互并进入狂暴，持续禁止主动。与上文“敌方不可选中”预设分开，不改变格温结界规则。
