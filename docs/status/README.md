# 状态与效果规则

本目录维护状态与效果的**当前设计**；既有机制迁移及本次验收已完成，未新增的状态仍是设计。当前代码能力见[实现现状与接入](IMPLEMENTATION.md)，已接入玩法见[卡牌机制](../CARD_DESIGN.md)。规则正文不保留讨论经过、旧方案或版本对比；未定细节在所属页明确标注。

涉及控制时先读[硬控制](HARD_CONTROL.md)与[动作合同](ACTIONS.md)；涉及不可选中、凝滞和 Buff 抑制时读[特殊状态](SPECIAL_STATES.md)；声音与特效所有权见[表现合同](PRESENTATION.md)。

## 阅读路径

| 需求 | 阅读顺序 |
| --- | --- |
| 人工讨论某个效果 | 本页 → 对应分类页；无需通读实现细节 |
| Agent 新增卡牌效果 | 共通规则 → 分类页 → 动作合同 → 表现合同 → 落地现状与相关验收用例 |
| 实现或迁移状态系统 | 共通规则 → 动作合同 → 实现现状与接入 → 验收清单 |
| 只接动画/音频 | 对应效果的权限与终止条件 → 表现合同 → 既有素材接入流程 |

## 分类约定

四类是查阅入口，不是互斥代码状态。硬控与软控通常也是减益；免控通常是增益，但按它改变的“交互权限”放入特殊状态。禁止用 `is_controlled` 或单个 `targetable` 代替具体权限。

判断一个效果时依次回答：**改变属性、剥夺行动、改变目标交互，还是只做表现？**一招可组合多项，各自准入。例如伤害 + 击退 + 眩晕，在仅免疫位移时仍可造成伤害和眩晕。

## 新效果的最小定义单

在卡牌文档中填下表，并引用所属规则；这是设计记录模板，**不是可直接复制进 gameplay 的 schema**。

| 必填项 | 必须明确的内容 |
| --- | --- |
| 身份与范围 | 效果 ID、家族/控制标签、来源、阵营、空地/建筑/塔目标范围 |
| 实际作用 | 属性公式；移动、转向、普攻、技能、外力各自权限；交互/可见性 |
| 时序 | 触发与释放节点、时长或次数、周期首跳/末跳、持续输出适配 |
| 叠加与结束 | 同源刷新、异源叠加、抑制/净化、替换、自然到期、死亡/换形继承 |
| 动作与归属 | 可打断/施法保护、保护窗口、位移专属策略、未释放后段、独立结果、费用和资源 |
| 表现 | 动作/材质/特效/声音的所有者、开始/刷新/取消/结束、素材缺口 |
| 接入证据 | 实际读取方、schema/validator、快照/事件、用例编号、渲染和试听记录 |

发现未支持的机制或事件时先补通用实现与验收，不把草案字段写进卡牌后宣布支持。缺规则就补所属页；不要在单卡文档另建冲突版本。数值精度引用[数值规则](../NUMERIC_SYSTEM.md)，拟议新增取整边界须单独说明。
