# 增益：属性、治疗、护盾与减伤

> 本页定义目标规则，已实现子集见 [IMPLEMENTATION](IMPLEMENTATION.md)。

[返回总览](README.md)

增益不自动解除控制；非凝滞的受控单位可以获益。凝滞拒绝新 Buff，已有 Buff 仅保留实例并继续计时，期间不贡献属性、触发或周期效果；离开时只恢复未到期实例，不补发或重新获益。免控、净化和动作保护统一见[特殊状态](SPECIAL_STATES.md)，不要为 Buff 再维护另一套免疫定义。

## 效果与表现速查

下表只描述增益本身；当前硬控、动作锁与交互门禁始终优先。所有声音按真实获得、命中、消费、到期事件触发，刷新不重复播放获得音。

| 增益 | 权威效果与影响范围 | 动画、特效与音频 |
| --- | --- | --- |
| 移速增加 | 提高允许执行的自主移动速度，不增加外部推拉速度，不解控 | 实际自主行走时调整步频；不能让受控 Idle/冻结姿势开始跑动；Buff 音轨独立 |
| 攻速增加 | 调整普攻节奏；龙王调整持续普攻 DPS；不改普通技能时长或弹速 | 只调整有效普攻动作的播放节奏；动作声音节点跟随动作进度，已播放声音默认不变调、不重播 |
| 普攻增伤 | 修改定义覆盖的普攻伤害，不自动扩大到技能、毒伤、治疗 | 不改变动作时长；强化标记随实例显示，命中声仍由真实命中产生 |
| 永久普攻增伤 | 对指定友军普通攻击施加一次永久倍率，不改技能伤害；结算仍由统一数值规则取整 | 只显示目标标记和获得反馈，不增加动作锁；未增幅筛选及触发时钟由权威玩法拥有 |
| 强化下一击 | 在正式出手消费次数；保留普通攻击身份，硬控可打断 | Buff 获得/持续声与强化挥击分开；被打断只取消动作层，见动作合同 |
| 治疗 / 持续治疗 | 一次恢复 / 按周期恢复生命；不解除控制，不复活 | 不切换主骨骼；成功收益产生治疗反馈，拒绝或零收益不伪造回血成功 |
| 最大生命增加 | 改生命上限及规定的当前生命差额，不当成攻击伤害 | 更新血条与 Buff 标记；不切动作，不因刷新或凝滞恢复重复播放获得效果 |
| 允许溢出生命 | 提高合法回复上限，与 max_hp 分开 | 血条按实际生命表达，不额外改变动作和播放速率 |
| 护盾 | 独立盾层吸收伤害，可能自然衰减；不挡控制 | 获得、受击、破盾、到期分开；凝滞不因拒绝伤害播放护盾受击声 |
| 减伤 | 降低合法伤害，不阻止独立控制和真实命中判定 | 不切动作；受击反馈依据真实结算，不因倍率刷新重播获得声 |

没有配置专属素材时保留通用图标/数值反馈，不创造新的动作锁。Buff 在眩晕、冰冻等非凝滞状态下照常贡献；凝滞的抑制、拒绝新收益及音轨保留统一引用特殊状态与表现合同。

## 加速、攻速、增伤

基础属性、换形基础属性和临时修饰器分开。不要在增益开始时直接乘写 `move_speed`，结束时再除回来；这种方式无法可靠处理多来源与换形。

本方案默认同组取最强：

```text
有效移速 = 当前形态基础移速 × 最强有效加速倍率 × 最强有效减速倍率
有效攻速倍率 = 最强有效攻速增益 × 最强有效攻速减益
有效普通攻击伤害倍率 = 最强有效同组增伤倍率
```

被凝滞抑制的 Buff 不参与有效属性聚合；不存在可贡献的增益/减益时对应倍率为 1。这里的一增一减可以相乘，但多个同类加速或多个同类减速不互相连乘。当前减速倍率的下限可先保留为 0.1；新数值上下限集中配置并验证，不偷偷写入不同技能。

奥恩全场锻造提供单次永久普攻倍率（20%），不进入临时Buff计时、不作用于主动技能。首次部署后4秒就绪，真正起锻时消费机会并启动6秒CD；无目标或动作受阻保持一次就绪，中断/失效不退款。目标费用、距离、出生身份排序及完整准入见[奥恩](../units/ornn.md)。

攻速改变保留归一化进度，统一重算前摇、剩余攻击间隔、后摇和仍有效的攻击内延迟段；不改变已飞出弹体速度。普通技能的前后摇默认不受攻速影响，除非它声明自己是按普攻速率缩放的特殊动作。

移动动画速度由自主移动与真实步幅需求决定。被牵引的世界位移不自动当成自己跑得很快，不能用“总位移距离”把站立受拉单位的 Run 播到数倍速。

## 治疗与持续治疗

普通治疗、吸血、命中回复、技能结束回血、恢复护盾回血都经过同一个“允许接受生命收益”的检查。活着、非凝滞并符合目标类型才可获得；敌方不可选中与隐身不会阻止友方治疗。

普通治疗不超过合法治疗上限，不减少已有溢出生命；受控但非凝滞的单位可以回血。持续治疗使用独立周期实例，而不是等待攻击/移动 Tick 才处理。

保留当前治疗法术默认只治疗非建筑 Unit 的目标限制；这与“友方可增益”不矛盾：后者解除敌方不可选中的干扰，不会自动扩大一张治疗卡原本的目标类型。

## 最大生命与溢出生命

通用最大生命计算应为“当前形态基础上限 + 有效修饰器”，不能用生命条显示反推。

暂定采用与当前部分换形相近的缺失生命保持方式：上限实际增加 Δ 时，当前生命增加同样的 Δ；上限减少时仅把当前生命钳制到新的合法上限，不按旧百分比重新算生命，不造成攻击伤害，不触发击杀/受伤收益。重复刷新同一加成且上限未再提高时，不再白送一次 Δ 的生命。

凝滞抑制/恢复最大生命修饰器不是移除/重新施加，不因切换贡献而重复扣血或补血；真实到期才执行相应上限回收，见[凝滞规则](SPECIAL_STATES.md#凝滞)。

例如 300/1000 获得 +500 最大生命后成为 800/1500；结束时若为 1200/1500，则钳制为 1000/1000；若为 700/1500，则成为 700/1000。例子不包含特殊允许的溢出生命。

现有吸血提高可回复上限但不修改 `max_hp`，需作为独立的“允许溢出生命”规则保留。迁移时以合法生命上限统一钳制，不能为了新通用最大生命系统直接删除原有溢出行为。

## 护盾

保留 `ShieldState` 独立层实现。每层拥有自己的容量、剩余量、到期时刻、衰减率和小数余量；一次受击先耗最早到期层，相同到期时刻按稳定施加顺序。

衰减护盾默认按初始盾量/持续时间线性衰减，与受到多少伤害分别记账。500 点、5 秒的衰减盾，每秒自然减少 100 点；先被打掉 200 点后仍按这个速率减少，不改成对剩余盾量重新做 5 秒衰减。

盾吸收伤害不阻止附带控制。只有专门的法术护盾/控制屏障才可阻止效果；这些不是当前定义内容，不应偷偷赋予普通护盾。

赛恩灵魂熔炉也走 Unit 的通用加盾入口；与伤害同批提交时，新盾不追溯吸收本批伤害，存活者在伤害结算后获盾。技能只消费该盾层未破且自然到期的结果，交给通用范围伤害；破盾、死亡清理或清场不产生到期伤害，结果仅消费一次。已有盾层在凝滞中自然到期仍可爆炸，保留此既有例外。

加盾被凝滞等原因拒绝时，不创建空层、不播放获得护盾事件。到期、被打破、被替换/清除、死亡分别派发终止原因；只有真实符合恢复条件的自然到期才可请求回血。

## 伤害减免

普通Unit已通过`damage_reduction`状态家族接入，训练木桩余震为首个使用者；多个普通减伤效果取最强一项，独立到期；不直接相加到超过 100%。将来确实需要不同防御类别相乘时，再增加明确的数值组定义。

结算顺序：交互资格 → 原始伤害及来源倍率 → 目标伤害减免 → 护盾吸收 → 生命扣减 → 命中/耗盾/受伤回执 → 依规则发放收益。小数在统一数值边界处理，不能每一层任意取整叠出误差。

减伤不阻止眩晕。即使伤害被减到零，独立的控制请求仍按自己的准入规则处理；“受到有效伤害才触发”的事件则依据真实 HP/护盾损失。吸血默认按实际生命损失计算，不按原始伤害或耗盾量计算。

生命代价、自然寿命扣减、上限回收是独立的生命变化原因，不借用普通伤害以便绕过减伤/护盾；它们也不应触发潜行受伤显形或攻击者吸血。

## 尚未定义的属性扩展

降攻击力、易伤、部分治疗削减、韧性/控制时长缩减、抗性与穿透不在当前预设内。新增时先明确作用对象、数值组、叠加上限、结算顺序和读取方；不能借“增伤”同时改变普攻、技能、毒伤及治疗。当前公式的增伤默认仅覆盖声明的普通攻击部分，保留独立附伤边界。

通用减伤保留[既有数值规则](../NUMERIC_SYSTEM.md)的基础伤害与独立附伤取整；目标减伤在合并后的入盾伤害边界统一取整，不逐个减伤来源反复取整。生命上限修饰器默认同组取最大正增量，不同组求和必须显式声明。新上限与换形同时变化时按最终基础与修饰器计算一次差额，不能重复补血。

锻造行动锁为1秒，结束后按实际攻击/移动/待机进入纯表现衔接，0.65秒发锤且只响一次敲击；准备/在途预留目标，抵达才写入永久倍率。眩晕、冰冻、凝滞和外力位移打断，禁锢/普通伤害/减速不打断；新敌人不抢占已开始的锻造，主动技能可抢占。CD与严格脱战分离，已发锤独立于来源生命周期，目标失效清除且不重选；详见[奥恩](../units/ornn.md)。

## 一次性永久成长

`permanent_growth`在实际生效时选取中心范围内费用最高、距离最近、出生身份最早的未成长友方普通单位，排除建筑、冰鸟蛋及不允许友方增益的目标。Unit保存施加时固定生命增量与身体倍率，生命上限/当前生命只在首次获得时同时增加；普通换形保留增量，目标死亡结束。不同来源也不可重复。无目标仍可请求，生效时回退金币、次数与冷却；其他取消沿普通技能规则。主机推进并同步成长状态，客户端不重复加血。当前璐璐为30%生命与1.3身体倍率，永久成长在凝滞中保留生命上限、已获得生命与体型，解除不再增加生命；它不采用普通限时 Buff 的贡献抑制。奥恩永久普攻增幅同样保留；已发弹体使用出手时固化的伤害。

永久成长、牺牲强化与普通换形共用体型转换收尾：清旧路径，权威地面单位增大半径或由空中落地后，按现有地形/建筑规则修正位置并重置插值端点。空军、建筑、穿地形单位不因此强制落地；强制位移途中仍在抵达时按新半径处理。客户端只消费主机位置和属性，不重算权威落点；缩小和相同属性的重复赋值不重复移位。

## 拒绝死亡

蛮族之王的无尽怒火持续4秒，伤害在护盾之后最低保留1生命，期间暴击不耗怒。满怒在施放起点发生，结束不治疗也不自动死亡。暂停不计时，凝滞抑制但不延长窗口；同批多刀逐刀钳制，死亡、清场按实例生命周期释放。

## 单次效果护盾

梦魇黑暗庇护持续1.5秒，抵挡一次完整敌方攻击、技能或法术，包括该次效果附带的伤害、控制和减益。成功抵挡后获得2秒30%攻速加成，自然到期不触发；同次效果的后续段不重复刷新奖励。新敌方减速可以触发抵挡；已生效的流血和持续区域减速不触发。友方效果包括友方凝滞不消耗盾。效果级资格与普通盾层生命分开，状态由固定时钟推进；完整规则见[梦魇](../units/nocturne.md)。

同次施法的 Delivery 按目标保存首次接受/抵挡结果，先知R的准备、延后眩晕和固定区域共享该身份；挡住眩晕即挡住该次后续区域，已经接受该次R后再开盾不会拦截旧区域。区域仍独立维持完整寿命，其他目标分别判定。

收集期立即消费护盾并保存抵挡结果，保证同批只挡一个独立效果；攻速收益在提交期的全批扣血与控制之后只发给存活者。攻速增益开始/刷新统一通过Unit的旧新有效速率换算，结束与减攻速沿用同一进度合同，前摇、后摇、间隔及待发额外攻击保持归一化进度。

## 单位穿行

buff主动可声明`ignore_unit_collision`，由来源独立的`unit_phasing`窗口持有。存续时双方普通单位之间不作避让、体积分离或击退接触截停；不改变建筑占地、河流及导航合法范围，不提供免伤、免控或不可选中。凝滞抑制该状态；到期恢复普通接触处理，不传送单位。

单位穿行的通用能力保留，当前无正式卡携带；虚空兽的幽灵疾步已撤下。客户端只读取增益表现，不自行解碰撞。

## 永久牺牲强化

`sacrifice_empower`按部署身份强化存活且允许友方增益的成员。永久伤害与表现倍率独立保存，生命增量、身体半径倍率和移速倍率通过属性快照同步，不依赖临时Buff计时。虚空兽为1金币、每组一次，伤害×1.5、模型与碰撞×1.25、最大生命+20%并补新增生命、移速永久×1.2。凝滞仍阻止移动和技能受益；起跳结果固化伤害，后续强化不能追溯改动。

### 限时普攻吸血

Buff主动的`heal_ratio`创建独立`timed_lifesteal`窗口，与技能`duration`同长。来源独立计时，同类比例取最强，与永久吸血和攻击段比例相加；不改变最大生命或溢出上限。仅有效普攻实际生命伤害提供收益，凝滞抑制收益但窗口继续计时。护盾耗尽不移除吸血。狂战士使用5秒30%。

庇护清泉按同一来源刷新盾层，每秒60且不设上限，持续刷新1秒寿命；其他护盾独立，重叠清泉只补一次。详见[庇护清泉](../units/pool_of_reflection.md)。

## 100%重伤

终极爆弹地狱火炮为非建筑单位施加无持续时间的100%重伤。普通治疗、普攻吸血、命中回复、恢复盾到期回血统一拒绝；被抑制的治疗不能转为过量护盾。最大生命提升及对应当前生命补偿属于属性变化，不受影响。独立布尔状态，重复施加不叠加；死亡清除，普通变形及清除有时限Buff不移除。图标保留于血条右端；凝滞不移除重伤，特殊恢复盾亦不能绕过仍存续的重伤。
