# 动作与生命周期合同

[返回总览](README.md)

## 阅读约定

本页集中维护硬控对普攻、移动、变形、部署和技能的打断规则；具体权限见[硬控制](HARD_CONTROL.md)，动画及音频所有权见[表现合同](PRESENTATION.md)。已实现子集和延期范围以 IMPLEMENTATION 为准。

“打断动作”是取消旧动作及未释放后段；“冻结模型”是立即保持命中时的姿势，**不表示暂停旧动作等待续播**。动作是否结束、状态何时到期均由 20Hz 权威逻辑决定。

## 硬控 × 行为速查

控制从实际施加时开始计时。未通过免疫/准入的控制不取消动作、不清攻击间隔、不播放控制成功反馈。

| 硬控 | 普攻 / 强化普攻 | 自主移动 | 已开始的变形 / 部署 | 已开始的普通技能 |
| --- | --- | --- | --- | --- |
| 眩晕 | 任意阶段打断 | 停止 | 动画、音频继续 | 动作、声音、合法后续效果继续 |
| 冰冻 | 任意阶段打断 | 停止 | 立即冻住姿势、停动作音；计时继续，不续旧片段 | 立即冻住姿势、停动作音；取消未释放后段 |
| 击退 | 任意阶段打断 | 外部轨迹接管 | 动画、音频继续，位置受位移影响 | 动作、声音继续，位置受位移影响 |
| 禁锢 | 不直接打断原地普攻 | 停止 | 动画、音频继续，禁止自主移动 | 动作、声音继续，禁止自主移动 |
| 嘲讽 | 已正在攻击嘲讽者则不打断；否则打断并转目标 | 向嘲讽者追击，仍受其他锁限制 | 动画、音频继续，普通目标受嘲讽约束 | 动作、声音继续，不重定向本次技能 |
| 强制推拉 | 任意阶段打断 | 外部轨迹接管 | 动画、音频继续，位置受位移影响 | 动作、声音继续，位置受位移影响 |
| 凝滞 | 任意阶段打断 | 停止，终止外部轨迹 | 立即冻住姿势、停动作音；计时继续，不续旧片段 | 立即冻住姿势、停动作音；取消未释放后段 |

动作不中断不等于自由行动：原有部署锁、变形锁、施法锁继续生效。动作结束后重新聚合剩余控制，不统一写成“恢复全部行动”。死亡/清场终止所有自身动作；独立已释放结果按各自生命周期处理。

## 普攻：重新前摇，保留循环进度

普攻等待、前摇、出手、后摇及持续输出都可被对应硬控打断。解控后若能攻击，**立即开始下一次完整前摇，不等待被打断时剩余的攻击间隔**。旧前摇、后摇和间隔作废；不回放旧动作、不立即补一次伤害。重复刷新控制或嘲讽未打断当前攻击时，不额外重置节奏。

前摇、出手、后摇及等待下一次攻击的剩余间隔属于同一攻击周期，即使模型已回到待机，合法打断仍清除旧周期。控制刷新、控制解除、已有控制从抑制中恢复都不再重置一次；解除后仍须满足部署、变形、技能和其他行动锁。同目标嘲讽保留其攻击周期，包括等待再次攻击嘲讽者的间隔。

短控制在后摇或剩余间隔中打断时，下一次攻击可能比未受控时提前；这是取消旧间隔的既定结果，仍必须走完整新前摇。

“下一次攻击”不是 Attack1，按实际完成节点推进循环：

| 攻击类型 | 本段完成及推进节点 | 尚未到达节点就被打断 |
| --- | --- | --- |
| 近战 | 权威结算确认实际命中 | 保留该段，解控后重走该段前摇 |
| 远程弹体普攻 | 成功创建该次权威弹体 | 未创建则保留该段；已创建则下一段 |
| 持续普攻 | 不把每个 Tick 当成一个离散攻击段 | 停止旧输出，解控新建持续攻击实例 |

剑魔普通形态示例：`Attack1 → Attack2 → Attack3 → 被动攻击`。Attack3 前摇被打断，下一次仍是 Attack3；Attack3 实际命中后被打断，下一次为被动攻击。

护盾吸收了全部伤害仍可构成命中；目标失效、致盲落空或命中被拒绝不算近战命中。**致盲落空是攻击段推进的例外：正式出手仍计一次普通/强化攻击并推进段号，但不产生任何命中计数或附带控制。**远程弹体之后是否落空，不回滚已推进的攻击段。动画切片号、动作实例序号、实际命中收益计数分别维护；一次攻击的溅射命中多个目标不重复推进段号。同一批次提交与控制的先后见[共通规则](CORE.md)，不能靠动画帧或遍历顺序决定。

已提交伤害、已创建弹体保留。旧动作尚未释放的追加刀取消；已完成段保留进度，未完成段下次重起，不整个循环归零。强化状态、长期被动计数等独立状态不因清理动作而清零。龙王属于持续普攻，适用普攻打断，不享受普通技能保护。

### 强化下一击

获得强化是一次已完成的 Buff 施加；随后打出的强化攻击仍是普攻。不能因强化攻击使用 Spell 动画就将它归为不可打断的普通技能。

| 时点 | 被硬控实际打断后的结果 |
| --- | --- |
| 强化 Buff 已获得，还未攻击 | 保留实例；有时限则继续计时，Buff 声音不受打断。凝滞中强化贡献被抑制，离开时仍有效才恢复 |
| 强化攻击前摇，尚未正式出手 | 取消挥击及挥击声，不消费强化；解控后强化仍有效则重新起手 |
| 已正式出手 | 强化已消耗，不返还；合法已提交伤害/弹体及真实命中音保留，致盲落空不产生这些命中结果 |
| 后摇 | 取消旧后摇，下一次按现有循环与剩余强化状态决策 |

强化消费节点是正式出手（近战提交该次攻击、远程创建实际攻击弹体），不是前摇或播放声音；出手后落空不返还已消耗的强化。致盲在正式出手处判落空，正常计攻击次数、推进攻击段并消费对应强化；它不产生伤害、真实命中、命中附带控制或可命中的弹体，纳尔变形命中计数不增加。攻击循环完成节点与强化消费节点不同，不能共用一个“完成”标志。盖伦强化 Buff 声与强化挥击声必须分层，详见[表现合同](PRESENTATION.md)。

## 移动与目标

眩晕、冰冻、禁锢停止自主移动；击退/强制推拉接管位置；嘲讽只向合法嘲讽目标追击。控制解除后从当前位置重新检查目标和路径，不补跑距离、不回到原坐标。目标离开禁锢单位射程时先查其他圈内合法目标，没有才待机。

冰冻保持姿势，但仍允许外部推拉；凝滞锚定并终止现有轨迹。眩晕不暂停外部轨迹；轨迹遇阻结束，不在解控后补走。具体轨迹替换、质量与地形约束见[硬控制](HARD_CONTROL.md)。

目标约束与移动许可分别判断：部署/技能本来锁移动时，嘲讽可以改变后续普攻目标，却不能让单位提前行走；还被眩晕、禁锢或凝滞时也不能追击。嘲讽到期立即清除强制目标和追击意图，重新按普通规则选敌；尚未追到嘲讽者且身旁有更近可攻击目标时，转攻近处目标。已开始普攻是否继续按普通攻击规则判断，到期本身不额外取消合法攻击。空中单位不能发起嘲讽，详见[硬控制](HARD_CONTROL.md)。

自主冲刺属于位移执行。眩晕、冰冻、禁锢截停自主轨迹，击退/强制推拉接管位置；只有明确配置对应免控或位移保护才可例外，普通技能动作保护不包含位移保护。已截停的自主轨迹不在解控后恢复，不补走剩余距离；仍合法的技能后段可继续。位移技能须声明截停后的合法释放节点；未到达/未碰撞不能仅凭动画演完补伤害。跨越障碍与免疫位移须另有明确规则。

## 技能：区分五类普通硬控与冰冻 / 凝滞

技能请求分为两个阶段。**提交资格**由按钮和玩家/AI/RPC入队共用：技能资格仍有效、部署完成、归属正确、费用足够、次数未耗尽、冷却已结束、没有待执行请求，并处于允许操作的对局。眩晕、冰冻、变形、已有施法、击退及先锋准备/冲撞/恢复不禁止提交。按钮显示与点击时可重复读取同一谓词，主机接收时仍须验证，不能信任客户端。

**执行资格**在请求到期时检查当前权威状态：基础资格仍有效且 START_SKILL 允许才 Cast Start。已经预扣的费用不再次以当前余额检查，当前请求本身不作为重复请求拦截。执行时存活但受限则取消并通过原收据退款，不扣次数、不启动冷却、不消费技能资源；不自动延迟重试。死亡/终局取消不退款，槽位替换沿用退款；成功开始后才扣次数、启动冷却，后续冰冻取消施法不退款。等待期间解控即可在原执行边界正常施放。

单体死亡移除按钮；群体资格按存活成员转交。相同主动槽的新实例生成时替换旧资格，新实例部署完成前不可提交。客户端只读同步的部署、次数、冷却及经济，临时行动权限不再作为提交门禁；请求成功或拒绝回执解除等待标记。

已正式开始的普通技能遇到眩晕、击退、禁锢、强制推拉、嘲讽，动画、音频和合法后续效果按原时间线完成；控制即时计时并限制相应移动和后续行动。保护不允许受控时开启新技能，不扩大命中范围，不免伤，不自动免疫位移。

例：技能 t=0 开始、t=1.0 结束，t=0.4 被眩晕 1.2 秒；技能在 t=1.0 完成后再受剩余 0.6 秒眩晕。若控制已经提前结束，不补控制、不补播控制动作。

冰冻或凝滞施加时，**立即捕获当前模型姿势**，不等技能结束、不先混合到 Idle。取消本次尚未释放的技能段、待播动作声音和完成奖励，停止正在播放的本次动作声音；不退款、不归还次数或已消费资源。解除后从冻结姿势混合到当前合法的新动作，不继续剩余施法，不恢复旧声音。

| 效果归属 | 冰冻 / 凝滞取消施法后 |
| --- | --- |
| 未释放伤害、未生成弹体、依附施法的后段及结束奖励 | 取消，不补发 |
| 已造成伤害、已发射弹体、已落地独立区域 | 保留，按自身规则继续 |
| 已施加 Buff / 护盾 / 已完成的变形 | 不回滚，独立计时；凝滞中已有 Buff 无效果，离开后仅恢复未到期实例；Buff 声不因施法取消中断 |
| 跟随自身的持续效果 | 声明依附施法或独立 Buff；前者取消，后者保留实例但在凝滞中不执行效果 |

随身技能（瑟提梯形、格温扇形、纳尔框等）的未结算伤害范围以每次结算时施法者的权威位置为起点，位移会同时移动伤害位置和对应特效；已结算伤害不回滚。依赖动作的范围特效随冰冻/凝滞取消技能而清理。固定落点的独立结果不因来源位移改变：龙王星辰特效创建时即建立独立星辰结果，此后冰冻/凝滞只冻结龙王模型动作，不取消或暂停星辰；坠落、落地伤害及后续特效按自身生命周期继续，不再检查龙王后续动作是否完成或是否受控。创建节点由权威逻辑确定，不由表现驱动伤害。远程技能弹体从创建时的世界起点独立运动，不跟随后续施法者位移。嘲讽不改写已开始技能的目标/朝向；目标失效仍检查合法性，不能为了“完整释放”隔空命中。施法保护窗口由权威定义决定，不随声音尾音、Buff 时长或独立区域延长。

未正式开始就失去资格，沿用请求退款/关闭规则；已经开始的技能按上述规则处理。先锋准备属于特殊动作，不因普通技能保护自动获得保护。未来长引导等新动作先写具体硬控响应，不能按“动画长”私自加入例外。

## 变形

眩晕、击退、禁锢、强制推拉、嘲讽不打断转换动画和音频，但移动及普通目标约束立即生效。转换结束若控制仍在，继续受剩余控制。

冰冻/凝滞立即冻住转换中的姿势并停止转换声音；**逻辑形态不回滚，转换计时继续**。解除后混合到届时有效形态的下一合法动作，不续播旧转换片段或声音，不重复加血。若控制提前解除而转换窗口未结束，仍保留剩余转换行动锁，以当前形态的待机或原本允许的移动承接，不能提前攻击。

现有 `transform_to_mega/small` 先提交形态再建立转换窗口。应在既定权威节点切换一次，形态、体型与战斗属性不等动画结束。冻结期间自然形态到期仍执行；解控按届时实际形态显示，不强行恢复已过期的强化形态。需要换模型时不得播放旧转换，冻结覆盖由表现层保持/重建，死亡始终可退出冻结。

形态寿命起点按逐卡定义，例如剑魔在转换窗口正常到期后开始 5 秒大灭，窗口不会因冰冻暂停。变形兼带攻击时拆开：已经变大保留，尚未释放的拍地攻击遇冰冻/凝滞取消。主动换形尚未开始时仍检查施法资格。

### 纳尔：转换窗口的主动请求

变大、变小窗口内不能开始新主动技能。窗口中允许按基础资格提交并预扣费用；请求执行时若仍存活但处于窗口，取消该请求，通过原付款收据退款一次，不延迟重试，不消费次数、不启动冷却、不消耗技能资源，也不发布本次施法动作、声音和特效。次数只在成功 Cast Start 后扣除，拒绝分支不得“补回一次”。沿用收据幂等及费用上限；死亡、终局、槽位替换的既有取消政策不变。

解冻边界先兑现同代待变形，进入真实转换窗口，再判请求资格。窗口结束边界按统一时钟先到期再校验。没有待变形的小纳尔合法主动技能，其自身触发变大及拍地属于同一次已开始施法，不能被随后产生的转换窗口自我拒绝或退款；开始后受冰冻按施法取消规则处理。

### 纳尔：命中计数，冰冻 / 凝滞时延后变形

小纳尔第 6 次真实普攻命中满足变大条件，大纳尔第 4 次真实近战命中满足变小条件。攻击段推进与变形计数独立：小纳尔的攻击段按创建弹体推进，变形计数按真实命中推进。

| 命中达到阈值时的状态 | 处理 |
| --- | --- |
| 没有冰冻或凝滞 | 在该次结算后的合法生命周期节点开始变形，包括仍有眩晕、击退、禁锢、强制推拉或嘲讽的情况 |
| 冰冻或凝滞仍有效 | 记录一次待变形，保持当前形态；不提前加血或播放变形动作/声音 |
| 冰冻和凝滞都已解除，待变形仍有效 | 检查存活与形态后触发一次变形，无需等待其他五类硬控结束 |

冰冻与凝滞重叠时须等两者都结束；多来源同类冻结也须全部解除。其他控制继续限制移动/目标选择，变形不会净化它们。例：冰冻结束时仍有眩晕，纳尔可以开始变形，动画和音频按变形规则完成；完成后继续承受剩余眩晕。

待变形关联实体与形态代次；等待期间继续命中不排队多次变形、不计入下一形态。死亡/清场丢弃标记，其他规则已切换形态则清除旧标记。旧小形态弹体不能给大形态或之后新一轮小形态计数。

冰冻/凝滞期间旧弹体真实命中，可记录当前形态的变形计数和一次待变形条件，不提前发放属性或生命收益；其他吸血、技能资源收益仍按凝滞规则拒绝且不缓存。这是命中事实记录，不是既有 Buff 在凝滞中执行效果。

变形已经开始后才受控时，按转换中规则处理：眩晕等五类硬控保留转换音画；冰冻/凝滞立即冻结姿势、停止转换声，转换计时照走，解除后不续旧片段。

## 部署

未生成的命令不接受单位状态；已经生成且部署未完成的实体正常接受合法控制。部署时长与控制独立计时，均不重新开始。

下牌与凝滞单位占位冲突时，新单位或建筑落到最近合法位置，不推开凝滞单位；编队逐成员检查，遵守原有部署与空地碰撞规则。凝滞进入时不额外整理位置，结束后少量已有重叠交给现有碰撞规则处理。具体占位合同见[凝滞](SPECIAL_STATES.md#凝滞)。

眩晕、击退、禁锢、强制推拉、嘲讽不打断部署动画、音频，位移与目标约束正常生效，但不能越过部署行动锁。冰冻/凝滞立即冻结部署姿势并停止部署声音。解除后不续播旧部署，混合到下一合法动作；若部署剩余时间尚未结束则待机，仍不能攻击或自主移动。

当前内容设计方向为部署不超过 3 秒，冰冻/凝滞法术效果为 3 秒；这不是所有来源控制的全局固定时长，也不能依赖这一数值替代剩余部署检查，提前解除时同样正确。

已提交的入场效果不回滚。未释放的入场攻击按其动作归属检查冰冻/凝滞取消；部署完成后的普攻/周期召唤受当时行动权限约束。首批召唤等未分类内容，实施前明确归属，不因部署动画保留而自动授予全部产出免控。

## 生命周期完成与战斗奖励

部署锁到期、转换锁解除、形态寿命开始计时和必要状态清理属于生命周期维护，不能挂在会随动作取消而丢失的“正常完成奖励”中。冰冻/凝滞取消音画或战斗后段，不取消这些维护。

入场攻击、转换拍地、结束爆炸等属于战斗效果，按所属动作及释放节点决定是否取消；独立周期召唤按产出权限执行，禁止时跳过、不补发。卡牌必须声明首批召唤等产出的归属，不能借部署动画保留绕过门禁。

例如剑魔在转换中被冻结，转换窗口仍正常结束并开始大灭寿命计时；取消转换表现不能导致形态永不到期。

## 解控后的动作决策

在现有权威阶段内，先处理死亡和生命周期到期，再整理当前控制权限；随后执行有效的强制形态变化，检查剩余行动锁，最后按既有技能优先级决定技能、普攻或移动。此顺序不改变已锁定批次的结算规则，也不追溯撤销已提交结果。

纳尔解冻后有有效待变形时，先变形，不先发起小形态普攻。被取消的旧动作永不恢复；尚未开始的技能请求独立检查有效期、当前资格及既有取消/退款规则，不把排队请求当作旧动作续播。

## 其他生命周期边界

### 固定建筑、防御塔、水晶

| 效果 | 非建筑军队 | 建筑卡 | 防御塔/水晶 |
|---|---|---|---|
| 眩晕/冰冻 | 支持 | 支持，限制攻击与需要行动的产出 | 保留已有支持；不把休眠当作控制 |
| 禁锢、移速变化、外部推拉/吸引 | 按规则支持 | 默认不适用/锚定 | 默认不适用/锚定 |
| 致盲、减攻速/加攻速 | 对有相应普攻能力的单位支持 | 可支持有普攻的建筑卡，须有数据准入 | 暂定不扩展默认法术目标到塔；需明确卡牌允许与 Tower 适配 |
| 嘲讽 | 受攻击能力限制 | 暂定免疫 | 暂定免疫 |
| 沉默 | 禁主动技能 | 可限制其主动技能，不直接关掉普通被动光环 | 无主动技能则无适用效果 |
| 治疗 | 保留卡牌自己的筛选 | 现有治疗术默认不治疗建筑卡 | 不因通用化自动获得治疗资格 |
| 护盾 | 支持 | 保留已有支持 | 保留已有支持 |
| 凝滞、隐身、最大生命增益等 | 可按正式能力接入 | 未出正式卡前不默认向建筑开放 | 未明确设计前不开放 |

这里的默认目标范围是内容约束，不意味着写多套状态算法。Unit/Tower 应共享同一准入语义与控制家族；不能出现同一种新状态只在 Unit 被正确过滤，Tower 仍通过旧的直接写字段旁路生效。


### 自然寿命、周期产出与复生

状态、Buff、护盾、部署、转换窗口、自然寿命正常计时；冰冻/凝滞冻结模型不冻结这些时钟。受控期间不能执行的周期产出跳过，不积攒后补；普通软控不额外取消动作。自然寿命不得被控制延长，当前建筑受控早退需要实施时调整。

同实体换形保留状态、护盾与资源归属。死亡替身/复生的新实体默认不继承旧控制、毒、盾或隐藏状态，除非明确白名单；技能资格转交不等于复制整套状态。死亡与清场均终止冻结覆盖。

### 先锋特殊动作

准备、冲撞、撞后恢复分别处理：准备保持可打断，重新尝试走完整准备；冲撞按专属免控/位移规则执行；撞后 0.65 秒是自我恢复锁，不属于眩晕，也不被净化。控制与恢复分别计时，只有所有行动锁解除才能行动。 Tick K 确认撞击时不扣新恢复时间；旧 RECOVERY 在下一边界起、技能请求与普攻资格判断前每 Tick 推进一次，K+13 结束。后续读取更新后的阶段，无其他控制或锁时当边界即可起手或执行合法排队技能。仅提前恢复时钟，不移动冲撞路径、碰撞或伤害阶段。

未被外部控制覆盖时保留原撞击/恢复动画；外部眩晕等可混合到 Idle，冰冻/凝滞立即保持姿势。恢复时钟不随动画冻结暂停。不能把准备动作误归为普通受保护主动技能；现有准备阶段的位移免疫等专属门禁实施前逐项保留核对。
