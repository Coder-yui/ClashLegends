# 减益与软控制

> **当前设计，尚未实施。**本文规定目标行为；当前代码支持情况见[实现现状与接入](IMPLEMENTATION.md)。

[返回总览](README.md)

减益是效果对目标不利；软控制是其中限制部分能力或降低效率的一类。中毒、流血不属于控制。当前设计规定动作打断由硬控制处理；软控仅改变相应能力、倍率或输出结果，不主动取消已开始动作。

| 效果 | 改变什么 | 不自动改变什么 | 叠加 |
| --- | --- | --- | --- |
| 移动减速 | 自主移速 | 外力速度、攻击、技能时长 | 独立计时，当前最强 |
| 减攻速 | 普攻节奏、持续普攻输出 | 弹体速度、普通技能时长 | 独立计时，当前最强 |
| 致盲 | 普通/强化攻击落空，仍计一次攻击；龙王普攻免疫 | 移动、出手动作、主动技能 | 剩余攻击次数取最大 |
| 沉默 | 主动技能开始资格 | 不直接打断已开始技能、普攻或被动 | 独立计时，任一有效即限制 |
| 持续吸引 | 额外外力贡献 | 不直接取消动作 | 多区域合力并限幅 |
| 中毒 / 流血 | 周期伤害 | 行动权限 | 同源刷新，异源独立 |

减速倍率下限暂沿用 0.1；加减速组合公式见[增益](BUFFS.md)。无可用行动的目标也正常消耗减益持续时间；致盲是次数预算，按下面的出手规则消费。

## 动画、音频与硬控边界

| 效果 | 动作与声音处理 | 与硬控同时存在 |
| --- | --- | --- |
| 减速 | 不切动作；允许自主行走时按有效移速调整步频，状态声音独立 | 禁止自主移动时速度加减成不能使其行动；外部位移仍按自己的轨迹 |
| 减攻速 | 保留普攻归一化进度，调整动作节奏及未触发声音节点；已响声音默认不变调、不重播 | 已取消攻击无进度可恢复；冻结姿势不因速率变化推进，解控新攻击读取当前倍率 |
| 致盲 | 攻击和强化动作照常播放，不因致盲停止挥击声；攻击后仍走正常后摇与间隔 | 硬控在出手前取消时不消费致盲；出手后按已确定结果执行，不因解控重试同一次攻击 |
| 沉默 | 不切换当前动作、不停止已开始技能音轨；无效技能请求不播放起手音 | 与硬控开始门禁合并，沉默结束不能解除硬控；已开始技能遇冰冻/凝滞仍取消 |
| 持续吸引 | 不直接切动作或停动作声；只改变模型世界位置，不用外力距离加快 Run | 冰冻姿势可被整体拉动；凝滞拒绝吸引，强制轨迹接管期间清除吸引积累 |
| 中毒 / 流血 | 图标/附着特效独立；每跳真实伤害才产生伤害反馈，不插入打断动作 | 普通硬控不停止毒伤；凝滞跳过伤害、不补发；状态本身计时与独立音轨按生命周期继续 |

软控施加/刷新不取消普攻、技能、变形或部署。位置、目标资格等普通条件变化仍须检查；因这些条件无法命中不算新增一次硬控。状态层音轨与动作层分开，硬控只取消按规则被打断的动作声音。

### 沉默

沉默作为软控，限制新主动技能开始，不直接取消已开始技能；不影响普攻、按命中触发的被动、已有增益、已发出的弹体或独立持续区域。技能打断依[硬控动作合同](ACTIONS.md)处理，技能请求的资格、取消及费用按动作合同处理。

外形来自某个 LOL 技能动画，不代表它在 Clash Legends 中属于技能。龙王喷吐在当前项目中是持续普攻，因此沉默不禁止它；它受“是否允许普攻”约束，但不受致盲影响。

自动能力必须明确归类：普攻被动、被动光环、主动技能、主动技能的持续段。不要凭函数名包含 skill 或模型片段名是 Spell，改变该能力的开始门禁或打断策略。

### 持续吸引

吸引不是不断施加小击退。它不占用硬控动作锁，而是在运动阶段提供额外速度/力贡献：

```text
合外力 = 各有效吸引区域的力矢量之和
外力加速度 = 合外力 / 有效质量
下一外力速度 = 限幅(带阻尼的当前外力速度 + 外力加速度 × dt)
最终移动候选 = 自主移动速度 + 外力速度
```

阻尼、力随距离的曲线、加速度/速度上限由法术参数决定，数值必须实测。接近中心时钳制过冲，避免来回振荡；无有效区域后清理该外力贡献，不留下隐藏的长期惯性。

单位被禁锢或眩晕时自主速度为零，但吸引仍能拉动它；凝滞、固定建筑或明确的外部位移免疫拒绝吸引。离散强制轨迹执行期间暂停使用吸引的运动贡献，并清除其积累速度；轨迹结束后只重新计算仍有效区域，不能突然释放之前攒下的力。

吸引造成的位置变化可能使普攻/技能失去目标或距离，这属于动作合法性变化，不是吸引额外自带一次眩晕。

## 致盲：攻击成立，命中不成立

普通/强化攻击到达正式出手节点时，若有致盲次数，则消费一次并将本次攻击标为落空。**仍算一次普通或强化攻击，正常推进攻击段、消费强化并进入后摇和攻击间隔，但不造成伤害，也不算命中。**前摇被硬控打断而未出手，不计本次攻击、不推进段号、不消费致盲或强化。

按“攻击出手”触发的次数正常记录；附带控制、普攻命中收益、吸血以及纳尔按命中累计的变身次数均不触发。一次落空攻击不会因为没有命中就重试同一攻击段，也不跳过正常后摇和间隔。后续硬控实际打断攻击周期时，再按硬控规则取消剩余间隔。

每记明确为独立普攻的追加刀各自消费一次致盲；同一次攻击的多个目标、溅射或多枚弹体不重复消费。一次攻击被判为致盲落空后，其所属伤害与命中附加效果全部无效，不能由溅射绕过；独立技能、此前已释放的弹体和区域不受本次致盲影响。

远程可保留空射/弹体表现，但不得创建可造成命中的权威弹体或触发命中回执。该次攻击段在正式出手确认落空时推进；这是对正常远程“创建权威弹体”、正常近战“实际命中”推进节点的明确例外。出手时已判定的致盲结果不会因途中净化或致盲到期改变；出手后才施加致盲也不倒追已发射弹体。

致盲次数使用非负整数，重施 N 次取 max(剩余次数, N)，不相加。若效果另有有效期，按定义正常到期；无攻击时不凭时间消费次数。挥击/空射声音按动作播放，强化获得声按 Buff 生命周期播放；没有真实命中，不播放成功命中音或命中特效。空射表现绑定对应攻击身份，不承担伤害和碰撞判定。

## 龙王持续普攻

龙王普攻不受致盲影响，不降低持续输出，也不消费致盲次数；不使用等效攻击秒或按 Tick 扣致盲的方案。免受致盲影响属于攻击能力定义，不按动画名、interval 或英雄名称临时判断。只含该免疫攻击能力的单位不接受无实际作用的致盲；未来混合攻击/换形单位若已有合法致盲实例，免疫攻击不消费它，其有效期仍照常计时。其他新持续攻击类型须声明致盲响应后接入，不能默认套用一次 Tick 一次普攻。

```text
本 Tick 输出预算 = 基础 DPS × 有效增伤倍率 × 有效攻速倍率 × 有效攻击时间
```

有效攻速包含加攻速与减攻速。龙王仍受实际打断普攻的硬控影响：终止本次持续攻击及动作声/喷吐特效，解除后新建攻击实例；禁锢不直接打断，同目标嘲讽不重起。使用自身配置的起手规则，当前 first_hit=0 不要求额外增加逻辑前摇，动画不得延迟权威伤害。

## 周期伤害

流血、中毒属于减益伤害状态，不需要为了放进控制系统而伪造一个“无法行动”标志。两者可先共享 `PeriodicDamage`，区别只在来源标签、伤害参数、图标、特效、音效；没有必要现在就增加两套几乎相同的执行器。

默认同一来源同一效果刷新时长、不叠每跳伤害；不同来源分别保留与结算。刷新不重置下一跳到无限远，也不在每次刷新时白送立即伤害。持续区域每 Tick 续期时尤其要避免这两种错误。

默认在施加时固化来源伤害参数与归因，命中时读取目标当前防护。施加者死亡后，已经附着的普通毒仍能结算；依赖活着的光环来源的效果则随提供者消失，二者在定义中区分。

毒伤不会触发普通攻击的连击、普攻吸血、强化下一击消费或普攻附带控制，除非定义明确允许其他收益。目标处于眩晕/禁锢时照常扣血；敌方不可选中时，已经附着的毒照常扣血；凝滞时跳过该次执行，但时长继续。

每个实例自己的伤害/治疗小数余量独立保存。被免疫或凝滞跳过的执行不能积攒为未来伤害。展示上的跳字和声音可以合并限频，权威伤害不能因表现预算而少结算。
