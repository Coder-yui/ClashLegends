# 卡牌机制与数据边界

单位的中文玩法和数值见 [单位手册](units/README.md)。本页供新增内容或修改机制时使用。

## 定义与运行状态

每卡定义放在 `scripts/data/cards/<id>.gd`，由 CardDB 注册和查询。四个域分别负责战斗、模型表现、卡面和可选音频。

定义递归只读，单位各自持有生命、目标、控制、攻击和技能状态。临时覆盖只复制该卡，不能修改共享库，也不能每次查询复制整个库。模型和音频使用同一套形态选择规则。

CardDB 提供卡牌查询、可选卡列表、单位数据和技能候选；新增普通卡只需数据、注册与资源，不建立英雄 Unit 子类。游戏内说明由 CardDetails 读取定义，用户手册用中文同步维护。

## 类型与几何

| 类型 | 关键规则 |
| --- | --- |
| 单位 | 通用 Unit；目标、攻击、速度、半径与状态由数据决定 |
| 建筑卡 | 不自主移动；占地格用于部署，身体半径用于碰撞；可有寿命和召唤 |
| 法术 | 必须有已实现的法术类型；当前为冰冻、治疗，由 SpellSystem 执行 |

`radius` 是唯一权威身体半径，模型缩放与 `visual_radius` 只影响画面。标准体型按档位校验；明确使用非标准半径时声明 `custom_radius`，仍要求合法正数。

普通弹体用 `projectile_spawn_at_edge` 指定从身体边缘或中心起算，再沿发射方向加 `projectile_spawn_offset`；命中使用 `projectile_collision_radius`。三者均是 gameplay 权威字段，与速度一起在出手时固定到弹体实例。未配置时从中心发射，偏移 0，单位弹体半径 4；防御塔半径 7。现有艾希半径 3，艾希/提莫/小纳尔/冰鸟从身体边缘再前移 7.5，保留此前实际行为。

`projectile_visual`、高度、缩放、视觉偏移、命中特效与音频不参与权威出生或碰撞。真实技能弹体仍由 gameplay 的 `length`、`projectile_flight_duration`、数量、扇形角度或梯形宽度定义飞行与碰撞；仅替换表现不得改变逐 Tick 轨迹和伤亡。弹体回归分别覆盖普通远程、建筑/防御塔及真实技能弹体。

限时建筑可随寿命衰减生命；护盾不能延长自然寿命。允许塔墟重建的建筑，由正式部署校验记录塔墟身份并取消该实例衰减；不要靠画面重叠推断合法。

## 已有机制

| 机制 | 用途 |
| --- | --- |
| 普攻、持续攻击、溅射、首击、延迟追加刀 | 单次或持续输出；真实命中后才发放收益 |
| 强化下一击、致盲、命中回血、吸血 | 沿用普攻时间线，不因按钮或动画额外结算 |
| 范围打击、前方区域、持续区域 | 圆形、扇形、梯形等；区分固定落点与跟随施法者 |
| 真实技能弹体 | 停在首个目标或穿透；按碰撞和施法目标集合去重 |
| 增益、护盾、技能资源 | 各实例计时；资源只在实际携带对应技能时启用 |
| 周期/死亡召唤、死亡替身、定时复生 | 通用生成入口，召唤引用必须有效 |
| 编队与双形态 | 编队成员各自独立；形态切换保持同一单位身份 |

主动效果由 ActiveSkillEffectSystem 处理；普通单位经 `_spawn_unit()`，法术经 `_cast_spell()`；玩家、AI、RPC 和工作台都通过 `play_card()` 提交卡牌动作。

## 技能时序与归属

请求入队时扣技能金币；技能真正开始时扣次数、启动冷却并固化资源。效果执行延迟与施法总时长都从开始时计，满足效果节点不晚于施法结束；真实弹体命中可以发生在之后；权限由技能配置决定，不能从动画反推。

编队技能以部署编号与阵营确定归属，在效果实际执行时查询同次部署的存活成员，持有者死亡后转交资格。资格与工作台独立保存部署编号，不依赖已释放的成员引用；全批死亡后不回退到旧批次。所有成员保留下牌来源卡，异构编队不能按成员类型推断所属卡牌。再次部署替换主动槽资格，不移除旧编队已经获得的持续效果。法术放入主动槽时使用其强化规则，不创建单位技能实例。

多剪等多次命中技能分别配置各段伤害与时刻；结束回血可要求同次技能实际命中过目标，空放或免疫不算。生命、伤害与吸血计算见 [数值规则](NUMERIC_SYSTEM.md)。

## 扩展与验证

新机制按“规则 → 通用实现 → 字段及校验 → 必要联网 → UI/手册 → 领域测试”推进。新字段必须有读取方，不得只让校验接受一个没有效果的配置。

CardValidator 检查字段、类型、时序、资源、召唤与动作关系；完整回归还会实际加载所有模型、核对动画与卡面。普通卡复用通用契约，特殊机制才增加专项断言。

动画字段见 [配置参考](reference/ANIMATION_CONFIGURATION.md)，声音能力见 [事件参考](reference/AUDIO_EVENTS.md)，完整交付见 [新卡清单](NEW_CARD_CHECKLIST.md)。

## 叠加与取消规则

| 情况 | 当前规则 |
| --- | --- |
| 多次获得护盾 | 每次施加独立成层，不合并计时、衰减或零头。瑟提 W 只衰减该次自身护盾，友方盾维持自己的完整期限。 |
| 多层抵伤顺序 | 最早到期者优先；同刻到期按获得顺序。一次伤害可连续消耗多层，剩余伤害才扣生命。 |
| 护盾显示 | 总盾量为各有效层剩余量之和；容量只统计仍有效的层。客户端只显示权威快照。 |
| 减速、减攻速、主动增益 | 保留最长窗口、最强倍率及已有免疫合并规则，不改为独立来源相乘。 |
| 主动请求入队 | 立即扣费，保存原付款者和实际金额；重复请求不重复付款。 |
| 入队后控制、变形、资格替换等阻止施放 | 存活单位取消时退回原金额，金币不超过 10；未开始施放不消耗使用次数或冷却。 |
| 入队后因死亡无法施放 | 不退款；编队技能可转交存活成员时继续原请求，不重复付款。 |
| 已开始施放 | 消耗使用次数与冷却，收据结清；冻结/眩晕暂停施放及尚未触发的效果，解除后继续，不视为取消。死亡会取消尚未发生的效果，不退款。 |
| 终局、退出、工作台清场 | 关闭本局经济并清理所有排程、收据，不向已结束的对局追加退款。 |

护盾顺序参考《英雄联盟》的常规护盾描述（[社区机制资料](https://leagueoflegends.fandom.com/wiki/Shield)，核对于 2026-09-14），本项目明确采用上述顺序；不引入资料中特殊护盾的例外优先级，也不将其视为所有游戏通用标准。

## 建筑命令与占地

建筑命令接受时只检查已存在的结构，扣费并轮换手牌；等待生成期间不预留占地，不阻挡下牌或行军。例如 A 在 0 秒下牌、0.5 秒生成，B 在 0.25 秒提交同一占地、0.75 秒生成：两条命令均接受，A 原地生成，B 真正生成时重新校验，挪到离原落点最近的合法格，不退牌、不退费。共边允许，重叠禁止。同距离按己方视角行、列固定顺序选取；同 Tick 命令依队列顺序逐个生成。额外预部署阶段结束时也重新校验。主机生成并同步实际坐标，客户端不自行挪位。全场无合法位置时保留命令，每 Tick 重试，终局或清场统一取消等待。

存活防御塔对受结构占位约束的卡牌统一阻挡。公主塔死亡后，普通兵种与其他建筑将废墟视为正常地面，仍遵守阵营部署区域等规则；太阳圆盘占地若与废墟重叠，只允许中心精确对齐废墟正中心，其他重叠均拒绝。圆盘也可在不重叠废墟的其他合法位置下牌。塔墟重建效果按实际生成位置计算：被挤到普通地面的圆盘仍按普通建筑寿命衰减。


## 原始定义的四域契约

`CardDefinitionCompiler` 在平铺编译前检查字段归属和同名冲突；`CardSchema.CARD_VISUAL_FIELDS` / `SKILL_VISUAL_FIELDS` 明确列出表现字段，其余已登记规则字段放 gameplay。不允许依赖合并顺序静默覆盖。半径、弹体碰撞、技能飞行时长和伤害仍在 gameplay；颜色、模型、动画、弹体绘制高度等放 visual。card_art 只放卡面路径，audio 放声音配置。

主动技能的规则列表放 `gameplay.active_skills`，表现列表放 `visual.active_skills`；后者配置时必须与规则列表等长，没有表现覆盖的技能写 `{}`。编译按索引合并，运行系统仍读取平铺的 `active_skills`。表现列表不能写伤害、费用等规则，也不能与规则列表重复声明字段。

变形配置分别写在 `gameplay.transformed_stats`、`visual.transformed_stats`、`audio.transformed_stats`，每项仍只包含所属域的字段；编译为同一个运行期 `transformed_stats`。形态音频保持原有选择语义，不隐式继承另一形态。可参考纳尔定义。编译只发生在内容初始化；编译结果深复制并递归只读，运行实例继续持有自己的副本。

`CardShapeValidator` 先检查容器、字段类型和数值有限性，类型失败时停止后续资源及跨字段校验；通过后由原 validator 检查必填、范围、引用、资源和真实消费者。新增字段除了白名单和消费者，还须更新类型/域分类及异常输入回归。错误包含卡牌、字段路径、期望类型与实际值。


## 同刻命中与追加刀（规则协议 20）

保持 20Hz 和既有阶段先后：已开始技能的到期影响 → 技能区域 → 部署 → 新技能命令 → 法术区域 → 单位/塔行动 → 移动 → 在途弹体 → 胜负检查。技能影响、区域、技能命令、单位/塔和弹体各自在自己的阶段收集到期命中；不把整个 Tick 合成一个伤害批次。

每批先固定合法目标、伤害、来源形态、权威攻击段及附带效果，收集时不扣对方生命或施加控制。随后逐刀消耗独立护盾层并扣血；全批血量确定后提交控制、逐刀命中回调、存活来源收益及一次性死亡/召唤/替身。该批新产生的死亡或控制不撤回已经提交的攻击；更早阶段或 Tick 已经死亡、冻结/眩晕等非法状态仍阻止新攻击。新生单位不进入已收集的批次。普通受伤不增加通用硬直。

剑圣按累计主攻击的三段循环产生追加刀：第 3、6、9…次主攻击出手后才排队，追加刀不推进主攻击周期。前摇取消不占用权威段，重播动画/音效重新对齐该段。每刀独立消费致盲，既有同动作命中音效去重仍保留。

追加刀使用与前后摇相同的有效攻速（包括增益、减攻速及免疫）；速率变化或效果到期按旧/新速率比例缩放剩余时间，移速不参与。冻结/眩晕暂停，解除后续计；已出手连击不因移动、击退或后续施法取消。锁普攻施法仍显式重置旧主攻击时间线，强化普攻仍不重置攻击时刻。来源更早死亡会清理未来追加刀，目标失效则不再提交命中。

全部战斗阶段完成后才判断胜负；双水晶同 Tick 摧毁为平局（winner_team=-1、reason=nexus），单水晶正常判胜；已正式结束不接受晚到状态改判。


## 建筑自然退出与击退接管（规则协议 21）

在单位/塔行动批次之前，固定参与者快照并统一推进建筑自然寿命和生命衰减，立即提交到期退出及导航解除。自然到期的建筑不再被本阶段索敌或命中，也不执行攻击、首次或周期召唤；退出生成的对象不回头加入这份参与者快照。之前技能、命令、区域阶段的结果不追溯撤销。部署尚未完成以及 Tick 起点仍冻结/眩晕时，寿命仍暂停；部署本 Tick 正常结束时推进一次。预处理不推进部署、控制或召唤计时，行动阶段不再重复推进寿命。自然衰减不是受击，不耗盾、不给攻击者收益。

伤害请求的 `accepted` 只表示收集成功；提交扣血前统一冻结 `landed`，排除已自然退出的目标，但不按本批逐刀实时血量撤回同刻合法命中。`health_lost` 表示按既有比例分摊的实际掉血；全盾吸收可同时满足 `landed=true`、`health_lost=0`。命中回调依赖最终 landed，存活收益仍要求来源在全批伤害后存活。

击退采用最后合法事件接管：从目标当前实际位置重设方向、质量修正后的距离和持续时间，停止旧位移的剩余部分；不相加、不排队、不恢复旧位移。较弱、较短的新击退同样接管。校验存活、建筑限制、有限有效距离等现有条件后才替换状态；非法请求不清理旧状态。独立控制、护盾、已经造成的伤害和已提交追加刀不被覆盖；地形约束和冻结/眩晕暂停规则不变。当前位移只有同步状态，没有异步完成回调。

跨 Tick/阶段按既有先后；同阶段击退在 CombatResolver 内按 `[combat_source_id, 来源内事件序号, 效果子序号]` 升序提交，最后合法事件接管。`combat_source_id` 是战场接入时分配的单调出生身份（单机与塔也有身份），不取场景树排序或对象地址；来源内序号在普攻出手/弹体发射、技能排队或部署横扫开始时确定，多段技能使用段子序号，弹体保留原身份。相同权威身份下容器或回调排列不影响结果；改变出生身份或事件序号属于改变权威事件，而非排列测试。此为项目内部平手约定，不宣称复刻 LoL 服务器算法。客户端不重算排序，只接收权威位置和可靠实体生命周期，无新增网络确认。

## 横排编队与恢复护盾

`deployment_formation` 支持 ring（默认）与 line；line 按相邻中心间距横排，正常下牌校验横排中心跨度，边缘身体在生成时逐兵限制到合法位置，不平移整排、不修改行走逻辑。`restoration_shield` 使用现有 shield / shield_duration / target_scope 字段。ShieldState 独立保存每层是否具备自然到期恢复资格；破裂或清除不发放恢复，Unit 只在权威存活时回复缺失生命。此盾计时沿用普通护盾，不因硬控延长，其他盾层不替代判断。

## 限时形态与分段吸血

`timed_form`主动效果切换到transformed_stats；基础定义的form_lifetime控制持续时间，form_refresh_on_kill决定敌方Unit击杀是否刷新。形态结束恢复基础数值并将溢出当前生命截到基础上限；飞行转地面时修正非法落点。

attack_passive_multipliers与attack_lifesteal_ratios分别定义每段独立百分比附伤倍率和实际生命伤害吸血比例。它们与攻击动画等长；当前消费者限定无追加刀、无溅射的单体近战。已出手推进段，取消前摇不推进；进入/退出限时形态和刷新击杀按配置循环起点重置。

`form_lifetime_after_transition`可让寿命从启动窗口结束后开始计时；`form_speed_boost_duration`与`form_speed_boost_multiplier`复用主动Buff移动倍率，开启及有效击杀刷新时发放。转换窗口只锁攻击，仍允许移动；持续阶段不因硬控延长。当前网络版本统一见MatchSession。

## 一次性建筑冲撞

`rush_*`规则字段由StructureRushState持有运行状态：准备、冲撞、收势、耗尽。配置限定地面普通单位、建筑索敌，召唤引用纳入预加载及校验。水域/建筑按完整圆柱直线检查，桥面可通过；当前位置无法冲撞时搜索可达发起点，接近途中逐步复检。准备2.5秒，眩晕/冰冻/击退均可打断并停止准备声音；解除后从当前位置重新索敌验证路线、完整准备且不消耗机会，冲撞拒绝控制；碰撞推进仍在MovementSystem，沿途伤害和建筑命中使用原单位行动阶段的CombatResolver批次。

冲撞撞击发生在抵达终点后的下一权威步；先结算该阶段伤害，再扣存活来源当前生命比例并生成召唤物。开始冲撞消耗唯一机会，目标失效或新增结构挡路不返还。所有伤害、召唤及位移都不由动画触发。当前协议35，沿用40项单位快照，冲撞动作/朝向通过现有动作字段同步；180°前方扇形现在合法，超过180°拒绝。

`passive_first_hit` 可为 `attack_passive_multipliers` 循环中比例大于零的被动刀单独指定前摇，须在0与攻击间隔之间；未配置沿用 `first_hit`。前摇选择不改变命中间隔；表现按已发布攻击序号读取本刀前摇，避免命中后计数前进导致错位。

冲撞伤害延迟提交时也复检先锋存活：同批死亡不执行自伤后孵化回调。成功撞中插入路线的新敌方建筑正常孵化；蠕虫权威出生点集中在接触点外侧，使用既有击退移动向外散开。

先锋发起点搜索首次立即执行，失败结果同样等待0.4秒重试；目标、位置、导航阻挡修订或当前路段失效时立即重判。搜索失败清空旧路径，候选仍按原行列及最短实际路径长度稳定选择。

技能请求等待期间进入建筑冲撞的准备、冲刺或恢复阶段，执行时统一取消并退回原实际付款；次数和冷却尚未消耗。金币的所有写入（自动回复、退款、未来奖励和直接赋值）均通过 ElixirManager.elixir 的 setter 限制在0至10。最新同卡部署替换旧资格并取消旧待执行请求；新批次全灭不恢复旧批次资格。

## 普攻起手、命中宽限与追击（规则协议40）

普通单位攻击严格在卡牌表面射程内起手。起手后，前摇期间目标出圈不因距离提前取消；到权威命中节点才检查表面距离是否不大于射程加20px（半格）。边界相等允许命中，超过则取消本次出手，不造成伤害、不推进普攻段和命中收益、不进入后摇，恢复追击。宽限不用于新攻击起手；远程普通攻击在离弦节点检查，已经生成的弹体沿用原规则。持续攻击没有普通出手前摇，仍按原射程规则处理；塔自身攻击逻辑不变。

成功出手后，普通单位完整读完后摇才能移动或开始下一击。行军不携带上一段攻击的剩余间隔。目标失效、控制、击退、技能锁和形态变更仍走各自现有处理；本次只调整距离引起的取消规则。

`attack_recovery_cancel_every_hits` 为非负整数，0禁用。配置N时，每N次普通出手结束后，若没有正常射程内可攻击目标，允许提前结束后摇并清除剩余攻击间隔。瑟提配置2：第一拳后保持双拳节奏，第二/四拳结束后可转走；随后重新进入正常射程就从正常前摇开始，不等待旧拳的剩余间隔，不重置拳段。始终有圈内目标时，仍保持0.6/1.4秒的双拳命中间隔。
