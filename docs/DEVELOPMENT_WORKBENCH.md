# 开发工作台使用说明

F5 启动项目，进入 **卡牌开发工作台**。也可运行 `Godot --path . -- --mode=workbench`。

工作台有 **模型、实战、音频与信息** 三页。左侧控制、右侧展示，退出后恢复游戏窗口。只读取正式卡牌和系统对象的配置，候选素材仍使用 [通用展台](../tools/README.md)。

## 模型观察

点击 **选择模型 / 对象** 打开可搜索的方块网格，点击一个模型即选择并关闭；本页只列已有模型的对象，不显示实战快捷栏。基础 / 变形形态仍可通过形态框快速切换。正义天使共用一个模型入口，以“近战形态 / 远程形态”切换模型部件、动作、音频与信息；实战部署也使用所选形态。

左侧常驻动作列表列出模型全部动画，绿色表示已接入，灰色表示未使用，并显示配置用途与动画总时长。点击动作播放；拖动时间轴可暂停在任意位置，**继续**从当前位置播放，**重播**才从头开始。下方可旋转、缩放、复位右侧模型。没有逐帧按钮。

源动画存在不代表已经用于实战；动作列表用于定位片段，真实动作衔接请到实战观察。

## 音频与信息

选择对象和形态，左侧按实际音频事件筛选，逐条列出已接入的文件变体及总时长；右侧展示卡面、当前形态属性、被动与主动技能，使用与备战详情相同的展示规则。卡面与简介横排，属性和技能分栏展示，减少上下滚动。双击一条或使用 **播放选中** 试听；播放器显示当前 / 总时长，支持暂停、继续、拖动和停止。切页、换对象或退出会停止试听。独立试听不替代实际对战事件检查。

## 实战观察

默认 **100%** 表示完整 720×1280 战场适配右侧区域。滚轮可放大至 300%，右键 / 中键拖动；**复位**同时恢复全图比例和居中。工具位于地图外，窗口变化不改变权威战场。

### 固定实验操作区

快捷开发槽固定在主栏下方，再下方是一行 **木桩、清场、暂停、复位、放置 / 选择** 五个按钮。放置 / 选择为同一个切换按钮，显示当前模式。下面依次是技能控制板、场景控制板、控制技能控制板，控制区采用紧凑间距，常用操作直接展示；内容超过可用高度时才滚动。

点击 **选择实验卡** 打开编辑框，上方是全部卡牌和模型，下方是 0–8 个快捷槽。点击上方卡牌加入，点击下方槽位移除。关闭编辑框后，点击快捷槽或数字键 **1–8**选中待放置卡，再点击地图部署。空快捷栏不能部署卡牌，木桩仍可独立放置。

快捷栏双方共用，自动保存顺序与空栏状态至本机 `user://workbench_quick_cards.cfg`。木桩独立于快捷栏。模型页和音频页不显示、也不使用快捷键切换实验卡。

### 放置与选择明确分开

| 模式 | 左键点击地图 |
| --- | --- |
| 放置 | 部署当前卡或木桩；法术按落点释放，不选中单位 |
| 选择 | 仅选中地图上的存活单位；点空地取消目标，绝不下牌 |

选卡、数字键、木桩和红蓝切换均不会自动退出选择模式。木桩按钮只将木桩设为待放置对象，在放置模式点击地图后按当前阵营生成。切卡、切阵营、切放置 / 选择模式保留场上单位；**清场**清除单位与效果并取消操作目标，不清空快捷栏。

### 当前操作单位

待放置卡和操作单位分别显示。新部署的单位自动成为操作目标，也可以切到选择模式后点击已有单位。目标有黄色选中圈，左侧显示名称、阵营、生命和编队批次；切换待放置卡或阵营不会改变操作目标。

控制效果只施加给点选的那个成员；技能来源取自操作单位，整组技能仍作用于同次部署的存活成员，面板会显示范围。目标死亡后不自动转交或回退其他单位，需重新选择。**暂停 / 继续**可用于准备实验；切页或打开选牌框暂停战斗，关闭后按原来的手动暂停状态恢复。

## 经典场景

在场景控制板中选择场景后点击 **重建场景**，可从相同布局反复观察。

| 场景 | 用途 |
| --- | --- |
| 敌人包围 | 八名地面近战环绕，观察范围技能、转身和索敌 |
| 拥挤过桥 | 友军过桥，对岸有敌人，观察排队、推挤和交战 |
| 远近夹击 | 近战牵制、远程侧击，观察选敌与防御技能 |
| 单体对战 | 对阵盖伦，观察首击、连续攻击和技能 |

蓝红布局会镜像；多单位卡正常生成编队，法术在样本中心施放。防御塔会正常参战，建筑与空军不会被强制行军过桥。

**清场**只清理单位和效果；**重建场景**还会恢复防御塔、导航与完整布局。

## 使用限制

- 切离实战页会暂停该页战斗和声音，回来继续；模型预览的暂停只影响预览模型。
- 操作目标是显式选中的单位，死亡后不自动转交。整组技能仍在实际生效时筛选同批存活成员。
- 牌库可直接选择“大灭形态剑魔”与“大纳尔”，或使用形态菜单；模型和音频按选定形态展示，实战通过原卡 play_card 生成后进入变形。之后仍按真实机制结束大灭/变回小纳尔。
- 工作台不运行正式金币、手牌、AI、兵线和倒计时，也不消耗正式技能使用资格；不能用它证明费用或联网资格正确。
- 工作台跳过通用命令缓冲，但保留卡牌自身预部署与部署。例如卡牌大师仍有 1.3 + 0.45 秒两阶段。
- 独立试听没有世界距离衰减；切页、换卡或退出会停止试听。音频页只列当前形态与阵营的正式配置；未接入候选请用独立声音展台比较。

开发与验证入口见 [维护架构](MAINTENANCE_ARCHITECTURE.md) 和 [测试手册](../tests/README.md)。

工作台仅用于预览和操作实验，不保存验收勾选、备注或导出报告。任务结果由 Agent 按 [交付模板](templates/delivery.md) 写入交付报告；用户反馈可以直接在对话中提出。

镜像法术：先在同一阵营放置原卡，再选择镜像放置；“完整镜像”开关决定复制体是否携带原卡预选技能。开启后可在镜像页对最新复制体预览技能；清空后需要重新放置原卡。正式两槽费用与资格仍以实战回归为准。

凯隐可选择普通、蓝凯、红凯定义分别预览模型和Q；正常对局卡组只可选择普通凯隐。工作台通过普通凯隐成长后，已选场上实例的实际定义决定技能预览，不能用普通Q覆盖红凯/蓝凯。清场重置局内成长；详情和战斗手牌显示实际形态，手牌提示包含成长计数。
