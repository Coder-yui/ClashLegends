# 开发工作台使用说明

F5 启动项目，进入 **卡牌开发工作台**。也可运行 `Godot --path . -- --mode=workbench`。

顶部搜索中文名，选择单位、衍生对象或木桩；蓝红按钮决定预览外观和实战阵营。想先了解对象，请看 [单位手册](units/README.md)。

## 三个页面

| 页面 | 可以做什么 |
| --- | --- |
| 模型·动作 | 选动画、重播、暂停、拖时间轴、前进 1/30 秒；旋转、缩放和复位模型，比较形态 |
| 实战·技能 | 放单位和木桩、释放技能、调整充能、切换强化法术、施加控制、观察死亡 |
| 音频 | 筛选声音、试听变体、暂停继续、拖动进度；查看音量设置 |

模型页可能显示未接入实战的源动画；播放素材不代表它已用于游戏。单独试听也不证明实战触发正确。没有模型的法术可以直接到实战页检查。

## 推荐顺序

1. 选对象，检查模型、卡面、双方外观和可用形态。
2. 到实战页放置对象与木桩，观察部署、攻击和命中；技能分别试空/满资源。
3. 攻击或施法中施加冰冻、眩晕或减速，等待恢复，检查动作和持续声音。
4. 回音频页定位问题声音，再到实战确认时机、响度和中断。

## 经典场景

在实战页选择场景后点击 **重建场景**，可从相同布局反复观察。

| 场景 | 用途 |
| --- | --- |
| 敌人包围 | 八名地面近战环绕，观察范围技能、转身和索敌 |
| 拥挤过桥 | 友军过桥，对岸有敌人，观察排队、推挤和交战 |
| 远近夹击 | 近战牵制、远程侧击，观察选敌与防御技能 |
| 单体对战 | 对阵盖伦，观察首击、连续攻击和技能 |

蓝红布局会镜像；多单位卡正常生成编队，法术在样本中心施放。防御塔会正常参战，建筑与空军不会被强制行军过桥。

**清空重测**只清理单位和效果；**重建场景**还会恢复防御塔、导航与完整布局。

## 使用限制

- 切离实战页会暂停该页战斗和声音，回来继续；模型预览的暂停只影响预览模型。
- 当前操作对象是最后放置的同卡、同阵营存活单位。切卡不会清掉已有对手。
- “变形素材”用于预览比较，实战形态仍由实际机制决定。
- 工作台不运行正式金币、手牌、AI、兵线和倒计时，也不消耗正式技能使用资格；不能用它证明费用或联网资格正确。
- 工作台跳过通用命令缓冲，但保留卡牌自身预部署与部署。例如卡牌大师仍有 1.3 + 0.45 秒两阶段。
- 独立试听没有世界距离衰减；切页、换卡或退出会停止试听。候选原声只供比较，不自动在实战播放。

开发与验证入口见 [维护架构](MAINTENANCE_ARCHITECTURE.md) 和 [测试手册](../tests/README.md)。

工作台仅用于预览和操作实验，不保存验收勾选、备注或导出报告。任务结果由 Agent 按 [交付模板](templates/delivery.md) 写入交付报告；用户反馈可以直接在对话中提出。
