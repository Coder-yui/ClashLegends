# 数值与结算规则

具体单位数值见 [单位手册](units/README.md)。本页只说明所有单位共同遵循的计算方式。

## 精度

| 数值 | 规则 |
| --- | --- |
| 生命、伤害、治疗、护盾、费用、次数 | 整数，结算时四舍五入 |
| 玩法时间、距离、速度、质量 | 配置最多两位小数，能用整数时优先整数 |
| 比例与倍率 | 按百分数最多两位小数，例如 12.50% 内部保留为 0.125 |
| 动画裁剪、音频排程、模拟余量 | 保留所需精度，不逐帧截断 |

战斗每秒更新 20 次，每步 0.05 秒。配置可写两位小数，不代表模拟每 0.01 秒运行一次。

## 伤害、治疗与吸血

单次伤害先计算基础值和倍率并取整；独立附加被动另行取整，再相加。之后先扣护盾，再扣生命。没有“最少造成 1 点伤害”的规则。

例：101 × 50% 取整为 51，独立附伤 101 × 5% 取整为 5，合计 56。格温的被动附伤不会被普攻基础强化倍率再次放大。

吸血只按实际损失的生命计算，不包含护盾吸收或过量伤害。目标只剩 7 血，被打 55 点，25% 吸血回复 2；全护盾吸收则回复 0。范围吸血尚未定义。

治疗与护盾同样在结算时取整；普通治疗不能反向削掉已有溢出生命。允许溢出的技能按各自上限处理。

## 持续效果

- 每秒伤害保留每个来源、每个目标的累计余量，再分配整数伤害。55 点/秒不会因每步独立取整变成 60 点/秒。
- 离开范围不扣血，重新接触沿用该目标余量；换目标不转移余量，目标死亡清理。
- 区域技能写的是每次脉冲伤害；持续吐息写的是每秒伤害，不能混读。
- 限时建筑按最大生命与寿命衰减，额外伤害可使其提前死亡；护盾不承担自然衰减，也不能延长寿命。
- 衰减护盾同样累计分配，期限结束清空；暂停不积累模拟外时间。

面板每秒伤害是基础理论均值，不包含主动技能、条件被动或目标相关附伤。

实现与验证：`BattleNumbers` 统一取整，CardValidator 检查精度；[测试手册](../tests/README.md)包含数值回归。历史数值只供追溯，见 [旧基准](archive/2026-09-13/numeric_baseline.md)。


## 同批多来源伤害归属

同批每刀独立保留伤害与命中记录。目标的盾仍按独立层既有到期/获得顺序扣除；实际生命损失和护盾吸收分别按各刀有效伤害占本批总伤害的比例归属，不按先后遍历挑尾刀。分配保留小数，所有来源的掉血归属之和等于目标本批实际掉血；吸血再沿用每次治疗取整规则。例：目标 90 血、30 盾，同时受到 120 与 60 伤害，掉血归属分别为 60、30，盾归属为 20、10。被免疫或致盲的刀不参与分配。

先确定全批血量，再发放存活来源的逐刀回血、吸血、攻击/命中资源及形态收益；该批致死来源不能用回调恢复。共同致死时，每个有实际掉血归属的存活参与来源对该目标至多得到一次击杀资源回调，不因同批多刀重复领取。此规则替代原先依赖遍历顺序的尾刀归属；卡牌数值不变。
