# 当前开发状态

更新于 2026-09-14。项目支持单机和本机/局域网主机权威对战，包含 22 张可选卡与 2 个衍生对象。[单位手册](units/README.md) 按独立形态、建筑和地图整理为 29 篇总览。

## 已有能力

- 卡组、部署、普攻、主动技能、控制、碰撞寻路、兵线和比赛结算。
- 独立的模型动画、特效、音频与联网表现。
- 工作台支持模型动作、实战技能和音频试听。
- 统一机制回归与资源/文档审计。已有 706 项机制断言通过记录，见 [整理验收](archive/2026-09-13/project_cleanup.md)；它不代表后续修改自动通过。
- 正式对战使用二维峡谷背景，3D 峡谷仍是独立候选预览。

## 尚未完成的工程验证

- 当前发布目标为 Mac；手机暂不在目标内。广域网连接、高延迟与丢包长测尚未完成。
- 当前 M5 Mac 已完成 305 秒完整渲染对局和 32/64/128 单位矩阵；高负载与批量模型变化仍有尖峰，见 [性能交付](deliveries/2026-09-14_工程审查E2_Mac性能基准.md)。
- 完整背景音乐和通用操作音配置。
- 工作台只作预览器；任务交付记录见 [交付目录](deliveries/README.md)，工程待办见 [问题目录](issues/README.md)。

新工作按 [接入清单](NEW_CARD_CHECKLIST.md) 推进；历史过程见 [归档](archive/README.md)。
