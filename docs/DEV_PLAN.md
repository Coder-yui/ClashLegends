# 当前开发状态

更新于 2026-10-07。Godot 标准版 1v1 学习项目，支持单机及本机独立服务器加两个客户端的权威对战；首期断线结束，玩家身份与连接分离，为后续重连保留边界。完整版本固定在 `godot-version.txt`；正式对战窗口 720×1400、权威战场 720×1280，工作台可使用独立宽屏布局。

## 已有能力

| 范围 | 当前能力与入口 |

| 内容 | 当前可选卡、形态、衍生物和系统对象见[单位手册](units/README.md)，每卡四域定义位于 scripts/data/cards |
| 特殊机制 | 限时/致死换形、固定圣霭、按金币选形态、镜像、流血与免费追斩、局内成长、穿地形、两段突进、命中攻速、预部署扫掠、永久队伍普攻增幅、固定速度地形冲锋、控制延后召唤与一次性永久体型/生命成长；支持边界见[卡牌机制](CARD_DESIGN.md)及[状态现状](status/IMPLEMENTATION.md) |
| 表现 | 3D 峡谷、独立模型/动作/特效/音频；预热与模型复用；控制和回血共用特效；己方蓝模/敌方红模及塔朝向按观察方呈现；表现不驱动模拟 |
| 工作台 | 全卡搜索、0–8 张实验快捷栏、独立放置/选择、成员控制/整组技能、模型动作定位、声音变体试听、观察缩放与窗口恢复，见[使用手册](DEVELOPMENT_WORKBENCH.md) |
| 工具 | 素材库分阶段管理、通用模型摄影与音频展台、支持多单位/特效布景及方案保存的峡谷封面摄影台、联调副本、按领域自动回归、资源/文档/注册审计、Mac 导出；见[工具索引](../tools/README.md) |

训练木桩建筑卡已接入：2×2占地、稍大碰撞、不可普攻、余震减伤到期爆炸；内容见[训练木桩](units/target_dummy.md)。剑圣高原血统使用黄色平行后向流线，移动减速按实际移动距离留下对称拖尾。系统对象卡面与柔光摄影参数见[卡面记录](../assets/cards/workbench_portraits.md)。

当前还支持可配速在途法术、凝滞与金身标识隔离、图奇公开玩家视图隐身，以及瑟提/图奇共用严格脱战。具体边界只在[实现现状](status/IMPLEMENTATION.md)和对应规则页维护；逐卡核对见[覆盖记录](reference/UNIT_DOC_COVERAGE.md)。

[先锋](units/rift_herald.md)准备时锁定目标，新建筑由冲撞中的实际接触挡停；[墓碑](units/tombstone.md)寿命20秒，被击杀或自然死亡均额外释放两只雾行者。建筑自然衰血与到期生成遵循[生命周期合同](status/ACTIONS.md#自然寿命周期产出与复生)。

## 尚未完成的工程验证

- 当前目标为 Mac；手机暂不在目标内，Intel 与广域网高延迟/丢包长测没有完整验收。
- M5 Mac 既有完整对局、加载和模型池测量属于历史证据。极端超库存仍可能卡顿，未保证全场景稳定 60 FPS；新的结构整理不构成新的性能认证。
- 背景音乐按当前决定暂不加入；通用操作音未完整配置。人工观感与听感按每份改动记录分别记录。
- Main、Unit 和模型代理仍较大，后续按状态所有者逐步拆分；不为文件变短而增加无职责的转发层。
