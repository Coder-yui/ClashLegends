# 当前开发状态

更新于 2026-09-27。Godot 标准版 1v1 学习项目，支持单机及本机/局域网主机权威对战。完整版本固定在 `godot-version.txt`；正式对战窗口 720×1400、权威战场 720×1280，工作台可使用独立宽屏布局。

## 已有能力

| 范围 | 当前能力与入口 |
| --- | --- |
| 对战 | 20Hz 权威模拟、随机首手与轮换、部署排程、主动资格、金币、兵线、碰撞寻路、同刻批次结算及可靠终局 |
| 内容 | 当前可选卡、形态、衍生物和系统对象见[单位手册](units/README.md)，每卡四域定义位于 scripts/data/cards |
| 特殊机制 | 限时/致死换形、固定圣霭、按金币选形态、镜像、流血与免费追斩、局内成长、穿地形、两段突进、命中攻速和预部署扫掠；支持边界见[卡牌机制](CARD_DESIGN.md)及[状态现状](status/IMPLEMENTATION.md) |
| 表现 | 3D 峡谷、独立模型/动作/特效/音频；预热与模型复用；控制和回血共用特效；表现不驱动模拟 |
| 工作台 | 全卡搜索、0–8 张实验快捷栏、独立放置/选择、成员控制/整组技能、模型动作定位、声音变体试听、观察缩放与窗口恢复，见[使用手册](DEVELOPMENT_WORKBENCH.md) |
| 工具 | 素材库分阶段管理、通用模型摄影与音频展台、联调副本、按领域自动回归、资源/文档/注册审计、Mac 导出 |

## 正在推进

- 各卡模型、特效、动作中断及并发混音继续按单位专页核对；资源存在不等于目视或听感通过。
- 原版粒子仅接入已经核验的能力，未实现的原引擎行为不标为完成；潘森落地特效已于2026-09-27按用户确认定稿，具体时序/覆盖范围与未完整支持项见对应单位手册及素材记录。
- 声音缺项与暂不接入决定集中维护在[音频覆盖](AUDIO_CARD_MAP.md)，这里不复制逐卡清单。
- 开放缺陷集中维护在[问题目录](issues/README.md)；完成后迁入归档并保留交付链接。

## 尚未完成的工程验证

- 当前目标为 Mac；手机暂不在目标内，Intel 与广域网高延迟/丢包长测没有完整验收。
- M5 Mac 既有完整对局、加载和模型池测量属于历史证据。极端超库存仍可能卡顿，未保证全场景稳定 60 FPS；新的结构整理不构成新的性能认证。
- 背景音乐按当前决定暂不加入；通用操作音未完整配置。人工观感与听感按每次交付分别记录。
- Main、Unit 和模型代理仍较大，后续按状态所有者逐步拆分；不为文件变短而增加无职责的转发层。
