# 当前开发状态

更新于 2026-09-15。项目支持单机和本机/局域网主机权威对战，当前卡牌、独立形态与衍生对象见[单位手册](units/README.md)。

## 已有能力

- 卡组、部署、普攻、主动技能、控制、碰撞寻路、兵线和比赛结算。
- 独立的模型动画、特效、音频与联网表现。
- 工作台支持模型动作、实战技能和音频试听。
- 统一机制回归与资源/文档审计。最新验证见[任务交付](deliveries/README.md)，历史测试数量不代表当前工作区已通过。
- 正式对战使用二维峡谷背景，3D 峡谷仍是独立候选预览。

## 正在推进

## 尚未完成的工程验证

- 当前发布目标为 Mac；手机暂不在目标内。广域网连接、高延迟与丢包长测尚未完成。
- 当前 M5 Mac 已完成 305 秒完整渲染对局和 32/64/128 单位矩阵；高负载与批量模型变化仍有尖峰，见 [性能交付](deliveries/2026-09-14_工程审查E2_Mac性能基准.md)。
- 背景音乐按当前决定暂不加入；通用操作音仍未完整配置。
- 工作台只作预览器；任务交付记录见 [交付目录](deliveries/README.md)，工程待办见 [问题目录](issues/README.md)。

新工作按 [接入清单](NEW_CARD_CHECKLIST.md) 推进；历史过程见 [归档](archive/README.md)。

## 本轮内容

- 剑魔：四段吸血攻击循环、限时大灭与击杀刷新；同模型换形、原表动画衔接、部署/战斗/死亡声音已接入，粒子待制作。
- 工作台：独立选择大灭剑魔、大纳尔等形态，动画映射条目标色。
- 工具：中文台词定位本地LoL音频，支持事件解码与本地转写。
- 当前联网协议为28；详细规则与边界见[架构说明](MAINTENANCE_ARCHITECTURE.md)。
