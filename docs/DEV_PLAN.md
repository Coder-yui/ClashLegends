# 当前开发状态

更新于 2026-10-16。Godot 标准版 1v1 学习项目，支持单机及本机独立服务器加两个客户端的权威对战；首期断线结束，玩家身份与连接分离，为后续重连保留边界。完整版本固定在 `godot-version.txt`；默认设计窗口 720×1280（9:16），支持调整与 F11 全屏，权威战场保持 720×1280；窗口只改变取景与 HUD，工作台使用独立宽屏布局并在退出后恢复。

训练木桩建筑卡已接入：2×2占地、稍大碰撞、不可普攻、余震减伤到期爆炸；内容见[训练木桩](units/target_dummy.md)。剑圣高原血统使用黄色平行后向流线，移动减速按实际移动距离留下对称拖尾。系统对象卡面与柔光摄影参数见[卡面记录](../assets/cards/workbench_portraits.md)。

当前还支持可配速在途法术、凝滞与金身标识隔离、图奇公开玩家视图隐身，以及瑟提/图奇共用严格脱战。具体边界只在[实现现状](status/IMPLEMENTATION.md)和对应规则页维护；逐卡核对见[覆盖记录](reference/UNIT_DOC_COVERAGE.md)。

[远程虚空鱼大军](units/voidfish_ranged_army.md)已接入：5费六只、正六边形顶点部署，复用整批虚空再生。近远程虚空鱼出生溅射按原始概率表逐实例取样并保留项目尺寸；致盲新增通用随身标识及权威快照字段；赏金猎人W加速拖尾与双枪火焰已更新，普通弹体保持原实现。

[虚空召唤](units/void_summoning.md)已接入：4格范围、8秒10只虚空鱼、固定随机落点及圈内边界约束；强化额外1费转化范围内真正死亡单位。女皇大招与持续循环声音已接入，精确原版时序不可得，适配与听感待确认项见[音频页](units/audio/void_summoning.md)。

## 正在推进

- 工程精简已落地：工作台暂停统一推进门禁、主动请求与UI解耦、六类小兵生成计划、变化驱动的成长刷新、纯费用查询，以及弹体只读投影、快照采集/解码复用、部分固定几何/出生索引和依赖头。当前职责与数据流见[整体设计地图](MAINTENANCE_ARCHITECTURE.md#整体设计地图)，当次验收与测量由对应改动记录提供；这里不以任务批次编号充当架构状态，也不把局部优化等同于整局性能认证。
- 按用户当前状态，现有卡牌制作已完成，后续修正按单位专页和问题记录开展；不把这一状态等同于本轮重新逐卡目视或试听。主动技能图标已补齐，雾行者保留内部 `imp` ID。
- 3D 地图升级仍制作中，源件及预览工作路径保持在 `03-制作中/3D地图/`；已完成卡牌素材见[归档索引](reference/MATERIAL_LIBRARY.md)。
- 原版粒子仅接入已经核验的能力，未实现的原引擎行为不标为完成；潘森落地特效已于2026-09-27按用户确认定稿，具体时序/覆盖范围与未完整支持项见对应单位手册及素材记录。
- 声音缺项与暂不接入决定集中维护在[音频覆盖](AUDIO_CARD_MAP.md)，这里不复制逐卡清单。
- 开放缺陷集中维护在[问题目录](issues/README.md)；完成后迁入归档并保留交付链接。

单局准备已增加虚空召唤离线紧凑格式、剑魔本场派生模板及未选卡面缓存释放；实际可达性和保守预热保持。最新合法重卡组准备15.034秒、峰值RSS2.039GiB，尚未达到5秒；旧普通组5.773秒仅是历史版本，不提供整局提速百分比。证据和ObjectDB/首技能FPS等限制见[单局加载记录](deliveries/2026-10-16_match_loading.md)。

## 尚未完成的工程验证

- 当前目标为 Mac；手机暂不在目标内，Intel 与广域网高延迟/丢包长测没有完整验收。
- M5 Mac 既有完整对局、加载和模型池测量属于历史证据。极端超库存仍可能卡顿，未保证全场景稳定 60 FPS；新的结构整理不构成新的性能认证。
- 背景音乐按当前决定暂不加入；通用操作音未完整配置。人工观感与听感按每份改动记录分别记录。
- Main、Unit 和模型代理仍较大。对局/命令协调的继续收拢、其他内容家族的来源卡与生成定义关系，以及属性派生和一次性生命补偿的拆分仍是候选工作，尚未全面实施；不为文件变短而增加无职责的转发层。取舍见[当前实现与后续拆分](MAINTENANCE_ARCHITECTURE.md#当前实现与后续拆分)。
