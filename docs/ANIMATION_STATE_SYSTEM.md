# 动画与动作时序

本页解释共用行为；具体单位的片段与观看说明见 [单位手册](units/README.md)，开发字段见 [动画配置参考](reference/ANIMATION_CONFIGURATION.md)。

## 动作如何选择

基础状态是部署、待机和移动，上面可覆盖攻击、技能、变形和死亡动作。

优先级：**死亡 → 部署 → 变形 → 技能 → 普攻 → 待机/移动**。高优先级动作结束后，按最新战斗状态接回攻击、移动或待机。

战斗逻辑提供动作和时间进度；动画只负责表现，不能通过“播放完成”触发伤害、位移、索敌或复活。

## 施法与控制

| 情况 | 行为 |
| --- | --- |
| 默认站定施法 | 锁定移动、普攻和朝向 |
| 明确允许移动的技能 | 依配置保留移动权限；全身技能动作仍须锁普攻 |
| 冰冻 | 保持当前姿态，暂停动作与施法计时 |
| 眩晕 | 有素材时播放眩晕动作，否则保持姿态；施法计时暂停 |
| 冰冻与眩晕重叠 | 冰冻也会暂停眩晕表现 |
| 攻速变化 | 同步调整普攻当前阶段和播放速度，不从头重播 |
| 死亡 | 接管表现并解除控制覆盖；未发生的技能效果取消 |

施法总时长和命中延迟都从技能开始计时，命令缓冲另算。已经生成的独立区域和弹体按各自生命周期处理，不能随施法者死亡一概取消。

## 连续动作

有专门收势或转跑素材时先使用它；没有时用姿态混合过渡。进入跑步只选一条过渡路线，不把专用转跑和通用入跑连续叠放。

多段攻击、剪切与变形可按原片区间组合；素材裁剪只改变表现。新攻击即使与上次片段同名，也必须从本次正确进度开始，不能停在上次末帧。

第一次接敌正常开始前摇，不预先装满一个攻击间隔。取消尚未出手的前摇不产生冷却；已出手后的再次接敌仍受真实剩余冷却约束。

## 联机与实例隔离

客户端按主机动作序号和进度播放，重复快照不重播，晚到则定位到当前阶段。动画资源按实例隔离，避免一个单位修改循环方式影响其他单位。

头顶锚点应稳定；没有专用锚点时，只在接入或换模型时计算回退位置，不能逐帧追随武器或披风最高点。死亡后续模型只负责表现，不延长存活。

修改后检查连续攻击、取消/恢复、控制叠加、死亡与双方联网进度。测试入口见 [测试手册](../tests/README.md)。
