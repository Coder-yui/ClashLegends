## 文档维护规则

- 操作手册描述当前唯一流程，不追加“旧版/新版”的平行步骤。
- 单位手册面向用户，用中文描述当前数值与规则；改实现时同步核对手册，不以字段转储或源码清单代替说明。
- 已结束的阶段计划、一次性审查和验收报告移动到 `archive/<日期>/`，保留来源与适用时间，并修复入口链接。仍在用的专项手册与素材出处不能当历史删除。
- 改接口同时更新相关手册和测试；未试听、未目视或未实测的项目明确标注，文件存在不能算验收完成。
