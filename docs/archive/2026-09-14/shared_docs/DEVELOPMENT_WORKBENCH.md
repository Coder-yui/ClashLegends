# 卡牌开发工作台

F5 → **卡牌开发工作台**，或：

```sh
Godot --path . -- --mode=workbench
```

顶部搜索中文名称或 `card_id`，直接选择全部注册卡、系统召唤物或训练木桩。没有八张测试卡的数量限制。蓝/红方按钮决定模型阵营和实战放置阵营。

## 四个工作区

| 工作区 | 用法 | 验证范围 |
| --- | --- | --- |
| 模型·动作 | 选择真实动画片段，查看配置映射；重播、暂停、继续、拖时间轴、前进 1/30 秒；旋转、缩放、复位；选择变形素材 | 包装、比例、朝向、片段内容；独立预览不派发攻击或技能 |
| 实战·技能 | 点击战场或“放置当前卡”，添加敌方木桩；选主动候选并释放；有资源的技能可清零/充满，法术可切换普通/强化；叠加冰冻、眩晕、移速/攻速减速，检查死亡 | 使用正式模拟、动画与音频，检查真实命中、范围、前摇/恢复、控制、形态和声音层 |
| 音频 | 按 cue 筛选已配置文件变体，双击或点播放；暂停/继续、进度拖动、停止；显示文件、总线和配置音量 | 单个素材试听；不证明真实机制会在正确时刻触发 |
| 验收记录 | 查看当前资源入口；逐项选择未验证/通过/需修复/不适用，记录复现步骤；导出 Markdown | 人工结论，不自动把素材存在判为通过 |

无 3D 模型的法术仍可进入实战页；未配置音频显示缺项提示，不填充假静音资源。动画列表保留未映射片段，便于接卡时比较素材，但运行时只使用定义中的映射。

## 推荐一次审查顺序

### 经典场景

在“实战·技能”下方选择场景，点击 **重建场景**。它会清掉上一轮单位、排程、弹体和法术/技能区域，重建防御塔与导航，再使用当前卡和当前阵营布置；反复点击可从相同布局重新观察。

| 场景 | 布置与用途 |
| --- | --- |
| 敌人包围 | 当前卡位于中心，八名敌方地面近战环绕，适合范围技能、转身和索敌 |
| 拥挤过桥 | 当前卡、十二名友军从左桥一侧出发，对岸六名敌军，适合排队、推挤与交战 |
| 远近夹击 | 两名近战牵制、四名远程两侧射击，适合目标选择、弹体、减速与防御技能 |
| 单体对战 | 当前卡对敌方盖伦，适合部署、首击、攻击衔接和主动技能 |

蓝/红方会镜像场景位置。当前单位仍是技能、资源和控制按钮的操作对象；多单位卡正常生成完整编队。当前卡为法术时，在其他角色布置后于样本中心释放，可使用原有“强化法术”选项；选建筑或飞行单位时仍遵守自身机制，不强制它们行军过桥。防御塔保留正常行为，进入射程会参战；这些是当前竞技场中的交互场景。

“清空重测”仍只清理当前单位与效果；需要恢复塔与完整场景布局时使用“重建场景”。本功能不修改卡牌属性或正常比赛的战斗规则。

### 审查步骤

1. 选卡，分别检查双阵营与可用形态的模型、片段和卡面。
2. 切实战，放置当前卡与木桩，观察部署、自动移动/攻击和真正命中；切换主动候选检查技能，有充能资源时分别测试空/满资源。
3. 在攻击或施法中叠加控制并等待恢复，检查死亡接管；需要重新开始时清空重测。
4. 音频页逐个排查变体，再回实战听真实触发、中断、持续层并存和清理。
5. 验收页填写结论与问题，导出到 `user://workbench_reviews/`；界面会显示本机绝对路径。

## 会话与边界

- 切离实战页暂停当前实战分支及其声音，回来继续；不更改全局 `Engine.time_scale`。素材预览的暂停与时间轴只控制独立模型。
- 切页、换卡、换形态或退出停止独立试听。审查记录按卡保留于本次会话；离开主菜单前导出需要保存的记录，尚未实现跨会话自动恢复。
- 实战当前对象为最后放置的同卡、同阵营存活单位。主动技能和控制按钮作用于该对象；多单位卡仍生成完整编队。切卡不会清空已有对手。
- 实战没有金币、手牌、AI、兵线和倒计时。出牌仍走 `play_card()`，主动保留正式 Cast → Impact → Recovery，但开发测试不消耗正式主动使用资格。不能用此模式认证正式费用、部署合法性或联网资格。
- 顶部“变形素材”仅用于模型和音频对比；实战形态由真实技能/机制决定。
- 试听使用配置总线和音量，但没有世界距离衰减；最终混音必须回实战听。尚未提供波形编辑、音轨混合或自动录像。

## 维护入口

- `scripts/ui/development_workbench.gd`：选择、四页 UI、试听与记录；数据来自 CardDB，不维护第二份卡牌名单。
- `scripts/ui/workbench/model_preview.gd`：独立 3D 观察器与播放器，动画库按实例复制。
- `scripts/ui/workbench/battle_scenarios.gd`：经典场景配方，只描述卡牌、阵营和落点。
- `scripts/main.gd`：开发会话装配、正式出牌/技能接口和受限场景操作。
- `tests/suites/workbench_suite.gd`：选卡、预览隔离、形态、试听清理、记录与资源技能回归；仍由统一 mechanics 入口执行。
- `tests/suites/workbench_scenario_suite.gd`：场景重建、红方镜像、过桥、法术以及正式模式隔离；实际渲染工具为 `tools/demos/workbench_scenarios_preview.gd`。

开发工作台不能代替 [完整测试](../../../../tests/README.md)或联机验证。相关字段分别查 [卡牌设计](../../../CARD_DESIGN.md)、[动画状态](../../../ANIMATION_STATE_SYSTEM.md)和 [音频接入](../../../AUDIO_INTEGRATION.md)。

卡牌预部署：工作台 immediate 出牌跳过通用命令缓冲，但保留卡牌配置的 pre_deploy_time 和对应声音；卡牌大师预部署 1.3 秒后出现，再经历 0.45 秒实际部署，共 1.75 秒后可参战。清空重测会取消尚未完成的预部署。

### 卡牌大师 Spell4 原声试听

选“卡牌大师 → 03 音频”，在事件下拉框选择“仅试听 · R1…”或“仅试听 · R2…”，双击文件试听不同变体。五组目录来自 `assets/audio/workbench_auditions.json`，只用于工作台，不参与实战自动派发；当前部署采用 1.3 秒预部署 + 0.45 秒实际部署，声音使用 Gate_marker 原声前 1.75 秒。分阶段说明见 [事件音频记录](../../2026-09-13/research/event_audio_expansion.md)。
