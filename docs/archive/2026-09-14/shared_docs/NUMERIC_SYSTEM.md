# 数值体系与卡牌基准（2026-09-13）

当前资料入口：[按对象查询全部详细数值](../../../units/README.md)。

## 边界与精度

- 生命、最大生命、实际伤害、治疗、护盾、费用、数量、次数：整数。配置使用整数文字，兼容既有 API/Snapshot 的 float 储存整数值，不把 UI 舍入当成权威结算。
- 攻击间隔、首次命中、技能命中延迟、控制/Buff/施法/冷却/寿命：玩法配置最多两位小数。非整数显示两位（1.20），整数显示整数（1）。
- 百分数优先整数，必要时最多两位。25% 对应内部 0.25，12.50% 对应 0.125；不可将后者截成 0.13。倍率同样按百分数精度校验，例如 1.3636 对应136.36%。
- 基础移速/射程/半径/质量尽量整数，必要时最多两位；运行坐标、方向、碰撞与插值保留内部精度。
- 倒计时与固定时钟累加器、持续效果余量、连续资源比例、动画原片裁剪与音频原始排程不逐帧截短。它们不是生命或伤害存量。
- 主机固定20Hz：0.05秒一次权威更新。两位配置不等于0.01秒模拟；排程继续使用现有固定Tick规则，素材动画不能驱动命中。

## 统一结算

BattleNumbers.quantity 负责非负数量四舍五入；BattleNumbers.decimal 与 format_value 负责两位小数和整数/小数显示。CardValidator 对基础、变形、主动技能及嵌套伤害/时间数组检查有限性和精度；不自动掩盖非法配置。

单次伤害：基础值 × 全部适用倍率 → 四舍五入；独立附加被动单独四舍五入 → 合计 → 先扣护盾 → 扣生命并限制至0。没有“最少1伤害”规则。例：101×50%=50.5→51，另加101×5%=5.05→5，合计56。

BattleNumbers.hit 返回命中是否成立、整数结算量、护盾吸收、实际生命损失、过量伤害。take_damage 的旧 bool API 保留，命中与免疫语义保持。

吸血：实际生命损失 × 吸血比例 → 四舍五入 → 限制至整数溢出上限。全护盾命中回复0；只剩7血的目标受到55点伤害，25%吸血回复2。范围吸血暂不定义，也不拿范围攻击的名义伤害冒充实际掉血；范围的其他命中收益仍保持每次攻击一次。

治疗、护盾、溢出上限均在结算边界取整。普通治疗不能反向削掉已有溢出生命。生命与护盾的客户端快照接收值也恢复为整数；表现比例仍允许浮点。

## 持续效果

单次离散命中分别取整；DPS/每秒衰减按累计值分配整数。每步加入应结算量，四舍五入扣除，留下有符号余量，避免将55DPS变为60DPS。

持续普攻的余量由来源实例持有，按目标弱引用隔离：离开范围不产生伤害，恢复接触延续该目标余量，不把余量移交给另一目标；死亡目标清理，来源重新setup重置。每个溅射目标独立累计。免疫导致命中失败时不提交余量。

建筑衰减使用最大生命/寿命速率；受外部伤害可以提前死亡，护盾不承担自然衰减。衰减护盾同样累计，期限结束清空。暂停不积累模拟外时间。

区域技能 damage / zone_damage 表示每个脉冲伤害，不是DPS；周期由 tick_interval / zone_tick_interval 决定。龙王 is_continuous_attack 的 damage 则明确表示DPS。卡牌DPS面板为基础理论均值的整数展示，离散命中的实际每秒结果受攻击相位、固定Tick和命中情况影响；面板不包含主动、条件被动或目标相关附加量。
