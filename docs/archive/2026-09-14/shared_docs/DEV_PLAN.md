# 当前开发状态

更新于 2026-09-13。项目支持单机与本机/局域网主机权威对战；Godot 4.x 标准版，20Hz 固定模拟，2D 权威战场与独立模型、特效、音频。24 个注册定义包括 22 张可选卡与 2 个衍生对象。模块入口见 [维护架构](../../../MAINTENANCE_ARCHITECTURE.md)，内容入口见 [卡牌索引](../../../units/README.md)。

## 已有基础

- 四域只读定义、通用 Unit、schema/validator 和统一回归入口。
- 部署、技能、控制、移动碰撞、攻击、弹体、数值与快照的领域回归。
- 工作台支持全部注册卡、形态、真实场景、素材/原声试听与人工验收记录。
- 当前四兵使用小兵专用男爵粒子，炮车具有强化弹体表现；沿用权威 Buff 和 Snapshot，不由特效驱动伤害。
- 当前正式背景仍是 `arena_rift_v4.png`；3D 峡谷仅为候选预览，未替换 F5 对战。

## 工程与设备待办

- 手机实测、广域网连接、高延迟/丢包长测尚未完成。
- 代表性完整对局的移动/索敌性能复测；现有局部 CPU 采样不等于帧率或手机认证。
- 背景音乐与通用操作声音尚未形成完整配置。
- 工作台记录仍按会话保存，重要人工结论需导出；尚未自动跨会话恢复。
- 原版粒子仅复现已核验子集，未支持的原引擎行为和声音不标作完成。
