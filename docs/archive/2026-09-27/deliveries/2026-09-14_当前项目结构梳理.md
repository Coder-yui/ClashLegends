## 已核实的关键边界

| 位置 | 当前职责 |
| --- | --- |
| `scenes/main.tscn` → `scripts/main.gd` | Node2D 主入口；菜单、对局装配、出牌、技能资格、RPC 与固定模拟编排 |
| `scripts/unit.gd`、`scripts/tower.gd` | 通用权威实体；普通卡复用 Unit |
| `scripts/battle/` | 20Hz 时钟、命令、结算、移动/碰撞、导航、法术/技能效果、控制/护盾、联网状态 |
| `scripts/data/cards/` | 24 个定义脚本，按 gameplay / visual / card_art / audio 四域配置；不是 24 个可选英雄 |
| `scripts/data/` | CardDB 显式注册、定义编译、字段/类型/语义校验及系统建筑、比赛音频配置 |
| `scripts/ui/` | 2D 手牌、技能栏、备战、详情和开发工作台；部分菜单/HUD 仍在 Main |
| `scripts/presentation/` | 透明 3D 视口、模型/动画/材质、2D/3D 特效；MatchResources 保留本局资源强引用 |
| `scripts/audio/` | 表现事件驱动的音频播放、缓存与生命周期 |
| `assets/cards/` | 卡面图片，由 CardArt 按命名发现 |
| `assets/units/`、`assets/towers/` | 模型、纹理、动画与运行时包装场景；source 中部分文件是运行依赖 |
| `assets/arena/` | 实际启用 arena_rift_v4.png；rift_arena 是未启用的候选 3D 地图 |
| `assets/audio/`、`assets/effects/` | 音频与特效素材；auditions 是候选试听，不自动接入战斗 |
| `tests/` | mechanics_check + suite_catalog 统一自动回归，含逐卡与网络/碰撞等领域套件 |
| `tools/` | 离线提取加工、预览摄影、验证审计、性能和 Mac 导出 |
| `docs/` | 当前手册、逐卡说明、参考、模板、交付、问题及历史归档 |
| `builds/` | 导出应用、验证日志、录音截图、性能报告等产物 |
| 两个本地素材队列目录 | 宣传素材和待开发卡牌素材，Godot 忽略，不能直接作为运行资源 |

数据流：操作请求 → Main 校验 → CommandSchedule → 固定模拟与结算 → 权威状态/快照/表现事件 → UI、模型与音频。

实现尚非完全按目录隔离：Main 仍持有部署几何与 RPC；Unit 仍持有多种被动/增益及形态行为；ProjectileSystem 同时包含权威弹体与客户端插值，SpellSystem/ActiveSkillEffectSystem 也持有部分表现数据。
