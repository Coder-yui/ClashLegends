# 交付合同：潘森原版组织方式审查与源件重建

- **需求 / 来源**：用户对话。将此前项目接入视为不存在，直接依据素材库原始素材检查、修正独立落地复现。
- **完成结果**：上一版不完全满足要求：复制过正式项目转换资源；错误抵消原生皮肤比例；混淆停止发射、绑定与死亡。本轮在素材库独立工程中修正这些问题，从原始 TEX/DDS、SCB、SKN/SKL/ANM 重新转换纹理、网格、人物和代理。保留原生 `skinScale=0.85`、初始隐藏子网格、材质映射及实际动画长度。构建和运行不再依赖正式项目成品资源；本轮未修改正式项目运行资源或战斗代码。通用预览器和粒子解释器仍有既有代码沿革，不冒充从零实现的 Riot 引擎。

## 已证实的组织方式

| 原定义关系 | 本轮处理 |
| --- | --- |
| PantheonRMissile3 → Pantheon_R_Spear_Landing | 读取技能 mMissileEffectKey，再经皮肤 ResourceResolver 定位系统 |
| Spear_Landing / spear 死亡 → Spear_Impact | 读取原 childEmitOnDeath；只在实际粒子死亡路径触发 |
| PantheonRMissile → Pantheon_R_update_missile | 同上，运行时使用源映射 |
| PantheonRMissile2 → Pantheon_R_Damage_Mis | 同上，运行时使用源映射 |
| Damage_Mis / Temp_Mesh1 死亡 → Ending_Shockwave | 原粒子寿命0.7秒，死亡子图直接读取 |
| 0xb8709efb → Update_Impact；Pantheon_R_Sliding_Comet → Sliding_Comet | 源表确认资源注册，不能由此证明宿主事件和触发时间 |
| Spell4_Hit / Spell4_Hit_ToIdle → 原 ANM 文件 | 动画图文件哈希与提取清单核对；切换条件仍为重建策略 |

证据、运行映射分别保存在独立工程 `source/`、`organization_source.json`、`character_source.json`；原始字段未丢弃。`stop_emitting()` 只停发，推定的宿主销毁名单独立记录在 `playback.json`，不再把 bindWeight 当作死亡规则。

## 验证与结论

- 基线 `7b061f5`；工作区原有大量未提交修改，已保留。Godot `4.7.1.stable.a13da4feb`，Apple M5 / OpenGL Compatibility 实际渲染。
- `verify_sources.py`：71项原始资源输入/输出哈希、两个重新转换的模型、121发射器、资源解析表、两条死亡子图、两段动画文件映射通过。
- `verify.gd`：停发不制造死亡、显式死亡只触发一次、原生皮肤比例、30/60fps、直接定位、倒拖、重复定位、6秒清空、零预算丢弃通过。该测试证明实现自洽，不证明与原版视觉等价。
- 已目视检查9个实际渲染关键帧，并重新输出180帧正常速度及四分之一慢放视频。与素材库保存的 LoL 官方研究帧对照：落矛、撞地、滑行、收尾链完整可播放；人物剪影遮挡、光色、收尾姿态仍存在差异，未通过原版一致验收，用户观感未确认。
- 核心回归 `Godot --headless --path . --script tests/mechanics_check.gd`：7410项断言全部通过。
- 首次编辑器导入将源 TEX 误识别成 Godot 纹理资源，现已用源目录 `.gdignore` 排除；最终重新导入检查通过。

**遗留 / 未验证**：缺少完整技能宿主脚本。绝对时点、坡度、射程1350作为实际滑行距离、两组效果共享轨迹、宿主销毁时机、0.7秒作为人物滑行时长均不能从粒子定义直接证明，已明确列为重建参数。Godot 的混合、折射、局部朝向、地表偏移及部分粒子字段仍为近似/待验证；额外子网格切换事件未完整复现。未接音频。本次完成的是源件组织审查和独立重建纠偏，不能宣称已经完整复现 LoL 原生播放，尚不进入项目适配。
