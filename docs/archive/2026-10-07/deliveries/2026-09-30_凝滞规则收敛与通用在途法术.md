## 已确认保持的交互

| 代表机制 | 凝滞中的行为 |
| --- | --- |
| 普攻、主动技能 | 取消动作后重新行动，最强打断，不暂停后恢复旧动作。已发出的独立弹体/区域继续，目标凝滞后不能命中它。 |
| 赛恩灵魂熔炉 | 已有盾层可自然到期爆炸；未修成暂停或取消。 |
| 恕瑞玛卫队 | 已有黄沙庇护恢复盾可到期回满，仅此机制例外。 |
| 璐璐永久成长、奥恩永久普攻增幅 | 永久数值保留，解除不重发收益。普通限时Buff仍抑制贡献、计时继续。 |
| 纳尔、剑魔变形 | 形态基础最大生命与体型不经普通Buff抑制；进入凝滞不回滚。纳尔100/430变形到490/820并保持；剑魔800/1050变形到1100/1350，凝滞中真实形态到期后截为1050/1050，解除不返还300。用户已确认，未改形态规则。 |
| 同批凝滞与普通Buff | 保留当前顺序：先凝滞则后续Buff拒绝；先Buff则保留实例但抑制贡献。批次是一个Tick内的结算阶段，不是整个Tick；固定步长0.05秒。仅精准限定此交互，不改同批伤害/同时死亡。 |
