# 麦林炮手部署语音与炮口外部特效

- **需求 / 来源**：用户对话。部署随机使用“交火咯。”“预备，瞄准，射。”“碰不到我。”；Q特效补足炮筒外部，并研究 Spell1；用户随后澄清应保留炮口内外效果。
- **完成结果**：三句原版中文台词接入 `deploy:voice` 随机池。以原版 Q 的光壳、环形网格和纹理替换平面光斑，光壳跨过炮口内外、光环向前扩散，整体随骨骼方向与模型倍率移动，保留深度遮挡与淡出。Spell1 在所给 GLB 中为2秒静态姿势（全部通道起止相同），未接入，以免覆盖普攻。
- **验证**：Godot 4.7.1；基线 `681ede8a426682f8885ef237af53b50eb7b26d7d`，工作区含用户及其他任务未提交修改，未覆盖。正式项目导入无 ERROR，`git diff --check` 通过。核心全量执行58套件、9207断言，其中 network_lifecycle_suite 的两项协议断言失败；同期间工作区 MatchSession.PROTOCOL_VERSION 由85修改为86。随后重新启动引擎复验 CardDBValidationSuite、ContentContractSuite、AUDIO_PRESENTATION_SUITE_SCRIPT、PresentationSuite 与 network_lifecycle_suite，1344项断言全部通过（含原两项失败）；未宣称全量首次通过。实际工作台检查蓝红双方、Q启停、攻击与炮口内外衔接，并录制声音；三句台词通过原事件目录与本地 ASR 对应，完整保留台词，统一 -4 dB 后 PCM16，峰值分别0.381、0.411、0.327，无削顶。
- **查看方式**：F5 → 卡牌开发工作台 → 麦林炮手 → 部署 / 急速射击。[蓝方炮口近景](../../../../ClashLegends-开发素材库/04-中间产物/预览与验证/1790926308-35024/tristana/q_0_close.png)、[红方炮口近景](../../../../ClashLegends-开发素材库/04-中间产物/预览与验证/1790926308-35024/tristana/q_1_close.png)、[实战录音](../../../../ClashLegends-开发素材库/04-中间产物/预览与验证/1790926308-35024/tristana/battle.wav)。
- **遗留 / 未验证**：原版Q粒子只适配光壳与环，未复刻全部 Embers 粒子。已在本机实际播放、确认运行事件和录音，工具无法作主观音频感知，因此不声称主观试听通过；用户尚未确认最终观感与听感。
