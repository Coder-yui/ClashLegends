# 奥恩二轮调校

- **需求 / 来源**：用户对话六项调整，以及参考LOL原版E动画组织方式。
- **完成结果**：工作台右侧按身体中心取景，避开包含隐藏道具的包围盒偏移；部署固定为“好吧，我们走。”；血条旁锻造锤各维度及线宽放大50%；被动替换为原生敲装备的锻造事件；冲锋按原生动画分段，区分碰撞与未碰撞；碰撞仅显示固定半径橙色范围标识，淡出而不扩散。

## 冲锋时序

| 阶段 | 本轮处理 |
| --- | --- |
| 蓄力 | 0.35秒，Spell3，锁定移动/攻击/朝向 |
| 冲刺 | 3.5格=140像素，280像素/秒，完整路径0.5秒；Spell3_Dash |
| 碰撞 | 在最后合法位置立即停止并结算范围伤害/眩晕；Spell3_Hit 0.3秒 + Spell3_hit_toIdle 0.25秒 |
| 未碰撞 | 无范围伤害、眩晕、范围标识和撞击音；0.2秒混合回待机，然后恢复普通动作 |

原生动画图中四个E片段独立，hit_toIdle用于TransitionClipBlendData。原版技能数据DashRange650/Speed1600约0.406秒，项目采用0.5秒并沿用用户指定3.5格。原生mCastTime=0.35与spellCastTime=0.25是不同字段，未把源坐标或所有时间直接复制。详细依据见 [动画手册](../../../units/animations/ornn.md)。

## 音频核对

- 中文选人原资源：LCU `zh_CN-assets.wad` 中 `champion-choose-vo/516.ogg`。台词目录与本机MLX转写均对应“好吧，我们走。”，替换全部重生随机语音。
- 锻造：`Play_sfx_Ornn_OrnnP_forging`，事件3114075896 → 媒体515457883，保留原生5.398秒。前次用了队友购买提示，本轮更正。
- 原生E脚步节点不作为伤害命中节点；路径仅伤害，移除误借的击飞声音。E起手、实际碰撞爆发、普攻三段出手/真实命中、死亡重新核对并保留相应事件。
- 额外发现旧SFX在直接转PCM16时发生峰值截断。原事件浮点峰值最高+1.943dB；21个SFX从原TXTP重新浮点解码，统一预留3dB再转PCM16，保持相对层次。最终SFX满幅截断样本为0。部署语音不套此衰减。
- 旧语音和错误音效已归档到本机素材库，正式资源中移除。来源见 [清单](../../../../assets/audio/units/ornn/event_manifest.json)，试听见 [音频页](../../../units/audio/ornn.md)。

## 命中节点

三段普攻原始castFrame均为8.5、30fps；按当前1.2秒攻击窗口映射为0.1594/0.1545/0.1594秒，保留公共前摇0.16秒。20Hz在跨越节点的Tick结算。E路径伤害在首次扫掠接触时结算，范围伤害在实际地形碰撞Tick结算；动作不驱动伤害。永久增幅仍只改普攻，抵达后生效并按既有规则取整。
