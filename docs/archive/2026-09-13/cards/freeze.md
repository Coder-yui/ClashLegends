# 冰冻（`freeze`）

当前定义：[`scripts/data/cards/freeze.gd`](../../../../scripts/data/cards/freeze.gd)，使用 gameplay / visual / card_art / audio 四域；通用接入与验收见 [卡牌设计](../../../CARD_DESIGN.md)。

## 1. 属性数据

| 属性 | 数值 |
| --- | --- |
| 类型 / 费用 / 可选 | 法术 / 3 / 是 |
| 描述 | 范围控制法术，冻结范围内的敌方单位，为己方争取进攻窗口。 |
| `spell_kind` | `freeze` |
| 作用半径 | 110 |
| 基础冻结时间 | 3.0 s |
| 强化名称 | 强化冰冻 |
| 强化减速时间 / 速度倍率 | 2.0 s / 0.50 |
| 阵营颜色 | `Color(0.40, 0.70, 1.00)` |

法术不生成 `Unit`，因此没有生命值、普攻、移速、体型、弹体或单位 AnimationPlayer 配置。

## 2. 被动

不适用。冰冻是一次性法术卡，没有独立被动状态。

## 3. 主动技能 / 强化效果

冰冻没有 `active_skills` 数组，而是由卡牌位于主动槽时启用 `active_name` 对应的强化效果：

- 普通施放：点击位置半径 `110` 内的敌方单位和防御塔被冻结 `3.0 s`。
- 强化冰冻：冻结结束后，在同一半径生成延迟减速区域，敌方单位减速 `2.0 s`，速度保留 `50%`。该持续减速逻辑只作用于 `Unit`，不额外冻结或减速防御塔。
- 强化冰冻的额外技能花费为 `0`；卡牌放在主动槽后，卡牌本次施放直接使用强化效果。强化次数随该张法术卡本次施放计算为 `1` 次，不生成独立的主动技能使用次数或冷却字段。
- 法术效果没有施法窗口和 `impact_delay`；出牌执行时立即结算。

## 4. 使用的动画 / 表现

- 没有单位场景和 `visual_animations` 动画名。
- 冻结区域和强化减速区域由 `SpellSystem` 的法术表现数据绘制/同步（`_rpc_freeze_fx`）；它们不是本卡配置的 AnimationPlayer 片段。
