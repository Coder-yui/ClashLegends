# 治疗术（`heal`）

当前定义：[`scripts/data/cards/heal.gd`](../../../../scripts/data/cards/heal.gd)，使用 gameplay / visual / card_art / audio 四域；通用接入与验收见 [卡牌设计](../../../CARD_DESIGN.md)。

## 1. 属性数据

| 属性 | 数值 |
| --- | --- |
| 类型 / 费用 / 可选 | 法术 / 3 / 是 |
| 描述 | 范围治疗法术，立刻回复范围内友军单位的生命值；对建筑卡、防御塔和水晶无效。 |
| `spell_kind` | `heal` |
| 部署区域 / 忽略建筑 | `global` / `true` |
| 作用半径 | 110 |
| 治疗量 | 300 |
| 特效持续时间 | 1.2 s |
| 强化名称 | 强化治疗 |
| 强化治疗倍率 | 1.25 |
| 强化护盾 / 持续时间 | 240 / 3.0 s |
| 主动槽费用加成 | +1 |
| 阵营颜色 | `Color(1.00, 0.93, 0.60)` |

法术不生成 `Unit`，因此没有生命值、普攻、移速、体型、弹体或单位 AnimationPlayer 配置。

## 2. 被动

不适用。治疗术是一次性法术卡，没有独立被动状态。

## 3. 主动技能 / 强化效果

治疗术没有 `active_skills` 数组，而是由卡牌位于主动槽时启用 `active_name` 对应的强化效果：

- 普通施放：点击位置半径 `110` 内的友方普通单位（`Unit` 且非建筑卡）立刻回复 `300` 点生命值。治疗统一走 `Unit.heal()`，不会超过单位最大生命值。建筑卡、防御塔、水晶不吃治疗。
- 强化治疗（卡牌位于主动槽）：施放费用 `+1`（基础 3 费 → 4 费）。全图友方普通单位按 `1.25` 倍治疗量回复（即 `375` 点），同样不超过最大生命值；范围内所有友方战斗对象（含普通单位、建筑卡、防御塔、水晶）额外获得 `240` 点护盾，持续 `3.0` 秒。护盾优先承伤，对一切友军生效。
- 强化治疗的额外技能花费为 `1`；卡牌放在主动槽后，卡牌本次施放直接使用强化效果。强化次数随该张法术卡本次施放计算为 `1` 次，不生成独立的主动技能使用次数或冷却字段。
- 法术效果没有施法窗口和 `impact_delay`；出牌执行时立即结算。

## 4. 使用的动画 / 表现

- 没有单位场景和 `visual_animations` 动画名。
- 治疗区域由 `SpellSystem` 的法术表现数据绘制/同步（`_rpc_heal_fx`）：淡黄色光圈、上升十字光点；强化版额外绘制全图扩散金圈提示全图友军被治疗。它们不是本卡配置的 AnimationPlayer 片段。
