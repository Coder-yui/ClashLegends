## 2. 被动

### 双形态循环

- 小纳尔每 `6` 次真正命中后变为大纳尔；大纳尔每 `4` 次真正命中后变回小纳尔。
- 形态切换会清空命中计数、读取目标形态的攻击/移动/射程/体型字段，并取消当前攻击前摇；在途回旋镖仍由权威弹体系统独立处理。
- 普通变大表现/锁定时长 `1.5 s`，变小 `1.333333 s`。变形不创建新单位，不改变 `net_id` 或主动技能归属。

## 3. 主动技能

**怒气爆发**（`kind = dual_form`）

- 当前主动技能数值：消耗 `2` 金币；每个纳尔最多使用 `1` 次；每次使用后冷却 `8.0 s`。
- 锁定施法开始时的朝向，在前方长度 `140`、宽度 `60` 的区域造成 `120` 点伤害，并使命中的地面敌人眩晕 `1.0 s`。
- 小纳尔使用时先立即变为大纳尔，再进行技能冲击；大纳尔直接释放。
- 大纳尔释放：`impact_delay = 0.8 s`，`cast_duration = 1.2 s`；小纳尔主动变大：`transform_impact_delay = 0.8 s`，`transform_cast_duration = 1.2 s`。
- 施法期间锁定移动、普通攻击和朝向；`ground_only = true`，不影响空中单位。
