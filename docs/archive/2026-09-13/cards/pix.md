# 皮克斯（`pix`）

定义：[pix.gd](../../../../scripts/data/cards/pix.gd)。一次部署五只小型空中射手，使用通用编队、追踪弹体与逐次攻击吸血机制。

主动「仙灵汲取」作用于本次部署仍存活的编队成员，之后的真实普攻命中回复生命并允许有限溢出；具体比例、费用和上限以定义为准。旧编队不继承新部署的主动资格。

模型入口为 `assets/units/pix/pix_view.tscn`，使用 Idle1 / Run / Attack1 / Attack2；卡面按 `pix_loading.*` 自动发现。当前定义未配置 audio，属于未接入，不能标记试听完成。素材出处以资源目录中的说明为准，本轮未迁移素材。

回归在 `tests/suites/cards/pix_suite.gd`；开发工作台检查编队生成、两段普攻、空中高度与吸血作用域。
