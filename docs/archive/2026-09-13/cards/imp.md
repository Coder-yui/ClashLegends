# 小鬼（`imp`，系统召唤物）

当前定义：[`scripts/data/cards/imp.gd`](../../../../scripts/data/cards/imp.gd)，使用 gameplay / visual / card_art / audio 四域；通用接入与验收见 [卡牌设计](../../../CARD_DESIGN.md)。

小鬼由墓碑周期召唤、亡语或“亡者集结”生成，是 `CardDB.all()` 中 `selectable = false` 的系统单位，不占用独立卡槽，也不会出现在选卡池。

| 属性 | 数值 |

| 部署时间 | 0 s |
| 阵营颜色 | `Color(0.55, 0.45, 0.80)` |

## 2. 被动

无独立被动。小鬼是基础近战地面召唤物。

## 3. 主动技能

无主动技能。小鬼不能占用主动槽。

## 4. 使用的动画

- 场景：`res://assets/units/imp/imp_view.tscn`；`visual_forward_yaw = 0`。
- 部署 / 待机 / 移动：`Spawn1` / `Idle1` / `Run1`。
- 普攻：`Attack1` / `Attack2` / `Attack3`；三段原表均使用普通 `GhoulAttack_cast` 出手事件。
- 死亡：`Death`，表现时长 `0.5 s`。
