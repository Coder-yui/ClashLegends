## 2. 被动

### 千穿百孔

- 每次普通攻击真正命中，额外造成 `round(目标最大生命值 × 0.05)` 伤害；例如最大生命 1010 时附加 51。
- 对防御塔、水晶改为固定附加 `20`；这是本轮对“稍小固定值”的初始取值，可继续调平衡。其他建筑单位仍按最大生命值计算。
- 快刀乱剪的每一次剪切、每一个实际命中的目标都独立附带被动；基础伤害与被动分别四舍五入后相加。中央倍率与普通攻击强化倍率均不放大被动。
- 丝缕缠流已从格温被动移除，不再触发圈外无法锁定/伤害免疫或其起止音频。未来作为可选主动单独开发，本轮不增加候选技能。

## 3. 主动技能

**快刀乱剪**（`kind = frontal`，`shape = fan`）

- 当前主动技能数值：消耗 `2` 金币；每个格温最多使用 `1` 次；每次使用后冷却 `8.0 s`。
- 普攻命中充能，最多 `3` 层；Cast Start 固化当前层数并清空资源，施法期间获得的新资源留给下一次技能。
- 从格温前缘向前延伸 `135` 的 `78°` 圆弧扇区；外边界为半径 `135` 的圆弧，圆弧外的区域不在命中范围内。
- 扇区中央是贯穿至外弧的 `30px` 恒宽长条，命中时每一剪的基础值造成 `1.2` 倍伤害；扇区两条侧边与中央长条近端共用两个端点，`ground_only = true`。
- 范围提示使用相同的圆弧扇区与中央长条，并持续到 `Spell1_C_anm` 最后一剪结算。
- 任意层数都先由 `Spell1_0` 剪切一次、造成 `40` 伤害，最后由 `Spell1_C_anm` 剪切一次、造成 `60` 伤害；每层资源在两者之间增加一次 `Spell1_B` 和 `20` 伤害。
- 0～3 层的逐剪伤害分别为 `[40, 60]`、`[40, 20, 60]`、`[40, 20, 20, 60]`、`[40, 20, 20, 20, 60]`；基础总伤害为 `100 / 120 / 140 / 160`，中央区域每一剪基础值乘 `1.2`，然后每剪再加独立被动。满层共 5 次被动；例如 1010 最大生命目标，中央总伤害为 `192 + 5×51 = 447`，边缘为 `160 + 5×51 = 415`。
- 四档 `cast_duration` 统一为 `1.5 s`；四档剪切相对 Cast Start 的结算时刻分别为 `[0.09, 1.04]`、`[0.09, 0.95, 1.04]`、`[0.09, 0.78, 0.95, 1.04]`、`[0.09, 0.62, 0.78, 0.95, 1.04]`。满 3 层且本次施法至少一剪成功命中时，在技能结束瞬间回复 `100` 点生命值；首剪击杀也算命中，空放/全部免疫不回复，每次施法最多回复一次。
- 施法期间锁定移动、普通攻击和朝向；没有弹体（`projectile_count = 0`）。

## 4. 使用的动画

- 场景：`res://assets/units/gwen/gwen_view.tscn`；`visual_forward_yaw = 0`。
- 部署 / 待机 / 移动 / 进入移动：`Respawn` / `Idle_anm` / `Run_anm` / `Into_Run`。
- 普攻：`Attack1`、`Attack2`、`Attack3`。
- 三段转跑依次是 `Into_Run`、`INTO_Run_-90_anm`、`INTO_Run_180_anm`：对应原方向参数图在目标角度 0° 时的三个分支。项目朝向由单位方向对齐，不照搬独立 `TURN` 轨道或动态方向插值。
- 0～3 层分别选择 `active_0`～`active_3`：`Spell1_0 → Spell1_B × 层数 → Spell1_C_anm`。
- `Spell1_0 + Spell1_C_anm` 的素材动作按比例安排在 `1.5 s` 技能时槽内；每段 `Spell1_B` 使用约 `0.1667 s`，各档技能总时长均为 `1.5 s`。
- `Spell1_0 → Spell1_B`、连续 `Spell1_B`、`Spell1_B → Spell1_C_anm` 均使用素材自身的逐帧衔接，内部 `sequence_blend = 0`。
- 技能转移动画：只从最终 `Spell1_C_anm` 接 `Spell1_C_to_Run_anm`；转跑片尾→`Run_anm` 使用原表零混合。
- 三段普攻回待机分别使用 `Attack1_To_Idle`、`Attack2_To_Idle`、`Attack3_To_Idle`；最终 Q 回待机使用 `Spell1_C_to_Idle_anm`，入口采用原表零混合。收势可以被移动、下一次攻击或技能打断，不延长权威动作锁。
- 死亡：`Death`，表现时长 `0.8 s`。
