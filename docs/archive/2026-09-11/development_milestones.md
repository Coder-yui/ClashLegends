# Clash Legends 开发规划

## 当前基线

- Godot 4.x / GDScript，窗口 `720×1400`。
- 权威战场 `18×32` 格、40px/格（`720×1280`），底部 120px UI。
- ENet 39152；主机固定 20Hz，客户端请求操作并接收压缩 Snapshot。
- 2D 战斗逻辑与透明 3D 表现严格分离。
