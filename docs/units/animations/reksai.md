# 虚空遁地兽动画

[返回单位](../reksai.md) · [总索引](../README.md)

采用用户指定基础皮肤GLB，蓝红共用模型、队伍圈区分。原生网格静态范围约341×202×403，统一缩放0.008；没有默认隐藏子网格配置。原始TailAdjust、Buffbones附加层未单独叠加。

待机Idle1_Base，移动Run1；部署击飞版Spell2_Knockup（源0.8667秒）映射0.75秒。普通攻击循环Attack1/Attack2，原片2.0333/2.0秒；原castFrame=10，按30FPS节点0.3333秒映射1.2秒攻速为0.1967/0.2000秒，共用0.20秒前摇，差约3.3毫秒。Q依次使用Spell1 → Spell1B → Spell1（源2秒，castFrame=9），节点0.3秒映射为0.18秒；20Hz结算于第4个Tick。第二击使用原版反向旋斩；取消前摇不消费段数，再次释放Q从第一段重来。段数编码在既有单调攻击序号中，双方使用同一序号选择动作、特效和声音。

死亡Death源3.9333秒，按统一上限压缩至0.8秒。动画和特效不决定命中或位移。

实战尺寸、双方朝向与连续动作验收记录见本任务交付。

Q待发粒子通过原模型左右手定位骨骼附着，随待机、移动和三段挥击运动。普通攻击动画内的挥爪拖尾声明按用户要求不接入。
