# 潘森动画

[返回潘森](../pantheon.md) · [总索引](../README.md)

使用用户提供的不屈之枪GLB，基础皮肤原版骨骼与动画；包装统一缩放0.015。

部署只播放Spell4_Hit落地收势，不播放起跳与引导。待机Idle1，行走Run_Base，普攻依次Attack1、Attack2、Attack3。短Q使用Spell1_Hit；普通与满怒保持同一刺击动作，通过伤害、红怒与声音区分。Q结束按原素材Spell1_Hit_Toidle或Spell1_Hit_Torun衔接，落地结束接Spell4_Hit_ToIdle。死亡使用Death，显示0.8秒。

原版动画图已从本地Pantheon.wad.client提取核对；游戏使用固定施法时间适配，未宣称完全复刻原版动画时序。
