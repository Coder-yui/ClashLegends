# 终极闪光时序

[← 终极闪光](../final_spark.md) · [总索引](../README.md)

法术没有英雄模型或骨骼动画。R_cas与R_mis_beam从同一权威起手时刻播放，原生光束timeBeforeFirstEmission=1秒；项目在20Hz第20Tick结算一次伤害；不播放R_tar受击特效。光束地面余光至2.5秒。表现按服务器Tick插值，不驱动权威命中。

本地LuxR定义的spellCastTime=1.375，旧LuxRMis=1秒；不能把完整施法动作锁定时间直接当作粒子爆发时刻。本卡以现代R光束层明确的1秒发射延迟决定预警窗口，不导入英雄施法动作或后摇。原版脚本与客户端逐帧调度未作完整复刻。
