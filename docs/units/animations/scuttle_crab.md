# 峡谷迅捷蟹：模型与动画

[返回单位](../scuttle_crab.md) · [总索引](../README.md)

使用用户纠正后的普通绿色版本 `scuttle_crab.glb`（原需求中的 `(6)` 为虚空外观，已替换），保持原材质。源模型包围盒约1.913×1.576×2.153，包装统一缩放0.91，脚底上移0.06世界单位；在同一战场镜头与艾希比较中体型观感。

| 状态 | 原片段 / 原时长 | 接入 |
| --- | --- | --- |
| 出生 | Crab_Spawn / 1.633秒 | 通用部署映射 |
| 待机 | Idle1 / 3.2秒 | 循环 |
| 行走 | Run / 0.533秒 | 循环 |
| 建筑前回复 | Crab_Dance / 1.6秒 | 权威停驻状态期间循环 |
| 死亡与祭坛 | burrow → ward_run_toground → ward_spawn → ward_idle → ward_tohide | 1秒沉没、1秒入地、2.7667秒展开、3.7秒待机、2.3秒收起 |

原GLB的 Crab_Hide 是静止藏身姿势，现改用源库 sru_crab_burrow.anm 转换的原版沉没动作。死亡后原地播放，2秒时开始祭坛展开并播放形成音效，4.8秒开始回血；省略游向河道中心的过程。单位禁用普攻，无攻击命中节点。舞蹈借用现有行为状态3和连续动画通道，客户端通过既有快照播放，不结算伤害，不启用持续光束。双方模型、舞蹈、死亡及同档对比已在实际渲染检查，最终外观由用户确认。

整段使用同一皮肤、同一骨骼、原单位缩放与死亡朝向，避免独立触角模型切换造成跳位。沉没片段由1.0667秒轻微加速至1秒，其他片段原速串接，20Hz阶段边界不足一帧的间隙保持末姿势；无游向河道中央的根位移。回血结束前2.3秒开始原版收起动作，触角与光圈同时结束，清场/终局立即取消死亡表现。
