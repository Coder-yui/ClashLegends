# 琴瑟仙女模型与动画

[返回琴瑟仙女](../sona.md) · [返回总索引](../README.md)

使用需求指定GLB，原始可见包围盒约1.134×1.158×1.508，包装XYZ等比1.7（初版2.0缩小15%）。稍大人形以德莱厄斯和腕豪为参照；琴与长裙不等同躯干体积。统一空军网格底部离地2.3，不参与权威坐标。源模型两个材质均标记visible，皮肤未声明默认隐藏网格。

| 阶段 | 映射 |
| --- | --- |
| 部署 / 待机 | Idle1 |
| 移动 | Run |
| 三套普攻 | Attack1、Attack2、Attack3，各原长约1秒，按1.4秒周期缩放 |
| 主动 | Spell4，原长约2秒，截取前1秒保持原速，项目1秒施法动作 |
| 死亡 | Death，源6.333秒压缩到0.8秒上限 |

原始SonaBasicAttack声明castFrame=11，按30Hz为0.3667秒；三套相同片长映射到1.4秒为0.5133秒，配置0.52秒，20Hz第11Tick约0.55秒创建，统一近似误差约36.7毫秒。源另有spellCastTime=0.4236及攻击槽偏移，不能将其与动画castFrame混为同一时间；此处采用动画帧标记近似。

普攻源只明确目标胸部骨骼，没有起始骨骼覆盖。项目显式绑定琴身WEAPON，不宣称与源端未公开的起点完全一致；R源明确WEAPON。权威普攻从身体边缘再偏移7.5出发，视觉挂点和空军抬升不改变碰撞。R原始castFrame=8.5（30Hz约0.283秒），项目0.3秒发射，相差约16.7毫秒；保留前1秒原速，避免将2秒整段压缩后提前出招。双方共用模型，用通用阵营提示区分。

W自身光环与R_Cas绑定模型根部并保留源局部高度；R_Cas从起手开始，独立于0.3秒后创建的WEAPON飞行层。动作取消或源单位释放时清空附属施法状态。组织和坐标约定见[特效页](../effects/sona.md)。

源骨架的绑定旋转与运行姿势差异较大，尤其WEAPON在绑定姿势朝后约180°、运行片段朝前。琴女包装初始化时，以Idle1首帧作为已有旋转轨道对应骨骼的混合参考；保留源GLB、动画关键帧和Skin逆绑定。修正动作交叉混合时绕长弧翻转、身体/琴闪跳的问题，不改动画速度或权威时序。单片段采样的全部骨骼姿势与原导入结果一致。
