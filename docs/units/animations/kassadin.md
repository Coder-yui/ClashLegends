# 虚空行者动画

[返回虚空行者](../kassadin.md) · [总索引](../README.md)

使用指定的虚空行者GLB，单网格与材质，XYZ统一1.1倍；源坐标主体高度约2.0，与同场艾希校准中体型。模型在原姿态上额外抬高0.4模型单位，体现裙摆离地；只改变模型包装，不使用空军高度规则，也不抬高权威碰撞体。

部署Respawn、待机Idle1、移动Run_Base、普攻Attack1/Attack2、技能Spell4、死亡Death。死亡源片3.233秒压缩到0.8秒。R源片0.333秒适配0.35秒施法，效果由权威0.25秒节点触发。

两套普攻原片均2秒，原始KassadinBasicAttack/2定义spellCastTime均0.3439秒；按0.3439÷2×1.2得到0.20634秒，统一前摇0.21秒（近似误差3.66毫秒），20Hz首次跨过节点在0.25秒。该字段是源施法节点，运行时不读取动画事件决定伤害。

双方待机与R生命周期已在实际工作台渲染；连续普攻、受控与死亡回归继续使用通用动画契约，主观动画观感可在工作台复核。

## 原版衔接与刀刃时机核查（2026-10-15）

按项目需求只保留 Spell4 转移动的 Spell4_To_Run。Run_In、Spell4_To_Idle、Idle_In 不接入实战，使用姿态混合；移动及动作退出混合0.16秒。Respawn 转 Run_Base/Idle1 混合0.18秒，转 Attack1/Attack2 混合0.14秒。混合仅影响表现，不延迟权威移动、攻击或伤害。

Respawn 刀刃首次出现时机尚未查实：源动画无粒子开关事件，武器骨骼链无缩放隐藏，idle_blade 无首发延迟；常驻粒子由 KassadinBladeFX Buff 绑定，但本地客户端资源未提供其在重生期间的启用时刻。因此本次不猜测延时，保留当前刀刃行为，此项仍待原版运行证据。
