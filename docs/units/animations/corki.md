# 库奇动画

[返回库奇](../corki.md) · [单位总索引](../README.md)

用户指定“英勇投弹手.glb”，保留原始骨骼与片段；双方共用模型，以阵营标识区分。部署/待机为Idle1，移动Run，普攻Attack1/Attack2，火箭轰击Spell4，死亡Death压到0.8秒。普通与超级导弹使用同一动作，不改变伤害时刻。

源GLB网格范围约1.458×1.615×2.197，包装统一缩放1.0。默认基础皮肤只有一组Corki_MAT材质，skin0未声明默认隐藏子网格；不额外启用携带炸药包的Run_WithBomb/加法动画。空军离地与血条沿用统一表现规则。同场以艾希和冰鸟核对体量，不改变权威半径。

原始角色定义basicAttack为总周期1.553秒、离弦0.18秒；两种普通攻击共用AttackSlot前摇，extraAttacks不覆盖该值。GLB Attack1/2各1秒（30帧），按归一进度0.18/1.553≈0.1159映射，再压到项目1.2秒周期得0.1391秒，统一配置0.14秒；20Hz在0.15秒发射，约晚10.9毫秒。Spell4原片1秒，源R施法节点0.25秒映射到项目0.5秒片段得到0.125秒，按两位小数配置0.13秒，20Hz在0.15秒释放。动画只消费权威状态。

蓝红部署、连续攻击、技能、冻结恢复与死亡由corki_review实际渲染检查。最终用户观感未确认。
