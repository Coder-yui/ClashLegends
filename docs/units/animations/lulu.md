# 璐璐 · 动画与模型

[← 返回璐璐](../lulu.md) · [总索引](../README.md)

使用用户提供的仙灵女巫GLB。待机为Lulu_idle0_anm循环；部署原速播放同片段的末尾部署时长（当前1秒，原长约4.6秒），移动Run，普攻交替Attack1/Attack2，技能Spell4，死亡Death（压缩到1秒）。缺少Respawn/回城结束，部署按现有规则回退待机。

原网格约142×151×167源单位，包装统一缩放0.014；源皮肤配置未声明默认隐藏子网格。大帽子和长法杖保留，战场同镜头与提莫对比主体，未按完整轮廓强行等高。蓝红共用模型、方向与队伍标记区分。

普攻原生定义位于Lulu.wad.client内data/characters/lulu/lulu.bin，BasicAttack/BasicAttack2的castFrame均为7.5；以30fps施法节点解释为0.25秒（同表Spell4的7.5帧与0.25秒对应）。导入采样Attack1为30Hz、Attack2与Spell4为31Hz，采样率不重新定义SpellData的施法时间。原定义spellCastTime=0.42815与攻击槽偏移并存，未将该字段直接当作本项目离弦点。

| 普攻 | 片长 | 按1.2秒窗口映射的0.25秒节点 |
| --- | --- | --- |
| Attack1 | 1.1333336秒 | 0.2647秒 |
| Attack2 | 0.9677415秒 | 0.3100秒 |

公共前摇0.29秒，分别偏移+0.0253/-0.0200秒；固定20Hz在0.30秒发射。普通弹体命中另按飞行碰撞结算。大招Spell4原长0.9677415秒，对应0.97秒施法窗口、0.25秒效果节点。

狂野生长倍率读取权威状态；血条与发射挂点跟随模型。空军增长时保持统一飞行平面，不按模型反推碰撞。实际渲染截图和未验证事项见本轮交付。
