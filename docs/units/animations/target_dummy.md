# 训练木桩 · 动画

[返回建筑卡](../target_dummy.md) · [总索引](../README.md)

| 状态 | 源片段 | 接入 |
| --- | --- | --- |
| 出生 | Spawn | 1秒部署期 |
| 待机 | Idle1_Base | 循环 |
| 受击 | Hit | 真实受击事件触发，低优先级，不产生硬直 |
| 死亡 / 自然到期 | Death | 1秒退场 |

受击动画仅在空闲时播放；部署、死亡、冰冻/凝滞和已有动作优先，不排队补播。连续攻击不会不断重启尚未完成的Hit，结束自然回待机。受击事件共用既有0.18秒闪白节流，网络走已有可靠受击事件。

蓝红模型源分别为用户指定target_dummy.glb与target_dummy_(2).glb，均有6段原生动画；另外两段Idle不用于实战。原始网格高约1.446，包装统一缩放2.25，脚底偏移−0.0209；不隐藏子网格。当前卡面由蓝方Idle1_Base在0.3秒、模型12°朝向、相机yaw0°/pitch7°进行灰青底柔光摄影。素材参数见[资源记录](../../../assets/units/target_dummy/README.md)。
