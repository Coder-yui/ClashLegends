# 中型雷电法术动画

[返回卡牌](../medium_lightning.md) · [返回总索引](../README.md)

法术无角色模型或骨骼动画。公共0.5秒命令延迟后开始狗熊E的2秒蓄雷；施法方立即看到完整预警，敌方从第1秒看到敌方专用预警，第2秒由20Hz权威Tick按当时目标位置结算一次伤害、护盾和减速。预警与冲击尾迹按原粒子曲线播放，不驱动伤害。

防御塔失效持续2秒，复用眩晕中断和恢复；R的塔命中、附着电流、暗化与结束闪光独立表现。源结束闪光位于6秒模板的5.9秒，本卡平移至1.9秒并保留0.25秒曲线。暂停不推进权威时钟，清场取消待落雷排程，塔死亡清理附着表现，并按原Stop事件将持续声淡出1秒。
