# 狂战士动画

[狂战士](../olaf.md) · [单只对象](../olaf_single.md) · [总索引](../README.md)

指定狂战士.glb内嵌纹理、骨骼及19段动作。部署使用Idle4，待机使用Idle1，移动Run，普攻循环Attack1/Attack2，不使用Attack3，死亡Death。W即时生效且不打断攻击，不占用Spell2动作。

Idle4长1.5秒，按1.5倍速完整播放至1秒，随后交回普通状态机。部署窗口仍为1秒，动画不提前解锁移动/攻击。Idle1只用于普通待机。

使用的两套普攻源片长均约0.967741秒，原定义基础攻击施法偏移为-0.065625，相对默认30%约为23.4375%；映射1.2秒周期约0.28125秒，20Hz向上量化为0.30秒。额外攻击源配置未单独声明偏移，沿用同一近似节点，误差约18.75毫秒；不是逐动作脚本触发证明。

模型网格最高约1.413源单位，统一包装缩放1.42（较上一版1.47缩小约3.4%，保留两位小数）；原模型已经使用米量级，不沿用其他百单位模型的0.01级缩放。源Death约3.267秒，按普通单位规则压缩为0.8秒，不延长权威存活时间。
