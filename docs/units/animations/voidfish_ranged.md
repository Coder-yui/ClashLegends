# 远程虚空鱼动画与特效

[返回单位](../voidfish_ranged.md) · [单位索引](../README.md)

原版BelvethVoidling基础皮肤资源内包含Melee近战与Ranged远程两套网格，共用骨架和纹理，但外形及动作不同。原有近战GLB已删掉远程网格，因此从原版SKN/SKL重新导出双网格，再按实例只保留Ranged表面。近战与远程共用出生表现逻辑，各自保留原生模型及动作。双方共用模型，阵营由通用标记区分。原生数十至百单位量级，统一缩放0.014，飞行高度由通用表现层提供。

待机/部署ranged_idle，移动ranged_run，攻击ranged_attack，死亡ranged_death（映射到0.6秒）。远程攻击原生castFrame=14.1，30FPS对应0.47秒；攻击片长1.266667秒，缩放到1.25秒间隔得0.463816秒，按项目0.01精度取0.46秒（误差3.82毫秒）。权威20Hz决定发射，再由真实弹体命中决定伤害。

原版出生Belveth_Base_R_Minion_Transform保留14层；按用户要求不附加头部或身体常驻特效；弹体Belveth_Base_R_Voidling_BA_Mis保留3层。提供者声明源采样JSON、网格、纹理和Shader，资源计划按卡牌/主动召唤引用递归展开。

单只卡面使用模型摄影；正式三只卡面使用用户选定的三单位摄影截图；虚空再生使用用户选定的卑尔维斯被动图标。

## 出生特效组织与尺寸

出生采用原版 `Belveth_Base_R_Minion_Transform` 的14层：液体卷入、暗壳、菲涅尔、反射、内光、静态鱼剪影、溶解与尾迹，保留各层起发、寿命、混合和排序。恢复原版按宿主尺寸缩放（原生选择半径70、直径140；各层0.005/0.004系数），五层SCB按原版Pitch/Yaw面向镜头，SCB恢复原始索引面法线以支持菲涅尔。

出生原点使用模型根变换，保留原版各层局部中心(0,50,0)，不再额外挂胸骨平移；尺寸、方向随模型根。源坐标仅镜像X一次；五个朝镜头SCB保留其背面朝镜头的原规则，其余层保留对象朝向及粒子自身旋转，鱼剪影保留原版随机Euler旋转。三个groundLayer（Backdrop、GlowInside、Backdrop3）先绘制，鱼剪影使用原版不透明/写深度模式，随后按原始pass等键绘制蛋壳与反射。

连续120Hz采样，以只读部署进度及固定步长插值驱动；不会自行累计帧时间。0.72秒显示正式模型，0.78秒清除已结束的出生层，包含源采样边界余量。工作台近战“虚空鱼”、单只“虚空鱼（远程）”及正式三只“远程虚空鱼”正常部署均走此效果；虚空女皇死亡散出的八只鱼部署时间为零，不播放出生特效，也不隐藏模型。

原版虚空鱼皮肤资源表引用同一个Transform，其剪影本身就是Ranged.scb；近战复用原始剪影，没有伪造另一套近战特效。没有证据确认另一独立Transform_Impact的触发时点，因此不追加。当前核对范围是源定义/渲染组织及项目蓝红实渲，尚未与原版游戏录像逐帧对照。

## 弹体挂点与创建时机

原始攻击定义指定 `BackSpine_end`，远程模型通过通用弹体挂点接口绑定该尾端骨骼，替代此前的包围盒中心回退。发射时锁定实际挂点及高度，随后按权威弹体进度向目标模型挂点过渡，原生+Z方向沿三维飞行方向；蓝红及翻转镜头共用同一路径。

前摇仍为0.46秒，权威20Hz首轮量化在0.50秒发射；特效仅在弹体存在后创建。移除首帧直接跳到0.1秒的预推进，零进度使用1/120秒最早采样，后续按已发生的弹体位移推进；同一快照重复同步不加速。伤害仍由真实弹体碰撞结算。远端描述符按正确net_id查找模型，跳过同队其他单位。

## 移动循环

远程使用原版ranged_run，约1.9秒；源片首尾BackSpine1旋转差约16.43度、BackFin位移差约7.88原生单位，直接回到首帧会跳姿。通过既有move_cycle与clip_blends配置，在ranged_run接回自身时使用0.12秒姿态混合。保留原片、模型缩放及权威移动速度；近战run不变。

## 虚空再生

开启时一次紫色光流从身体下方向上升起，约0.8秒内结束；持续3秒窗口内使用与男爵之力相同的紫色流动覆层覆盖模型。覆层跟随蒙皮动画，保留原模型轮廓与动作；两队相同，不开技能没有常驻特效。上升光流为项目程序化表现，不使用之前试样的外部环绕光壳。

由20Hz权威Buff剩余/总时长驱动，客户端从快照恢复同一进度；重复表现帧和暂停不累计年龄，中途恢复不补播开启。死亡、到期和回收恢复原材质；凝滞暂时隐藏效果，恢复时继续剩余进度。技能资源、场景和动态Shader归该主动技能声明，模型覆层与上升光流均实际绘制预热。

窗口内成功生成新鱼时不发出旧鱼死亡动作，可靠死亡通知同步携带false；新鱼走既有出生表现且不继承技能效果。窗口外、新鱼自身死亡及生成失败时仍播放ranged_death。
