# 武器大师动画

[返回武器大师](../jax.md) · [单位索引](../README.md)

使用需求指定的武器大师.glb。当前GLB相对原SKN的三轴缩放实测均为0.0085，模型包装再统一缩放1.25，与稍大档德莱厄斯同机位比较；权威半径独立为21。基础皮肤定义默认隐藏Bluefish、Goldfish，包装只移除这两个表面，保留身体、武器、骨骼和动画。

部署2秒，继续使用Respawn、待机Idle1_Base、移动Run_Base；普通攻击交替Attack_1_anm与Attack_2_anm。反击风暴先以0.4秒Spell3_Run_Intro_anm起手，再按移动状态接Spell3_Idle/Spell3_Run；期间普攻使用Spell3_Attack1/2/3按攻击序号循环；死亡Death源片5秒，压缩上限0.8秒。原始头发ConformToPath修饰未复现，使用导入骨骼动画。

普攻原版castFrame=10.5，按30fps为0.35秒；两套源动作均2.166667秒，映射1.4秒周期后为0.226154秒，配置0.23秒，20Hz结算到0.25秒。E期间攻击片长2.333333秒，统一前摇对应约0.21秒，近似误差0.02秒。源spellCastTime=0.40855与castFrame不相同，本项目以castFrame映射作者动作，不声称复现原游戏完整攻速求解。

动画不驱动命中、伤害或免疫计时。双方、同档尺寸、技能中普攻和死亡清场截图见本任务交付记录。

原版animationGraph的TransitionClipBlendData已接入：Idle1_Base→Run_Base使用Run_In，反向使用Idle_In；两段普通攻击分别用Attack1/2_To_Idle、Attack1/2_To_Run收势。入跑被停止时、攻击转跑被停止时都接Idle_In，待机收势期间起跑可由新动作接管。只接当前卡使用的普通攻击和E，不因素材存在而启用Q/W/R。

E起手和正常结束使用纯表现事件覆盖当前姿态：无论待机、移动或普攻前后摇，开启E立即从头播放Spell3_Run_Intro_anm；正常到期立即播放静止Spell3_B_Idle_anm（1.6秒）或移动Spell3b_run（约1.567秒）。不创建权威visual_action窗口或施法锁，不取消/重启攻击序号和计时；被覆盖攻击仍按原节点触发伤害、挥击/命中声音和命中特效。

同一渲染帧E事件优先于新攻击；该攻击照常结算，画面不排队补播。后续新攻击序号立即接管E起手、持续或结束；E有效时使用三段专用攻击，否则使用普通攻击。E起手播完、E专用攻击播完后按当前移动状态恢复持续；E结束播完恢复普通待机/移动，不恢复旧攻击姿态。结束动作中移动/停止会同相位切换静止/移动版本，不从头重播。

硬控沿通用攻击合同：眩晕、击退取消当前普攻并退出E事件动作，受控期间使用普通Idle1_Base，不使用Spell3_Idle；解控后按当下移动、攻击与E剩余时间恢复，不重播E起手；冰冻/凝滞保持受控瞬间姿势、取消旧调度，解除后不续播旧起手/结束；受控期间到达的E事件消费但不播放，死亡直接接管。E窗口及爆发仍由原有权威机制决定，不能因画面冻结而暂停或补发。禁锢等是否取消普攻继续由通用控制准入决定。

上述覆盖规则是用户确认的项目适配。原版动画图能确认三段E攻击及E起手/结束到普攻的零混合边，不能据此认定已还原原版运行时调度。源Run_In、Idle_In及普通攻击收势继续按原片播放。
