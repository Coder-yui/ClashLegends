## 目前怎样呈现

普通吹箭分起手和收势；致盲换用 Spell1，并有自己的收势与转跑。重新攻击与切入致盲采用短衔接，避免上一次动作拖慢下一针。

## 已使用的动作

动画名保留素材原名，方便在工作台选中查看；不需要阅读代码。

| 看到的动作 | 对应素材 | 使用方式 |
| --- | --- | --- |
| 部署 | Respawn | 按游戏中的对应状态播放 |
| 待机 | Idle1_Base | 状态持续时循环 |
| 开始移动 | Run_In_ASU_Teemo_anm | 按游戏中的对应状态播放 |
| 持续移动 | Run_Base | 状态持续时循环 |
| 普通攻击 | Attack1_ASU_Teemo_anm | 按攻击顺序播放，跟随实际攻击速度 |
| 命中与收势 | Attack1_ToIdle | 按攻击顺序播放，跟随实际攻击速度 |
| 强化攻击 | Spell1 | 按游戏中的对应状态播放 |
| 强化攻击收势 | Spell1_ToIdle | 按游戏中的对应状态播放 |
| 强化后转跑 | Spell1_ToRun | 按游戏中的对应状态播放 |
| 死亡 | Death | 播放 0.8 秒 |

## 怎么观看与检查

进入“卡牌开发工作台”，选中该单位。先在模型预览中查看上表动作，再到实战页连续观察部署、攻击、技能和结束衔接。蓝红版本在同一篇记录，观看时分别切换阵营。

重点看：脚底是否贴地、朝向是否正确、动作有无突然跳姿，以及攻击后能否自然回到跑步或待机。命中时间以总览中的战斗数值为准，不能用原片总长度代替。
