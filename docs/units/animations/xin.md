## 目前怎样呈现

前两击分别使用攻击与收势片段；第三击把同一个完整被动片段分为 0～0.3 秒起手和 0.3～3 秒后段，保持姿态连续。前两击转跑用普通入跑，第三击用被动专用转跑；部署和主动横扫结束用 Spell4_To_Run。旧的拆分候选存在跳姿问题，当前不启用。

## 已使用的动作

动画名保留素材原名，方便在工作台选中查看；不需要阅读代码。

| 看到的动作 | 对应素材 | 使用方式 |
| --- | --- | --- |
| 部署 | Spell4 | 按游戏中的对应状态播放 |
| 待机 | IdleBase | 状态持续时循环 |
| 开始移动 | RunIn | 按游戏中的对应状态播放 |
| 持续移动 | RunBase | 状态持续时循环 |
| 普通攻击 | Attack1_Hit → Attack3_Hit → Passive_AA_01_XinZhaoRework_anm | 按攻击顺序播放，跟随实际攻击速度 |
| 命中与收势 | Attack_AA_01_settle_XinZhaoRework_anm → Attack_AA_03_settle_XinZhaoRework_anm → Passive_AA_01_XinZhaoRework_anm | 按攻击顺序播放，跟随实际攻击速度 |
| 攻击后转跑 | 沿用通用衔接 → 沿用通用衔接 → PassiveAA_to_Run_XinZhaoRework_anm | 按游戏中的对应状态播放 |
| 死亡 | Death | 播放 0.8 秒 |

## 技能与变形动作

### 新月护卫

动作顺序：Spell4。

游戏内播放时长：1 秒。

动作衔接：进入混合 0 秒。这里的混合只让姿态过渡平滑，不改变命中时间。

## 怎么观看与检查

进入“卡牌开发工作台”，选中该单位。先在模型预览中查看上表动作，再到实战页连续观察部署、攻击、技能和结束衔接。蓝红版本在同一篇记录，观看时分别切换阵营。

重点看：脚底是否贴地、朝向是否正确、动作有无突然跳姿，以及攻击后能否自然回到跑步或待机。命中时间以总览中的战斗数值为准，不能用原片总长度代替。
