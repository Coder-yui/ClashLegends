# 金克丝动画

[返回金克丝](../jinx.md) · [轻机枪](../jinx_minigun.md) · [总索引](../README.md)

采用用户指定暴走萝莉.glb，保留64个原始动画与完整骨骼。原模型包围范围约0.842×1.935×1.550世界单位，包装统一缩放1.232（较初版放大10%）；与艾希、女枪同一实际战场镜头比较体量。基础皮肤单个网格、单材质，原skin0没有默认隐藏子网格；火箭炮和机枪由各自骨骼动画携持，未使用武器在背后，不另外隐藏武器。

部署使用原版Respawn（原长2.5667秒压入公共1秒部署窗口），包含动画图第25帧的Rocket_Launcher→Rocket_Launcher_World挂点切换。首次部署不播放切枪动作。

| 路线 | 火箭炮形态 | 轻机枪形态 |
| --- | --- | --- |
| 待机 | Jinx_Rlauncher_idle1_anm | Idle1_Base |
| 入待机 | Rlauncher_Idlein1 | IdleIn1 |
| 入跑 → 跑步 | Jinx_Rlauncher_run_in_anm → Jinx_Rlauncher_run_anm | Jinx_minigun_run_in_anm → Run_Base |
| 普攻 | Jinx_Rlauncher_attack1/2_anm | Attack1/Attack2 |
| 死亡 | Jinx_Rlauncher_death_anm | Death |

每种形态只保留一个待机与普通跑步，不接入加速跑或待机轮播。只保留实际使用的入跑和移动/攻击回待机路线，每形态共用一段入待机；无专用AttackToRun时使用同形态通用入跑（0.5秒原速）。不接入回城、表情及未携带W/E/R的衔接。

原模型保留的Attack1/3/5与Attack2/4/6各为一组近似动作；原始关键帧数据存在差异，不是逐字节相同的副本。没有本项目所需的独立条件，正式配置仅保留Attack1与Attack2，其他片段在工作台仍可查看原素材，但不参与战斗轮播。

Q原图为ParallelClipData：身体weapon2约0.3667秒，Minigun遮罩层1秒。文件前缀表示来源武器：切到火箭使用minigun_spell1_weapon2_anm + minigun_spell1_weapon_GunOnly_anm；切到机枪使用launcher_spell1_weapon2_anm + launcher_spell1_weapon_anm。方向已用源片起止肩/肘/武器姿态与两形态Idle比对，并在实际渲染复核。切枪改为通用变形动作：0.37秒窗口（原片0.3667秒按项目精度取值），期间禁止攻击，20Hz第8Tick结束。Minigun武器遮罩（含转换模型的Minigun_Body，共14骨骼）按同一权威动作进度压入0.37秒，不另起一个1秒计时器。眩晕/击退继续播放，冰冻/凝滞取消旧音画、冻结姿势；计时继续，解控不续播，死亡停止。模型始终复用，炮口挂点随形态更新，不影响权威弹体出生点。

两种死亡均用0.8秒表现窗口。

原始节点来源：Jinx.wad.client内data/characters/jinx/jinx.bin的JinxQAttack/2（castFrame=7）与JinxBasicAttack/2（castFrame=8.5）；data/characters/jinx/animations/skin0.bin给出30FPS。

| 动作 | 原片长 | 节点秒数 | 映射到本项目间隔 |
| --- | --- | --- | --- |
| 火箭炮1 | 1.600秒 | 7/30 | 0.21875秒 |
| 火箭炮2 | 1.667秒 | 7/30 | 0.21000秒 |
| 机枪1/2 | 1.567秒 | 8.5/30 | 0.18085秒 |

公式为原节点/原片长×本项目基础攻击间隔。火箭炮统一0.22秒，20Hz在0.25秒发射，相对原映射晚约31–40毫秒；机枪统一0.18秒，20Hz在0.20秒发射，晚约19毫秒。攻速同时缩放攻击周期和前摇，动画不驱动伤害；弹体命中是之后的独立碰撞结果。

移动切枪共用一个连续步态时钟：两形态普通Run均约0.9333秒，下肢在相同相位按切枪进度平滑混合旧/新跑姿；切换结束时基础播放器定位到同一相位，持续跑步不从0重播。遮罩只覆盖Root、Pelvis和明确列出的双腿骨骼，不包含挂在骨盆/大腿下的轻机枪、手枪。上身仍播放原切枪身体片段；静止切枪混合两个形态的唯一Idle下肢。冰冻/凝滞不推进步态，仍遵守通用动作取消和移动权限。

轻机枪使用完整1秒原武器片段映射到0.37秒窗口，包含枪管展开/收短与主体大小变化。切换结束后独立维持机械部件的目标尺寸和内部位置，基础Idle/Run/Attack不能将收起的机枪撑回全尺寸；持枪根、背带摆动、枪管旋转仍交给基础动作。火箭形态主体缩放约0.64、枪管纵轴约0.2046，机枪形态恢复1。部署保留Respawn原生轨道，冰冻/凝滞保持当前姿势，解控显示已生效形态，不续播旧切枪。

这属于Godot适配：本地原图Q身体片段位于Default轨；JinxRunCycleManager只有脚本引用，没有完整实现。共享时钟与渐变方案依据原动作数据和用户确认，不宣称逐项复刻LoL运行时。
