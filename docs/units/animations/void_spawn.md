# 虚空兽模型与动画

[返回虚空兽](../void_spawn.md) · [总索引](../README.md)

指定源件为开发素材库 `01-待开发/卡牌模型/void_spawn.glb`，正式依赖同步到 `assets/units/void_spawn/source/void_spawn.glb`。包装采用等比1.2缩放，保持原贴图与网格，没有额外隐藏部件配置。与提莫、虚空蠕虫同场比对稍小体型；源数据和最终观感分别记录在改动记录。

| 阶段 | 原生动作 |
| --- | --- |
| 部署 | VoidSpawn_Spawn_anm |
| 待机 / 行军 | Idle1 / Run |
| 牺牲跳跃 | VoidSpawn_TurretAttack1_anm |
| 被杀 | Death |

建筑攻击原片约1.333333秒（0至40帧，共41个采样点，30fps）。原动画定义在第23帧（23/30秒）触发TurretDeath，第24帧把Thorax移到远处隐藏身体，片段末尾不是爆炸时刻。按20Hz向上对齐到16Tick（0.8秒），起跳至爆炸的原动作等比适配这一窗口。没有普通攻击前摇；原生Attack1/2不参与战斗。起跳死亡不播放普通Death，独立代理从原位置平移到锁定落点并采样原跳跃动作，动画完成不提交伤害。普通被杀保留2.2秒纯表现代理承载原版死亡粒子，身体0.35秒后隐藏。

卡面使用用户在3D摄影棚手动编排的两个包装模型，前后错位构图，308×560；2026-10-12选定的原始照片保留在本地摄影棚shots目录，来源路径与图片SHA-256登记在assets/units/void_spawn/source_manifest.json。幽灵疾步技能图标已撤下；虚空强化使用云顶voidspawn_squarefixed图标，原样解码为64×64 PNG。

原版粒子来自 Map12.wad.client 的 Jade_VoidSpawn/Skins/Skin0：攻击建筑爆炸 TurretDeath 七层、普通死亡 NormalDeath_Explosion 七层、起跳 EnergyBuildUP 一层与 BuildUpGlow 三层。保留原版纹理、网格、曲线与层次，经120Hz离线采样适配Godot；不声称与LoL引擎逐像素相同。

蓄能按原定义从动作起点绑定头顶与武器骨骼；同一个纯表现代理持续承接跳跃，在0.8秒权威爆炸事件抵达后，于channel骨骼挂点启动TurretDeath并固定在世界坐标。爆炸接替身体与附体蓄能，保留2.2秒尾迹。客户端没有收到权威事件时停留在爆炸前姿态，不提前播放爆炸。部署仅保留原生模型动作和声音，撤下SpawnSplat及资源声明。旧虚空巢虫爆裂和幽灵疾步资源已撤下。来源与哈希见 assets/effects/void_spawn 各效果清单。

爆炸按原版七层分别播放：Sphere_core／Sphere_glow核心、ring冲击网格、cast_orbit飞散、Basic1瞬闪、muzz_flash撞击闪光、Conemesh侧焰。统一采用0.012原生单位换算，取消Basic1额外0.45缩放和强制贴地。TurretAttack第23帧channel骨骼具有约180°绕Y旋转，爆炸保留其完整正交朝向与位置，在建筑受撞面展开；抵达后冻结世界变换。迟到的独立抵达同样采样该姿态，保留进攻方向、高度和强化缩放。死亡仍0.012，FireRing和CenterFlare贴世界地面0.09；蓄能0.006。原始曲线、发射顺序、纹理、网格、混合和尾帧不变。

虚空强化在正常单位与牺牲代理中均应用1.25倍缩放；权威碰撞半径同时增加25%，永久移速加成20%。当前未确认兹若特强化虚空兽专属粒子，不能把普通攻击BuildUpGlow或Trail按名称推断为强化附体特效。按用户许可使用项目自制紫色轮廓光与通过BoneAttachment3D直接挂在Horn骨骼下的渐变紫色光球，局部偏移贴合角体，完整继承模型缩放和骨骼动画，读取永久强化状态；光球直径0.90（较原0.72放大25%），保持头角局部侧向偏移为0；浅紫亮心、紫色主体和渐隐外晕使用同心径向渐变，无上升光丝，死亡或起跳即停止，随后由原版攻城蓄能与爆炸承接。资源通过卡牌声明进入预热，无新贴图依赖。
