# 德邦军旗：模型与表现

[返回军旗](../demacian_standard.md) · [总索引](../README.md)

旗杆来自JarvanIVStandard基础皮肤；待机summonerbeacon_idle，死亡summonerbeacon_death，死亡表现上限0.8秒。源旗杆Y范围约-73.59至254.64，最终XYZ统一0.01，地下尖端保留原点。双方使用同一原版纹理，以通用阵营标识区分。

旗面不是模型网格，是皇子E的CameraTrail。由原始粒子数据60Hz离线采样（常驻旗面），绑定源配置的root骨骼，跟随待机/死亡骨骼方向；靠杆端沿杆身竖轴固定缝合边，远端按相机朝向展宽；使用原版蓝金纹理、20/秒出生率、1秒粒子寿命和运动曲线，原生比例0.01。持续旗面循环稳定段，停止模拟/冰冻/凝滞时冻结，死亡时随旗杆下沉，死亡动作结束后统一清理；不改变权威逻辑。摄影使用完整包装场景，不能直接用只有旗杆的GLB。

黄金圣盾包含原版W五层扩散与六层自身盾表现；总护盾归零或本次3秒窗口结束关闭自身表现，其他友军沿通用护盾条显示，敌军沿通用减速提示。范围层未做俯视压缩，深度测试按源miscRenderFlags逐层选择。当前使用离线采样，不复现LoL实时导航遮罩；实际画面验收状态见任务记录。

部署持续1秒：前0.5秒使用原版E_tar武器下落粒子（源高度2000、速度−4000），随后切到旗杆、旗面待机补满剩余0.5秒，并播放原版E_hit落地层。蓝红使用对应落点圈。重连不补播，取消/死亡清理。W扩散按可见主环3.0倍校准，尾段扩张裁在中心半径160内，与攻速光环一致；自身盾与模型统一0.01缩放。

常驻攻速范围以红/蓝细边标记中心半径160，圈内由双方同色的低透明度流动纹理覆盖整个区域；无强光和大幅闪烁，部署中、凝滞、死亡或取消时隐藏。黄金圣盾只播皇子W；范围护盾的烈阳之匣播放路径只接受显式声明该资源的卡牌。模型展台支持包装场景的部署回调，可重播、暂停和拖动部署时间轴。

E_hit最慢尘环寿命约1.1秒，部署结束后自然播放尾部，不在1秒处硬切；取消或死亡立即清理，不延长部署。

E部署与W技能已重新从源BIN及网格/纹理重建为120Hz采样。E武器使用原版不透明深度材质，事件起点去除模拟器空步；W自身盾按原速播放，项目3秒盾期末0.35秒淡出。范围平面和旗面排除通用模型受击叠加，保留旗杆正常白闪。来源与区别见[资源说明](../../../assets/effects/demacian_standard/README.md)。
