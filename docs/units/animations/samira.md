# 沙漠玫瑰动画

[返回沙漠玫瑰](../samira.md) · [总索引](../README.md)

使用用户指定的基础皮肤GLB，包装统一XYZ缩放1.2（较初版0.95放大约26.3%）；与寒冰射手、金克丝同战场镜头比较身体体量。保留枪、剑与身体，按skin0初始可见性移除Pistol_Blur、Revolver_Blur、Coin三个默认隐藏表面。源模型完整包围盒约0.957×2.284×2.457，包含装备，不能视为纯身体尺寸。

| 动作 | 片段与适配 |
| --- | --- |
| 部署 / 脱战待机 / 脱战移动 | Respawn / Idle.anm / Run_OOC.anm；持械状态见下表 |
| 远程两段 | Attack1/2_Gun_Start → 对应Hit → 对应INTO_Idle；移动时使用Gun_INTO_Run_Front |
| 近战两段 | Attack1/2_Sword → 对应Hit → 对应INTO_Idle；移动时使用各自INTO_Run |
| 炼狱扳机 | Spell4_Start源长0.866667秒适配0.5秒，Spell4_Loop（Godot导入名Spell4）源长1.466667秒适配1.5秒 |
| 死亡 | Death源长4秒，压缩至0.8秒上限 |

## 原版节点与项目映射

来源为本地 `Samira.wad.client` 的 `data/characters/samira/samira.bin`、`data/characters/samira/animations/skin0.bin` 及基础皮肤 ANM。四个 SpellObject 分别为 SamiraBasicAttack、SamiraBasicAttack2、SamiraBasicAttackMelee、SamiraBasicAttackMelee2，动画分别绑定以下四套，`castFrame` 均为8。起手 ANM 均为v5、9个采样点、间隔1/30秒，实际导入片长0.266667秒；Hit各3个采样点、0.066667秒。第8帧位于起手段末端，随后接Hit，再进入各自收势。

两套枪械起手图另有第4帧的枪口闪光，属于ParticleEventData，不能当作第8帧的弹体创建节点。近战SpellData含复用的MissileSpec字段，但动画与本项目近战结算不创建弹体；不以共享字段推断原游戏服务端实现。原AttackSlot还含cast offset=-0.15，本地客户端资料不足以单独还原其最终服务端时钟；以下明确为本项目的源动作节点适配。

分段动作以源基础攻速0.658对应的周期 `1/0.658=1.519757秒` 作为播放参考，而非把2.333/2.6秒的可中断收势当作完整攻击周期。适配到本项目1.4秒，参考倍率为 `1.4×0.658=0.9212`；第8帧映射为 `(8/30)×0.9212=0.245653秒`，公共前摇按项目0.01秒精度取0.25秒。近战整体再除以1.4，攻击间隔保持1秒。

| 动作 | 源节点 / 起手长 | 理论映射 | 配置后的节点 | 20Hz首次结算 | 对理论节点总误差 |
| --- | --- | --- | --- | --- | --- |
| Attack1_Gun_Start | 8/30 / 0.266667秒 | 0.245653秒 | 0.25秒 | 0.25秒，第5Tick创建弹体 | +0.004347秒 |
| Attack2_Gun_Start | 8/30 / 0.266667秒 | 0.245653秒 | 0.25秒 | 0.25秒，第5Tick创建弹体 | +0.004347秒 |
| Attack1_Sword | 8/30 / 0.266667秒 | 0.175467秒 | 0.178571秒 | 0.20秒，第4Tick命中 | +0.024533秒 |
| Attack2_Sword | 8/30 / 0.266667秒 | 0.175467秒 | 0.178571秒 | 0.20秒，第4Tick命中 | +0.024533秒 |

Start精确播放至源片末端；Hit按参考周期缩放为远程0.061413秒、近战0.043867秒，随后收势以同参考倍率播放，可被下一次攻击接管；分段衔接混合为0。旧配置的attack_hit_duration在存在Recover时未控制Hit段，曾落入默认0.3秒，现改为attack_reference_interval统一控制。伤害/出弹由20Hz权威模拟驱动，动画不反向结算。远程真正伤害在弹体到达后发生，不是创建时发生。

源远程弹体起点为Pistol_Muzzle，包装通过真实同名骨骼创建BoneAttachment3D。权威子弹从单位2D中心出生、偏移0、碰撞半径4；骨骼只改变视觉起点。枪刀模式通过现有单调攻击序号的四动作槽同步，客户端不按插值距离另猜模式；攻速继续走现有快照。

Godot导入时将片名中的点改为下划线，并移除Loop后缀；配置使用实际导入名，源文件名仅用于来源记录。

## 弹体尺寸与枪口验证

对比原SKL导出与用户GLB的Root和Pistol_Muzzle平移，比例均为0.0085；例如枪口Z从-39.999996变为-0.339999966。故原版弹体采用0.0085×包装1.2=0.0102，较旧0.012缩小15%，不随R半径缩放。弹头原网格纵长31.159779，源出生纵向倍率2，换算为0.63566个3D单位，战场标尺下约25.43像素（屏幕投影随朝向变化，辉光范围另计）。

莎弥拉弹体表现延后到本帧UnitModel3D之后更新，首次读取当前枪口投影并缓存；移除人为提前0.025秒采样。枪口骨骼只改变可见路径，权威出生点、弹速700、碰撞半径4保持原有配置。节点、源哈希与尺寸证据见开发素材库制作目录 `attack-audit/node-mapping.json`；实机逐套证据见本任务改动记录。

## 枪刀姿态与收武器

近战起手范围为身体表面间距1.6格（64像素）。权威起手选择枪/刀，四槽攻击序号分别表示两套枪攻击、两套刀攻击；表现始终按这个序号选择最近持械姿态，客户端不读取插值距离猜测武器。

| 状态 | 远程持枪 | 近战持刀 |
| --- | --- | --- |
| 停步进入待机 | Idle_Gun_IN → Idle_Gun循环 | Idle_Sword_IN → Idle_Sword循环 |
| 攻击转跑 | Attack_Gun_INTO_Run_Front → Run_Gun | 当前Attack1/2_Sword_INTO_Run → Run_Sword |
| 普通移动 | Run_Gun | Run_Sword |
| 站立收武器 | Sheath_Gun_Idle → Idle | Sheath_Sword_Idle → Idle |
| 移动收武器 | Sheath_Gun_Run → Run_OOC | Sheath_Sword_Run → Run_OOC |

出生仍使用Respawn，首次交战前使用普通Idle/Run_OOC。攻击起手、Hit和收势保持原有分段时序，不插入拔武器动画延迟伤害。攻击结束后的完整收势直接接对应持械待机；从跑步停下使用IN片段。普攻或技能动作之外累计4秒后收武器，冻结/眩晕期间不累加；4秒是本项目显式表现规则，并非声称恢复原版服务器脱战时长。收武器源长约3.33–3.47秒，以原速播放，可被新攻击、技能、死亡立即打断；冻结停在当前姿态。收武器过程中开始/停止移动切换到对应版本，保留已播放秒数。

跑步只使用普通Run_Gun、Run_Sword和Run_OOC，不按移速切换Boots/Haste片段；普通跑步循环的播放倍率仍跟随实际移动倍率。收武器为保持原事件节点以原速播放，其腿部采用基础Run_OOC采样，不单独随加速倍率重采样。

12个实际使用的待机、跑步、收武器片段保存在`assets/units/samira/locomotion.res`。由源skin0动画图、ANM对应的GLB、原Upper轨道遮罩及JointSnap事件离线采样；四个收武器片段按源权重叠加Idle/Run_OOC，避免全身动作覆盖腿部。原SKL独立导出和用户GLB的114个关节顺序逐项一致。挂点按目标全局变换设置后转回父骨骼局部，不累计叠加偏移；运行时只播放成品，不重新施加一轮挂点变换。

原始GLB不改。转换工具为`tools/assets/bake_samira_locomotion.gd`，源映射、遮罩与审计留在素材库`03-制作中/沙漠玫瑰/stance-audit/`，资源哈希见`assets/units/samira/locomotion_manifest.json`。本次不新增收武器音效，沿用已有音频事件。实际验收与当前限制见[改动记录](../../deliveries/2026-10-23_沙漠玫瑰新卡.md)。

## 炼狱扳机结束衔接

源skin0动画图中，Spell4_Loop到持枪跑步的路线使用Spell4_INTO_Run；到Idle_Gun和Idle_Sword分别使用对应的Idle_IN片段。本项目自然结束R后统一进入持枪姿态，新普攻按权威攻击序号立即接管；这是项目的姿态选择，不据客户端动画图推断原版服务端总是选择枪。

| 结束时状态 | 衔接 |
| --- | --- |
| 正在移动 | Spell4_INTO_Run（原速约0.933秒）→ Run_Gun |
| 静止 | Idle_Gun_IN → Idle_Gun |

R主体仍为0.5秒Start加1.5秒Loop。结束衔接只属于表现，不延长技能、伤害或攻击锁；移动衔接中停步转入持枪待机进入动作，新攻击、技能和死亡可以接管。源路线证据保存在素材库的`r-exit-audit/source-routes.json`。
