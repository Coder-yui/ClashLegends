# 虚空蠕虫动画

[← 虚空蠕虫](../voidmite.md) · [总索引](../README.md)

| 动作 | 实际片段 | 映射说明 |
| --- | --- | --- |
| 出生 | SRU_Horde_Mini_Hatch_anm | 原1.3333秒缩放至1.00秒；前0.45秒配合水平外抛 |
| 待机 / 行走 | Idle1 / Ranged_Run | 默认循环 |
| 普攻 | Ranged_Attack1 | 原片1.3333秒映射1.33秒周期，保留0.32秒命中 |
| 死亡 | SRU_Horde_Mini_Death2_anm | 原片1.3333秒映射1.33秒 |

模型来自用户指定GLB。带点号的原动画名由Godot导入时转为下划线，原片没有重命名改写。混合读取本地Map11基础皮肤动画表的TimeBlendData，以FNV-1a动作哈希恢复片段对；未声明的边沿用项目通用混合，不虚构原版时长。准备被硬控时清除动作窗口，恢复后新序号重播；冲撞位置和命中完全由20Hz权威逻辑决定。

素材与原表定位见[资源记录](../../../assets/units/voidmite/README.md)。

模型缩放0.60，体型小，权威半径12px。水平外抛由2D固定Tick推进，垂直跳起/落地来自原Hatch骨骼动画，不额外叠加人工高度曲线；动画不驱动权威位置。Ranged片段只用于姿态，玩法仍为只攻击建筑的近战单位。
