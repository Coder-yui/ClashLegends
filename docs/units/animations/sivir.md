# 战争女神模型与动画

[返回战争女神](../sivir.md) · [返回单位索引](../README.md)

使用用户指定的战争女神GLB。源网格约高1.83模型单位，包装等比缩放1.05，按中体型与艾希同场校准。源皮肤没有默认隐藏子网格；将原单网格按武器骨骼权重拆成身体与武器，保留源骨骼、纹理和动作。仅当快照显示其回旋镖在途时隐藏手中武器，回收后恢复；死亡显示武器。

| 阶段 | 动作与映射 |
| --- | --- |
| 部署 | Sivir_Base_Respawn.anm（Godot导入名 Sivir_Base_Respawn_anm） |
| 待机 / 移动 | Idle1_Base / Run |
| 攻击 | Spell1，原片约1秒，原版Q发射节点0.25秒（30Hz第7.5帧），项目基础1秒、20Hz第5Tick创建 |
| 接回 | Spell1_Catch，原片0.667秒，作为0.2秒表现过渡，不决定下一次攻击准入 |
| 死亡 | Death，原片3.733秒压缩到0.8秒 |

权威弹体从单位中心沿固定方向出发，去程200。视觉使用源Q的Buffbone_Glb_Channel_Loc骨骼挂点；挂点偏移不参与碰撞。回旋镖采用原版sivir_weapon_blur贴图，绘制直径60像素（源手持模型外径约63像素，略小）；平面三维投影保留战场54°透视关系；这是简化弹体表现，未完整还原Q的全部尾迹发射器。蓝红双方共用模型、通过通用阵营标识区分。

E为即时护盾，不叠加会打断投掷的整身施法动作。卡面来自原版sivirloadscreen_0.tex，E图标来自sivir_e.dds。
