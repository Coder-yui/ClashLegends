# 腕豪 · 动画接入

[← 返回腕豪总览](../sett.md) · [总索引](../README.md)

## 目前怎样呈现

四拳按“普通拳→重拳→普通拳→重拳”循环，每拳有起手与命中段。技能前 0.8 秒保持原速，后段压到 0.6 秒，总长 1.4 秒，保证拳头真正打出的时刻不漂移。技能后分别有接待机和跑步的过渡；普通版转跑从素材 0.4 秒处接入。

## 已使用的动作

动画名保留素材原名，方便在工作台选中查看；不需要阅读代码。

| 看到的动作 | 对应素材 | 使用方式 |
| --- | --- | --- |
| 部署 | Respawn | 按游戏中的对应状态播放 |
| 待机 | Idle_Base | 状态持续时循环 |
| 持续移动 | Run_Base | 状态持续时循环 |
| 普通攻击 | Attack1_Start → Attack1_Passive_Start → Attack2_Start → Attack2_Passive_Start | 按攻击顺序播放，跟随实际攻击速度 |
| 命中与收势 | Attack1_Hit → Sett_Attack1_Passive_anm → Attack2_Hit → Sett_Attack2_Passive_anm | 按攻击顺序播放，跟随实际攻击速度 |
| 攻击后恢复 | 沿用通用衔接 → Attack1_Passive_Into_Idle → 沿用通用衔接 → Attack2_Passive_Into_Idle | 按游戏中的对应状态播放 |
| 拳间移动 | Run_Passive → Run_Base → Run_Passive → Run_Base | 按游戏中的对应状态播放 |
| 死亡 | Death | 播放 0.8 秒 |

## 技能与变形动作

### 蓄意轰拳

动作顺序：Sett_spell2_anm → Sett_spell2_anm。

各段在游戏中的时长：0.8 秒 → 0.6 秒；合计 1.4 秒。

取用原片区间（秒）：第 1 段 0～0.8；第 2 段 0.8～1.567。

动作衔接：进入混合 0.1 秒，退出混合 0.1 秒。这里的混合只让姿态过渡平滑，不改变命中时间。

### 满层 / 强化版：蓄意轰拳

动作顺序：Spell2_Strong → Spell2_Strong。

各段在游戏中的时长：0.8 秒 → 0.6 秒；合计 1.4 秒。

取用原片区间（秒）：第 1 段 0～0.8；第 2 段 0.8～1.167。

动作衔接：进入混合 0.04 秒，退出混合 0.1 秒。这里的混合只让姿态过渡平滑，不改变命中时间。

## 怎么观看与检查

进入“卡牌开发工作台”，选中该单位。先在模型预览中查看上表动作，再到实战页连续观察部署、攻击、技能和结束衔接。蓝红版本在同一篇记录，观看时分别切换阵营。

重点看：脚底是否贴地、朝向是否正确、动作有无突然跳姿，以及攻击后能否自然回到跑步或待机。命中时间以总览中的战斗数值为准，不能用原片总长度代替。
