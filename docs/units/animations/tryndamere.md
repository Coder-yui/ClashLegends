# 蛮族之王动画

[返回蛮族之王](../tryndamere.md) · [单位索引](../README.md)

部署播放Idle1最后1秒（约2.3～3.3秒）烘焙的DeployIdle；普通待机Idle1，移动Run。原包含Run2，但动画图与本地定义未能证明它由满怒触发，按用户条件不启用满怒切换。大招只建立增益，不覆盖控制姿势或锁普攻。

## 攻击分段

| 时间 | 动作 |
| --- | --- |
| 0～0.4秒 | 保持本次Attack1、Attack2或Crit的首帧 |
| 0.4～1.47秒 | Attack1、Attack2或Crit原完整动作 |
| 1.47～1.7秒 | 保持本次攻击动作的末帧 |

HeldAttack1、HeldAttack2、HeldCrit是上述三段的精确片段。前后保持对应动作自身姿势，不切换Idle。原片长1.066667秒，按需求取1.07秒，仅约0.3%的时长差；不再把挥刀整体拉长到1.7秒。原GLB保留21条源动作；包装使用独立animations.res动画库，包含源动作、3条保持攻击和DeployIdle。独立资源避免GLB导入优化删除保持段边界。

命中沿用多动作共用权威前摇：0.4秒首帧保持＋约0.4秒动作内前摇＝0.8秒。原BIN普通攻击castFrame11.5、暴击13，以30Hz映射得到含等待的0.784秒和0.835秒；共用节点误差均小于一个20Hz Tick，普通与暴击命中间隔严格34 Tick。动画、音频不驱动伤害。挥刀音延后0.4秒，命中音仍由真实命中事件触发。

每刀允许在无圈内下一目标时跳过末尾0.23秒末帧保持。进入该窗口之前不调用会取消攻击的换目标流程，防止目标死亡截断原收招。固定模拟按20Hz边界执行，窗口进入可能延后不足1 Tick；有替代目标则保留完整1.7秒周期。加减攻速同比缩放，硬控仍遵循共通打断规则。

## 模型与尺寸

包装统一XYZ缩放3.1，权威半径21。原皮肤未声明隐藏子网格，保留全部网格。制作脚本和原始GLB保留于本地素材库03-制作中/蛮族之王；运行包装引用独立动画库；原始GLB不再包含上一版Idle拼接攻击。
