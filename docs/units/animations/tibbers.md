# 提伯斯动画

[单位索引](../README.md) · [提伯斯](../tibbers.md)

基础皮肤源为本机Annie.wad.client内AnnieTibbers的SKN、SKL和ANM，经lol2gltf转换。红蓝双方共用基础模型，由阵营提示区分。原网格包围盒约225.55×195.17×152.54，统一缩放0.013，脚底偏移0.01；原皮肤没有额外默认隐藏子网格。实机与同档大型单位盖伦同屏检查体量和脚底位置。

| 动作 | 片段 | 原始片长 / 项目时长 |
| --- | --- | --- |
| 出生 | 不绑定出生片段 | 落地直接接待机、移动或普攻 |
| 待机 | annietibbers_idle1 | 3.333秒循环 |
| 移动 | annietibbers_run | 0.968秒循环 |
| 普攻 | annietibbers_attack1、annietibbers_attack2 | 均1.5秒 / 1.2秒基础窗口 |
| 死亡 | annietibbers_death | 1.933秒 / 上限0.8秒 |

两套普攻的SpellObject（AnnieTibbersBasicAttack、AnnieTibbersBasicAttack2）均为castFrame=11；源ANM为30Hz，映射为11/30/1.5×1.2=0.2933秒，采用共用前摇0.3秒，误差+0.0067秒。强化倍率1.5时前摇0.2秒，20Hz Tick结算。两动作第9帧的挥爪粒子不作为伤害依据。此前“Attack1缺独立castFrame”的记录已纠正。

预警1秒后，下降阶段使用无碰撞的待机姿态模型副本，从8世界单位高度下降至落点。0.5秒到点后由权威生成真实单位并立即行动，不播放annietibbers_spawn，不添加部署锁；预警和下降期间没有可攻击单位。

按用户指定，`Idle_Enter` 不接入，待机只循环 `Idle1`。移动、待机与普攻使用通用状态机混合，两套普攻按攻击序号交替，强化期间随权威攻速加快，结束恢复基础速度。凝滞/冰冻暂停当前姿态，眩晕取消攻击并回到原速待机，不继承普攻的加速或减速，恢复后由真实行为接管；死亡抢占当前动作。
