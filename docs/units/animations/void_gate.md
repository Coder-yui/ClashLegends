# 兹若特传送门模型、动画与特效

[返回传送门](../void_gate.md) · [总索引](../README.md)

指定void_gate.glb的网格范围约1.73×1.49×1.76源模型单位，包装等比1.7。使用全部原生水晶网格，无额外隐藏部件。地面宽深约118×120像素，匹配3×3格的120×120像素部署占地；身体半径独立为30，提示半径50。

原版Map12.wad.client中的Jade_VoidGate动画图指定Spawn→Portal、Idle1→Portal_Idle、Spit→BirthSpit、Death→Death_01，均挂Buffbone_Ground。四套原粒子保留10/8/2/5个发射器和原贴图、网格、曲线，以120Hz采样播放，按指定GLB的0.0085转换比例、包装1.7及源skinScale=0.6，使用0.02408333原生单位换算。未声称与LoL引擎逐像素一致。

部署Spawn约1.667秒，按20Hz部署1.7秒；Spit约0.933秒由周期召唤产生的现有表现动作快照触发，动画不驱动召唤。Death保持原1秒关键帧，末姿态延续至2.2秒供死亡粒子结束，不放慢动作。部署粒子独立保留7.2秒；吐兽粒子最长采样2.6秒，吐兽事件退出后停止发射并按源linger清理；待机使用64秒采样，跨Idle/Spit连续运行，不在出兵或返回待机时重建。死亡关闭存活阶段粒子。虚空兽使用已有VoidSpawn_Spawn_anm出生动作；原1.1333秒片段映射到现有1秒部署窗口，不改权威部署和碰撞。第18帧触发原版SpawnSplat，第23帧触发已确认出生声，Thorax附着原版Trail。

卡面使用用户选定的3D摄影棚截图“兹若特传送门_20261012_212027.png”，308×560，原图直接接入。主动图标为Riot Data Dragon 9.22.1的3512兹若特传送门装备图标。来源与哈希分别位于assets/units/void_gate/source_manifest.json、assets/effects/void_gate各变体source_manifest.json及assets/skills/source_manifest.json。

本地装备引用链已核实：Global.wad.client的`items`总表包含`Items/773512`，技能为`ItemVoidGate_Jade`；Scripts.wad.client的该技能预加载声明直接引用`jade_voidgate`及`itemvoidgategate_jade`，后者引用`jade_voidspawn`。因此按装备实际引用使用Jade资源，不以Ruby名称或文件日期推断。增量更新可保留未变化文件的时间，版本判断不依赖旧归档说明。

原动画图的Spit位于独立优先级叠加轨道。包装保留原始增量动画，在连续Idle姿态上叠加位置、旋转和缩放；AnimationPlayer内部混合使用转换后的绝对姿态，避免出兵结束回到Idle时晶体塌陷。门户和出兵球仍采用原始独立粒子曲线：当前项目按表现需求保留整套待机粒子跨出兵持续运行（原版外部跨轨道调用仍未取得），BirthSpit约0.19秒膨胀到最大，约0.6秒淡出，不作为6秒孵化进度。

召唤来源位置通过可靠生成及出生描述同步。仅模型声明summon_birth_offset时，表现代理按门心至合法出生点的方向播放，出生身体的水平起点对齐门心，沿原始骨骼跃出曲线过渡至合法落点。保留原动画地下起始高度，不额外抬高；权威碰撞、寻路和落点不随表现移动。主动摧毁的两只虚空兽也保留死亡前门心，各自向外出生。

待机、出生与死亡时钟互相独立；冻结停止动画进度，死亡停止出生效果，模型回池清理出生状态。Trail在原出生动画末尾停止发射，保留0.4秒自然尾迹。当前选用常规Spawn片段，未接入原选择器10%的Spawn2变体。

中心球是独立球形网格粒子，不属于主体水晶的皮肤网格。部署球采用sphere_01，约0.44秒迅速膨胀、随后回缩，末段淡出并与待机衔接；待机采用Jade_VoidGate_sphere，尺寸恒定，另有独立光晕。出兵叠加球约0.19秒达到待机直径的2.2倍，回缩中有轻微回弹，约0.6秒淡出，当前项目保留持续发射的待机球和光晕；吐兽球与其光晕采用更高绘制优先级，覆盖在整套待机之上，回缩淡出后自然露出待机球。死亡关闭生前粒子，球快速压扁、纵向拉伸并向上冲，约0.4～0.5秒收束消失。时间为原生粒子年龄，实际显示含采样步长；不将粒子寿命当作可见球体持续时间。

Spawn、Spit、Death活动阶段直接使用AnimationPlayer当前年龄；新阶段不会再额外累计首帧delta。切换动作后尚未结束的粒子尾迹独立推进，冻结零步进保持。这样晚到首帧、低帧率及动画校时不会使球体提前越过膨胀峰值或抢先于骨骼播放死亡变形。

原始组织核对（2026-10-12）：原生类型元数据的 `ParticleEventData.mIsKillEvent` 缺省为 true，Idle/Spit 未覆写；Spawn/Death 显式为 false。社区逆向资料说明：事件所属片段停止时，停止发射并进入发射器各自的linger规则。项目将持续待机粒子与单 AnimationPlayer 的片段切换解耦；Idle/Spit切换不结束待机事件，吐兽退出仍执行其自身退出规则。原动画图是多轨道，客户端包内未取得装备外部控制模块的完整实现；不能声称已经证明LoL实际调用了哪一个跨轨道停止函数。

待机原始退出参数（吐兽不触发退出）：八个发射器均为 emitterLinger=0、particleLingerType=0。停止后禁止新粒子进入；Split_void1 / Split_void2 的 particleLinger=0，立即清理；void1 / VoidBallglow 上限1秒、BallLightning上限0.5秒，均从粒子出生计时，而不是停止后再延长；其余地面层按原寿命自然结束。缩短寿命后重新计算源颜色/缩放曲线的年龄比例。出生时间和随机寿命从120Hz原采样的serial存活区间恢复，精度受采样步长限制。待机事件在吐兽期间保持连续，冻结停止年龄推进，死亡及回池清理常驻效果。源参数仍保留，不等于已取得LoL完整运行时调度代码。

已补齐可直接由源定义确定的材质：待机球 `void1` 使用源 RGB=(0.6363775, 0.007843138, 1)、Fresnel 指数 0.15 的视角边缘色；颜色 alpha=0 不关闭此项，也不修改球体透明度。法线由原 SCB 索引拓扑生成，保留原顶点/UV/颜色。未指定反射贴图，因此不添加环境反射。四套特效共同按原 pass、复杂/简单类型、混合类型及标志映射渲染优先级。基础排序同键保持同优先级，文件内发射器索引不参与跨系统优先级；项目额外将吐兽两层优先级提高32，确保其晚于全部待机层绘制。死亡 Distort 使用源 mode=1、strength=0.05、distort-pinch 法线纹理及 ramp，接入屏幕取样扭曲，位于负 pass 与非负 pass 之间。Godot 的屏幕纹理取样并不保证包含所有此前透明层，未宣称与 LoL 帧缓冲逐像素等价。

本次项目叠加行为是用户明确指定的表现方案，不作为原版完整调度的证明。

同心球遮挡接入：源出兵球在膨胀前段 alpha=1，但 Godot 透明网格按中心排序不能区分两个同心球；网格又由 shader 位移，CPU 包围盒不代表实际球面。因此在同一原始优先级内，以当前粒子的中心和球形网格经缩放/旋转后的视线方向前表面计算 sorting_offset。使用正偏移向相机方向排序，外球后绘制覆盖内球；不是新增原版 pass；Idle是否继续存在由独立事件生命周期决定。此外，吐兽球及光晕整体晚于待机绘制，避免待机的加法光晕再次叠到吐兽球表面。出兵球淡出时仍按原透明度曲线混合。该规则是 Godot 接入适配，未声称已经证明 LoL 内部使用相同算法。

地面阵营标识采用通用最低透明绘制优先级（-128），门户各层在其上绘制；保留正常深度测试，地形和不透明模型仍能遮挡标识。蓝红共用这一规则。
