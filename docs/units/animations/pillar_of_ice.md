# 凛冬之柱模型与动画

[返回单位](../pillar_of_ice.md) · [总索引](../README.md)

可见主体是巨魔基础皮肤E的`Trundle_E_Pillar_base.scb`原生冰柱粒子网格。TrundleWall旧PlagueBlock骨骼皮肤在源配置中`skinScale=0`，其图只列Idle1/Death（Attack1/Run复用Idle1），未配置独立升起骨骼片段；不把旧隐藏模型叠加到当前E网格上。

原网格约189×345×193源单位，XYZ统一缩放0.009，保留原生90度旋转。相对上一版0.01整体缩小10%，没有单独拉高Y轴。包装顶端锚点3.06世界单位，随模型同步校准血条；稍大体型半径21、3×3占地不变；基础光环改为110。

| 阶段 | 原版来源与接入 |
| --- | --- |
| 升起 Rise | E主体粒子从地下升起，约0.36秒到稳定高度；1秒部署余下时间保持站立 |
| 待机 Idle | 原版柱体在稳定期没有骨骼摆动；保持源0.36秒姿态，持续烟雾等粒子独立连续发射，延长寿命不会重新升起 |
| 死亡 Death | 从源9秒生命周期的62.5%位置（5.625秒）开始原速下沉，取消初版从5.5秒开始带来的停顿；0.8秒窗口内整个网格已沉入地面，随后清理 |

Rise/Idle/Death现在含有真实粒子源时间采样轨道，模型预览可逐段播放和拖动；不是把旧ANM文件改名，也不再只有空的Idle/Death计时窗口。实战部署/死亡适配器读取相同原生时间段，模型不驱动伤害、衰血或主动计时。死亡立即隐藏范围圈，其他粒子在0.8秒内淡出。冻结/凝滞停止生前推进，暂停由场景处理；对象池复用重置姿态和淡出。
