# 荆棘喷射者 · 动画

[← 总览](../thorn_spitter.md)

采用指定“荆棘之兴 (1).glb”，源件移入开发素材库`03-制作中/荆棘喷射者/`。网格源范围约111×256×112，包装统一XYZ缩放0.016。单网格，未隐藏原生部件。双方复用模型，阵营由场上通用信息区分。

出生Up（0.967741秒），待机Idle1（1.666666秒），普攻Attack1（0.967741秒），死亡Death（8.333331秒）按项目普通死亡上限压缩至0.8秒。Buffbones按源动画图独立辅助轨处理：只初始化名称包含Buffbone的挂点姿态，不覆盖Vine/Bloom骨骼动画。

原动画图Attack1.mTickDuration=0.032258秒（约31fps），原ZyraQPlantMissile.castFrame=2且useAnimatorFramerate=true。源节点约0.064516秒，除以GLB片长0.967741秒再乘本项目周期1.25，映射约0.083333秒。按项目0.01秒数据精度配置first_hit=0.08，20Hz在约0.10秒出弹；不再直接取spellCastTime=0.25。该映射来自资源定义，不声称已经与LoL客户端逐帧录屏等价。强化仍为单发，只将伤害提高至150%。

源皮肤skinScale=1.2；指定GLB模型包装仍0.016，独立VFX采用0.016/1.2以保留模型和效果的源比例。弹体起点使用模型现有Buffbone_Glb_Weapon_1（花头），强化粒子使用C_Buffbone_Glb_Center_Loc。原MissileSpecification未覆盖起始骨骼，mOffsetInitialTargetHeight=100是目标高度参数，不能当成出生高度。这里明确选择上述现有挂点作为本项目接入，不声称从缺失的服务端脚本确认了原版默认挂点。

权威弹体仍从2D战斗中心发出；模型骨骼和效果不参与伤害、碰撞或联网判定。双方、对空、强化建立/到期与死亡须以当前渲染验收记录为准。
