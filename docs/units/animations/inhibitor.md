# 高地水晶动画

[返回高地水晶](../inhibitor.md) · [总索引](../README.md)

采用需求指定的 inhibitor_(3).glb（蓝）与 inhibitor_(4).glb（红）。原生模型最大水平跨度约3.882，统一缩放0.76，约118像素（3×3格为120像素）；地底碎片不作为主体尺寸依据。

待机使用 Idle_Normal1；死亡使用 Death_Base，源片长8.333秒，仅取前5秒，以5倍速压缩至1秒。原生完整材质与 Destroyed 碎片材质互斥：存活隐藏碎片，死亡隐藏完整晶体。部署使用原生开场 `SRUAP_ChaosInhibitor_spawn_anm`（Godot导入名；源名末尾为`.anm`，1.1667秒），按1秒窗口缩放播放，随后进入待机；源 `Respawn_Base` 为10秒复活过程，本卡采用开场片段。模型朝向偏移PI，双方均面向敌方。

模型不决定出兵时间、占地、碰撞或死亡结算。已在实际战场目视检查蓝红模型、首波小兵、主动超级兵和死亡碎片。血条使用晶体顶端锚点，摄影/模型展台取景采用地上主体包围盒，沿现有基地水晶的射线投影开口显示部分原生地下晶柱与井壁，开口半径0.82世界单位；模型以同一开口约束地下片元，避免穿出石框。开口按各渲染世界独立管理，模型隐藏/回收/销毁后恢复地面。

原始指定GLB已从待开发队列迁移至 `ClashLegends-开发素材库/03-制作中/高地水晶/models/`；正式运行依赖位于 `assets/units/inhibitor/`。

工作台暂停与拖动时间轴时以已分配动画维持完整模型/死亡碎片的可见性，暂停不切回完整晶体；继续从当前位置推进。
