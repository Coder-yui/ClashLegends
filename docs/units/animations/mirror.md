# 镜像法术模型与动画

[返回镜像法术](../mirror.md)

镜像不生成独立法术模型。复制单位、建筑和编队沿用原卡已接入的双方模型、部署与战斗动画；复制法术沿用原法术表现。动画不参与复制目标、费用、技能资格或碰撞判定。

开局准备双方卡组及形态、召唤物、技能资源的完整闭包；卡组含镜像时扩大模型预建库存以覆盖额外并发来源。局内卡面玻璃覆盖层仅负责显示。

成功释放镜像时，释放位置出现缩小的银蓝色地面镜面、双框与镜面斜光，约0.5秒后光片淡出。复制单位、编队、建筑及法术均触发一次；镜面固定在释放位置，不跟随单位。主机通过可靠卡牌表现事件向双方派发，客户端不自行推断复制。

镜面按施放队伍着色：蓝方冰蓝，红方淡红紫；镜框、玻璃与光片使用同一阵营配色，尺寸和持续时间一致。
