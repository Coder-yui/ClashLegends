# 法外狂徒：模型动画

[返回单位](../graves.md) · [返回总索引](../README.md)

采用用户指定的法外狂徒GLB，网格与贴图保持源件；站立高度约1.531模型单位，XYZ等比缩放1.8后约2.755场景单位。原皮Skin0未声明默认隐藏子网格，不额外隐藏部件。实际战场与腕豪同镜头比较，作为稍大体型接入，身体权威半径独立保持21。

待机Idle1、移动Run、攻击graves_attack1_anm、静止换弹graves_reload_anm、后撤Spell3、死亡Death（压缩至0.8秒）。只选择一套普通攻击，未接暴击动作。攻击片长1.5秒，按0.9秒间隔缩放；原始普通攻击spell节点第7帧/30Hz为0.2333秒，对应0.14秒，固定Tick发射落在0.15秒，量化误差+0.01秒。

原皮动画图的Upper蒙版用于移动换弹：89根骨骼名称与顺序核对后，将Run下身与Reload上身按原权重烘焙为2秒、30Hz的ReloadMove；不靠换弹动作驱动补弹。静止和移动换弹均按权威剩余时间定位，控制暂停、取消换弹和主动后撤均从当前事实切换。

弹丸权威出生在单位2D中心，视觉出生在buffbone_cstm_weapona枪口骨骼；六条路径从该挂点向释放时固定方向展开，创建时读取目标身体高度以对齐地面/空军，此后不随目标转弯。模型或挂点调整不改变命中。创建瞬间、连续攻击、移动换弹和双方后撤截图保留在本次交付记录所列素材目录。

烘焙入口：`godot --headless --path . --script res://tools/assets/bake_graves_reload.gd -- <reload_source.json绝对路径> <audit.json绝对路径>`。输入与原蒙版存于素材库`05-已完成/法外狂徒/源件与过程记录/`。
