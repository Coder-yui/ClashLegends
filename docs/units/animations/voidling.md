# 虚灵模型与动画

[返回虚灵](../voidling.md)

使用指定“虚空先知 (1).glb”，源网格约83×68×123单位，缩放0.0115，无默认隐藏部件。Idle1用于待机，Run用于移动，Attack1/2/3轮换，Death用于0.8秒死亡表现。

原版三段均castFrame=22，60fps、片长约1秒，映射0.9秒周期为0.33秒前摇。卡面通过工作台共用ModelPreview摄影入口拍摄：Attack1、0.25秒、偏航25度、背景#252438、柔光、308×560；不是绘制或生成图片。

与雾行者、近战/远程虚空鱼、虚空蠕虫同为小体型，权威半径均为12。本轮只将虚灵模型线性放大约64%，在同镜头蓝红双方并排校准主体观感；飞鱼尾部/翅膀较长不代表另一个体型档位。

W召唤时，包装在实际骨骼网格上叠加原版Avatar1出生材质，2秒内按原颜色和侵蚀曲线消退；单独放置不误播W。模型回收时清零材质时钟，避免下一只继承上次出生进度。
