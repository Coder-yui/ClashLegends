# 火药桶 · 动画

[返回火药桶](../powder_keg.md) · [总索引](../README.md)

| 状态 | 原片段 / 接入 |
| --- | --- |
| 出生 | Spawn，1秒 |
| 待机 | Idle1，单姿态循环 |
| 受击 | Timer，原版0.4秒衰减叠加动作烘焙到Idle1；只表现真实受击 |
| 死亡 | Death，原片长3秒，以3.75倍速度在0.8秒内播放 |

使用用户指定的“海洋之灾 (1).glb”，实际内容为桶模型。原始网格边界约108.07×127.91×100.82，包装统一缩放0.0175，脚底上移0.0653。单网格桶及桶盖，无额外英雄网格，不隐藏部件。双方共用模型并显示阵营圈。

受击走通用可靠Hit事件及0.18秒节流；同一动作未结束不重复重启，部署/死亡/凝滞等优先。自然生命衰减不播放受击动作。实际渲染对照木桩，保持桶体较矮、略宽的轮廓；动画不驱动爆炸结算。

原版动画图将Timer放在独立轨道，mBlendMode=1。用户GLB的Timer保留了相对位移/旋转，不能直接作为绝对姿态播放；正式GLB已将其叠加到Idle1（位移相加、旋转相乘、缩放相乘），避免Lid从约98.86高度被拉到0而看似消失。保留所有原始采样与0.4秒节奏，其余动画和网格不变。原始GLB保留在制作目录source_model；可重复烘焙脚本位于同目录animation-fix/bake_timer.py。
