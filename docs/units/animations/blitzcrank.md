# 蒸汽机器人动画

[返回蒸汽机器人](../blitzcrank.md)

使用用户指定的蒸汽机器人GLB。待机Idle1、移动Run、普攻Attack1/Attack2、飞爪Spell1、强化攻击Spell3、死亡Death。死亡源片长1.666666秒，播放压缩为0.8秒。包装统一缩放1.25，脚底上移0.005世界单位；与艾希同场完成中体型尺寸和双方朝向检查。

原版Blitzcrank.bin的BasicAttack、BasicAttack2、PowerFistAttack均为castFrame=12.96；导入三片长度均为0.870967388秒。普攻ANM v3头部核对为28帧、31帧/秒；Spell3绑定基础皮肤动画表引用的skin06/blitzcrank_i_spell3.anm，v4头为28帧、帧步长1/31秒；按节点12.96/31秒映射至1.6秒窗口得到0.768秒，统一前摇0.77秒，20Hz实际跨节点结算。不能将此配置当成动画事件驱动伤害。

Q瞄准1秒时保持站立、持续朝向目标；正式出钩才播放Spell1，动作窗口0.65秒，对应0.3秒飞行、0.3秒拉回及一次提交边界。瞄准可被硬控取消，出钩后的轨迹与粒子由独立弹体推进，不随来源冻结或死亡消失。跨塔等场景落点前延时，独立飞爪按实际路程继续回程，单位等待拉取完成；不拉伸原始Q骨骼片段。普攻节奏沿用通用施法锁，拉回结束无额外刷新。
