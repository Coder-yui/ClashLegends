# 战争之影动画

[返回战争之影](../hecarim.md) · [总索引](../README.md)

| 动作 | 源片段与适配 |
| --- | --- |
| 待机 | Hecarim_idle1.anm |
| 普通移动 | Run；动作速度读取实际表现移速 |
| 冲刺移动 | Spell3run；连续3格蓄势后切换，读取同步冲刺状态 |
| 旋斩 | Hecarim_Spell1.anm，源长0.96774149秒，适配1.2秒攻击周期 |
| 突进 | Spell3，源长1.066667秒；开始后沿权威接近过程播放，命中后保留动作尾段，打断立即停止 |
| W施放 | Hecarim_Spell2.anm，源长1.566667秒；低优先级事件动作，不锁移动或普攻 |
| 死亡 | Death，源长3.866664秒，压缩为0.8秒 |

Godot导入将动画名中的点替换为下划线，运行映射使用Hecarim_idle1_anm、Hecarim_Spell1_anm与Hecarim_Spell2_anm。

原Q定义的castFrame为3.04；以30fps换算0.101333秒，相对0.96774149秒源片长映射到1.2秒周期得到0.125655秒，20Hz向上对齐为0.15秒，误差约24.3毫秒。它是本项目普通攻击的适配节点，不声称恢复LoL服务端Q瞬时结算。

用户提供的GLB使用源单位，网格静态边界约162×285×212；包装统一XYZ缩放0.011。未拉伸压平，实际战场与稍大体型德莱厄斯并排核对。原皮肤没有默认隐藏子网格声明。原生常驻头尾粒子、UVtail运行逻辑不在提供GLB中，本次没有重建这些常驻附属效果。

素材来自开发素材库的战争之影.glb；原片段、纹理与皮肤定义来自本机只读Hecarim.wad.client。双方使用同一模型与阵营底圈。
