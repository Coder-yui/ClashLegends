# 草间人（建筑卡）：模型动画

[返回单位](../scarecrow.md) · [返回总索引](../README.md)

使用费德提克原皮SKN/SKL及原生动作。原始主体约221单位高，统一XYZ缩放0.012；完整保留Body、Weapon、Lantern、Tongue、L_Demon_Arm与R_Demon_Arm，按原版动画事件控制可选部件。待机idle1、移动run、每轮攻击以spell2起手（约0.27秒），接spell2_channel引导，进入停顿即退出攻击表现；直接持续结算无离弦节点。建筑部署以respawn完整缩放到2秒，两种形态死亡均使用death_effigies原速约1.93秒。

吸血连线为本项目制作的W式红色流动曲线，从Chest骨骼连到权威同步目标，仅作表现。尚非原版W粒子逐层复现；没有添加末跳动作或末跳伤害。实际渲染验收结果见交付记录。

原版 `skin0.bin` 动画图按30帧/秒控制部件；`initialSubmeshToHide` 只是初始状态，不能据此删除网格。

| 动作 | 可选部件显示窗口（源动画帧） |
| --- | --- |
| idle1 | Lantern、R_Demon_Arm全程；Tongue从64帧显示，91帧隐藏 |
| run、spell2、spell2_channel | 四个可选部件均隐藏 |
| respawn | 右黑手从91帧显示，灯笼从99帧显示 |
| spell2_channel_toidle | 右黑手从25帧显示，灯笼从58帧显示 |
| idlein1 | 右黑手从29帧显示，灯笼从61帧显示 |
| spell2_to_run、death_effigies | 四个可选部件均隐藏 |

包装脚本在 `prepare_visual_animations()` 中拆分可选网格，保留原骨骼绑定。开始播放新动作时立即应用该动作的部件状态，随后按当前播放位置更新帧窗。骨骼姿势独立混合，回池清理临时部件；死亡播放加速时显隐同步加速。Body与Weapon常驻。

## W动作与退出路径

源片段全部在素材库核对，时长按源动作记录。

| 源动作 | 时长 | 当前接入 |
| --- | --- | --- |
| spell2 | 0.267秒 | 每轮开攻起手 |
| spell2_channel | 2秒 | 起手后进入引导 |
| spell2_channel_toidle | 2.6秒 | 引导结束后收势到待机，可被下一轮攻击打断 |
| spell2_to_run | 1.667秒 | 引导转移动，结束后接run，可被重新进圈的攻击打断 |
| spell2_hit | 0.233秒 | 原版末段命中动作，保留素材库供核对 |
| spell2_hit_toidle | 3.2秒 | 原版末段命中后转待机，保留素材库 |
| spell2_hit_to_run | 1.633秒 | 原版末段命中后转移动，保留素材库 |

当前持续伤害按既有2秒窗口结算，起手期间也属于此窗口。退出从channel直接接原版的Channel_ToIdle或ToRun。原版动画图中，起手到引导以及引导到ToRun采用零混合，专门过渡动作结束后接待机/跑步也采用零混合。临时从收势或ToRun重新开攻采用0.08秒混合，收势途中改移动采用0.1秒混合，以承接被打断的实际姿势。

移动到待机补接idlein1，去掉run_in后待机直接以0.14秒混合进入run，移动/待机开攻以0.1秒混合进入spell2。建筑草间人始终保持阵营初始朝向，移动形态攻击及其原地收势保持本轮开攻朝向，实际移动时转向移动方向。部件显隐由目标动作自身帧窗决定，独立于姿势混合。
