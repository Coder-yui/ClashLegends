# 剑圣 · 动画接入

[← 返回剑圣总览](../masteryi.md) · [总索引](../README.md)

## 目前怎样呈现

两种普通刀法之后接被动双刀动作，作为一个三招循环。高原血统期间跑步换成加速跑；双刀里第二次伤害由战斗计时决定，不能因片段重复播放而多扣一次血。

## 已使用的动作

动画名保留素材原名，方便在工作台选中查看；不需要阅读代码。

| 看到的动作 | 对应素材 | 使用方式 |
| --- | --- | --- |
| 部署 | Respawn | 按游戏中的对应状态播放 |
| 待机 | masteryi_2013_idle1_anm | 状态持续时循环 |
| 持续移动 | Run | 状态持续时循环 |
| 普通攻击 | masteryi_2013_attack1_anm → masteryi_2013_attack2_anm → masteryi_2013_passive_anm | 按攻击顺序播放，跟随实际攻击速度 |
| 加速跑 | 2013_Run_Haste | 按游戏中的对应状态播放 |
| 死亡 | Death | 播放 0.8 秒 |

## 怎么观看与检查

进入“卡牌开发工作台”，选中该单位。先在模型预览中查看上表动作，再到实战页连续观察部署、攻击、技能和结束衔接。蓝红版本在同一篇记录，观看时分别切换阵营。

重点看：脚底是否贴地、朝向是否正确、动作有无突然跳姿，以及攻击后能否自然回到跑步或待机。命中时间以总览中的战斗数值为准，不能用原片总长度代替。
