# H-28G进化炮台 · 动画

[← 总览](../evolution_turret.md)

使用用户指定的“大发明家 (1).glb”，源件已移到开发素材库03-制作中/H-28G进化炮台。正式包装等比缩放0.022，不压平模型。

部署Spawn；待机Idle1；收缩Deactivate后循环Deactivate_Idle；展开Activate以0.2秒表现并交还攻击；普攻交替Attack1/Attack2；Death原片约1秒，播放压缩至0.8秒。

实际工作台追踪确认收缩路由直接从Deactivate进入Deactivate_Idle，没有经过Idle1；收缩原片约1秒，末段自带抬升再落下的回弹，切换使用通用0.04秒混合。当前帧检查未复现额外切换闪动，仍需与用户所见场景对齐，不把原片回弹直接认定为缺陷。

两套普攻原片均1.666667秒，原始HeimerTYellow两个SpellData均castFrame=12.775，按30fps得到0.425833秒。缩放到0.8秒攻击周期为0.2044秒，采用0.21秒前摇；20Hz结算向上对齐，不以动画驱动发射。

普攻现在使用自制黄色彗星，发射时读取Rocket炮口位置；不再接入原版第8帧炮口粒子，也不再使用缺失weapon的高度适配。动画仍按上述前摇匹配既定权威发射时刻，表现不驱动伤害。
