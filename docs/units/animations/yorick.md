# 牧魂人动画

[返回牧魂人](../yorick.md) · [总索引](../README.md)

使用需求指定的“牧魂人 (1).glb”，源坐标为米级，包装统一缩放1.25，与稍大档德莱厄斯同镜头比较校准；披风、武器与挂点随模型同比缩放。待机Idle1；部署使用IdleIn的前1秒（源片6秒，包装复制动画库并裁剪，原GLB不修改），移动Run_Base，普攻依次Attack1、Attack2、Attack3，强化攻击Spell1，死亡Death。三段攻击及Q源片均约1.833333秒；死亡源片5.666667秒，按公共death_duration上限压缩为0.8秒。

原版YorickBasicAttack2与QAttack的castFrame为10，30fps对应0.333333秒；Q另有spellCastTime 0.33335，基础AttackSlot的mAttackCastTime为0.33。按导入片长映射到1.5秒周期，节点约0.272727秒，配置0.27秒，20Hz结算约0.30秒。Attack1/3共用基础攻击节点，导入动画图未提供独立伤害事件；这里是统一近似而非声称每片都有独立事件。攻击和回血均由权威模拟结算。

原版隐藏Yorick_Cape实体材质并通过AttachedMesh重新绘制该蒙皮。包装只替换该表面为两层原版流动材质，保留骨骼动画和内部偏移。路径修饰器按原版三组骨链、120°上限及逐骨遮罩重建；跑步沿历史移动路径弯曲，进入待机/攻击/部署/死亡后混回作者姿态。详见特效页。

部署片段以1倍速播放，1秒后即使模拟暂停也保持裁剪末帧，不继续播放原片后5秒。IdleIn接Run_Base或Idle1混合0.18秒，接Attack1/2/3或Spell1混合0.12秒；采用已有clip_blends，不改公共状态机或权威部署时间。

牧魂人的动作切换统一使用专用Weapon模型空间旋转混合，身体沿用公共混合，武器位置跟随混合后的手部骨链。开始时选择当前姿态到目标原片的短弧，随后保持目标四元数方向连续，避免攻击跨过180°时反向跳变；混合结束完全交回原片。支持部署、跑步、待机、普攻、Q及死亡；首次出现和模型复用清除缓存姿态，切换中断从已显示姿态重新衔接。只改牧魂人表现，不改原片、混合时长、权威时钟或其他卡牌。
