# 浪潮法术表现时序

[返回浪潮法术](../tidal_wave.md) · [返回总索引](../README.md)

本卡没有角色骨骼动画。20Hz权威时钟控制1.4秒推进，可靠法术飞行事件携带起终点与起止Tick；客户端按表现时钟插值。抵达后按原版各层停止发射、粒子linger及颜色曲线结束，最后粒子在生成后约3.42秒消失；表现容器于3.45秒清理，不延长命中窗口。清场释放表现节点。

两阵营沿相反方向前进；娜美R粒子沿局部+Y布置推进、+Z布置浪峰，包装层作绕X轴-90度刚性旋转后再按目标方向旋转，整体等比缩放，无相机压平或拉伸。主体可见宽度约600原生单位，对应项目160像素，软水雾可以超出伤害边界。卡面与信息页展示来自统一四域定义。
