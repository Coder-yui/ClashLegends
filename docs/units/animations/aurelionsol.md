# 龙王 · 动画接入

[← 返回龙王总览](../aurelionsol.md) · [总索引](../README.md)

## 目前怎样呈现

吐息分为开始、持续和退出三部分；换目标时有重新起手的动作。跑动不是一段反复循环，而是四段顺序轮播。部署仅使用原片前半段。普通星落和满层天瀑各用一段动作，约 1.93 秒和 1.90 秒。

## 已使用的动作

动画名保留素材原名，方便在工作台选中查看；不需要阅读代码。

| 看到的动作 | 对应素材 | 使用方式 |
| --- | --- | --- |
| 部署 | Respawn | 按游戏中的对应状态播放 |
| 待机 | Idle1_Base | 状态持续时循环 |
| 开始移动 | RunIn | 按游戏中的对应状态播放 |
| 持续移动 | Run1B | 状态持续时循环 |
| 移动循环 | Run1B → Run1C → Run1D → Run1A | 按游戏中的对应状态播放 |
| 吐息起手 | AurelionSol_Spell1_newtst_anm | 按游戏中的对应状态播放 |
| 持续吐息 | AurelionSol_Spell1_loop_anm | 状态持续时循环 |
| 吐息换目标 | AurelionSol_Spell1_new_looptoin_anm → AurelionSol_Spell1_newtst_anm | 按游戏中的对应状态播放 |
| 死亡 | Death | 播放 0.8 秒 |

## 技能与变形动作

### 星落/天瀑

动作顺序：Spell4。

游戏内播放时长：1.933 秒。

动作衔接：进入混合 0.25 秒。这里的混合只让姿态过渡平滑，不改变命中时间。

### 满层 / 强化版：星落/天瀑

动作顺序：AurelionSol_Spell4_base_anm。

游戏内播放时长：1.9 秒。

动作衔接：进入混合 0.25 秒。这里的混合只让姿态过渡平滑，不改变命中时间。

## 怎么观看与检查

进入“卡牌开发工作台”，选中该单位。先在模型预览中查看上表动作，再到实战页连续观察部署、攻击、技能和结束衔接。蓝红版本在同一篇记录，观看时分别切换阵营。

重点看：脚底是否贴地、朝向是否正确、动作有无突然跳姿，以及攻击后能否自然回到跑步或待机。命中时间以总览中的战斗数值为准，不能用原片总长度代替。
