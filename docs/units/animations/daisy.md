# 小菊模型与动画

[返回单位](../daisy.md) · [单位索引](../README.md)

源模型为用户指定翠神 (1).glb，统一缩放0.012。待机IvernMinion_idle、移动Run、出生IvernMinion_spawn、死亡Death（最长0.8秒）。

Attack1/2片长2.033333秒，Attack3片长2.166666秒。源各攻击castFrame均18，30Hz节点0.6秒；缩放至1.4秒攻击周期分别0.413115、0.413115、0.387692秒。统一前摇0.4秒，误差-13.12、-13.12、+12.31毫秒，20Hz第8Tick结算。攻击序号按权威循环同步，前摇被取消不会使第三击动作提前。
