# 藤蔓鞭击者 · 动画

[← 总览](../vine_lasher.md)

来源为用户指定的`荆棘之兴 (3).glb`，已迁入素材库制作中/藤蔓鞭击者；SHA-256见运行模型来源清单。原坐标边界约100.68×311.09×94.16，统一缩放0.016；以同为稍大体型的荆棘喷射者为参照，保持模型原比例。源皮肤skinScale=1.2；特效原生比例除以该值，随模型一起增大。

| 动作 | 原片段 | 导入片长 / 项目处理 |
| --- | --- | --- |
| 部署 | Up | 1秒 |
| 待机 | Idle1 | 1秒循环 |
| 攻击 | Attack1 / Attack2 | 各1秒，按1.25秒周期交替播放 |
| 死亡 | Death | 8.333秒，按通用上限压缩至0.8秒 |

源ZyraEPlantAttack以spellCastTime=0.25秒作为节点参考；Attack2有castFrame=7.5且useAnimatorFramerate=true，动画图tickDuration=0.032258，节点约0.241935秒。按导入1秒和攻击周期1.25映射为0.3125/0.302419秒，统一前摇0.31秒，误差分别-0.0025/+0.007581秒，20Hz约0.35秒结算。Attack1没有显式castFrame，不能声称其服务端默认节点已验证。强化按1.6倍攻速缩短周期和前摇，动画只读权威进度，不决定伤害。

源皮肤defaultAnimations虽列Buffbones，但基础动画图没有该片段、基础资源包与指定GLB也均未提供（仅其他皮肤存在），因此不套用荆棘喷射者的辅助骨恢复。强化粒子直接挂在C_Buffbone_Glb_Center_Loc下，保持世界朝向并继承模型尺度。没有源服务端脚本可证实挂点默认值，因此该骨骼选择是项目适配。
