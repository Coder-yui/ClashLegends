# 太阳圆盘 · 动画接入

[← 返回太阳圆盘总览](../sun_disc.md) · [总索引](../README.md)

## 目前怎样呈现

蓝红模型各自使用相同动作规则。两种攻击交替，但只驱动圆盘相关部分，避免基座也跟着变形。待机以固定顺序穿插第二种动作；死亡取原片前 2 秒并适配为 0.8 秒。塔墟版应隐藏自带废墟。

## 已使用的动作

动画名保留素材原名，方便在工作台选中查看；不需要阅读代码。

| 看到的动作 | 对应素材 | 使用方式 |
| --- | --- | --- |
| 部署 | Spawn | 按游戏中的对应状态播放 |
| 待机 | Idle1_Base | 状态持续时循环 |
| 待机轮播 | Idle1_Base → Idle1_Base → Idle1_Base → Idle1_Base → Idle2_Base → Idle1_Base → Idle1_Base → Idle2_Base → Idle1_Base | 按游戏中的对应状态播放 |
| 普通攻击 | Attack1_BASE → Attack2_BASE | 按攻击顺序播放，跟随实际攻击速度 |
| 死亡 | Death | 播放 0.8 秒 |

## 怎么观看与检查

进入“卡牌开发工作台”，选中该单位。先在模型预览中查看上表动作，再到实战页连续观察部署、攻击、技能和结束衔接。蓝红版本在同一篇记录，观看时分别切换阵营。

重点看：脚底是否贴地、朝向是否正确、动作有无突然跳姿，以及攻击后能否自然回到跑步或待机。命中时间以总览中的战斗数值为准，不能用原片总长度代替。
