# 未来守护者动画

[远程](../jayce.md) · [战锤](../jayce_hammer.md) · [总索引](../README.md)

源件为用户指定的未来守护者.glb，原网格坐标约X -86～87、Y -40～220、Z -160～140，包装统一缩放0.0095。源GLB单网格单材质，不另删武器网格。远程待机/跑步使用 ranged idle / Ranged_Run，普攻交替 Ranged_Attack1/2；近战使用 melee idle / Run，普攻交替 Attack1/2。换形使用原版独立Passive武器层，按当前形态立即应用武器姿态；Default层继续播放Idle/Run，移动步态相位不重置。死亡原片3.967秒，按0.8秒上限压缩。

本地Jayce.wad.client的jayce.bin记录远程两次普攻castFrame 3.6、近战9，原始ANM采样30Hz，两组GLB片段均1.5秒。初版按1.2秒窗口校准得到远程0.10秒、近战0.24秒首击点（20Hz近战实际跨界0.25秒）。本轮攻击间隔分别调整为1.4秒和1.1秒，权威首击点仍保留0.10/0.24秒，表现按攻击时间线对齐。两段同组无额外统一误差；3倍攻速时同时缩短窗口，仍由20Hz模拟出手。

视觉弹体挂在原生BUFFBONE_CSTM_WEAPON_1骨骼；权威弹体从身体边缘发射，半径4，不读取骨骼。炮形态首击使用Ranged_Attack2，锤形态首击使用Crit；远程W使用Ranged_Spell2_Attack1/2。首击与W重叠时优先首击动作。近战W源定义引用Spell2，但当前基础动作映射指向远程W射击片段，没有独立近战施法动作，因此电场开启不借用错误的远程射击姿势。美术目视结果见任务交付记录。

原生Hammer遮罩97骨骼中32个武器/挂点权重为1，Blank遮罩全零；Passive优先级1，Default优先级2。两份Passive素材为静态姿态，不能作为全身换形动作播放。独立SkeletonModifier3D按同步形态直接设置Hammer权重，近战为1、炮形态为0；不写腿/躯干骨骼。复用模型与播放器，在Run/Ranged_Run之间保留归一化步态相位。武器源姿态、遮罩与GLB保持原值；不再进行0.3秒权重过渡。0.3秒仅保留为声光表现窗口，不锁攻击或移动。

远程W保持原连射动作。动画中残留的六个EXHAUST事件位于柄尾，且源短闪发射器禁用，现不创建这些粒子。W白色喷气仅挂锤头GAP_1/2；附着光在Skeleton3D最终姿态信号后更新。
