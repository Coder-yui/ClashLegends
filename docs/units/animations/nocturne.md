# 永恒梦魇动画

[返回永恒梦魇](../nocturne.md) · [单位索引](../README.md)

用户指定永恒梦魇.glb：Idle1用于部署/待机，Run用于移动，Attack1/2普通循环，主动强化攻击使用Attack3；Death截取前1.5秒，压缩到通用0.8秒。仅黑暗庇护的Spell2沿用低优先级事件动作入口，攻击时忽略，不补播。

原版Nocturne.bin的BasicAttack与BasicAttack2 spellCastTime为0.41305秒，UmbraBladesAttack为0.42360002秒；GLB三段攻击片长均0.96774149秒，约30帧。映射到1.4秒间隔后为0.59754/0.61281秒，统一权威前摇0.60秒，误差约3/13毫秒，小于一个20Hz Tick。动画不驱动命中。

原模型为米制，静态网格约1.439×0.635×1.518；包装均匀缩放1.8，以冰鸟同镜头展开形态和主体体量校准。沿用空军网格底部自动抬升2.3。模型只有riotRig:lambert2一组材质/网格，皮肤定义未声明须隐藏的额外子网格。

W的Spell2起手混合0.16秒，结束回移动/待机混合0.18秒，转Attack1/2/3使用0.16秒混合；不锁移动、不打断进行中的普攻。
