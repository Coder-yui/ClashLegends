## 目前怎样呈现

普通目标用两种普攻交替，建筑使用专门的砸塔动作；原模型的 Fast 版本是攻速替代素材，目前不作为第二招轮播。普通变大、主动变大、还原使用专门合成动作，必须保留缩放层。死亡先播大形态约 0.27 秒，再换小模型播 0.8 秒。

## 已使用的动作

动画名保留素材原名，方便在工作台选中查看；不需要阅读代码。

| 看到的动作 | 对应素材 | 使用方式 |
| --- | --- | --- |
| 静态预览初始姿态 | Idle1_Base | 大纳尔不能单独出牌，实战由变形进入 |
| 待机 | Idle1_Base | 状态持续时循环 |
| 开始移动 | Run_In | 按游戏中的对应状态播放 |
| 持续移动 | Run_Base | 状态持续时循环 |
| 普通攻击 | GnarBig_Attack1_anm → GnarBig_Attack2_anm | 按攻击顺序播放，跟随实际攻击速度 |
| 死亡 | GnarBig_Death_anm | 播放 0.27 秒 |
| 攻击建筑 | GnarBig_Turret_Attack01_anm | 按游戏中的对应状态播放 |

## 技能与变形动作

### 怒气爆发

动作顺序：GnarBig_Spell2_anm。

游戏内播放时长：1.2 秒。

动作衔接：进入混合 0.06 秒，退出混合 0.12 秒。这里的混合只让姿态过渡平滑，不改变命中时间。

### 普通变大

动作顺序：gnar_runtime/Rage_Transform。

游戏内播放时长：1.5 秒。

动作衔接：退出混合 0.12 秒。这里的混合只让姿态过渡平滑，不改变命中时间。

### 主动技能变大

动作顺序：gnar_runtime/Rage_Spell2_Transform。

游戏内播放时长：1.2 秒。

动作衔接：退出混合 0.12 秒。这里的混合只让姿态过渡平滑，不改变命中时间。

## 怎么观看与检查

进入“卡牌开发工作台”，选中该单位。先在模型预览中查看上表动作，再到实战页连续观察部署、攻击、技能和结束衔接。蓝红版本在同一篇记录，观看时分别切换阵营。

重点看：脚底是否贴地、朝向是否正确、动作有无突然跳姿，以及攻击后能否自然回到跑步或待机。命中时间以总览中的战斗数值为准，不能用原片总长度代替。
