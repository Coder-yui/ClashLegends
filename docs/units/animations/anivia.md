## 目前怎样呈现

凤凰模型按稍大体型校准，包装缩放为0.018216（原值的1.6倍）；权威碰撞仍为自定义半径20。空军网格底部仍由通用表现层抬到统一2.3世界单位，血条与胸部弹体挂点随模型自动更新。蛋模型保持自身小体型。

部署与待机都用同一段静止动作；两种挥翼交替作为普攻。风暴使用 Spell4，动作约 1.17 秒，落地判定在 0.72 秒。只有失去复活资格后才正常播放本体死亡；第一次死亡应转到蛋。进入死亡的已明确衔接不额外混合。

## 已使用的动作

动画名保留素材原名，方便在工作台选中查看；不需要阅读代码。

| 看到的动作 | 对应素材 | 使用方式 |
| --- | --- | --- |
| 部署 | Idle1 | 按游戏中的对应状态播放 |
| 待机 | Idle1 | 状态持续时循环 |
| 持续移动 | Run | 状态持续时循环 |
| 普通攻击 | Attack1 → Attack2 | 按攻击顺序播放，跟随实际攻击速度 |
| 死亡 | Death | 播放 2.4 秒 |

## 技能与变形动作

### 冰雪风暴

动作顺序：Spell4。

游戏内播放时长：1.167 秒。

## 怎么观看与检查

进入“卡牌开发工作台”，选中该单位。先在模型预览中查看上表动作，再到实战页连续观察部署、攻击、技能和结束衔接。蓝红版本在同一篇记录，观看时分别切换阵营。

重点看：脚底是否贴地、朝向是否正确、动作有无突然跳姿，以及攻击后能否自然回到跑步或待机。命中时间以总览中的战斗数值为准，不能用原片总长度代替。
