# 麦林炮手模型与动作

[返回麦林炮手](../tristana.md) · [总索引](../README.md)

用户提供的麦林炮手.glb，单网格、内嵌纹理。待机Idle1_Base、移动Run、普攻Attack1/Attack2交替、部署Respawn、死亡Death；死亡窗口0.8秒。Q不切换全身动作，连续普攻按增益速率播放。

## 出手节点

原始data/characters/tristana/tristana.bin的TristanaBasicAttack及TristanaBasicAttack2均为castFrame 6.4625；两段导入片长均1.833333秒。按原版30帧节点时间约0.215417秒，映射到1秒攻击窗口为0.1175秒，统一取0.12秒，近似误差+0.0025秒。20Hz跨节点Tick实际发射，量化延后不足0.05秒；这是发射点，伤害仍在弹体真实抵达时结算。源GLB优化了关键帧，不可用关键帧数量反推帧率；本次提取的原生tristana_attack1/2.anm头部偏移36、40分别为1.833333秒和30fps，已核对帧率。

## 尺寸与挂点

源网格静态范围约1.279×1.263×1.313单位，包装统一缩放1.45，脚底约0，不拉伸比例。实际战场与提莫、小纳尔同场检查，以躯干而非大炮轮廓判断稍小档体量。原生Skin0未声明默认隐藏子网格；当前单网格全部保留。

炮口使用Buffbone_Glb_Weapon_1挂点，只用于弹体绘制和Q光效；身体半径仍为15。部署默认1秒，Respawn全片1.466667秒缩放到部署窗口。控制、死亡与清场沿用通用模型代理。

## Spell1 检查

当前提供的 GLB 中 Spell1 长2秒，各动画采样器只有相同起止值，没有变化通道，是静态持炮姿势。原生 Q 配置使用 Idle1。故不将 Spell1 接入 Q 全身施法动画，避免覆盖连续普攻。
