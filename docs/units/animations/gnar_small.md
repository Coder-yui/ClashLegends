# 小纳尔 · 动画接入

[← 返回小纳尔总览](../gnar_small.md) · [总索引](../README.md)

## 目前怎样呈现

进入跑步先播放 Run1_In，再衔接 Run_Base。两种普攻按顺序交替；回到小形态时使用由主体与缩放合成的还原动作，动画约 1.333 秒，对应游戏锁定 1.33 秒。

## 已使用的动作

动画名保留素材原名，方便在工作台选中查看；不需要阅读代码。

| 看到的动作 | 对应素材 | 使用方式 |
| --- | --- | --- |
| 部署 | Respawn | 按游戏中的对应状态播放 |
| 待机 | Idle1_Base | 状态持续时循环 |
| 开始移动 | Run1_In | 按游戏中的对应状态播放 |
| 持续移动 | Run_Base | 状态持续时循环 |
| 普通攻击 | Gnar_Attack1_anm → Gnar_Attack2_anm | 按攻击顺序播放，跟随实际攻击速度 |
| 死亡 | Death | 播放 0.8 秒 |

## 技能与变形动作

### 还原为小纳尔

动作顺序：gnar_runtime/Revert_Transform。

游戏内播放时长：1.333 秒。

动作衔接：退出混合 0.12 秒。这里的混合只让姿态过渡平滑，不改变命中时间。

## 怎么观看与检查

进入“卡牌开发工作台”，选中该单位。先在模型预览中查看上表动作，再到实战页连续观察部署、攻击、技能和结束衔接。蓝红版本在同一篇记录，观看时分别切换阵营。

重点看：脚底是否贴地、朝向是否正确、动作有无突然跳姿，以及攻击后能否自然回到跑步或待机。命中时间以总览中的战斗数值为准，不能用原片总长度代替。
