# 赛恩动画

[返回赛恩](../sion.md) · [狂暴](../sion_berserk.md) · [总索引](../README.md)

使用用户提供的亡灵战神GLB，对照本地LoL `data/characters/sion/animations/skin0.bin` 与 `sion.bin`。常态持斧，狂暴模型移除Weapon网格，保留身体、骨骼和被动动作。

| 行为 | 片段与时序 |
| --- | --- |
| 部署 / 待机 / 行走 | Idle_In / Idle1_Base / Run |
| 常态攻击 | Attack_Tower2 → Attack_Tower交替 |
| 第一次致死、等待复生 | Passive_Death完整2秒，不发布最终死亡 |
| 护盾自然爆炸 | Spell2_B纯表现；攻击中跳过，新普攻可立即打断 |
| 狂暴待机 | Passive_Idle1 |
| 狂暴奔跑 | 直接使用Sion_Passive_Run_anm，不播放Run_In |
| 狂暴攻击 | Passive_Attack1、Passive_Attack2交替 |
| 第二次、最终死亡 | Death前2.5秒压缩至通用英雄0.8秒 |

原表的Passive_Run是Run_In与Run的序列；加速技能另外使用Passive_Dash，本卡按用户要求跳过Run_In，直接进入Run；不添加加速技能、Dash或加速音效。原版Passive_Death在第23帧隐藏weapon，本地包装只读动画位置执行此隐藏；第12帧世界挂点与第20帧独立落斧粒子未移植。

四种已使用普攻的原版法术表均为castFrame=11。完整原片按本卡攻击间隔等比播放，不裁剪、不切段、不分别缩放前后摇。常态动作55帧，命中点为1.8×11/55=0.36秒；狂暴动作分别54/55帧，0.6×11/54≈0.1222秒、0.6×11/55=0.12秒，按项目0.01秒数据精度均取0.12秒。20Hz权威结算落到首个到期Tick，动画不能驱动伤害；OnHit音效跟随真实结算。

包装缩放1.4，保持27的权威半径。具体来源和加工见[模型记录](../../../assets/units/sion/source_manifest.json)；实战截图、日志与听感限制见交付报告。

首次致死立即清除上一条命的冰冻/眩晕，模型从当时姿势直接混合到复生动作。2秒等待期间血条按复生进度从0逐渐填满；这是表现进度，真实生命仍为0，敌我双方均不可选取，结束时才恢复满血。

常态转普攻与普攻之间的姿势混合均为0.14秒，限定在Attack_Tower2/Attack_Tower入口；完整动画播放速度与权威命中节点仍按原配置。

复生结束原位切换为无斧狂暴形态，保留同一骨骼和AnimationPlayer的末帧姿势；Passive_Death到狂暴移动、两段攻击或待机均混合0.18秒。

Spell2_B播放期间受冰冻时保留当前骨骼姿势，取消旧表现动作。解冻按当前状态直接混合到待机、移动或新的普攻，不续播旧技能、不先绕到待机。
