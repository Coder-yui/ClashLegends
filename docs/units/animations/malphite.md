# 熔岩巨兽动画

[返回单位](../malphite.md)

使用指定的熔岩巨兽GLB，待机Idle1、移动Run、普攻Attack1/Attack2交替、技能Spell3、死亡Death。没有独立出生动作，部署期沿用待机。死亡源片长1秒，压缩至0.8秒。

原始SKN宽134.7856、高134.9054源单位；GLB约1.1457×1.1467，换算0.0085。包装XYZ等比2.50，落脚上移0.01375世界单位；不改变权威半径。源皮肤没有默认隐藏子网格，GLB单网格。

原版普通攻击castFrame分别11.745/11.57，按30fps对应0.3915/0.3857秒；导入片长0.870967/0.838709秒。整段缩放到1.8秒后节点约0.809/0.828秒，统一前摇0.82秒，误差约+0.011/-0.008秒；20Hz实际结算向上到0.85秒。E原版7.5帧，即0.25秒，权威按5 Tick结算；动作片长0.612903秒，播放至0.65秒。施放粒子独立按Spell3动画事件第8帧（8/19片长，映射约0.274秒）从右手挂点释放，不驱动伤害。

模型以盖伦、大纳尔同镜头同朝向对照，保留矮壮轮廓；身体碰撞仍为大档半径24。模型和粒子共享visual_scale.gd中的换算。
