# 终极爆弹时序与卡面

[返回终极爆弹](../mega_inferno_bomb.md) · [总索引](../README.md)

法术无单位骨骼。公共出牌等待后，从己方水晶开始抛物飞行；抵达可靠事件才开始爆炸。弧线高度230px、起点抬高100px是本项目表现选择，不能驱动伤害，也不代表LoL原始轨迹参数。

卡面由内置imagegen生成：巨型铁制炸弹、燃烧引线、中心强烈爆炸与外围冲击波，深青烟雾和橙金火光，纵向无文字插画。正式路径为`assets/cards/mega_inferno_bomb_loading.png`。技能图标从本地Global.wad.client提取巨蛇之牙和莫雷洛秘典，以现有形态图标的左下至右上对角线算法组合；正式路径为`assets/skills/inferno_cannon.png`。
