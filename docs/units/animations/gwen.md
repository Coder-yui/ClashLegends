## 目前怎样呈现

剪切使用同一套起剪、中剪、终剪素材，按 0～3 层充能组合成 2～5 次剪切；所有组合都在 1.5 秒内完成。终剪结束按接下来的行为接回待机或跑步；不要把终剪末帧硬切到普通跑步。

## 已使用的动作

动画名保留素材原名，方便在工作台选中查看；不需要阅读代码。

| 看到的动作 | 对应素材 | 使用方式 |
| --- | --- | --- |
| 部署 | Respawn | 按游戏中的对应状态播放 |
| 待机 | Idle_anm | 状态持续时循环 |
| 开始移动 | Into_Run | 按游戏中的对应状态播放 |
| 持续移动 | Run_anm | 状态持续时循环 |
| 普通攻击 | Attack1 → Attack2 → Attack3 | 按攻击顺序播放，跟随实际攻击速度 |
| 攻击后转跑 | Into_Run → INTO_Run_-90_anm → INTO_Run_180_anm | 按游戏中的对应状态播放 |
| 死亡 | Death | 播放 0.8 秒 |

## 怎么观看与检查

进入“卡牌开发工作台”，选中该单位。先在模型预览中查看上表动作，再到实战页连续观察部署、攻击、技能和结束衔接。蓝红版本在同一篇记录，观看时分别切换阵营。

重点看：脚底是否贴地、朝向是否正确、动作有无突然跳姿，以及攻击后能否自然回到跑步或待机。命中时间以总览中的战斗数值为准，不能用原片总长度代替。

## 丝缕缠流

使用原片 `Spell2`；原动画表的 TickDuration 为 1/35，28帧动作按0.8秒播放。该窗口只锁普攻，允许移动和转向；圣霭在技能开始即生成，寿命独立于动作。

原表使用 `Spell2 → Spell2_To_Idle`、`Spell2 → Spell2_To_Run` 两条过渡，均为0秒混合；转跑片段回普通Run使用0.05秒混合，Stunned进入Spell2保留0.05秒例外。其余常用入口为0秒。转换表依据本地 `Gwen.wad.client` 的 `data/characters/gwen/animations/skin0.bin`，不是从技能命中时间推导。
