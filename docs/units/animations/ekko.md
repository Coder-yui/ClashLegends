# 时间刺客动画

[返回时间刺客](../ekko.md)

使用用户指定基础模型时间刺客.glb，源件现位于`ClashLegends-开发素材库/03-制作中/时间刺客/源件/时间刺客.glb`；正式资源位于`assets/units/ekko/ekko.glb`。源静态网格Y范围约-0.0163至1.7076，属于米级GLB。包装同比1.48（静态高度约2.55，与剑圣约2.56对齐），朝向偏移0度；源Skin0没有默认隐藏子网格配置，保留身体、武器和背部玻璃材质。

| 行为 | 动画 |
| --- | --- |
| 部署 / 待机 | Idle_In（源0.833333秒以0.833333倍速完整拉伸到1秒） / PunkGenius_Idle01_anm |
| 移动 / 加速移动 | Run_Base / Run_Haste |
| 普攻 | Attack_P_1、Attack_P_2、Attack_P_3顺序播放 |
| 回溯 / 落地 | Spell4适配0.75秒；落地解除行动锁，待机接Spell4_End，移动接Spell4_End_To_Run，允许攻击接管 |
| 死亡 | Death，仅取源片前1.5秒，以1.875倍速压缩至0.8秒 |

本地Ekko.bin的三套EkkoBasicAttackP普攻castFrame均为8，30fps对应0.266667秒，基础攻击周期1.6秒。项目1.2秒周期缩放后节点为0.2秒，精确落在第4个20Hz Tick。Start截取0至8帧，Hit从8帧继续，三套源片长均为2.133333秒，剩余片段按0.75缩放至1.4秒，允许下一次攻击或移动接管。不由动画扣血。

模型与技能实际渲染证据、未完成项见本次交付记录。原版加载图来自ekkoloadscreen.tex；技能图标来自Ekko_R.dds。

## 原版动画组织核查（2026-10-23）

依据本地原始 `animations.ritobin`、`ekko.ritobin` 及正式GLB核对，未进行LoL客户端逐帧复现：

- 原版 `Idle1` 是首段 → `Idle01_to_Idle2` → `Idle_Normal` 的序列，后者按60/40权重选择后续待机组合。当前只循环 `PunkGenius_Idle01_anm`；建议后续补全待机组织，不能把固定轮播描述为原版随机选择。
- 原版包含 `Run_In2` 入跑转场（正式模型2.3秒），当前基础移动直接混入 `Run_Base`。可按来源状态选择入跑过渡，但应允许新攻击立即接管，不增加移动锁。
- 原版 `Run` 按移动速度选择 `Run_Base` / `Run_Haste`（源阈值315/535），当前按项目加速状态切换，属于有意适配，不能直接照搬原版速度数值。
- 原版单独定义 `Attack_Tower`，castFrame为12；当前攻击建筑仍使用三段P攻击。若后续接入，须单独对齐其0.4秒源命中节点与项目0.2秒前摇，并核对配套声音，不能只换动画名。
- 原版基础普攻配置是普通攻击与 `EkkoBasicAttack2` 各0.5权重，另有P1/P2/P3、暴击及技能攻击定义。当前固定顺序P1→P2→P3是项目既有选择；仅凭源动画图不能证明原版P攻击的完整脚本选取条件，本轮保留。
- R源片 `Spell4` / `Spell4_End` 分别0.8/1.1秒，但不是原版行动锁。已撤销将两段相加作为1.9秒施法锁的接入：本地EkkoR mCastTime=0.25，结合Riot技能演示采用0.5秒回卷，项目第15个20Hz Tick落地解锁。落地收尾作为可被正常行动接管的过渡。

上述建议尚未实施；本轮仅调整指定死亡片段与音频。

回卷期间按RewindPose1至RewindPose6六套源特效姿态顺序沿历史路径播放；这些是粒子网格，不代替本体Spell4动画，也不改变0.75秒权威时序。
