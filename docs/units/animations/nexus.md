# 水晶 · 动画接入

[← 返回水晶总览](../nexus.md) · [总索引](../README.md)

## 目前怎样呈现

出生使用基座与水晶两部分的动作，持续约 5.17 秒后进入待机。当前出生前没有额外停留。摧毁动作持续 8 秒，外观换成毁坏材质；死亡时刻由游戏规则决定，不等待动画结束。

## 已使用的动作

动画名保留素材原名，方便在工作台选中查看；不需要阅读代码。

| 看到的动作 | 对应素材 | 使用方式 |
| --- | --- | --- |
| 建筑出生 | Nexus_spawn_anm | 播放 5.167 秒 |
| 待机 | Idle1_Base | 状态持续时循环 |
| 摧毁 | Death | 播放 8 秒 |

## 怎么观看与检查

进入“卡牌开发工作台”，选中该单位。先在模型预览中查看上表动作，再到实战页连续观察部署、攻击、技能和结束衔接。蓝红版本在同一篇记录，观看时分别切换阵营。

重点看：脚底是否贴地、朝向是否正确、动作有无突然跳姿，以及攻击后能否自然回到跑步或待机。命中时间以总览中的战斗数值为准，不能用原片总长度代替。
