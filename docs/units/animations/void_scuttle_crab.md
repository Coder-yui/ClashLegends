# 虚空迅捷蟹：模型与动画

[返回单位](../void_scuttle_crab.md) · [总索引](../README.md)

使用 `ClashLegends-开发素材库/01-待开发/卡牌模型/scuttle_crab_(6).glb`，保留 Skin05 紫色虚空原材质。源包围盒约1.913×1.598×2.153；包装缩放1.25、脚底偏移0.09，比普通河蟹0.91稍大。完整骨骼及17个动画保留，不额外隐藏网格。

| 状态 | 原片段 | 时长 |
| --- | --- | --- |
| 出生 | Crab_Spawn | 1.633秒 |
| 待机 | Idle1 | 3.2秒循环 |
| 行走 | Run | 0.533秒循环 |
| 建筑前自疗 | Crab_Dance | 1.6秒循环 |
| 死亡与祭坛 | burrow → ward_run_toground → ward_spawn → ward_idle → ward_tohide | 1秒沉没、1秒入地、2.7667秒展开、3.7秒待机、2.3秒收起 |

原GLB的 Crab_Hide 是静止藏身姿势，现使用原版 sru_crab_burrow.anm 转换的 Skin05 沉没模型。原地沉没后接原版触角入地动作，第2秒开始祭坛展开与形成音效，第4.8秒开始回血，不游向河道中心。单位无普通攻击，不设命中节点；舞蹈仅消费既有行为快照状态3，不驱动治疗，不显示持续光束。

整段使用同一皮肤、同一骨骼、原单位缩放与死亡朝向，避免独立触角模型切换造成跳位。沉没片段由1.0667秒轻微加速至1秒，其他片段原速串接，20Hz阶段边界不足一帧的间隙保持末姿势；无游向河道中央的根位移。回血结束前2.3秒开始原版收起动作，触角与光圈同时结束，清场/终局立即取消死亡表现。
