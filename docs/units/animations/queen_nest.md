# 女王巢穴动画

[返回女王巢穴](../queen_nest.md) · [总索引](../README.md)

洞穴使用原版RekSaiTunnel基础皮肤，源静态范围约187.7×99.3×258.7，缩放0.0117后约2.20×1.16×3.03世界单位；Spawn、Idle1、Death_Open分别对应部署、待机和摧毁，死亡压缩上限0.8秒。头顶三个Z错峰循环：每个Z在2.5秒内从0.25倍逐渐放大至1.15倍，同时向上侧飘动，末段淡出后重新出生；主动唤醒切换空巢后立即隐藏，摧毁时同样隐藏。洞口额外旋转180°朝敌方，已在双方战场截图检查尺寸和朝向。

雷克塞复用原基础皮肤，缩放0.008，单独保留Respawn（源1.066667秒，部署1.1秒）。普通Attack1/Attack2，主动唤醒后Spell1/Spell1B交替；Q源2秒、命中节点0.3秒，按1.2秒周期映射0.18秒，20Hz于第4Tick结算。Q原生粒子比例0.008，手部常驻粒子跟随源骨骼。死亡Death压缩至0.8秒。

卡面已接入用户拍摄的女王巢穴_20261108_201031.png，正式路径assets/cards/queen_nest.png。Zzz只在部署完成的待机阶段出现，部署和死亡动画均隐藏。
