# 灵魂触手 · 动画

[← 返回灵魂触手](../soul_tentacle.md) · [总索引](../README.md)

使用IllaoiMinion基础皮肤原生骨骼与动作，按拍击宽度统一映射0.01，网格另保留源皮肤skinScale=0.9（最终0.009），不按相机压平或拉伸。

| 状态 | 原始动作 | 项目播放时长 |
| --- | --- | --- |
| 部署 | illaoiminion_spawn | 1秒（源2.533秒，约2.533倍速） |
| 待机 | illaoiminion_idleangry | 8.967秒 |
| 攻击 | illaoiminion_attack1 | 2.633秒 |
| 死亡 | illaoiminion_death | 0.8秒（源1.633秒，约2.042倍速） |

原动画图Attack1_BASE的拍地事件在第22帧，按30Hz为0.733秒；动作映射至2.65秒间隔后约0.738秒，20Hz权威节点为0.75秒。强化攻速×1.5，前摇0.5秒；不增加新的攻击动作。动作只能读取权威攻击序号和进度，不能生成伤害。

出生完整压缩到1秒权威部署窗口，完成后进入IdleAngry或权威攻击，不再续播出生尾段。死亡完整压缩到项目通用0.8秒；开始死亡即停发底座粒子，尾迹压缩在此窗口内，结束后底座模型与剩余特效统一清理。源动画图mCascadeBlendValue及三项TimeBlendData均为0，本卡各动作衔接配置为0，不沿用通用混合默认值。

[模型包装场景](../../../assets/units/soul_tentacle/soul_tentacle_view.tscn)

缩放依据为原版IllaoiPassive的PassiveTentacleWidth=200，映射到2格（80像素），即2/200=0.01。源网格0.9尺寸在宽度映射之前保留，粒子使用0.01倍率，伤害长度独立为9格；不按长度二次拉伸模型。

工作台“模型”页是原始片段观察器，因此列表仍标源片时长；1秒部署和0.8秒死亡的运行时适配在“实战”页生效。
