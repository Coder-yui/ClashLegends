# 惊吓魔盒模型与动画

[返回惊吓魔盒](../jack_in_the_box.md) · [单位索引](../README.md)

使用用户指定“恶魔小丑 (1).glb”，实际为ShacoBox魔盒，单网格并无多形态默认隐藏部件。源网格范围约23.20×28.87×15.72单位；包装场景统一XYZ缩放0.10，保持原比例，脚底源最低点0.166约对应0.66像素。以2×2占地及同场金币守卫为建筑体量参照，双方共用模型与阵营标记。

| 动作 | 片段 / 源长度 | 项目行为 |
| --- | --- | --- |
| 部署 | 无独立片段 | 通用1秒部署，模型使用待机，不伪造生成动作 |
| 待机 | Idle1 / 1.20秒 | 循环；隐身材质由状态驱动 |
| 攻击 | Attack1 / 1.00秒 | 每次齐射播放一次，基础1秒攻速 |
| 死亡 | Death / 1.866667秒 | 压缩至0.8秒 |
| 主动 | 无独立片段 | 瞬发眩晕与激活声，保留当前骨骼动作 |

原始ShacoBoxSpell定义castFrame=10，按30fps对应0.333333秒；GLB Attack1实长1秒，本项目配置前摇0.33秒，配置近似误差-0.003333秒，20Hz首发为0.35秒。原定义另有spellCastTime=0.25秒；当前采用明确帧节点，不声称与LoL运行脚本时序完全一致。

原始弹体mStartBoneName=head，包装脚本创建对应BoneAttachment3D，实际模型头部挂点仅提供视觉偏移；权威弹体从建筑中心创建，速度520，碰撞半径4，且不读取骨骼。弹体外观使用原版Shaco_Base_W_Box_Mis，飞行粒子按项目体量等比缩放0.007，独立于模型缩放。

隐身保留公共半透明材质；破隐和主动复用同一原皮W四层范围爆发，范围受控提示复用通用眩晕。见[特效页](../effects/jack_in_the_box.md)。运行截图与发射记录见本任务交付记录。
