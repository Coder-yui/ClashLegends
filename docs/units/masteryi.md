## 总览

移动和攻击都很快的近战单位。普攻循环中的第三招带有额外一刀；高原血统可以进一步加速，并抵抗移动和攻击减速。

## 被动与特殊规则

**双重打击：**每轮第三招在主刀后 0.12 秒追加一刀，伤害为基础普攻的 50%（当前 26）。两刀各自判断是否受到致盲影响。第三、第六、第九…次主攻击均触发；0.12 秒为基础攻速下的延迟，等待期间攻速变化按剩余进度调整。冻结/眩晕暂停；主刀出手后的施法、移动和击退不撤销已提交连击，来源死亡或目标失效则取消未来追加刀。取消前摇不会消耗主攻击段。

## 主动技能

### 高原血统

在持续时间内获得以下增益。

| 项目 | 当前数值 |
| --- | --- |
| 技能费用 | 1 |
| 最多使用 | 2 次 |
| 冷却 | 6 秒 |
| 持续时间 | 5 秒 |
| 移动速度 | 150% |
| 攻击速度 | 140% |
| 伤害倍率 | 100% |

持续期间忽略移动减速和攻击减速。
