# 虚空蠕虫

[← 单位总索引](README.md) · [峡谷先锋](rift_herald.md)

## 总览

峡谷先锋撞击建筑时生成的六只小型近战召唤物，不能单独加入卡组。每只价值1金币，生命值对齐远程兵、伤害对齐防御塔单次攻击，只以建筑、塔和水晶为目标。

## 被动与技能

无独立技能；出生时向碰撞点外散开，随后正常寻路攻击建筑。遵守地面碰撞、控制和死亡规则，没有冲撞免控。

## 撞击爆出

峡谷先锋成功撞击建筑后，6只蠕虫从接触点外侧集中出生，向左右和背离建筑的半圆扇形执行通用强制位移，原始0.45秒、距离约38.4–124.8px，六只近远交错。途中忽略碰撞，避免同批出生互卡；合法原落点保持，不合法按[强制位移](../status/HARD_CONTROL.md#通用强制位移已实现)修正，保速延长增时或缩短早停，召唤出生不叠加部署锁。每只原Hatch完整出生片段缩放到正常散开基准0.45秒；路径缩短早停仍按0.45秒等待与播放，落点延长只增加强制位移控制时间，不拉长出生动画；不是绕建筑预先排成一整圈。先锋途中死亡、目标中途死亡或同批结算先锋死亡都不孵化。
