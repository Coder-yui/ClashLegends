# 金币守卫（建筑卡）

[返回总索引](README.md)

6金币经济建筑，不移动、不攻击。生命640，稍大体型（身体半径21），占地2×2格；部署1秒后每秒自然衰减20生命，标称存续32秒。治疗可延长寿命，受伤可提前死亡，凝滞期间暂停自然寿命与衰血。

部署完成后5秒首次产出1金币，此后每5秒一次。眩晕、冰冻、凝滞期间到期则等待，解除后发放一次，再计5秒，不累积多轮。自然死亡或被摧毁均给所属方2金币，清场不发放；沿用10金币上限。无干扰完整生命周期产出6次，加死亡共8金币。

主动“完美时机”：0金币、每次部署1次、冷却20秒；进入凝滞2.5秒。沿用正常主动技能准入及公共命令延迟，凝滞期间不可选取、不可受伤、保留碰撞并冻结姿势，不能重复施加。状态和金币由主机权威结算，客户端只读取快照与收益事件。
