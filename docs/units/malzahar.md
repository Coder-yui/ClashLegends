# 虚空先知

[← 返回总索引](README.md)

5金币中型空中后排，普攻对地对空，并周期召唤[虚灵](voidling.md)。

| 项目 | 数值 |
| --- | --- |
| 生命 / 普攻伤害 | 620 / 60 |
| 攻击间隔 / 发射前摇 | 1.2秒 / 0.35秒 |
| 攻击距离 / 视野 | 190 / 250像素 |
| 移速 / 身体半径 | 60像素每秒 / 18像素 |
| 弹体速度 / 部署时间 | 380像素每秒 / 1秒 |

## 周期召唤

部署完成后2秒开始第一批，此后每8秒一批。每批先开门，0.25秒后生成首只，再间隔0.5秒生成第二、第三只；从开批时先知脚下的同一个固定裂隙依次生成；先知移动不改变本批裂隙位置；地面落点遵守地形与建筑合法性。未出现的虚灵随先知死亡取消。首批延时与周期不会因眩晕或冰冻暂停；到期被这两种控制阻止的批次沿用现有周期召唤规则，跳过该批。已开始的逐只召唤不被控制取消。

## 冥府之握

3金币、1次、冷却10秒。按钮准备下一击，在普通攻击的合法命中节点改为引导，不发普攻弹体，也不消费致盲次数。命中后使敌人眩晕2.5秒；自身不能移动、攻击或再次施放技能。眩晕、冰冻、凝滞、击退、强制位移、沉默、嘲讽直接打断，死亡、目标失效也结束引导；只解除本次引导的眩晕，不移除其他来源的控制。

从命中位置建立半径90像素的固定圆形区域，持续5秒，每0.5秒对圈内敌方地面和空中目标造成30伤害，共10次。目标可离开区域；先知被打断、移动、死亡或释放后区域仍继续，清场或终局删除。建筑能承受区域伤害，控制免疫仍沿用对象既有规则。

## 虚空虫群（W）

新增可选主动技能：1金币、可用3次、冷却6秒。原地播放1秒W施法动作，期间禁止普攻；0.25秒时开启裂隙，0.5秒第一只、1.0秒第二只、1.5秒第三只，再保持0.25秒，于1.75秒关门。后两只沿已开启批次继续生成；先知死亡取消尚未出生的虚灵。释放前冰冻取消尚未形成的批次。

与被动共用原版W三只虚灵的裂隙、出生层和一次施法声；重叠触发时，两批独立计时，各产出3只，不覆盖对方。备战技能选择或卡牌开发工作台中，可在冥府之握与虚空虫群之间选择携带；每个实例仍只携带一个主动技能。
