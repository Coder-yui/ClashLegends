# 狂战士（单只）

[返回总索引](README.md) · [双人狂战士](olaf.md)

工作台系统对象，不进入正式卡组。单只部署费用为0；其余生命、攻击、移动、模型、原版加载卡面和音频与双人卡成员相同。

残暴打击仍为1金币、1次、10秒冷却，只强化自身：180护盾持续2.5秒，30%攻速和30%吸血持续5秒。

[动画](animations/olaf.md) · [音频](audio/olaf.md) · [特效](effects/olaf.md)

诸神黄昏与双人卡使用同一数值、解控和免疫规则，单只对象仅作用于自身；工作台可选择两项主动技能。详见[狂战士](olaf.md#诸神黄昏)。
