# 虚空兽

[← 返回总索引](README.md)

## 总览

3费部署两只稍小的地面虚空兽，横向并排、中心间隔1.2格（48像素），以点击格心为间隔中点。空场时，在中线左右相邻格下牌均左右各走一只；再向外一格，两只同路推进。它们只追击建筑，不进行普通攻击，用一次牺牲跳跃爆炸伤害锁定建筑。

## 牺牲爆炸

建筑进入起跳距离后立即死亡并释放碰撞与被选取资格，锁定建筑近侧表面落点。独立结果在16个权威Tick后爆炸，仅对起跳时锁定的敌方建筑、防御塔或水晶造成240伤害，没有范围伤害。目标死亡、释放、变为友方或处于效果保护时不扣血，不转移到其他目标；爆炸表现仍在原落点完成。清场或终局取消未抵达结果。起跳前被杀不会爆炸，冰冻和眩晕阻止起跳。

桥头左路单只、不施放主动且无其他单位干扰时，双方均承受3次55点塔伤，以1点生命完成牺牲起跳，16个权威Tick后对锁定防御塔造成240伤害。该参考从蓝方(140,700)／红方(140,580)出发，塔目标与冷却归零；当前基础移速为80像素/秒，适配精确塔时钟，不提供额外存活保护。

## 主动技能：虚空强化

消耗1金币，每组部署只能使用1次。永久强化本组仍存活的虚空兽：爆炸伤害从240提高到360，模型和碰撞半径增大至1.25倍（15→18.75像素），最大生命增加20%（166→199），当前生命同时增加33点，保留已有损伤。移速永久提高20%（80→96像素/秒），不获得穿行能力。

死亡或已经起跳的成员不会获得强化，已排程的爆炸仍使用起跳时固化的伤害。技能资格随同批存活成员转交，不影响其他部署批次。图标采用云顶虚空兽fixed版。幽灵疾步已撤下；兹若特强化虚空兽专属粒子的引用尚未从现有素材中确认，按用户许可接入项目自制紫色轮廓光与头角渐变光球，强化后持续到死亡或起跳，没有上升光丝。原版出生第一变体用于部署，第二变体按用户要求用于技能。

## 动画、声音与特效

工作台另提供“虚空兽（单只）”（`void_spawn_single`）系统对象，只部署一只，保留同样的模型、音频、牺牲攻城和虚空强化。该对象不能加入正式卡组；单体摄影卡面使用灰橄榄绿背景（#52614C）。正式3费双只卡仍使用原有卡面与部署数量。

- [模型与动作](animations/void_spawn.md)：指定模型、原生建筑攻击动作和摄影卡面。
- [声音](audio/void_spawn.md)：原版出生、死亡、旋转起跳与撞建筑爆炸声音。
- 起跳为独立3D模型代理；爆炸使用旧版虚空兽攻击建筑的七层原版特效，同时接入普通死亡与起跳蓄能；部署仅播放模型动作与声音。表现只读状态和可靠事件，不控制伤害。
