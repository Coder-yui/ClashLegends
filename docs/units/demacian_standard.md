# 德邦军旗（建筑卡）

[返回总索引](README.md)

2金币，不移动、不攻击，生命360，中体型（身体半径18），占地1×1格。可部署在双方半区的合法地面，仍受河道、占位和地图边界限制。部署完成后每秒自然衰减30生命，标称12秒；受伤可提前摧毁，治疗可延寿，凝滞暂停自然衰血。

被动攻速光环：以旗杆中心为圆心，半径160（4格），身体圆接触范围的友方地面、空中单位和卡牌建筑攻速提升25%；不影响系统防御塔、水晶。多旗及其他攻速增益取最强，不相乘。来源部署中、死亡、凝滞时不贡献；眩晕和冰冻不关闭被动。离开范围在下次权威行动边界移除，无额外残留时间。

主动“黄金圣盾”：1金币、每次部署2次、冷却5秒。以旗杆中心为圆心、半径160（4格）范围内，友军获得120点非衰减护盾，3秒到期；包含自身、友方建筑、防御塔及水晶。敌方Unit移速降低35%，持续2秒，无伤害。遵守凝滞、技能保护及独立盾层规则；沿用公共技能请求延迟，执行时结算。
