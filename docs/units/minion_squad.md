# 小兵分队

[← 返回总索引](README.md)

一次出牌生成3只近战兵和3只远程兵。六名成员是独立单位，按六边形的6个顶点站位，并共享本次部署的主动技能资格。

## 数值

| 项目 | 当前数值 |
| --- | --- |
| 出牌费用 / 数量 | 3金币 / 6名（3近战、3远程） |
| 站位 | 更紧凑六边形的6个顶点，中心间距44像素 |
| 成员战斗数据 | 分别复用[近战兵](melee_minion.md)与[远程兵](ranged_minion.md) |
| 部署 | 常规命令等待0.5秒，生成后部署1秒 |

## 男爵之力

2金币，每次下牌只能使用1次，冷却6秒。给**这一次下牌**仍存活的所有小兵施加其自身的男爵之力：近战兵获得移速135%与伤害125%，持续4秒；远程兵获得攻速125%与伤害125%，持续5秒。队长阵亡后，技能资格转交同一编队中仍存活的小兵。

## 动画、声音与卡面

- 成员模型与动作分别复用[近战兵动画](animations/melee_minion.md)和[远程兵动画](animations/ranged_minion.md)。
- 成员的部署、普攻、远程弹体和死亡声音分别复用两张成员卡的正式音频；[音频接入说明](audio/minion_squad.md)记录了复用边界。本卡没有额外的独立技能音频素材。
- 卡面使用近战兵与远程兵前后站位的3D模型摄影图。
