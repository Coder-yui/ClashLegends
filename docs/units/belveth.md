# 卑尔维斯

[← 返回总索引](README.md)

## 总览

7金币大型空中推进坦克，只攻击建筑。死亡后在周围八个方向生成8只虚空鱼，以数量接续推进。

## 数值

| 项目 | 当前数值 |
| --- | --- |
| 费用 | 7金币 |
| 生命 | 1500 |
| 普攻伤害 / 间隔 | 90 / 1.5秒 |
| 攻击距离 / 前摇 | 32像素 / 0.15秒 |
| 移速 / 身体半径 | 44像素每秒 / 24像素（大） |
| 目标 | 仅建筑 |
| 移动 / 部署锁定 | 飞行 / 1秒 |

## 被动与特殊规则

死亡召唤只触发一次，八只鱼各自拥有生命、目标与行动状态；召唤不走手牌命令缓冲，出生后仍有1秒部署锁定。死亡本身不额外造成范围伤害。

## 主动技能

**虚空突袭**：1金币，2次，冷却6秒。沿当前朝向突进3格（120像素），路径宽48像素；每名碰到的敌方空中单位受到100伤害一次。不会伤害地面单位或建筑。基础突进0.4秒，收势0.2秒；速度随有效移速调整。可越河，场边提前停止；冰冻取消，眩晕不取消已开始技能，外部击退接管位移。没有旋转二次伤害。
