# 虚空女皇

[← 返回总索引](README.md)

## 总览

外观固定采用原生大招形态，待机、移动、普攻、部署与突进均使用大招动作。

7金币大型空中推进坦克，只攻击建筑。死亡后从死亡位置生成8只虚空鱼，朝八个方向散开，以数量接续推进。

## 被动与特殊规则

死亡召唤只触发一次，八只鱼从死亡点朝向各自散开方向，以100像素（2.5格）/0.45秒的原始速度通用强制散开，途中无碰撞；场界及不可推动落点按[强制位移](../status/HARD_CONTROL.md#通用强制位移已实现)修正并保持速度，不从外移后的点重复计算100像素。八只鱼各自拥有生命、目标与行动状态；召唤不走手牌命令缓冲，出生后仍有1秒部署锁定。死亡本身不额外造成范围伤害。

## 主动技能

**虚空突袭**：1金币，2次，冷却6秒。沿当前朝向突进3格（120像素），路径宽48像素；每名碰到的敌方空中单位受到100伤害一次。不会伤害地面单位或建筑。基础突进0.4秒，收势0.2秒；速度随有效移速调整。可越河，场边提前停止；位移中有效眩晕、冰冻、凝滞或击退取消剩余突进和未来路径伤害；击退接管位移，不当作正常抵达。已提交伤害保留；正常结束后的普通收势不被眩晕/击退取消。没有旋转二次伤害。
