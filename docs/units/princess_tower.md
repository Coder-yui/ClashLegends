# 防御塔

[← 返回总索引](README.md)

## 总览

双方各有两座防御塔，会自动攻击接近的敌人。塔身随受损逐步破裂，最终留下塔墟；塔墟可以与太阳圆盘产生配合。

## 控制与生命周期

眩晕、冰冻取消攻击，解除后重新索敌起手；冰冻期间塔身覆盖淡蓝色，已脱离碎块保持原色；解冻恢复塔身原色。受损破裂与碎块动画照常播放，不因这两种控制暂停。凝滞可作用于双方防御塔，金身冻结塔身并隐藏附属标识，已脱离碎块保留原色并独立下落/消散，解除后重新攻击。这里指场地Tower；墓碑、太阳圆盘和炮台是Unit型建筑，不套用本条生命周期播放器规则。统一边界见[表现合同](../status/PRESENTATION.md#防御塔与水晶的生命周期动画)。
