# 艾希

[← 返回总索引](README.md)

## 总览

可以对空的远程射手。普通攻击发射单支箭；万箭齐发向前射出扇形箭阵，每支箭会被第一个敌人挡住。

## 主动技能

### 万箭齐发

朝前方扇形区域射出 8 根非穿透箭矢，每支命中首个敌人后消失；同次施法对每个目标最多造成 70 点伤害并减速 1 秒。

| 项目 | 当前数值 |
| --- | --- |
| 技能费用 | 2 |

| 冷却 | 10 秒 |
| 基础伤害 | 70 |
| 向前距离 | 210 |
| 扇形角度 | 72° |
| 开始后命中时间 | 0.16 秒 |
| 施法总时长 | 1 秒 |
| 减速时间 | 1 秒 |

| 飞出数量 | 8 |
| 飞行时间 | 0.2 秒 |

施放期间：不能移动、不能普攻，也不能转向。
