# 艾希

[← 返回总索引](README.md)

## 总览

可以对空的远程射手。普通攻击发射单支箭；万箭齐发向前射出扇形箭阵，每支箭会被第一个敌人挡住。

## 主动技能

### 万箭齐发

朝前方扇形区域射出 8 根非穿透箭矢，每支命中首个敌人后消失；同次施法对每个目标最多造成 70 点伤害并减速 1 秒。

| 项目 | 当前数值 |
| --- | --- |
| 技能费用 | 2 |
| 最多使用 | 1 次 |
| 冷却 | 10 秒 |
| 基础伤害 | 70 |
| 向前距离 | 210 |
| 扇形角度 | 72° |
| 效果执行 / 发射延迟（配置） | 0.16 秒 |
| 实际发射 Tick | 施法开始后第 4 Tick，即 0.20 秒 |
| 施法总时长 | 1 秒 |
| 减速时间 | 1 秒 |
| 减速后移速 | 55% |
| 飞出数量 | 8 |
| 飞行时间 | 0.2 秒 |
| 目标受伤时间 | 由真实箭矢与目标碰撞决定 |

施放期间：不能移动、不能普攻，也不能转向。

正式操作还需先经过 10 Tick（0.5 秒）命令等待；表中延迟从施法真正开始算起。每 Tick 为 0.05 秒，因此 0.16 秒配置在第 4 Tick 执行，生成箭矢后才检查飞行碰撞。发射所在 Tick 就会推进第一段飞行：固定测试中，距离 80 的目标在第 4 Tick 受伤，距离 180 的目标在第 6 Tick 受伤；例子使用半径 24 的静止目标，不能当成任意目标的固定命中时间。共同术语见[动作时序](../ANIMATION_STATE_SYSTEM.md)。
