# 牧魂人

[返回总索引](README.md)

4金币部署一名稍大体型地面近战战士。每次选定一个地面目标挥铲，命中点周围的地面敌人受到相同伤害。

| 项目 | 当前数值 |
| --- | --- |
| 费用 / 数量 | 4金币 / 1名 |
| 生命 / 普攻伤害 | 820 / 110 |
| 攻击间隔 / 前摇 | 1.5秒 / 0.27秒（20Hz下约0.30秒） |
| 攻击距离 / 目标 | 表面距离32像素 / 地面，含建筑 |
| 命中范围 | 以主目标命中位置为圆心，半径35像素；与敌人身体相交即命中 |
| 移动 / 速度 | 地面，稍慢，52像素每秒 |
| 体型 / 碰撞半径 | 稍大 / 21像素 |

## 被动：重铲横扫

普攻对命中圆内每名合法敌人各造成110伤害，同一目标不重复受伤。空军、友军、凝滞目标不受伤；无合法主目标时不产生范围伤害。命中时显示短暂红色圆圈，圆圈标示35像素作用半径，敌人的身体边缘也参与范围判定。

## 主动：临终仪式

1金币，3次，冷却6秒。刷新普攻并强化下一次攻击，圆内每名敌人各承受220伤害；只要有效命中，牧魂人回复一次120生命，不因目标数增加且不超过最大生命。纯护盾承伤也算有效命中，这是固定治疗而非吸血。致盲空挥、主目标失效不会回血；同批已致死的牧魂人不会复活。强化未打出时不可重复武装。
