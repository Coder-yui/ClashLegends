# 星芒凝汇

[← 返回总索引](README.md)

3费法术，改造自龙王E。全场施放；持续5秒，半径160像素（4格）。每0.25秒对范围内敌方地面、空中及建筑造成6伤害，共20次、120伤害；防御塔与水晶每次按30%倍率结算。身体与作用圆相交即受影响。

持续以每秒40像素（1格）的外力牵引可移动单位，不锁定攻击；可与自主移动对抗，保留地形边界，多黑洞向量相加。建筑、凝滞与位移免疫对象不移动；正在强制位移和技能突进的单位不叠加牵引。普通护盾只吸收伤害；法术盾阻止整次区域作用。

主动「黑洞吞噬」额外1费，每次出牌强化一次，无独立冷却。身体触碰中心金色圆内部、半径60像素（1.5格）且生命严格低于最大生命15%的敌方单位被斩杀；先结算当次持续伤害，再检查斩杀。无视普通护盾与减伤，不斩杀建筑，保留拒绝死亡、死亡替身、复生和死亡召唤。
