# 金克丝（暴走萝莉）

[← 返回总索引](README.md) · [轻机枪形态](jinx_minigun.md)

## 总览

5金币地面后排，单次部署1名，中体型，对地对空。默认使用火箭炮，以较长射程与范围伤害支援推进；切换轻机枪换取更快的单体输出。

## 数值

| 项目 | 当前数值 |
| --- | --- |
| 费用 / 生命 | 5金币 / 440 |
| 伤害 / 间隔 | 100 / 1.5秒 |
| 射程 / 溅射半径 | 220 / 45像素，范围与目标身体圆相交即命中 |
| 移速 / 体型 / 身体半径 | 中（60像素/秒）/ 中 / 18像素 |
| 弹速 / 发射前摇 | 500像素/秒 / 0.22秒（20Hz第5Tick） |
| 部署 | 公共0.5秒命令等待，再1秒部署 |

生命、伤害、射程、溅射与机枪间隔是需求留空后的首版平衡值。炮弹命中合法主目标才产生溅射，同时影响空中、地面和建筑，不伤友军；主目标死亡或凝滞使追踪失效时不产生落点爆炸。

## 被动：罪恶快感

普通攻击（包括火箭溅射）命中过的敌方建筑卡、防御塔或水晶，在最后一次命中后3秒内被摧毁，获得6秒被动，每层增加30%攻速，同时获得从100%在6秒内线性衰减到0的移速加成。自己补刀也触发；普通单位死亡不触发；建筑在命中后3秒内自然衰血归零或寿命到期同样触发。3秒边界包含第60Tick，61Tick不触发。被动期间每次触发增加1层，并将全部层数刷新为6秒（未设层数上限）；1/2/3层分别增加30%/60%/90%攻速。移速不叠加，每次触发取消旧衰减，重新从100%加成开始。窗口结束时全部层数一同清零，下一次从1层开始；同一批次击败多座建筑分别叠层。

被动可跨武器形态保留。攻速增益按项目共通规则与机枪层数取最强，减攻速独立相乘。凝滞拒绝新收益、抑制现有属性与特效，但计时继续；死亡来源不再获得收益。

| 最小状态定义 | 规则 |
| --- | --- |
| 身份 / 范围 | structure_haste，自身增益；助攻目标仅敌方建筑、塔、水晶 |
| 时钟 / 叠加 | 20Hz；同源叠层并刷新6秒；移速倍率为1+剩余秒数/6；攻速倍率为1+层数×0.3 |
| 行动 / 结束 | 不解除任何行动锁；到期、死亡、清场结束；换枪保留 |
| 表现 / 接入 | 只读快照的拖线与笑脸；获得时播放原版被动声，刷新不重播；JinxSuite覆盖 |

## 主动技能：枪炮交响曲！

0金币、每次部署共5次、冷却4秒。遵守通用0.5秒请求缓冲，真正执行时立即切换武器属性与弹体配置并清空旧普攻周期，随后进入0.37秒切枪窗口（原片0.3667秒按项目精度取值；20Hz第8Tick即0.40秒结束）。窗口内不能攻击或开始新技能，圈外可按新形态射程追击；结束后从新武器完整前摇起手。硬控交互沿用变形：眩晕、击退不取消切枪动作；冰冻、凝滞保持当前姿势并停动作音，窗口继续计时，解控不续播旧动作。

切换清空机枪层数，保持当前生命、单位身份与主动技能资格。在途炮弹/子弹保留发射时的伤害、溅射、声音和形态；旧火箭不会在切枪后为机枪叠层。再次部署按通用主动槽替换规则提供新5次资格。
