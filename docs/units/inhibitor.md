# 高地水晶

[← 返回总索引](README.md)

7费兵线召唤建筑，不进行普通攻击。

| 项目 | 当前数值 |
| --- | --- |
| 费用 | 7 |
| 部署 | 1秒，播放原生生成动画 |
| 生命 | 1200 |
| 占地 | 3×3格 |
| 身体半径 | 40像素 |
| 存续时间 | 50秒，每秒自然衰减24生命；治疗可延长 |

部署完成立即召唤第一波，之后每8秒召唤一波，按下列顺序循环：

1. 一个近战兵和一个远程兵。
2. 一个近战兵和一个远程兵。
3. 两个近战兵和一个炮车兵。

每波按上述顺序逐个生成，相邻小兵间隔0.5秒（同基地水晶兵线），起波周期仍为8秒。部署在战场左半区从建筑左侧出兵，右半区从右侧出兵，中线归右侧。未生成成员在控制期间暂停，建筑死亡后取消。

眩晕、冰冻、凝滞时到期的一波延后到解除控制，不累积补发多波。被摧毁或自然衰血死亡时召唤一个超级兵，清场不触发。

主动「超级增援」花费2金币，立即召唤一个超级兵；每座可用2次，冷却18秒。主动不推进被动波次。主动与死亡召唤的超级兵同样按建筑所在半区从左/右侧生成。所有来源的小兵（周期、主动、死亡召唤）均无部署等待，生成后可立即行动。
