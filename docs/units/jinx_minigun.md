# 金克丝·轻机枪

[← 返回总索引](README.md) · [火箭炮与完整规则](jinx.md)

## 总览与数值

通过金克丝主动切换进入，不能独立组卡。保持440生命、100伤害、中移速60像素/秒、中体型18像素半径与对地对空能力；射程缩短至170像素，攻击间隔1秒，发射前摇0.18秒（第4Tick），弹速650像素/秒，无溅射。

## 机枪预热

每次真实普通攻击命中获得15%攻速，最多3层、45%；每次命中刷新全部层数持续3秒。未命中、被阻挡、免疫或旧形态弹体不计层。达到三层时基础1秒间隔约为0.69秒，仍由20Hz模拟推进。切换武器清空层数，罪恶快感的6秒窗口与被动层数保留；两个同类攻速增益取最强，不相加。

主动沿用枪炮交响曲：0金币、共享5次、4秒冷却，切回火箭炮。属性立即更换，0.37秒切枪窗口内禁止攻击，硬控交互同变形。形态不改变剩余次数与当前生命。
