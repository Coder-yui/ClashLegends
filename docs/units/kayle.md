# 正义天使（近战）

[← 返回总索引](README.md)

对地、对空的飞行单位。卡组中只有“正义天使”一张卡；提交出牌时，金币达到6便花6金币部署远程形态，不足6但达到3便花3金币部署近战形态；不足3不能出牌。形态在付款时锁定，部署等待和此后金币变化不会改变已有单位。

## 数值

| 项目 | 当前试玩值 |
| --- | --- |

| 移速 / 身体半径 / 质量 | 60像素每秒 / 18像素 / 4 |

普攻为单体近战，不产生远程弹体或溅射。

## 被动：登神之阶

每次普攻真实命中获得1层，每层提高10%攻速，最多4层（40%）。每次命中都会让全部层数重新持续3秒，满层时也刷新；3秒没有新命中则全部清空。远程创建弹体时不叠层，焰浪不额外叠层，一次光剑命中只加1层。命中护盾算命中，空挥、无效目标和死亡来源不获得层数。冻结、眩晕不暂停持续时间。

叠层与到期保留当前普攻进度，按有效攻速调整剩余前后摇；技能、移动和已发射弹体不加速。与其他同类攻速增益取最强，再受攻速减缓影响。

工作台模型目录选择“正义天使”，在“近战形态／远程形态”中快速切换；共用一个GLB，切换部件、材质与动画配置。

## 主动：星界恩典

0金币，6秒冷却，每次部署2次。技能正式开始回复自身160生命，不超过生命上限，并获得1秒30%移速加成。施法动作0.6秒，期间可移动、不可普攻。请求仍经过0.5秒命令缓冲；入队不提前消费次数，实际开始时消费次数并启动冷却。

加速来自本单位W，同源刷新，同类增益按最强倍率聚合，不改变基础移速。死亡不复活；冻结可以取消尚未执行的动作，已得到的治疗不回滚、加速按自身窗口结束。再次部署替换旧单位的主动资格。

| 状态定义 | 规则 |
| --- | --- |
| 身份 / 范围 | 星界恩典，自身治疗与移速Buff，无友军范围收益 |
| 时间 / 权限 | 生效节点0秒，20个固定Tick加速；不提升攻速、弹速或外力速度 |
| 生命周期 | Buff实例计时，同源刷新，死亡结束；遵循共通控制门禁 |
| 接入证据 | ActiveSkillEffectSystem → Unit.heal / apply_active_buff；KayleSuite与现有快照 |
