# 训练木桩（建筑卡）

[← 返回总索引](README.md)

## 总览

3费防守建筑，用生命吸收火力，不移动、不攻击。蓝红双方分别使用用户指定的木桩模型。与工作台“木桩”按钮生成的[百万血测试对象](training_dummy.md)独立；本卡可加入卡组，标识为 `target_dummy`。

## 数值

| 项目 | 当前数值 |
| --- | --- |
| 出牌费用 / 生命 | 3 / 750 |
| 占地 / 身体半径 | 2×2格，中心落在四格交点 / 21（稍大） |
| 移动 / 普攻 | 无 |
| 部署 / 存续时间 | 1秒 / 部署结束后15秒 |
| 自然退出 | 寿命到期消失；不持续扣血，受伤可提前死亡 |

750生命、21半径、90爆炸范围及80伤害为本轮补齐的首版数值。每格40像素；模型尺寸与碰撞独立。

## 主动技能：余震

消耗2费，每次部署可用1次，冷却10秒。立即获得60%减伤，持续2.5秒（50个权威Tick），然后对中心90像素内的敌人造成80伤害。范围包含敌方地面、空中、建筑与塔，按目标身体半径检测；不伤友军。

减伤先于护盾，多个普通减伤取最强，不相加；不减少自然生命代价或建筑寿命。已施加的余震不占用全身动作，不因眩晕或冰冻取消；凝滞抑制增益但不延长时长，期间到期不爆炸、不补发。来源死亡或清场取消后续爆炸。释放前沿用普通技能受控准入。
