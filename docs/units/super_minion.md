# 超级兵

[← 返回总索引](README.md)

## 总览

高生命的重型近战兵，用于前排推进。男爵之力同时提高移动和伤害，并补上一层护盾。蓝红双方模型不同，战斗数值相同。

[查看卡面原画](../../assets/cards/super_minion_loading.png)
