# 凛冬之柱（建筑卡）

[返回总索引](README.md)

3金币、不移动、不攻击的控制建筑，生命600，稍大体型（身体半径21），占地3×3格。可在双方半区的合法地面部署，仍受河道、占位和地图边界限制。部署1秒；完成后每秒自然衰减30生命，标称存续20秒。伤害可提前摧毁，治疗可延寿，凝滞暂停自然衰血。

被动以柱心为圆心，半径110（2.75格）；身体圆接触范围的敌方地面、空中单位和卡牌建筑移速降低30%、攻速降低25%。不影响友军、系统防御塔或水晶。多柱及其他同类减益取最强，不叠乘。离开范围、来源死亡或被移除后，在下一权威行动边界清除光环贡献，不删除其他来源的减益。来源部署中和凝滞时不贡献；眩晕和冰冻不关闭被动。遵守目标凝滞、控制免疫、圈外保护和效果盾规则。

主动“冰封领域”：1金币、每次部署1次、冷却10秒。减速与减攻速强度不变，范围扩大至200（5格），持续5秒。沿用公共主动请求与权威Buff时钟；结束后恢复基础范围。
