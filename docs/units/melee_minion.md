# 近战兵

[← 返回总索引](README.md)

## 总览

低费用近战兵，可从卡牌部署，也会随兵线出现。适合在前排承受攻击，为后排创造输出时间。蓝红双方使用各自模型，战斗数值相同。

[查看卡面原画](../../assets/cards/melee_minion_loading.png)
