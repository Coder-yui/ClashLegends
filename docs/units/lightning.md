# 大型电击法术

[← 返回总索引](README.md)

每次重新选择范围内尚未被本次法术电击、当前生命值最高的敌方目标，只命中一个。同一次施法不能重复电击同一目标；血量相同时按出生顺序。某次没有目标则跳过该次，后续次数继续；例如0秒击杀唯一目标，1秒空场跳过，2秒可命中新进入的目标。强化伤害按固定段号计算，跳过第二段后第三段仍为144%（662伤害）。对空、对地、建筑、防御塔和水晶有效，不影响友军。

## 主动技能

递增电击：额外1金币，三次伤害倍率为100% / 120% / 144%，对单位实际伤害为460 / 552 / 662，对塔与水晶为138 / 166 / 199。放入主动槽后随出牌生效，总费用7金币。首击在法术正式执行时发生，后续落点范围固定；伤害仅在最终结算时四舍五入。半径按目标身体边缘相交判定，沿用其他范围法术规则。护盾不阻止眩晕，死亡目标不再施加控制，免控与不可交互目标遵守[状态规则](../status/README.md)。独立追加电击不依赖单位动画，终局或清场取消。
