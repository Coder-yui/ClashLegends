# 浪潮法术

[返回单位索引](README.md)

2金币的地面推进法术，浪潮从所选格心朝敌方半场直线前进。每个敌方地面目标只受到一次伤害与击退；空军不受影响。

| 项目 | 数值与规则 |
| --- | --- |
| 费用 | 2金币，强化不加费 |
| 释放区域 | 同普通兵种的初始己方部署区，排除河道（含桥面）；忽略建筑占位，破塔不解锁敌方半场 |
| 宽度 / 射程 | 160像素（4格） / 440像素（11格） |
| 推进速度 / 时间 | 320像素每秒 / 1.4秒（28个权威Tick，末Tick截断到440像素） |
| 基础伤害 | 120 |
| 击退 | 朝浪潮前进方向，基准40像素（1格） / 0.2秒；受质量与地形影响 |
| 建筑卡 | 承受120伤害，不被击退 |
| 防御塔 / 水晶 | 承受30%伤害，即36；不被击退 |

最前方合法格心为蓝方y=700、红方y=580；同路敌方防御塔中心距离440像素，11格射程可到达塔中心。公共0.5秒出牌延迟结束后开始播放施法声，再经过原版0.5秒施法前奏才生成浪潮。作用区域按移动前后浪头扫掠与目标身体圆相交判定，不是瞬间结算整条矩形。

## 踏浪而行

放入主动槽后随法术生效，额外费用0金币，无独立二次施放按钮。浪潮经过己方地面普通单位时，提供2秒30%移速加成；每个单位每次浪潮只触发一次，追上同一道浪潮不刷新。友军不受伤，空军和建筑不获得加速。不同浪潮按通用来源独立、同类取最强规则处理。

## 交互边界

凝滞与来源保护遵循通用效果准入；被法术盾抵挡时伤害与击退一并拒绝。全额生命护盾吸收仍可击退，死亡单位不补位移。不额外施加眩晕或减速。暂停停止权威时钟，终局和清场销毁浪潮；客户端只接收表现事件及单位状态快照，不计算伤害。
