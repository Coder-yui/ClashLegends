# 远程虚空鱼大军

[← 返回总索引](README.md)

## 总览

5费部署6只小型空中远程虚空鱼，分别位于正六边形的六个顶点，中心不放单位。每只属性与[远程虚空鱼](voidfish_ranged.md)一致，可攻击地面、空中和建筑。

## 主动技能：虚空再生

2费，每批一次，冷却10秒。对本批仍存活的全部成员开启3秒再生窗口；每只在窗口内被击杀时，在死亡位置生成一只满血远程虚空鱼。技能开启前已经死亡的成员不复活，其他批次和敌军不受影响。

新鱼不继承主动资格或再生状态，不会连锁复生；原批次的技能资格按通用编队规则在存活成员间转交。窗口内再生省略旧鱼死亡动画，直接播放新鱼出生；窗口外死亡正常播放死亡动画。没有独立被动。
