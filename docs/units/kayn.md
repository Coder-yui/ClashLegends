# 凯隐

[返回单位索引](README.md)

4费近战成长卡。每局从凯隐开始，同阵营所有凯隐共享进度，远程4次、近战6次普攻命中分别累计，先达标的一条锁定本局后续部署形态。同Tick两条任务都达标时按主机既有命中提交顺序先到先锁。技能、建筑、队友、致盲空挥不计数；全盾吸收的真实命中计数。远程按弹体或持续远程攻击能力分类。场上旧凯隐不变形，已经接受的部署命令也保持接受时形态。

可穿越河流和双方存活建筑、塔、水晶；桥面视为普通地面。仍受战场边界及同层普通单位碰撞约束。完整圆柱进入地形时回复，连续留在或跨越相连地形只触发一次，完整离开后才能重触发。在地形里不能普攻：准备普攻时，在目标攻击范围内检查3圈各16个站位，选挤出距离最小的合法点，当步挤出并开始正常普攻前摇，不主动走向出口。修正距离上限三格（120px，允许从水晶中心挤出），无满足条件的位置则等待，不退回射程外。

致盲普攻不造成命中，不获得成长能量。击退和普通单位接触可以将凯隐推进地形并触发进入回复；建筑落地沿用通用推挤，建筑摧毁后若当前位置成为普通地面则解除地形状态，不额外挪位或回复。

局内手牌卡槽左侧显示蓝色4格成长条，右侧显示红色6格成长条，从下往上点亮，任一形态升级完成后两侧进度条立即隐藏；备战与下一张预览不显示。成长完成时，卡槽上方以对应蓝字或红字显示“凯隐已经升级为影流刺客／凯隐已经升级为暗裔杀手”2秒，凯隐在待抽队列时也提示。进度与升级提示仅己方可见。

## 巨镰横扫（Q）

<!-- card-fact: kayn active_skills.0.cost -->2金币，<!-- card-fact: kayn active_skills.0.cooldown -->6秒冷却，每次部署<!-- card-fact: kayn active_skills.0.max_uses -->2次。沿施法开始时的朝向突进120px，路径碰撞宽40px，对实际经过的每个地面敌人造成90伤害。突进速度持续随有效移速变化：凯隐/拉亚斯特正常移速68px/s时，突进0.43秒；影流刺客正常移速88px/s时约0.332秒。突进结束后停步0.14秒、旋转0.43秒，后两段不随移速缩放；结束突进后0.28秒，以当前位置为中心对半径65px内敌人再造成90伤害。凯隐/拉亚斯特基准总时长1秒、旋转节点0.71秒，影流刺客基准总时长约0.902秒。碰到竞技场边界（含身体半径）立即停止突进并接停步、旋转，不沿边滑动。

Q可在地形里使用。突进不推开单位，全程可受伤；突进结束立即恢复通用单位碰撞，Stop/Circle阶段像普通部署单位一样由接触推挤逐步分离，地形仍可进入；旋转在伤害节点按当前位置和当时圈内敌人结算，不因重叠延迟。突进期间有效眩晕或击退取消剩余突进及尚未开始的旋转，击退独立接管位置；不补距离、不退款、不伪造抵达结果。突进已结束、进入停步/旋转后恢复普通技能保护：眩晕不取消，击退带着旋转移动，伤害按节点当前位置结算。冰冻/凝滞在两阶段都取消尚未释放后段；同批已提交伤害及独立结果不撤回。死亡和清场清除后段。

普攻出口检查固定48个点，复用地面区域与碰撞圆柱数据，计算量随场上单位数量线性增长；不再枚举全场边界交点。攻击圈内缩2px，避免浮点边界导致重新追击。
