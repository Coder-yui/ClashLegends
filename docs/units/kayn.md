# 影流之镰·凯隐

[返回单位索引](README.md)

4费近战成长卡。每局从普通凯隐开始，同阵营所有普通凯隐共享进度，远程4次、近战6次普攻命中分别累计，先达标的一条锁定本局后续部署形态。同Tick两条任务都达标时按主机既有命中提交顺序先到先锁。技能、建筑、队友、致盲空挥不计数；全盾吸收的真实命中计数。远程按弹体或持续远程攻击能力分类。场上旧凯隐不变形，已经接受的部署命令也保持接受时形态。

可穿越河流和双方存活建筑、塔、水晶；桥面视为普通地面。仍受战场边界及同层普通单位碰撞约束。完整圆柱进入地形时回复，连续留在或跨越相连地形只触发一次，完整离开后才能重触发。在地形里不能普攻：准备普攻时，在目标攻击范围内检查3圈各16个站位，选挤出距离最小的合法点，当步挤出并开始正常普攻前摇，不主动走向出口。修正距离上限两格（80px），无满足条件的位置则等待，不退回射程外。

## 巨镰横扫（Q）

2金币，6秒冷却，每次部署2次。沿施法开始时的朝向突进120px，持续0.3秒；路径碰撞宽40px，对穿过的每个地面敌人造成90伤害。开始后0.5秒，以自身为中心旋转，半径65px，再造成90伤害。总施法0.7秒。

Q可在地形里使用。突进不推开单位，全程可受伤；突进结束立即恢复通用单位碰撞，Stop/Circle阶段像普通部署单位一样由接触推挤逐步分离，地形仍可进入；旋转在伤害节点按当前位置和当时圈内敌人结算，不因重叠延迟。冰冻取消剩余突进和旋转；眩晕不取消已开始Q；击退接管位置、停止剩余突进，旋转仍按原时间在新位置执行。死亡和清场清除后段。

普攻出口检查固定48个点，复用地面区域与碰撞圆柱数据，计算量随场上单位数量线性增长；不再枚举全场边界交点。攻击圈内缩2px，避免浮点边界导致重新追击。
