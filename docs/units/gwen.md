# 格温

[← 返回总索引](README.md)

**逐剪受控：**眩晕、击退不取消已经开始的技能，每剪按当时位置结算。冰冻取消剩余剪击与范围；已结算伤害和首次命中的回血保留，命中前被取消则不回血，解冻不续剪。

## 总览

适合对付高生命目标的近战单位。普攻和每次剪切都会附加生命比例伤害；普攻积攒层数后，主动技能能在同一段动作里剪更多次。

## 被动与特殊规则

**附加伤害：**普攻及每次有效剪切额外造成目标最大生命的 5%；对防御塔、水晶改为固定 20。携带快刀乱剪时，每次普攻命中增加 1 层充能，上限 3 层。

## 主动技能

备战时从快刀乱剪与丝缕缠流中选择携带一个；携带丝缕缠流时不显示Q充能。

### 快刀乱剪

作用目标：地面敌人。

普通攻击命中充能，最多 3 层；必定先剪 40 点、最后剪 60 点，每层充能在中间追加一次 20 点剪切。每剪附带被动，中央仅提升基础伤害；满层时首次实际命中立即回复 100 点生命值；每次施法只回复一次，未命中不回复。

### 丝缕缠流

| 项目 | 当前数值 |
| --- | --- |
| 每次费用 | 1金币 |
| 最多使用 | 2次 |
| 冷却 | 8秒 |
| 结界半径 | 120（3格） |
| 持续时间 | 4秒（80个权威Tick） |
| 动作 | Spell2，0.8秒，只锁普攻 |

开始时以格温中心建立固定圣霭结界，不移动、不扩缩。格温中心走出边界后立即消失，回到原处不会恢复。中心恰好在边界仍算圈内。

对结界外的敌方单位，格温不可选取：不能成为新目标，已有锁定脱离，拒绝新的直接/范围伤害、控制、减益及其他敌方效果。圈内敌方单位正常交互，从外面进入后立即恢复新选取与命中资格。已失去追踪资格的旧弹体永久失效；非追踪弹体跳过格温继续飞行。

已经附着的控制、减益、增益继续计时并生效；不净化、不抑制已有状态，友方治疗/护盾正常。结界不授予控制免疫、隐身或碰撞豁免。法术卡的释放者是施法方水晶，按水晶中心判断圈内外，落点仅决定覆盖范围；独立技能/弹体保留原来源，不能把飞到圈内的弹体位置当作施法者位置。
