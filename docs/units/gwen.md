# 格温

[← 返回总索引](README.md)

## 总览

适合对付高生命目标的近战单位。普攻和每次剪切都会附加生命比例伤害；普攻积攒层数后，主动技能能在同一段动作里剪更多次。

## 被动与特殊规则

**附加伤害：**普攻及每次有效剪切额外造成目标最大生命的 5%；对防御塔、水晶改为固定 20。携带快刀乱剪时，每次普攻命中增加 1 层充能，上限 3 层。

## 主动技能

### 快刀乱剪

作用目标：地面敌人。

普通攻击命中充能，最多 3 层；必定先剪 40 点、最后剪 60 点，每层充能在中间追加一次 20 点剪切。每剪附带被动，中央仅提升基础伤害；满层且本次技能实际命中时，结束回复 100 点生命值。
