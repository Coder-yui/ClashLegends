# 峡谷迅捷蟹

[返回单位索引](README.md) · [虚空迅捷蟹](void_scuttle_crab.md)

2金币的中体型地面承伤单位，只追逐敌方建筑，不发动普攻。

| 项目 | 当前数值 |
| --- | --- |
| 费用 / 数量 | 2金币 / 1只 |
| 生命 | 550 |
| 移速 / 身体半径 | 60像素每秒 / 18像素 |
| 停驻距离 | 建筑身体边缘外32像素 |
| 普攻 | 禁用，不造成伤害 |
| 部署时间 | 通用1秒 |

## 被动

到达敌方建筑前停下跳舞，每秒回复30生命，最多恢复至最大生命。眩晕、冰冻、凝滞、击退及锁攻击的施法期间暂停，建筑失效或离开距离后继续追逐。它仍是地面单位，需要经过桥梁。

真实死亡后先原地沉没，完成触角入地与祭坛展开后（死亡第4.8秒）在死亡位置生成半径110像素的区域，持续6秒，每秒回复范围内友方普通单位25生命，对空军有效，对敌人、建筑卡、防御塔和水晶无效。按身体与区域接触判断；进入即开始累积治疗，离开不再治疗。每个区域独立结算，重叠区域可叠加。区域独立于死亡来源，凝滞目标不接受治疗；清场/终局取消。

## 谦卑

1金币，最多2次，冷却8秒。立即使周围130像素内敌方单位移速降低40%、攻速降低30%，持续3秒；对地对空，不造成伤害。复用通用减速与减攻速规则，同类取最强，效果抵挡和凝滞遵循公共规则。
