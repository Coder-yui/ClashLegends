# 草间人（建筑卡）

[返回总索引](README.md)

6金币防守建筑，1200生命，稍大体型（半径21），占地3×3格。射程180，视野250，可攻击地面、空中、建筑及防御塔。每个目标每秒60伤害，按实际扣除生命的50%回复自身；护盾吸收与过量伤害不提供回复。

部署时间2秒，播放原版respawn，死亡播放death_effigies。部署完成后自然衰血为每秒24生命，标称50秒，治疗可延长存续；凝滞暂停衰血。持续汲取没有末跳爆发。

主动“巫骇草人”：1金币、每次部署1次、冷却20秒。变为[远古恐惧](fiddlesticks.md)，保留当前生命与实体身份，停止自然衰血，释放建筑占地并允许移动。

每轮开始时锁定射程内全部合法目标，连续汲取2秒，再停0.75秒。目标失效或离开射程即断线，重新进入也须等下一轮。全部断线时提前进入停顿。草间人在停顿时原地等待，部署、攻击、换目标和收势期间始终保持阵营初始朝向。
