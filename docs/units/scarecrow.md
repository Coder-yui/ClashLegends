# 草间人（建筑卡）

[返回总索引](README.md)

6金币防守建筑，1200生命，稍大体型（半径21），占地3×3格。射程180，视野250，可攻击地面、空中、建筑及防御塔。每个目标每秒60伤害，按实际扣除生命的50%回复自身；护盾吸收与过量伤害不提供回复。

部署完成后自然衰血为每秒24生命，标称50秒，治疗可延长存续；凝滞暂停衰血。持续汲取没有末跳爆发。

主动“巫骇草人”：1金币、每次部署1次、冷却20秒。变为[远古恐惧](fiddlesticks.md)，保留当前生命与实体身份，停止自然衰血，释放建筑占地并允许移动。
