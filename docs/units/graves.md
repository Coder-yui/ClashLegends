# 法外狂徒

[← 返回总索引](README.md)

4金币地面霰弹枪手，贴近目标能让更多弹丸命中；射程内的空军也可攻击。弹匣和换弹是基础能力，放在普通槽同样生效。

## 被动与特殊规则

每枪仅消耗一发弹药，生成6颗独立弹丸。弹丸不追踪、不穿透，遇到的第一个敌人挡住该弹丸；友军不挡枪。目标横移可以躲开，前排能保护后排。发射者死亡不会取消已出膛弹丸。

满血时也显示血条。血条左端上方用原版弹壳图显示剩余弹药：两个固定弹位分别显示同尺寸的原版弹壳，有弹时点亮，空位变暗。

两发打完开始换弹，空匣时不能攻击，但可向射程外目标移动。剩一发离开攻击转为移动时也会换弹；敌人进入射程就取消未完成的换弹，使用剩余一发攻击。冰冻、眩晕与凝滞暂停换弹。

每颗命中对质量小于4的敌人施加基础强度12的小幅普通击退，遵循通用质量折算、建筑免疫和落点规则。

## 主动技能：快速拔枪

1金币，最多2次，冷却8秒。沿释放时朝向的反方向滑行3格（120），用时0.4秒；开始时获得1发子弹，最多2发，并取消换弹。不附带伤害或额外防御。

名义终点受阻时，再沿后撤方向寻找最多40＋当前身体半径＋2的距离。基础半径21时最多额外寻找63，找不到合法落点则在障碍前停下。定身禁止起步；冰冻、眩晕、定身或击退中断已开始的滑行。
