# 电击法术

[← 返回总索引](README.md)

中心落下一道闪电，命中范围内所有敌方目标。对空、对地、建筑、防御塔和水晶有效，不影响友军。

| 项目 | 当前数值 |
| --- | --- |
| 费用 | 2金币 |
| 作用半径 | 90 |
| 每次基础伤害 | 55 |
| 基础电击次数 | 1 |
| 电击间隔 | 1秒（20个权威Tick） |
| 眩晕 | 每次0.2秒 |
| 防御塔与水晶 | 伤害保留30%；建筑卡承受全额 |

## 主动技能

多重电击：额外1金币，首次之后1秒在相同范围再电击一次。放入主动槽后随出牌生效，总费用3金币。首击在法术正式执行时发生，后续落点范围固定；伤害仅在最终结算时四舍五入。半径按目标身体边缘相交判定，沿用其他范围法术规则。护盾不阻止眩晕，死亡目标不再施加控制，免控与不可交互目标遵守[状态规则](../status/README.md)。独立追加电击不依赖单位动画，终局或清场取消。
