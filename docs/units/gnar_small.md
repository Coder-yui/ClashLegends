# 小纳尔

[← 返回总索引](README.md)

## 总览

纳尔的初始形态，跑得快，投掷回旋镖，也能攻击空中敌人。命中积累到一定次数后变成大纳尔；两种形态共用同一个单位和技能次数。

## 被动与特殊规则

**变大：**6 次有效命中后变成大纳尔，变形动作占用 1.5 秒。最大生命从 430 增至 820，当前生命增加两者差额 390。主动技能也能让小纳尔直接变大并出手。

## 主动技能

### 怒气爆发

作用目标：地面敌人。

小纳尔先变大再释放前方重击；大纳尔直接释放。命中时造成伤害并眩晕地面敌人。

| 项目 | 当前数值 |
| --- | --- |
| 技能费用 | 2 |
| 最多使用 | 1 次 |
| 冷却 | 8 秒 |
| 基础伤害 | 120 |
| 向前距离 | 140 |
| 区域宽度 | 60 |
| 效果执行延迟（配置） | 0.8 秒 |
| 施法总时长 | 1.2 秒 |
| 眩晕时间 | 1 秒 |

施放期间：不能移动、不能普攻，也不能转向。
