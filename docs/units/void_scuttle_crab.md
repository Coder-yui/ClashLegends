# 虚空迅捷蟹

[返回索引](README.md) · [峡谷迅捷蟹](scuttle_crab.md)

3金币、1只大档碰撞地面坦克，1260生命（参考6费奥恩）、移速60、碰撞半径24、质量7，只以建筑为目标，不进行普通攻击。到建筑边缘外32像素停驻跳舞，每秒回复45生命，受控暂停；满血仍跳舞。

## 死亡治疗与金币

真实死亡后先原地沉没，完成触角入地与祭坛展开后（死亡第4.8秒）留下半径150像素治疗区，持续6秒，每秒为友方普通单位回复25生命。只回血，不加速。地面/空军均有效，建筑、敌人不受益；凝滞中不能接受治疗。按身体与区域接触判定；各圈独立，可重叠，来源死亡不终止，清场取消。

被击杀后给对方玩家2金币，受10金币上限限制；双方规则相同，只有权威端发放一次，通过既有金币快照同步。清场移除不发奖励。

## 归于虚空

1金币，1次，冷却10秒。立即自尽，仍留下治疗区，不给对方金币。自尽直接结束生命，不以伤害实现，所以护盾不能阻止；仍须满足通用主动施法资格，受控时不能绕过规则。AI在低于等于25%生命且附近有敌人时考虑施放。
