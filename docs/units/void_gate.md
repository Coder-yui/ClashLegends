# 兹若特传送门

[返回总索引](README.md) · [关联虚空兽](void_spawn.md)

6金币召唤建筑，不移动、不攻击。占地3×3格，中心落在格心，身体半径30像素，生命900。部署1.7秒，完成部署生成1只虚空兽，之后每6秒生成1只；召唤物复用已有单只虚空兽的166生命、76移速与240牺牲攻城伤害，不继承虚空强化主动资格。

部署后存续60秒，每秒自然衰减15生命；受伤可提前摧毁。冻结、眩晕、凝滞期间到期召唤等待，解除后只生成一批，从这次生成重新计算6秒，不积攒多批。召唤从建筑靠地图外侧的合法位置生成，通用落点校验处理阻挡。

## 主动：虚空迸发

消耗1金币，每次部署1次，冷却10秒。效果执行时传送门立即死亡、释放占地，然后生成2只虚空兽。普通受伤死亡和寿命结束不额外出兽。生成仍由主机权威统一处理，死亡动画不会触发第二次召唤。

生命值900为设计补齐值；占地与碰撞按当前尺寸调整，模型等比缩放到地面宽深约118×120像素，匹配每格40像素的3×3占地。
