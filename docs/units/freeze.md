# 冰冻

[← 返回总索引](README.md)

## 总览

全图选点的范围控制法术，冻结落点附近的敌人。放入主动槽后，冻结结束时还会留下短暂的减速区域。

[查看卡面原画](../../assets/cards/freeze_loading.png)

## 数值

| 项目 | 当前数值 |
| --- | --- |
| 费用 | 3 |
| 施放位置 | 全图选点 |
| 作用半径 | 110.0 |
| 冻结时间 | 3 秒 |
| 强化额外费用 | 0 |
| 强化后减速区域 | 冻结结束后持续 2 秒，移速降到 50% |
