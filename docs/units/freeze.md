# 冰冻

[← 返回总索引](README.md)

## 总览

全图选点的范围控制法术，冻结落点附近的敌方单位、建筑卡和防御塔，水晶免疫。放入主动槽后，冻结结束时还会留下短暂的移速与攻速降低区域。

[查看卡面原画](../../assets/cards/freeze_loading.png)

## 数值

| 项目 | 当前数值 |
| --- | --- |
| 费用 | 3 |
| 施放位置 | 全图选点 |
| 作用半径 | 110.0 |
| 目标 | 敌方地面/空中单位、建筑卡、防御塔；水晶免疫 |
| 冻结时间 | 3 秒 |
| 强化额外费用 | 0 |
| 强化后减速区域 | 冻结结束后持续 2 秒，移速与攻速各降低 30%（保留 70%） |
