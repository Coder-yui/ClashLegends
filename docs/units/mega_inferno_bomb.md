# 终极爆弹

[← 返回总索引](README.md)

6费重型伤害法术，从己方水晶抛向固定落点，抵达时查询范围内敌人。普通槽与主动槽均为6费。

| 项目 | 数值与规则 |
| --- | --- |
| 外圈 | 半径160px，4格；360伤害 |
| 中心 | 半径80px，2格；600伤害，中心优先，身体圆接触即命中 |
| 飞行 | 700px/s，至少0.8秒，20Hz向上取整；另有公共0.5秒出牌延迟 |
| 目标 | 敌方地面、空军、建筑卡、防御塔、水晶；友方不受影响 |
| 塔与水晶 | 30%伤害，中心180、外围108；建筑卡全额 |
| 地狱火炮 | 主动槽强化，无额外费用，每次法术生效一次；先清普通伤害盾，再结算伤害 |
| 重伤 | 强化命中的非建筑单位持续至死亡不能回血，无持续时间，包括治疗、吸血、恢复盾回血和过量治疗转盾；最大生命提升不受影响 |

重伤无倒计时，重复施加不叠加；死亡清除，普通变形与有时限Buff清理不移除。伤害同批提交时先清护盾，再结算全批伤害；清盾不产生伤害或吸血收益，不触发自然到期爆炸/治疗。重伤在扣血后、同批治疗收益前建立。梦魇效果护盾可抵挡整次法术，普通盾不被移除；凝滞拒绝整次效果。建筑可破盾但不受重伤，原有复活/重生不作为治疗。

重伤以红色爱心加灰黑色叉显示在血条右侧，位置取基础条与实际扩展条的较右端，兼容护盾及吸血溢出。
