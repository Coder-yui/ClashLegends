# 虚空鱼

[← 返回总索引](README.md)

## 总览

卑尔维斯死亡时召唤的小型空中近战单位，不能单独编入卡组；可攻击地面、空中单位和建筑。生命与伤害略低于远程兵。

## 被动与特殊规则

无独立被动或主动技能。召唤与死亡都由权威战场处理。

## 主动技能

无。
