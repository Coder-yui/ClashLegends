# 熔岩巨兽

[返回总索引](README.md)

7金币大型慢速近战坦克，攻击地面单位与建筑。花岗岩护盾提高初始承伤能力，主动拍地压制周围地面敌人。

| 项目 | 数值 |
| --- | --- |
| 生命 / 部署护盾 | 1600 / 400 |
| 普攻伤害 / 间隔 / 前摇 | 120 / 1.8秒 / 0.82秒 |
| 攻击距离 / 身体半径 | 32像素 / 24像素（大） |
| 移动 / 部署 | 44像素每秒（慢速地面）/ 1秒；遵守桥梁与碰撞规则 |

## 花岗岩护盾

部署时获得400点无自然到期护盾，花岗岩护盾存在时，受到的伤害降低50%。先减伤再吸收，破盾当次溢出伤害仍采用该次减伤；下次受击恢复正常。其他来源护盾不能维持或恢复此减伤。盾不再生；多个减伤来源取最强，不相加。

## 大地震颤

1金币、2次、冷却8秒。施法锁定移动、攻击和朝向0.65秒，第0.25秒结算：对自身周围160像素圆形范围内地面敌人造成160伤害；单位降低30%移速、70%攻速，持续2秒。建筑可受伤，但不赋予减攻速。边界计入目标身体半径，不伤友军或空军。

技能3D特效保持原生三维比例，不按俯视镜头拉伸或压平；权威伤害始终由2D圆形距离判定。
