# 赏金猎人

[← 返回总索引](README.md)

## 总览

可以对空的双枪射手。对每个敌人的第一次普攻更痛，持续攻击同一个目标不会重复获得这次加成；主动技能短暂提高移动与攻击速度。

## 被动与特殊规则

**首次攻击：**对每个目标的首次普攻造成 150% 伤害，当前为 93。再次攻击同一目标没有这项加成。
