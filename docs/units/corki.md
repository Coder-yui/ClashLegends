# 库奇

[← 返回总索引](README.md)

## 总览

4金币空中远程后排，单次部署1架飞机，对地对空。生命低于4费麦林炮手（440），依靠飞行和射程持续输出。

## 数值

| 项目 | 当前数值 |
| --- | --- |
| 费用 / 数量 | 4金币 / 1 |
| 生命 | 360 |
| 普攻伤害 / 间隔 | 80 / 1.2秒 |
| 射程 / 目标 | 190像素 / 地面与空中 |
| 移速 / 体型 / 身体半径 | 中（60像素/秒）/ 中 / 18像素 |
| 普攻弹速 / 前摇 | 580像素/秒 / 0.14秒（20Hz第3Tick发射） |
| 部署 | 公共0.5秒命令等待，再1秒部署 |

## 被动与特殊规则

无额外被动。飞行遵循通用空军移动与索敌规则，模型高度不改变碰撞半径。

## 主动技能：火箭轰击

每次1金币，共3次，冷却3秒。朝当前正前方发射非追踪导弹，从身体边缘起最多飞行300像素，速度500像素/秒。首个合法敌人（地面、空中、建筑或塔）拦截，爆炸中心为真实碰撞点，55像素范围对地对空，包含与范围相交的身体圆。前两枚各100伤害，第三枚180伤害（1.8倍），不重复伤害直接碰撞者。友军不拦截、不受伤；凝滞目标不拦截、不受伤。到最大距离未命中直接消失，不爆炸。

施法0.5秒，释放节点0.13秒（第3Tick）；施法锁移动、普攻和朝向。请求时扣费，真正开始时扣次数与启动冷却。已发导弹独立于施法者存活，出手后的目标移动不会改变方向。再次部署拥有新的3次资格；旧单位遵循通用主动槽替换规则。

工作台技能按钮按普通、普通、超级循环预览；不扣正式对局金币与次数。
