# 未来守护者·远程

[返回总索引](README.md) · [另一形态](jayce_hammer.md)

杰斯是4费中体型双形态战士，单次部署1个，以远程形态入场。双方使用同一原版基础皮肤模型。

| 项目 | 远程 | 战锤 |
| --- | --- | --- |
| 生命 | 650 | 650 |
| 普攻伤害 | 65 | 80 |
| 攻击间隔 | 1.4秒 | 1.1秒 |
| 攻击距离 | 180像素（4.5格） | 32像素（0.8格） |
| 攻击目标 | 地面、空中、建筑 | 地面、建筑 |

| 身体半径 | 18像素 | 18像素 |

## 被动：墨丘利变形

从生成开始计时，每8秒尝试换形。到时打断当前普攻前摇或后摇并清空攻击冷却；冰冻、眩晕、击退、凝滞期间延后，控制结束后立即换形。部署及已有转换/施法锁仍遵循通用资格。实际切换后重新计8秒，不积攒多个换形。形态与武器姿态瞬时切换，生命与单位身份保留；不影响移动，切换同一Tick即可开始新普攻前摇，不继承旧攻击冷却。声光表现独立保留0.3秒发射窗口与粒子尾迹，不阻塞攻击；跑步姿态与步态相位持续。

部署后的第一次攻击也带炮形态首击：额外40固定伤害。切换为战锤后的首击对主目标额外造成其最大生命值8%的伤害，对防御塔、水晶和建筑改为60固定伤害。普攻不再对邻近目标造成伤害。加成在正式出手消费，前摇被打断则保留，致盲落空仍消费；在途弹体保持出手时的形态与加成。

## 主动：超能电荷 / 闪电领域

费用1，使用2次，共享冷却10秒。按钮为两种原版W图标沿对角线各半的圆形组合；水晶上提示本次实际释放形态的单独图标，后续换形不改变该提示。释放时依据当前形态决定效果，换形不清除已经获得的效果。

- 炮形态：4秒内接下来3次普攻为3倍攻速，前摇和间隔同比加快；每次正式出手消费一次，次数耗尽后保留末击后摇加速，但最多到施放后的第80个权威Tick。控制期间继续计时，到期清除未用次数并恢复攻速。与普通攻速增益取最高倍率，减攻速仍有效。
- 锤形态：开启4秒随身电场，半径95像素，每0.5秒对范围内敌军造成10伤害，总计8跳80伤害；可以移动与普攻，不附带治疗。范围判定含目标身体半径。该数值由本轮用户确认。
- 两种效果独立存在，换形不会重置持续时间或剩余次数。电场随单位移动，死亡后结束；冻结不取消已开启的电场。炮强化重复释放刷新为3次和4秒，不累加。
