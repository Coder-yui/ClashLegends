# 墓碑

[← 返回总索引](README.md)

## 总览

不会直接攻击的召唤建筑，周期性生成小鬼，被摧毁时还会留下小鬼。主动技能可以立即再召唤一批。

[查看卡面原画](../../assets/cards/tombstone_loading.png)

## 数值

| 项目 | 当前数值 |
| --- | --- |
| 出牌费用 | 3 |
| 生命 | 400 |
| 攻击 | 不攻击 |
| 移动速度 | 不移动 |
| 身体半径 | 40 |
| 建筑占地 | 3 × 3 格 |
| 部署时间 | 1 秒 |

距离采用游戏内统一单位；一格为 40。表中为基础值，技能增益另列。

## 被动与特殊规则

**召唤：**每 5 秒产生 2 只小鬼；被摧毁时再产生 2 只。建筑寿命 10 秒，护盾不能延长自然寿命。

## 主动技能

### 亡者集结

在身边立即召唤一批小鬼。
