# 爆破酒桶

[← 返回总索引](README.md)

抛出酒桶，在固定圆形落点爆炸，伤害敌军并从爆心向四周小幅击退。范围比[电击法术](zap.md)稍大，对地面、空中、建筑、防御塔与水晶有效，不影响友军。

| --- | --- |
| 出牌费用 | 3金币 |
| 作用半径 | 105（电击为90） |
| 基础伤害 | 180 |
| 击退距离 / 时间 | 基准40 / 0.2秒；按质量乘0.35～1.4，受地形阻挡 |
| 飞行速度 / 最短飞行 | 900像素/秒 / 0.4秒，向上取整至20Hz Tick |
| 防御塔与水晶 | 承受30%伤害，普通54、强化81；建筑卡承受全额 |

## 主动技能

烈性火药：额外1金币，伤害提高到270，范围与击退不变。放入主动槽后随出牌生效，总费用4金币；没有独立二次施放按钮。技能图标使用酒桶原版R图标；卡面使用本次生成的阳光草地酒桶爆炸插画。

## 命中与击退规则

公共0.5秒出牌延迟结束后，从己方水晶向固定落点飞行；抵达时重新查询目标，以范围和目标身体边缘相交判定。飞行不追踪、不碰撞，伤害只结算一次；动画不决定抵达时刻。建筑卡、防御塔与水晶不被推动；凝滞与来源保护按公共准入规则拒绝伤害/位移。护盾全额吸收仍可击退，已死亡目标不推动。爆心重合时沿目标阵营默认前进方向推出。质量较大者位移较小。

击退家族使用[通用击退规则](../status/HARD_CONTROL.md)：新合法位移接管旧轨迹，停止自主移动并打断普攻；不新增眩晕。效果由本次法术独立持有，来源后续死亡不撤回，暂停停止推进，终局与清场取消未抵达结果。
