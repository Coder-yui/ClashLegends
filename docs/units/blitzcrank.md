# 蒸汽机器人

3费地面近战单位，部署1只，中体型（半径18像素）。生命560、攻击70、攻击间隔1.6秒、普攻距离1.4格（56像素）、视野5.5格（220像素）、移动速度60像素/秒；只能攻击地面目标。距离按双方碰撞体边缘计算。

机械飞爪近身优先：1.4格内普攻，超过1.4格但不足2格追击；没有这种近身目标时，锁定2～4.5格内最近的可牵引敌方地面单位，停步瞄准1秒。建筑只参与普通攻击和追击，不被牵引。瞄准期间跟随目标朝向，不因出现更近敌人换目标；原目标进入普攻范围则结束瞄准。目标超过5.5格、死亡、凝滞、不可选中或无法被牵引时取消瞄准，重新决策，下次从零计时。眩晕、冰冻、凝滞或外部位移会打断瞄准，禁锢和减速不打断。

出钩后为独立技能结果，不再检查5.5格距离，不受机器人后续控制、位移或死亡影响。飞行0.3秒后拉取，基础回程0.3秒；落点以出钩时机器人位置为准，保留双方半径及0.7格间距，身前预定落点合法时优先使用；不合法则以固定出手位置为中心，寻找最近合法落点，允许改变拉取方向。搜索半径为双方半径＋0.7格间距＋额外1格，附近无解时回退到原直线策略，允许退选远处桥面。普通单位重叠沿用自然分离。选定后由通用直线强制位移执行，不改变其落点规则；基础回程0.3秒，修正距离增加时相应延长。目标死亡、凝滞、不可选中或牵引免疫会使钩子失效，效果护盾与来源保护遵循统一技能准入。不造成额外伤害，不按质量缩短。

飞爪没有独立冷却，不等待普攻冷却；瞄准及拉取动作沿用通用施法锁对普攻周期的处理，不建立机器人专用冷却规则，拉回结束也不额外刷新。拉回后按攻击距离及控制状态恢复普攻，仍需正常攻击前摇。

能量铁拳：1费、2次、冷却7秒。刷新普攻，下一次攻击造成105点伤害（1.5倍），真实命中敌方单位后眩晕1秒；不击飞。被闪避或取消的攻击不会伪造眩晕。自身瞄准或牵引动作未结束时不能开始新的主动技能。
