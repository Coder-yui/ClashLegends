# 麦林炮手

[← 返回总索引](README.md)

4金币长射程地面远程射手，单发炮弹可攻击地面、空中和建筑。体型稍小，模型在同档中偏饱满；蓝红共用指定模型。

| 普攻伤害 / 间隔 / 前摇 | 76 / 1秒 / 0.12秒 |
| 射程 / 视野 | 220（5.5格）/ 260 |

## 急速射击

2金币，每次部署可用2次，冷却12秒。生效后持续5秒，攻速提高60%，间隔缩短至0.625秒，前摇缩短至0.075秒；伤害、射程和弹速不变。0.25秒施法窗口不锁移动或普攻。没有额外被动、溅射、炸弹或跳跃。

## 效果定义

| 项目 | 规则 |
| --- | --- |
| 身份 / 目标 | tristana的主动攻速Buff，只作用于本单位 |
| 权限 | 不改变移动、转向、外力或受击准入；不能解除控制 |
| 计时 / 结束 | 权威20Hz推进；5秒到期、死亡和清场释放，暂停停止计时 |
| 叠加 / 抑制 | 沿用[增益规则](../status/BUFFS.md)：同类取最强，凝滞抑制贡献但不延寿；正常冷却长于持续时间 |
| 消费 | 请求时扣金币；正式开始扣次数并启动冷却，取消退款沿用[动作合同](../status/ACTIONS.md) |
| 表现所有者 | 通用模型代理读取Buff状态，炮口特效只跟随骨骼；声音管理器负责Q启停 |
| 实现 | CardDB四域定义、通用Unit/ActiveSkillEffectSystem与既有快照；不新增网络字段 |
