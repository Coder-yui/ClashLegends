# 尖端炮台

[← 返回总索引](README.md)

## 总览

只能攻击地面的防守建筑。普通炮弹会溅射周围敌人，还能额外释放穿透激光；有寿命限制，受到攻击可能更早被摧毁。

## 被动与特殊规则

**限时建筑：**寿命 45 秒，生命随时间衰减，额外伤害会使其更早死亡。普通炮弹的溅射半径为 32。

## 主动技能

### 海克斯穿透激光

作用目标：地面敌人。

沿当前朝向发射一枚可穿透的激光弹，对 270（6.75 格）长路径上的所有地面敌人造成 240 点伤害。
