# 扭曲空间

[返回单位索引](README.md)

2金币控制法术。短暂延迟后建立圆形空间，敌军接触边界时眩晕，单纯站在圈内不会触发。

| 项目 | 数值与规则 |
| --- | --- |
| 费用 | 普通槽2金币；主动槽额外2金币，共4金币 |
| 释放区域 | 全场合法格心，忽略建筑占位 |
| 半径 | 120像素（3格），身体圆接触圆周即可触发 |
| 成形延迟 | 公共0.5秒出牌延迟后再等待0.75秒（15Tick） |
| 有效时间 | 成形后3秒（60Tick），到期Tick不再新增命中 |
| 控制 | 敌方地面及空中普通单位眩晕1.5秒；不会对建筑卡、防御塔和水晶造成眩晕；友军不受边界影响 |
| 次数 | 每次施法每目标最多一次；不同空间独立 |

本卡主动设定：空间边界不会对建筑造成眩晕；这项限制只针对扭曲空间的边界控制，不代表建筑普遍免疫眩晕，也不限制黑暗物质对建筑造成伤害。

## 黑暗物质

主动槽随法术生效，无独立二次施放按钮。首个成功眩晕的位置在1.2秒（24Tick）后落下黑暗物质，半径65像素（1.625格），造成220伤害；敌方空军、地面和建筑卡承受全额，防御塔与水晶承受66伤害。每次空间只触发一次，没有成功眩晕则不触发。同一Tick多个目标按出生身份排序。

落点锁定后不追踪目标，落地重新查询范围。空间结束、触发目标死亡或移开不取消已创建的黑暗物质；暂停冻结权威时钟，终局和清场取消所有待发生结果。

## 交互与表现

边界使用相邻有效Tick的运动线段和身体圆扫掠，防止高速穿越漏判。成形前不累计轨迹；成形瞬间仅检测当时接触。凝滞、不可选中、来源保护和免控遵循通用准入。法术盾消耗并抵挡该次空间接触，之后同一空间不再重试；被抵挡不触发黑暗物质。黑暗物质为独立伤害结果，可被独立法术盾抵挡。

客户端只接收可靠法术事件及单位状态快照，不创建权威区域或计算控制伤害。眩晕复用通用状态提示，不额外实现专属头顶眩晕粒子。
