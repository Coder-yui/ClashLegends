# 赛恩

[返回总索引](README.md) · [狂暴形态](sion_berserk.md)

8费大型推进坦克，常态只攻击建筑。首次生命归零后保留实体，经过2秒复生为满血狂暴形态。

| 项目 | 数值 |
| --- | --- |
| 费用 / 生命 | 8 / 2400 |
| 普攻伤害 / 间隔 / 前摇 | 180 / 1.8秒 / 0.36秒 |
| 表面攻击距离 / 视野 | 40 / 240 |
| 移速 / 身体半径 / 质量 | 44（慢）/ 27（极大）/ 12 |
| 部署时间 / 目标 | 1秒 / 建筑 |

## 被动：死亡荣耀

每个实例只触发一次。生命归零后2秒内，敌我双方均不能选取、命中、治疗、加盾或施加增益；已有附着伤害也不在此窗口造成伤害。赛恩不能自主移动、攻击或施法。护盾与未完成施法清除，已释放的独立结果保持原生命周期。2秒后满血进入[狂暴形态](sion_berserk.md)，不更换实体或部署身份。

## 主动：灵魂熔炉

1金币，8秒冷却，最多2次。立即获得400点独立护盾；2秒后若该层护盾仍有生命，则消除剩余护盾并在自身周围110半径内造成240伤害，可以命中地面、空中和建筑。若护盾提前被打破、清除或赛恩进入复生，则不爆炸；其他护盾不能替代资格。爆炸以当时位置为中心，与目标身体圆相交即可命中。复生和狂暴阶段均禁止使用。

## 效果定义

| 维度 | 规则 |
| --- | --- |
| 身份与来源 | 一次性致死换形；自身独立爆炸盾 |
| 时序 | 20Hz；复生40Tick、护盾40Tick；刚创建不扣时 |
| 交互 | 复生全阵营隔离，不等同格温的来源条件结界；复生完毕恢复交互 |
| 结束与继承 | 护盾破裂/清除无爆炸；狂暴死亡最终退出；暂停停止模拟 |
| 消费者与验证 | DeathFormState、ShieldState、通用Unit、技能系统；SionSuite及网络生命周期套件 |

[动画](animations/sion.md) · [音频](audio/sion.md) · [特效](effects/sion.md)

首次致死立即清除上一条命的冰冻/眩晕，模型从当时姿势直接混合到复生动作。2秒等待期间血条按复生进度从0逐渐填满；这是表现进度，真实生命仍为0，敌我双方均不可选取，结束时才恢复满血。

部署时间为2秒。
