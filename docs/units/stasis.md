# 凝滞法术

[← 返回总索引](README.md)

从使用方水晶射出金色星光，在抵达时使落点范围内双方单位凝滞。既能保护友军，也会暂时停止友军进攻。

| 项目 | 当前数值 |
| --- | --- |
| 费用 | 3金币 |
| 作用半径 | 110（2.75格），与目标身体边缘相交即命中 |
| 普通凝滞 | 双方3秒（60个权威Tick） |
| 飞行 | 公用0.5秒下牌延迟后，以900像素/秒飞行，至少0.4秒，向上取整到20Hz Tick |
| 对象 | 地面单位、空中单位、建筑卡及双方防御塔；水晶免疫 |
| 伤害 | 无 |

## 主动技能

友军优待：0金币；放在主动槽时随出牌生效，总费用仍为3金币。范围内友方凝滞2秒（40Tick），敌方仍为3秒。法术不生成场上技能按钮。

## 特殊规则

抵达时一次性查询范围，之后进圈者不追加凝滞。交互隔离、Buff抑制、永久属性/形态保留、先锋冲撞免疫、旧盾到期特例及退出均遵循[凝滞唯一规则](../status/SPECIAL_STATES.md#凝滞)，本卡不另设版本。

凝滞中新下单位主动避开不可推动占位，遵守原部署范围和地形；普通可移动及冰冻单位仍靠自然碰撞分离。统一规则见[特殊状态](../status/SPECIAL_STATES.md)。

## 动画、声音与特效

金身期间暂时隐藏血条、技能积攒及其他实体附属状态标识；解除按当前值恢复。

无需角色模型；单位复用通用模型冻结与金色材质；防御塔塔身在原有裁切材质内变金并冻结，已脱离碎块保留原色并独立下落，避免显露隐藏碎块/废墟；2D回退实体使用金色填充。巴德基础皮肤R原始粒子定义重建为旋转预警圈、金色弧线星光，以及紫金落地光晕、上升符文、火花和立体光柱。使用120fps离线采样在Godot重播，属于原版数据适配，并非完整移植LoL运行器。
