# 凝滞法术

[← 返回总索引](README.md)

从使用方水晶射出金色星光，在抵达时使落点范围内双方单位凝滞。既能保护友军，也会暂时停止友军进攻。

| 项目 | 当前数值 |
| --- | --- |
| 费用 | 3金币 |
| 作用半径 | 110（2.75格），与目标身体边缘相交即命中 |
| 普通凝滞 | 双方3秒（60个权威Tick） |
| 飞行 | 公用0.5秒下牌延迟后，以900像素/秒飞行，至少0.4秒，向上取整到20Hz Tick |
| 对象 | 地面单位、空中单位、建筑卡及双方防御塔；水晶免疫 |
| 伤害 | 无 |

## 主动技能

友军优待：0金币；放在主动槽时随出牌生效，总费用仍为3金币。范围内友方凝滞2秒（40Tick），敌方仍为3秒。法术不生成场上技能按钮。

## 特殊规则

命中时一次性查询范围，之后进圈者不追加凝滞。凝滞停止行动与外部移动、保留碰撞，拒绝双方选取、伤害、治疗和新状态。不能在凝滞中再次施加以延长时间；已有控制和增益继续计时，已有增益暂停贡献，到期不补发收益。旧普攻及依附施法后段取消，已发出的独立结果保留。建筑自然寿命继续。先锋冲撞阶段免疫双方凝滞。已建立的赛恩护盾仍可到期爆炸，黄沙庇护未破的盾层仍可到期回满；普通治疗和新收益仍被拒绝。永久成长及奥恩永久增幅保留。

凝滞中新下单位主动避开不可推动占位，遵守原部署范围和地形；普通可移动及冰冻单位仍靠自然碰撞分离。统一规则见[特殊状态](../status/SPECIAL_STATES.md)。

## 动画、声音与特效

金身期间暂时隐藏血条、技能积攒及其他实体附属状态标识；解除按当前值恢复。

无需角色模型；单位复用通用模型冻结与金色材质；防御塔在原有裁切材质内变金并冻结动画，避免显露隐藏碎块/废墟；2D回退实体使用金色填充。巴德基础皮肤大招纹理适配为预警圈、金色弧线弹体和落地冲击环，属于Godot表现重建，不是原游戏粒子运行器的完整移植。
