# 训练木桩

[← 返回总索引](README.md)

## 总览

开发工作台里的耐打目标，方便观察单位连续攻击、技能和声音。木桩不会移动或还击，不属于可选卡牌。

## 数值

| 项目 | 当前数值 |
| --- | --- |
| 生命 | 1000000 |
| 攻击 | 不攻击 |
| 移动速度 | 不移动 |
| 身体半径 | 18 |
| 质量（影响推挤与击退） | 1000 |

距离采用游戏内统一单位；一格为 40。表中为基础值，技能增益另列。
