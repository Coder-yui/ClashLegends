# 恕瑞玛卫队

[← 返回总索引](README.md)

六名黄沙士兵一行横排部署，以三段长矛攻击循环作战。属于同一次出牌的成员共享一次主动技能资格，每名士兵独立持有生命与护盾。

## 数值

| 项目 | 当前数值 |
| --- | --- |
| 出牌费用 / 数量 | 7金币 / 6名 |
| 每名生命 / 普攻伤害 | 420 / 60 |
| 攻击间隔 / 首击前摇 | 1.6秒 / 0.4秒 |
| 攻击距离 / 目标 | 1.8格 / 地面单位和建筑，不对空 |

| 初始间距 | 相邻中心2.5格；最后一行中间6格可下牌：1/2号左4右2，3/4号3/3，5/6号左2右4；边缘士兵出生时单独挤回场内 |
| 部署 | 常规命令等待0.5秒，生成后部署1秒；无出生护盾 |

## 黄沙庇护

2金币，每次部署只能使用1次，冷却8秒。给**这一次出牌**仍存活的每名士兵180点护盾，持续2秒。每名士兵独立判定：自然到期时这层护盾仍有剩余，回复至满血；被打破、清除或已经死亡则不回血。其他来源的护盾不能代替这层盾满足条件。

持有技能的成员阵亡后，资格转交同队存活成员。不同次出牌、友军和敌军不共享效果。再出同卡使用现有主动槽替换规则，旧队已经获得的盾仍独立结算。已经生效的护盾沿用现有计时规则，硬控不会延长它。
