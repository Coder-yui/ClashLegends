# 腐蚀法术

[← 返回总索引](README.md)

## 总览

4金币的圆形持续伤害法术。用于消耗聚集的地面与空中敌军，放在主动槽时还能减缓区域内敌军移动。

[查看原创卡面](../../assets/cards/corrosion_loading.png)

## 数值

| 项目 | 当前数值 |
| --- | --- |
| 出牌费用 | 4金币 |
| 施放位置 | 全图选点，公共出牌延迟0.5秒 |
| 作用半径 | 110像素（2.75格），按目标身体边缘接触判定 |
| 持续时间 | 5秒 |
| 每次伤害 | 60；每0.5秒一次，10次共600（平均每秒120） |
| 目标 | 敌方地面、空中单位、建筑卡、防御塔和水晶；单位及建筑卡承受全额伤害；防御塔/水晶仅30%，每跳18、总计180 |
| 强化额外费用 | 0金币 |

## 主动技能：强化腐蚀

放入主动槽时随法术出牌自动强化，区域内可移动敌军移动速度降低20%，不降低攻击速度；静止建筑只承受伤害。无需额外点击技能按钮；每次出牌自动使用本次强化。技能定义为1次、0秒冷却、0金币，不创建单位主动技能实例。

## 区域与状态规则

| 项目 | 规则 |
| --- | --- |
| 身份与来源 | 每次施法独立区域，来源阵营的水晶提供法术交互上下文 |
| 时序 | 20Hz；施放当Tick不扣未来伤害，在0.5、1、1.5、2、2.5、3、3.5、4、4.5、5秒各结算60伤害，共10次 |
| 进出范围 | 每Tick检测入圈减速；伤害节点查询圈内目标，离圈不受伤，重新进入不补伤 |
| 减速 | 施法时圈内立即减速；后续入圈在下个20Hz检测Tick施加，不等待伤害节点；区域内续期0.1秒通用减速；离开后最多0.1秒消失；外力、攻击与技能时长不受影响 |
| 叠加 | 多个区域独立伤害；移动减速按当前最强来源取值 |
| 交互 | 凝滞与来源保护按通用准入拒绝伤害和新状态；拒绝期间不积攒补伤 |
| 结束 | 独立5秒结果，不依赖单位动作；清场、终局取消剩余区域与声音 |

总伤害600，以完整覆盖可击杀未受保护的4金币后排为基准：图奇420、麦林炮手440、卡牌大师/璐璐460、龙王580生命值。半径110保持不变。
