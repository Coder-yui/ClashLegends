# 剑魔·大灭

[← 返回剑魔](aatrox.md) · [总索引](README.md)

## 数值与变化

最大生命1350，开启时增加300当前生命并获得1秒30%移速；普攻88、射程1.6格、攻击间隔1.1秒和稍大体型不变。长出翅膀并成为空中单位，可攻击地面和空中目标；飞行高度使用全项目统一表现规则。

## 攻击与回复

开启后下一次攻击立即使用被动，然后循环：强化一刀 → 强化二刀 → 被动。被动仍附加目标最大生命10%的伤害，防御塔和水晶改为固定20点。

被动前摇0.4秒，普通攻击前摇0.25秒，连续命中间隔仍为1.1秒，随攻速缩放。

普通攻击按实际生命伤害吸血20%，被动整刀吸血50%。这些比例不再乘以1.2，也不放大友方治疗；护盾和过量伤害不吸血。

## 持续时间与击杀

起手1秒结束后持续5秒；起手和收翼受硬控时暂停，持续阶段冰冻和眩晕不延长计时。击杀敌方Unit（含建筑卡）刷新为5秒，刷新1秒30%加速，并让下一次攻击重新从被动开始；不重复增加最大或当前生命；塔和水晶不刷新。共同致死沿用项目既有实际掉血归属规则：有实际掉血贡献的存活来源获得一次击杀收益。

到期瞬间恢复地面形态与1050生命上限，播放0.73秒收翼；起手和收翼均可移动、不能攻击。当前生命超过1050时截到1050，否则保留。若正在河道或其他非法地面位置，权威端复用最近合法地面修正；客户端接收最终形态和位置，不自行决定落点。
