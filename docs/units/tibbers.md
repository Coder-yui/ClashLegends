# 提伯斯

[单位索引](README.md) · [空投熊](airdrop_bear.md) · [动画](animations/tibbers.md) · [音频](audio/tibbers.md) · [特效](effects/airdrop_bear.md)

空投熊的地面近战衍生单位，不加入可选卡池，可在工作台单独放置。单独放置使用普通形态；强化效果通过强化空投熊生成。

| 属性 | 当前值 |
| --- | --- |
| 生命 | 1000 |
| 普攻伤害 | 100 |
| 攻击间隔 / 前摇 | 1.2秒 / 0.3秒 |
| 移速 | 60像素/秒 |
| 体型 / 碰撞半径 | 大 / 24像素 |
| 质量 / 视野 | 4 / 220像素 |
| 出生部署 | 0秒，落地立即行动；不播放出生动画 |
| 自然寿命 | 无；存活至被击败或清场 |

普攻不能攻击空中单位；强化火圈可以。5秒攻速加成期间攻击间隔为0.8秒，前摇为0.2秒。控制、伤害、移动和碰撞均使用通用Unit。模型和动作不驱动结算。

卡面使用用户在项目3D摄影棚拍摄并确认的照片，原图按308×560规格直接接入。
