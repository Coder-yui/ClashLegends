# 时间刺客特效

[返回时间刺客](../ekko.md)

大招使用基础皮肤原版资源；持续影子与路径标记按本机观察阵营选色：己方使用 `TrailEnd` / `RewindIndicator`，敌方使用原始 `TrailEnd_Red` / `RewindIndicator_Red`。切换到红方观察时，权威队伍不变，己敌配色随观察阵营交换。持续影子以20Hz只读表现记录重放4秒前的位置、朝向与骨骼姿态；不足4秒取最早样本。使用所选原版系统的角色材质、电弧、地面光和头顶标记，RewindIndicator保留各自路径颜色、纹理、数字碎片与标记，TimeDevice_Active跟随背包装置挂点。

施法按0.25秒起手、0.5秒回卷组织。回卷期间在目的地播放AOERing（end）；0.75秒落地后播放Tar，真实命中回执触发Tar_Impact。回卷按顺序使用RewindPose1～6；持续历史影子不再额外生成TrailEndPose1白色姿态。原始ChargeIndicator无发射器，不伪造粒子。

角色包装1.48，与剑圣视觉高度接近。伤害半径固定140像素，AOERing、Tar及消失范围层采用140/40/375=0.009333333的三轴比例；人物随身层、命中附着与六套回卷姿态保持模型校准0.01345，避免范围调整缩小人物身影。装饰光晕和碎片可以超出伤害边界。

影子、路径、动作和音频不驱动权威回溯、伤害或治疗。角色死亡、取消、技能消耗及场景清理会停止对应表现。固定落地及命中由可靠表现事件驱动；客户端历史从已收到的表现开始记录，不新增快照字段。

本地原纹理、网格、粒子采样、材质混合与深度标志记录于assets/effects/ekko/source_manifest.json。现有源包没有服务器施法脚本，阶段编排结合本地0.25秒起手参数与Riot官方技能视频的回卷/落地顺序；不将跨引擎重建声称为LoL客户端逐帧一致。

附着角色的8个源发射器均未配置reflection；运行着色器只使用源贴图与颜色，不执行额外视角Fresnel计算。该计算曾使特定朝向的影子发白，已通过同一姿态逐层渲染对照修正。影子网格标记为presentation_fx，避免被通用受击／控制材质收集。原版未提供红版的回卷姿态、装置与落地层保留其原色，不将全套特效强行染为纯蓝／纯红。

连接线使用完整源采样窗口映射当前运动历史，范围止于4秒前影子，不再每4秒重置到起始采样。按源半宽、逐点UV变换、WAKE累计路程和纯加法混合绘制；原版参数与项目历史窗口适配分开处理。六套回溯Pose在0.75秒落地边界停止，避免回卷阶段继续生成身影。

落地紫色电纹来自 `end/Avatar`。之前仅凭资源存在将其持续绑定本体，不能证明原版实际调用；结合官方演示，已撤销落地本体Buff接入，播放器也不为end创建附着材质。源采样数据保留用于追溯。AOERing与Tar分阶段播放，不再落地同时叠加两套系统。

原版表现参考：[Riot艾克英雄页](https://www.leagueoflegends.com/en-us/champions/ekko/)。本地保存的官方R演示可见先目的地圆环、后落地爆发，再恢复移动；视频帧用于核对表现顺序，不声称获得原版服务器脚本。

治疗在施法开始的权威事件执行，落地只结算位移与伤害，不再次治疗；表现不驱动治疗与伤害。

仅携带主动技能的实例创建影子、连接线、装置和骨骼历史；普通槽不创建这些节点，也不请求R资源预热。主动资格使用既有同步身份，工作台允许技能预览并遵守无技能样本标记。失去主动资格后清理已创建表现。
