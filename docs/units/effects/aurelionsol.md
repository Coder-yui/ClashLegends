## 画面中会出现什么

普攻只伤害当前锁定目标，周围喷流和散射粒子不表示溅射范围。接入 LoL 基础皮肤 Q 吐息：金色流动焰心、蓝紫外缘、星点、嘴部闪光与螺旋喷流，目标端带原版散射和冲刷粒子。喷流从 Jaw 嘴部挂点发出，随当前目标伸缩；攻击空中单位时终点跟随目标模型身体，攻击地面单位时终点仍在目标战场位置。停止攻击、冰冻或死亡会同时关闭喷流和命中端，恢复攻击重新起播。3D 模型接管后不再叠画原有浅蓝梯形；无模型时保留简化回退。

源自 `AurelionSol_Base_Q_Beam`（16 层）和 `AurelionSol_Base_Q_Beam_End`（7 层），保留原纹理、网格、颜色、UV 滚动与材质混合；粒子按 30Hz 离线采样，光束端点逐帧更新，持续发射段循环，单粒子 UV 继续滚动。网格光束按当前距离适配，因此不宣称与 LoL 渲染器逐像素一致。来源与转换见[资源说明](../../../assets/effects/aurelionsol_q/README.md)。

主动技能使用 LoL 基础皮肤 R 的原始纹理、网格、颜色与粒子曲线：普通星落和强化天瀑分别接入 Tell、Mis、Impact，天瀑另接 Calamity_Shockwave。预警为蓝紫星云与金色收束环，星辰携带原版流动焰心、碎星和双层拖尾向落点坠落；星辰创建后普通版飞行1.25秒、强化版2秒；从施法起手计，分别1.65秒、2.25秒落地。落地爆炸包含原版星核、放射尖刺、地面裂纹和余辉，最长保留4秒的纯表现尾段。

强化版落地后才出现原版蓝紫冲击波，波头按现有2.8秒、92至1500半径的权威传播进度适配。普通版没有冲击波。预警外环和落地爆炸主轮廓分别标定到92的伤害半径；普通与强化版保持相同范围。少量向上星芒只表示高度，不扩大地面判定。

这是原素材移植，非LoL渲染器逐像素复刻。坠落轨迹、视角投影与尺寸适配本项目；波内三个子粒子引用未在本地基础皮肤定义中解析到，未以自制粒子替代。来源和具体边界见[资源说明](../../../assets/effects/aurelionsol_r/README.md)。

预警创建时已建立固定落点的独立结果，来源冰冻、眩晕或死亡不取消或暂停它；落地爆闪由该独立结果的权威节点触发。光环与碎星均不参与伤害判定。普通版不产生全场冲击波。
