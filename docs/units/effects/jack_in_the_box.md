# 惊吓魔盒特效

[返回惊吓魔盒](../jack_in_the_box.md) · [单位索引](../README.md)

## 当前编排

破隐及主动技能共用原皮W的 `Shaco_Base_W_box_aoe` 完整系统：fireRing、shockwaves、shockwaves1、RWShockwave 四层同时从魔盒脚底开始，按原始出生延迟、旋转、曲线和寿命播放，最后一层在约0.617秒结束，0.625秒释放。没有额外叠加 `box_poof` 烟雾或 `Reveal_buf` 整模型染色；上一版三组叠加已撤销。目标身上的眩晕提示仍复用公共状态特效。

普攻使用 `Shaco_Base_W_Box_Mis` 七层：两条camera trail、地面方向光、背景光、爆发、RayFront和烟尘。从模型head骨挂点飞往目标，进度读取权威弹体；不改变弹速、伤害或碰撞。没有额外接入命中粒子。

原始包来自本机只读 `Shaco.wad.client`。源数据、原始纹理/网格、120Hz采样与制作脚本保存在开发素材库 `03-制作中/惊吓魔盒/vfx/`；`composition.json` 明确记录各系统的事件与缩放。正式 `assets/effects/jack_in_the_box/` 只保留missile、aoe及其必要依赖。

[Riot原作者的VFX说明](https://www.reddit.com/r/LeaguePBE/comments/tsdq0o/shaco_vfx_update/)将W激活描述为盒子周围的短促范围爆发，同时区分放置效果与弹体。该说明用于核对效果用途；本地资源版本与该视频不保证相同，未取得原游戏服务端粒子触发脚本，不声称完整逐帧复刻原游戏。

## 项目尺寸

- 用户指定破隐/主动的主可见波纹半径4格，即160像素。以项目顶视逐帧渲染对照背景，颜色差8/255定义主要可见边缘，标定原生可见半径373；四层统一XYZ缩放为160/40/373≈0.01072386。复测主要可见边缘最大159.83像素。透明面片本身半径650并不等于画面可见波纹，不再用该画布边界换算；更淡的粒子尾缘保留原始曲线。
- 这次只校准表现，权威攻击/眩晕判定仍为射程加身体半径。
- 弹体统一XYZ缩放0.007，约为上一版0.023256的30%；核心/纵向光束保持原始比例，不再直接从模型skinScale推导飞行粒子大小。仍使用原始粒子颜色、宽度比例、寿命与侵蚀曲线。
- 模型保持0.10缩放；权威身体半径、攻击/眩晕范围不变。没有为了相机压平、拉伸或抬高整套效果。
- 两条拖尾按出生顺序连接，按120Hz采样首次出生时刻在两次权威路径位置间插值，并保留出生世界位置；避免20Hz单次更新新生粒子堆叠，原始侵蚀贴图采用镜像寻址，基础纹理保持重复寻址；保留原透明裁剪阈值。
