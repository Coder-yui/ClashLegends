# 电击法术 · 特效

[返回总览](../zap.md) · [总索引](../README.md)

使用本地LoL原版电刑符文纹理，在Godot中适配闪电、地面电弧和淡出。电击在范围中心落雷；大型电击在每次权威选定目标的位置落雷。0.6秒表现生命周期不参与伤害和控制计时。眩晕沿用通用头顶旋涡。

这是原版素材的引擎适配，不是LoL粒子运行时的完整移植；仅接入落雷所需层，不添加风暴狂涌原版延迟引爆玩法。来源见[素材清单](../../../assets/effects/lightning_spells/source_manifest.json)。

施法生效期间显示半径与权威范围一致的阵营色圆圈，固定在施法中心，持续普通0.2秒、强化1.2秒；覆盖追加电击等待间隔，并在最后一次电击的眩晕窗口结束后消失。空范围仍提示完整作用区域。

每次呈现一道中心落雷，叠加快速消失的闪光；地面电弧独立播放，以原图每格底部中央的出生点锚定范围中心，六个方向使用不同长度与轻微错开的动画相位，控制在半径90内，约0.6秒内消散。两击间只保留范围提示圈，1秒时再次完整播放。属于范围法术的表现适配，不声称还原原版发射器编排。
