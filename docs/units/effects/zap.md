# 电击法术 · 特效

[返回总览](../zap.md) · [总索引](../README.md)

使用LoL原版装备风暴狂涌的完整17层粒子组织，原始混合、出生时序、寿命、随机帧、颜色/缩放与侵蚀由原始定义采样。在施法中心落雷，地面冲击圈按90像素权威半径换算；强化第二击在1秒时独立重播。普通范围提示持续0.2秒，强化1.2秒，空范围也完整播放。

天空落雷层按相机投影单独调整为约320像素，从目标上方落下而不贯穿画面；地面圈、火花保持校准尺寸，主雷柱横向加粗为原来的1.8倍。原版尾迹保留，表现对象2.1秒回收。表现生命周期不参与伤害、眩晕和追加电击排程，眩晕沿用通用头顶旋涡。

采用120Hz、固定种子79离线采样与Godot三维渲染适配，不引入来源技能的触发玩法。来源见[素材清单](../../../assets/effects/lightning_spells/source_manifest.json)，适配边界见[资源说明](../../../assets/effects/lightning_spells/README.md)。

所有粒子关闭场景深度遮挡与软粒子深度淡出，绘制在单位/建筑上方，仍保留特效内部层次；落点以下的雷柱尾段裁掉。地面圈、冲击和焦痕平铺在地面，相机投影补偿后与圆形作用范围对齐。

本局卡组包含此法术时，纹理由MatchResources提前收集，加载阶段通过SpellEffectWarmup实际绘制完整时序样本，保留材质/网格后清理样本；原生JSON进入导出包。见[加载职责](../../MAINTENANCE_ARCHITECTURE.md#法术加载与绘制准备)。
