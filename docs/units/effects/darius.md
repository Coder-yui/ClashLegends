# 德莱厄斯状态提示

[返回德莱厄斯](../darius.md) · [总索引](../README.md)

受击单位血条下方用1至4个红点表示流血，多个来源显示最高层数；各来源伤害和到期独立计算。

血怒以德莱厄斯自身的红色脉动轮廓和环绕上升火星体现，跟随模型移动；不再显示头顶“血怒”文字。效果继承通用ActiveBuffVisual3D，订阅blood_rage状态，读取主机状态或客户端血怒快照，不会因其他增益而误亮。结束约0.125秒淡出，死亡隐藏；不参与攻击、流血和计时。资源位于 `assets/effects/darius/`，为项目程序化效果，非LoL原版粒子移植。

主动按钮使用LoL原版断头台图标；免费资格显示“免费追斩”，保留付费次数，后台冷却继续计时。已武装、待命令、冷却和次数耗尽遵循正式按钮资格。
