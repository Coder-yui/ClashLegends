# H-28G进化炮台 · 特效

[← 总览](../evolution_turret.md)

普攻使用自制黄色彗星弹体：浅黄色亮芯与柔和光晕，拖尾由浅黄过渡到金橙，沿真实经过的位置逐渐收窄并透明。弹头与尾迹使用程序网格和渐变着色器，不需要贴图。起点读取Rocket炮口，三维飞行进度来自权威弹体，命中/失效/清场即清理表现；不再播放原版炮口及飞行粒子。

尺寸以模型0.022缩放为基准：弹头画布22单位、拖尾最大85单位、半宽7单位。拖尾最多32个历史点，不伸到炮口后方；朝向镜头的截面保持清晰，支持对空飞行，不改变权威速度和碰撞。

仅海克斯修复继续使用原版Heimerdinger_Base_Q_Turret_Spawn的flares/rings两层，等比0.022、正常深度测试。部署不播放该特效，治疗提示复用通用表现。原版普攻素材已移出assets，保留在制作目录projectile-rework/retired-native。
