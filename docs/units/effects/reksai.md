# 虚空遁地兽特效

[返回单位](../reksai.md) · [总索引](../README.md)

基础皮肤原版Burrowed_W_movement_idle沿水晶外缘至落点的曲线移动；开始时复用地面单位寻路避开建筑和河道，曲线圆角也检查身体净空，之后新建建筑不改变路线。移动方向随曲线切线转动，抵达或取消停止发射，已出生粒子自然消散。Burrowed_W_cas基础闪光与Burrowed_W_cas_knockup击飞碎石在生成实体时组合播放；Q_cas_frenzy的启动闪光只播放一次，原版持续层分别附着左右手，在仍有强化次数时显示、消费完毕即关闭；Q第一、三击使用Q_swipe_cas，第二击使用Q_swipe_2nd_cas，随对应挥击时钟播放。采样120Hz、固定随机种子79，原生三维比例统一0.008，不补偿54°镜头。

逐层读取miscRenderFlags，只有原始关闭深度测试的层选择no_depth材质。曲线长度用于权威预部署计时，以320像素/秒推进；路径不创建身体或沿途伤害，实体由权威预部署队列生成。

破土使用原版W击飞效果，rockShard_Spike按原SKN/SKL/ANM烘焙两秒、60FPS的骨骼形变，每个粒子按出生年龄取样。部署锁定结束后继续推进尾帧并清理；地裂保留出生世界位置，不跟随走动，不存在常驻黑色地面特效。

原版实时随机、动态光照与声音RTPC不等同于本项目采样播放器。未将这些差异表述为完整原版复刻。

按用户要求，不接入Q主目标/范围命中粒子；保留挥击特效，命中音效仍只在真实命中时播放。

普通攻击挥爪拖尾按用户要求不接入。
