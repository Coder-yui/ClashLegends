# 琴瑟仙女特效

[返回琴瑟仙女](../sona.md) · [返回总索引](../README.md)

原版基础皮肤Sona_Base_BA_Mis、Sona_Base_W_Zone_Self、Sona_Base_R_Missile、Sona_Base_R_Cas经120Hz采样接入。保留原生三维比例、颜色、网格、纹理、混合、逐层深度测试标志和出生位置拖尾；未做俯角拉伸。

W使用完整的自身光环W_Zone_Self（14层），不与W_Zone叠加。粒子系统绑定琴女模型根部，包含空军抬升；各层继续使用源文件的局部高度，自身光晕随琴女移动，bindWeight=0的星点保留出生位置。源AuraRange=400，等比映射为项目160像素；主客端读取同一光环年龄/剩余时钟。原版W护盾、减伤强化普攻、Q/E粒子未接入。

R按职责组织：

- **施法者层R_Cas**：在施法起手即开始，挂模型根部，保留源100/125/250等高度偏移，不再叠加琴身高度；读取既有动作年龄，与W是否开启无关。结束、取消、死亡和凝滞隐藏由通用表现状态控制。
- **飞行层R_Missile**：0.3秒从WEAPON的当帧位置发出，读取权威穿透弹体路径；不继承琴骨骼旋转。源导弹对象采用局部Y前进/Z向上坐标约定，项目空军版本保留发射高度并沿水平路径飞行。原版两个−50字段描述目标高度，不能据此推导从琴身到终点存在50源单位落差；不再额外添加0.625世界单位落差或约4.47°俯仰。140像素宽的权威扫掠不读取模型或粒子。
- **粒子运动**：R以项目飞行速度1280源单位/秒、640源单位路径（0.5秒）在原生导弹姿态下重新采样，再按逐粒子的出生时刻与bindWeight消去采样路径位移，转换到导弹局部空间；世界加速度始终沿世界上下方向。不能先按静止地面姿态采样，再把所有运动整体旋转成导弹，否则音符下坠会偏到飞行轴。23层的原始局部旋转、纹理、网格及比例保留。
- **范围适配**：光波主体`Wave_ADD1`源网格横向约130像素，对应项目宽140的恒宽扫掠，每侧约5像素余量；射程320。`Left_outline`、`Left_outline1`和`Right_outline1`是原版长射程的固定边线/底纹，几何外沿宽约245像素，不能作为项目命中范围。实战路径隐藏这三层，统一采用项目已有技能范围提示；独立素材预览仍保留完整原版层。光波本体、带状尾迹、三维比例与实际伤害范围不受隐藏影响。
- **带状光波**：`R_Edge`、`R_Edge1`与三条`ORA_TRAILYUS`均是原版`VfxPrimitiveArbitraryTrail`，沿粒子自身局部X轴展开，不朝向相机。保留源遍历方向、平滑、截断和WAKE出生行程UV；镜头转动不能扭转光带。三条`ORA_TRAILYUS`的`rateByVelocity`依赖运动，不能以静止采样替代；出生时刻与累计行程随采样存储，运行时不重复叠加路径位移。
- **收尾**：权威弹体移除后停止新粒子出生，既有粒子按采样寿命消散，采样已包含0.5秒结束发射后的源消散过程，最多1.5秒后回收；清场立即释放。此处使用采样回放及出生时间过滤，不宣称完整复现原引擎所有particleLinger规则或高度求解器。

受治疗者复用统一回血特效，受R眩晕者复用统一眩晕提示；不将目标用R_buf聚光层挂在施法者身上。本次源R_tar_flash解析无发射器，不额外伪造命中爆点。普攻继续读取跟踪路径和琴身挂点。全部播放器只表现，不发伤害、治疗、控制或移动命令。

时序核对：源施法时间为0.25秒、castFrame为8.5/30≈0.2833秒；项目20Hz使用0.3秒释放，施法总长1秒，Spell4保持原速截取前1秒。R_Cas从起手计时、R_Missile从释放计时。水平空军路径和采样回放属于本项目适配，不宣称完整还原原客户端高度求解或逐帧像素一致。

普攻来源已再次核对：Sona基础皮肤资源表将Sona_BA_Mis映射到Sona_Base_BA_Mis，运行时使用同源8层粒子，8个纹理引用均与归档提取转换件逐字节一致。本轮R重制与范围适配保持普攻资源和路径原样。

原版比对边界：使用归档BIN、SCB和素材库源模拟/渲染器比对网格与光带顶点、UV；没有用原客户端录像证明逐帧像素一致。素材库预览器将`isGroundLayer`垂直压地是其明示的预览假设，本项目不照搬该假设，也不通过镜头补偿或整体倾斜掩盖局部光带错误。
