# 大型电击法术 · 特效

[返回总览](../lightning.md) · [总索引](../README.md)

使用LoL原版符文电刑本体的完整8层粒子组织，原始混合、出生时序、寿命、随机帧、颜色/缩放与侵蚀由原始定义采样。每次在权威选定的单个目标位置落雷，三段间隔1秒。120像素是选敌范围，定点特效按90像素参考半径换算；范围提示固定在施法中心持续2.2秒，无目标的段不播放落雷。

天空落雷层按相机投影单独调整为约320像素，从目标上方落下而不贯穿画面；地面圈、火花保持校准尺寸，主雷柱横向加粗为原来的1.8倍。原版尾迹保留，表现对象1.1秒回收。表现生命周期不参与伤害、眩晕和追加电击排程，眩晕沿用通用头顶旋涡。

采用120Hz、固定种子79离线采样与Godot三维渲染适配，不引入来源技能的触发玩法。来源见[素材清单](../../../assets/effects/lightning_spells/source_manifest.json)，适配边界见[资源说明](../../../assets/effects/lightning_spells/README.md)。

所有粒子关闭场景深度遮挡与软粒子深度淡出，绘制在单位/建筑上方，仍保留特效内部层次；落点以下的雷柱尾段裁掉。

本局卡组包含此法术时，纹理由MatchResources提前收集，加载阶段通过SpellEffectWarmup实际绘制完整时序样本，保留材质/网格后清理样本；原生JSON进入导出包。见[加载职责](../../MAINTENANCE_ARCHITECTURE.md#法术加载与绘制准备)。
