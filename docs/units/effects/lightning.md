# 大型电击法术 · 特效

[返回总览](../lightning.md) · [总索引](../README.md)

使用本地LoL原版风暴狂涌装备纹理，在Godot中适配闪电、地面电弧和淡出。电击在范围中心落雷；大型电击在每次权威选定目标的位置落雷。0.6秒表现生命周期不参与伤害和控制计时。眩晕沿用通用头顶旋涡。

这是原版素材的引擎适配，不是LoL粒子运行时的完整移植；仅接入落雷所需层，不添加风暴狂涌原版延迟引爆玩法。来源见[素材清单](../../../assets/effects/lightning_spells/source_manifest.json)。

施法生效期间显示半径与权威范围一致的阵营色圆圈，固定在施法中心，持续2.2秒；覆盖追加电击等待间隔，并在最后一次电击的眩晕窗口结束后消失。空范围仍提示完整作用区域。
