# 法外狂徒：原版粒子

[返回单位](../graves.md) · [返回总索引](../README.md)

从Graves Skin0提取普攻弹丸、枪口闪光和快速拔枪粒子，以120Hz采样保留层、颜色、生命周期和运动；三轴统一缩放0.018，不为俯视镜头压平或拉长。子弹使用固定释放路径，枪口闪光绑定武器骨骼，E烟尘附着角色后撤位置。

弹丸Trail4与枪口LittlePuffs1/muzzel_flames1原标志1走不写深度的对应材质，其余层按原深度标志处理。拖尾同样选择原生深度模式；预加载资源声明覆盖这些着色器。普通槽加载弹丸/枪口，携带主动时额外预热E；E播放器仅在实际动作出现时建立。

未加入原版Q/R、暴击或独立受击粒子；命中反馈沿用通用受击提示与源命中声。深度自动检查和真实有地面渲染分别验证。
