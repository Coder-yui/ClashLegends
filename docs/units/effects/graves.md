# 法外狂徒：原版粒子

[返回单位](../graves.md) · [返回总索引](../README.md)

普攻每枪生成六颗独立霰弹。每颗在出膛时从原版武器挂点BUFFBONE_CSTM_WEAPONA出发，按各自固定射线和权威飞行距离推进120Hz采样的原版弹体。只绘制这一套3D弹体，命中或到达射程末端即结束。粒子按当前模型比例等比缩放0.015，保留Trail4的原生深度标志。

快速拔枪使用原皮GravesMove指定的Spell3动作。施放朝向锁定，角色向后滑动，0.4秒动作窗口与位移进度同步。E的发射位置随角色移动，三个拖尾层保留出生位置，烟尘与火星按原版绑定权重曲线继承后撤位移。粒子寿命根据120Hz采样的首末帧估算。普通槽预热霰弹，携带主动时额外预热E。
