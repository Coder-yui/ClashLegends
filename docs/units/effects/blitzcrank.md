# 蒸汽机器人特效

[返回蒸汽机器人](../blitzcrank.md)

Q使用基础皮肤Q_cas（1层）、Q_mis（10层）和Q_mis_return（10层）；E使用E_buf（5层）及真实强化命中后的E_tar_1（8层）。原生纹理、网格和粒子曲线按120Hz采样、种子79，不按镜头拉伸或压平。Q经原始SKN/骨架与当前GLB逐轴比对，比例为0.0085，再乘Model的实际世界缩放；默认1.25时为0.010625，包含模型后续体型缩放。E同样按0.0085乘模型实际缩放，默认0.010625。34层深度标志检查通过。

飞爪按出手烟汽、去程张手、回程握拳组织，分别计时，按发射方向旋转。去程原生出生偏移只应用一次，拳头高度匹配出手手部。烟尘和拖尾依据bindWeight保留出生世界位置。电缆使用原始圆柱网格、UV、贴图及深度遮挡：源birthScale50为网格截面缩放，不能当成50单位平面带宽；仅轴向按端点距离伸缩。出手端记录右手R_hand位置，拳头与回程读取独立弹体快照，不依附来源动作存活。结束有0.12秒纯视觉收束。目标投影使用固定权威坐标相机。挂点、飞行时长与尾段是本项目适配，不声称恢复LoL运行脚本的全部参数。

E拳部光效在强化待发期间发射，强化消耗时立即停发；仅停发瞬间存活的粒子继续按原生曲线消散，不因攻击后摇继续出生新粒子，随R_hand骨骼位置和旋转，持续阶段循环成熟采样段而不反复重播起始闪光。E_buf采样扩展至3秒供停发尾段使用，不代表固定显示3秒。命中特效只响应真实强化命中：原版PowerFistAttack指定E_tar_1与胸部挂点，项目使用目标已有模型受击挂点；无挂点时沿用事件坐标。爆闪/螺旋等bindWeight=0层留在出生位置，电弧绑定层随目标移动；保留1.5秒采样尾段。骨骼映射与采样循环为项目适配，不声称完整复现官方脚本。眩晕复用通用提示。双方视角、桥面与塔遮挡、冻结、死亡及清场均完成实际渲染检查；尾段不改变权威控制时长。
