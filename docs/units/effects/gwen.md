# 格温 · 特效说明

## 画面中会出现什么

快刀乱剪以起剪、中间剪和终剪连成完整动作；充能越多，中间剪越多。

## 观看要点

在工作台实战页连续观察效果开始、持续和结束，确认没有残留、重叠或突然跳变。

## 圣霭结界

丝缕缠流生成半径120的固定圆形青蓝雾面、双层边缘与缝线标记；红方使用紫红边缘区分阵营。位置、半径、图案在建立后保持不变，不跟随格温；不隐藏格温模型，也不影响单位碰撞。4秒到期、格温中心出圈或死亡时消失。图案为本项目绘制，不宣称复刻LoL原粒子特效。
