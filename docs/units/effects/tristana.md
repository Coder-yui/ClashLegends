# 麦林炮手弹体与急速射击特效

[返回麦林炮手](../tristana.md) · [总索引](../README.md)

普攻采用原版基础皮肤 `Tristana_Base_BA_mis` 的弹头网格本体，不带烟迹、模糊拖尾、火星或额外命中特效，命中沿用通用闪白。画面从武器发射锚点飞向目标，朝向跟随可见路径；来源死亡不取消在途弹体，弹体命中、失效和清场后释放。

急速射击使用原版 `Tristana_Base_Q_Buf` 的炮筒流动光环与双层光壳，仅去除外喷火星，替换自制炮筒热光。挂在武器骨骼上随动画旋转，保留原纹理、网格和UV流动。Buff的5秒窗口结束后隐藏；临时隐藏恢复不重启粒子，暂停停止表现计时。

骨骼挂接与坐标转换属于项目适配；原资料未提供LoL脚本的完整挂接契约，不宣称逐像素复刻。未改变伤害、弹速、碰撞、攻速、声音与网络载荷。资源来源和加工参数见[资源记录](../../../assets/effects/gwen_tristana/README.md)。
