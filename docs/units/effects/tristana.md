# 麦林炮手急速射击特效

[返回麦林炮手](../tristana.md) · [总索引](../README.md)

当前使用项目自制的炮筒灼热效果：橙红热光贴着炮筒表面，带流动亮点，靠近枪托处渐隐。Q持续期间可见，结束后恢复原外观。不是原版粒子系统复刻。

实现复用模型的武器蒙皮面（Weapon_Base / WeaponTip_Scale 权重大于0.95的三角形），与原模型共享 Skin 和 Skeleton3D；从源网格生成独立叠层，不修改共享模型资源。补齐原GLB缺失的法线，外移0.008避免重叠闪烁。按炮口静止绑定空间的轴向距离遮罩枪托，贴合尺寸和全部武器动作，不再以弹体发射点摆放光壳或向前移动的环。

特效只消费主动Buff状态与表现时钟；到期隐藏，死亡/清场随模型释放，暂停停止热光动画。伤害、攻速、碰撞与网络状态仍由通用权威逻辑决定。

原版 Q 的粒子定义能确认光壳和环的纹理、网格与发射参数，但当前提取资料未确认完整运行时挂接契约。之前的炮口偏移适配已弃用，旧资源移入开发素材库中间产物，不留在运行 assets 中。加工记录见[清单](../../../assets/effects/tristana/source_manifest.json)。
