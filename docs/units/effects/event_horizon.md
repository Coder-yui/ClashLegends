# 扭曲空间 E/W 特效

[返回扭曲空间](../event_horizon.md)

来源为本机 `Veigar.wad.client` 基础皮肤。正式资源在 `assets/effects/event_horizon/`，来源及逐文件哈希见该目录 `source_manifest.json`。

- E：友方/敌方预警与围栏，解析皮肤的 effectKey 关联，包含柱体与预警子系统。以源技能范围参数390对应120权威像素；原生五边围栏外观并非项目圆周碰撞几何。
- W：友方/敌方施法、下落子系统和爆炸。225源单位对应65权威像素。E/W缩放分别为120/390与65/225，相差约6.51%。
- E保留0.25秒施法与0.5秒延迟组成的0.75秒成形；W按1.2秒结算。粒子使用真实秒数，不将预警或落体压缩到结算时间，预警、成形和尾焰可自然重叠。W下落子系统保留源节点1.15秒启动及其父级运动。
- XYZ始终同比例；没有为54°镜头压平高度或拉伸地面。受影响目标使用通用眩晕提示。
- 普通槽声明E四组依赖，主动槽增加W四组依赖；子系统递归包含在采样内，每组提供预热配方。120Hz采样至5秒，保留W爆炸约4.08秒的地面残留。

采样保留颜色、尺寸、UV、纹理、网格和深度标志；按层选择关闭深度测试的Shader，保留不写入深度、排序、软粒子与混合配置。源减色使用现有乘色近似；子发射系统由明确映射接入，不宣称完整还原LoL运行时。未做LoL客户端逐帧对照。

卡面使用AI生成的原创空间漩涡插画，参考原版E图标的空间禁锢概念，生成提示词和原图位于素材库本卡目录；输出 `assets/cards/event_horizon_loading.png`。
