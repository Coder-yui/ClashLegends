# 赛恩特效

[返回赛恩](../sion.md) · [狂暴](../sion_berserk.md) · [总索引](../README.md)

W 使用 LoL 基础皮肤原版 `Sion_Base_W_Cas`、`Sion_Base_W_Shield` 与 `Sion_Base_W_Nova`：施放时出现球面扫光，持续期间保留红色护盾球、暗色旋流和原版纹理滚动；独立W护盾提前打破、清除或进入复生时撤去球体，不播放爆炸。通用护盾条继续显示真实盾量，其他盾层不能延长W球体。

真实到期事件触发原版冲击环、火焰环和地面阴影，替换旧平面红色圆片。爆炸固定在事件位置，完整表现窗口1.3秒；伤害仍在原权威Tick一次结算，表现时长不延后伤害。200半径只用于对齐特效比例，粒子不参与命中。蓝红双方使用同一原版红色素材。

原始纹理、网格与粒子曲线以120Hz离线采样，运行时按表现时间回放；球面保持真实3D比例，地面爆炸按战场投影适配。护盾状态复用已有快照标记，爆炸复用已有技能表现载荷，无新增协议字段。来源见 `assets/effects/sion_w/*/source_manifest.json`。被动炉心燃烧及碎斧粒子仍未接入。

护盾自然爆炸事件同时尝试播放原版Spell2_B完整动画，属于低优先级纯表现动作。仅空闲或移动时播放；攻击中跳过且不补播，新普攻立即打断，受控、部署和复生时不抢动作。不写入2D动作锁、移动、朝向或攻击时间线；爆炸伤害仍由原有权威结算负责。

W护盾持续3秒；球体采样覆盖完整3秒，持续期间纹理继续滚动，真实到期才切换爆炸。
