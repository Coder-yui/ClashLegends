# 赛恩特效

[返回赛恩](../sion.md) · [狂暴](../sion_berserk.md) · [总索引](../README.md)

护盾复用通用护盾条，爆炸使用随真实到期事件发布的深红色中心闪光与铺开至伤害范围的不规则余焰，不绘制范围描边：前0.08秒迅速炸至外圈，之后衰减至0.45秒结束，主客双方只读表现载荷。复生等待时生命条按进度填充，狂暴时换为无斧模型。没有把特效半径用作独立命中来源。

未移植LoL原生护盾球体、被动炉心燃烧及碎斧粒子；当前使用项目绘制的范围爆炸表现，不含碎片或放射尖刺。

护盾自然爆炸事件同时尝试播放原版Spell2_B完整动画，属于低优先级纯表现动作。仅空闲或移动时播放；攻击中跳过且不补播，新普攻立即打断，受控、部署和复生时不抢动作。不写入2D动作锁、移动、朝向或攻击时间线；爆炸伤害仍由原有权威结算负责。
