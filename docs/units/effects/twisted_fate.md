# 卡牌大师 · 特效说明

## 画面中会出现什么

普攻只绘制原版 `TwistedFate_Base_BA_Mis` 的 `TF_Card` 卡片本体，使用原始 `common_cardburst` 网格和卡背贴图。万能牌只绘制原版 `Q_Child_Yellow / Red / Blue` 的 `Card_Missile` 卡面层，保留对应图集帧与旋转。三个原版子弹体的 `birthRotationalVelocity0` 均为 `(0, 0, 1200)`，即每秒 1200°；使用原采样相位与三维轴向，不自行固定角度。普通卡片保留原网格长宽比，不使用原特效的拉长变形。依照本次要求，不接光晕、拖尾、闪点或扭曲层。

万能牌使用完整 60° 扇形范围提示，不绘制内部弹道线；提示表示瞄准范围，伤害仍按三张牌的实际路径判定。三张牌依次为黄、红、蓝色，相邻夹角 30°，飞行距离 300、速度 400/秒。三张牌可穿透，同次施法对同一敌人只结算一次伤害。

## 观看要点

在工作台实战页施放，观察起手、效果出现、实际命中和消失的顺序。范围提示用来帮助观看；伤害、治疗和护盾仍按总览里的规则结算。

技能权威弹体和扇形提示仍使用身体前方 20 的起点；卡片视觉从右手发出并沿对应权威路径前进。表现挂点不改变碰撞、飞行距离或伤害。
