# 虚空召唤特效

[返回卡牌](../void_summoning.md) · [返回单位索引](../README.md)

区域复用装备虚空献祭223069的Indicator_On原版20层，包括环、地面光纹、扭动纹理与冲击波；各层起发、粒子时长、UV、混合与源偏移保留在120Hz采样中。原版19层无深度测试，Groundlights仍受地面/模型遮挡；逐层检查已通过。19个地面层按源标志处理。

Shockwaves1采用原版减色关系dst×(1-src)，避免错误的普通透明混合出现黑块。Godot与原版渲染阶段并不完全相同，depthBias/阶段排序保留元数据并近似映射，不宣称逐像素一致。

525源单位按法术半径160像素校准，通过战场镜头逆投影适配圆形范围；不影响权威位置。区域在8秒结束或清场后移除。双方起始、持续、结束阶段已实机渲染检查。

每只虚空鱼沿用原版Transform出生特效：约0.72秒显示实体、0.78秒特效结束，权威0.8秒允许行动。既有女皇散出物仍走原规则。
