# 恕瑞玛卫队出生、护盾与回复表现

[← 单位说明](../shurima_guard.md)

180点护盾使用每名士兵独立的护盾条。护盾自然到期且实际恢复生命时，士兵脚下出现黄色光环，身上升起金黄十字光点，持续0.9秒并跟随移动；整体不透明度为原来的35%。破盾、清除、死亡和本来已满血时不播放回复效果。

治疗由权威模拟结算；主机通过带会话校验的可靠消息通知客户端播放。特效不驱动回血、不改变寻路或碰撞。


## 黄沙士兵出生

每名士兵生成时播放原版`Azir_Base_W_SpawnIn`：DustIn内卷沙尘、Dustfill填充沙尘、DustDevilMesh沙堆旋风、DustDevil_Wind外圈风线四层。源网格、纹理、颜色/尺寸曲线、发射延迟、粒子寿命与混合方式保持原定义，使用60fps采样重放和0.011源单位比例。

共用士兵模型的部署入口负责每个实例只播一次；沙皇主动四兵、被动转化单兵、恕瑞玛卫队六兵都走同一实现。出生地固定，士兵走动不会拖走地面沙尘；播放尾迹最多1.8秒后释放，不延长默认1秒部署。死亡、清场及部署被控制取消时释放，不在控制结束后重播；模型池复用时重置。

`shurima_guard`在卡牌表现域声明`azir/player.gd:spawn`依赖，`sand_soldier`继承该声明，沙皇通过召唤依赖展开到士兵。因此只带沙皇或只带卫队都能在对局加载时加载纹理、网格JSON、Shader并实际绘制预热四层；各机制无需单独预加载或重复播放特效。
