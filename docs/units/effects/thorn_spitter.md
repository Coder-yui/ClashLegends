# 荆棘喷射者 · 特效

[← 总览](../thorn_spitter.md)

弹体只保留原版Zyra_Base_Q_Plant_Mis的vine_thorn网格和原纹理，未接入拖尾、烟雾、孢子、叶片与毒雾；命中无粒子，保留命中声音。出生沿原模型武器挂点，朝向指向目标身体；首次观察按已经飞过的权威距离计算年龄，不再漏掉首帧飞行时间。仅显示尖刺网格，不生成飞行附属层。

技能使用Zyra_Base_P_Enrage原star粒子，粒子节点直接作为植物中心骨挂点的子节点，继承放大后的模型变换；只抵消挂点旋转/镜像以保持世界竖直向上；按权威/快照的6秒时钟采样，凝滞隐藏、到期和死亡清理。模型由权威临时体型状态放大25%，粒子同步增大一次，不叠乘两次，也不依赖逐帧复制旧的世界缩放。

模型原坐标包装缩放0.016，源皮肤skinScale=1.2，因此独立VFX统一XYZ缩放0.013333333；保留源三维比例、原层混合和深度测试。源服务端挂接脚本不可用，武器/中心挂点是依据模型现有辅助骨骼选择的本项目接入，详见[动画说明](../animations/thorn_spitter.md)。

源定义、依赖与采样配方位于开发素材库03-制作中/荆棘喷射者，正式运行资源为assets/effects/thorn_spitter。已移出的飞行附属层与命中特效仅保留于制作素材。
