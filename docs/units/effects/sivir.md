# 战争女神法术护盾

[返回战争女神](../sivir.md) · [返回单位索引](../README.md)

接入基础皮肤 `Sivir_Base_E_shield` 的5层护盾与 `Sivir_base_E_proc` 的2层抵挡表现。共用原生粒子播放器，等比0.0075缩放，不压平三维球体。逐层保留 `miscRenderFlags`：标记关闭深度测试的层选择对应Shader，其余层仍接受地面遮挡。

护盾以模型 `C_Buffbone_Glb_Center_Loc` 的静止姿态高度校准，跟随角色整体位置与朝向，不跟随投掷弯腰。原始护盾中心85映射到该高度；各层原始发射高度80、85、-10以及抵挡95、80继续保留相对关系。与普攻 `Buffbone_Glb_Channel_Loc` 出手挂点分离。当前模型包装1.05下球壳半径约0.803、最低点约0.251，攻击姿态不会使球壳碰到地面。

转换显式保留 `SpawnShape.emitOffset`，避免被默认零 `birthOffset` 覆盖；还原本地朝向开关、等比缩放标记及原始颜色寿命贴图。颜色采样采用本次源定义的X=1/Y=0组合；相关字段见[LTK参考](https://wiki.leaguetoolkit.dev/editor/vfx-editor/reference/#color)。无主纹理的 `spheredetail` 使用视角衰减球壳材质，避免白色缺省纹理造成实心过曝球；此处是项目材质适配，不宣称还原LoL原生Shader全部语义。

护盾开始建立持续播放器，抵挡触发原版proc粒子，抵挡或到期立即销毁整个持续护盾系统；抵挡时单独建立E_proc，按其发射窗口与活粒子结束回收。治疗提示复用通用治疗表现。死亡、清场随模型释放；暂停由通用表现时钟停止。实际双方截图、逐帧离地测量及回归结果见本次[交付记录](../../deliveries/2026-11-04_战争女神新卡.md)。

护盾全部发射层仅在Buff持续期间保持完整位置绑定，结束不保留球壳尾部。源spheredetail的1→0绑定曲线会留下旧位置球壳，接入时覆盖为常量1；保留原始素材数据供追溯。
