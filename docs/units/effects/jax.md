# 武器大师特效

[返回武器大师](../jax.md) · [单位索引](../README.md)

反击风暴使用原版基础皮肤Jax_base_E_buf（11层）及Jax_base_E_cas（10层），以及真实命中目标的Jax_base_E_tar（8层）。前者跟随单位建立2秒持续阶段，到期按源particleLinger软停止，范围圈0.2秒、穹顶0.25秒、顶部光1秒退场；结束爆发同时由权威到期结果发布固定落点事件。死亡和凝滞到期不伪造爆发。

原始网格、贴图、颜色、缩放、UV与寿命曲线由本地ltk采样器按120Hz、固定种子79采样。Godot播放器读取采样，不参与权威状态。逐层miscRenderFlags的关闭深度测试位映射到对应shader变体，共用运行和预加载路径；全部层保留原生三维比例与高度，不做足印拉伸或地面压平。所有阶段的坐标换算统一使用SKN到当前GLB实测0.0085×模型包装1.25＝0.010625。结束cas另有统一粒子尺寸倍率2，作用于整组10层的三轴尺寸，发射中心、高度、旋转与源曲线不变；buf与tar不乘该倍率。这个倍率根据Riot官方E演示的可见爆发/烟圈重建，并非从客户端Lua恢复出的服务端创建常量。不按伤害半径或相机单独变形wave。持续范围环源外沿397.19772；原版JaxE.castRadius为375，按模型比例和40像素/世界单位原本换算为159.375像素。本次伤害、眩晕范围取150像素，buf/cas/tar统一追加150/159.375三轴等比缩放，保留三维比例与层间关系。持续与结束系统使用单位地面根点，保留采样内每层高度；命中特效去掉此前人为增加的1世界单位高度。源粒子数据不含运行时施法脚本的挂骨调用，因此目标命中系统目前使用目标地面根点，尚不能声称其运行时骨骼挂点完全复现。持续阶段只有自身免疫，没有范围伤害。

这是原始素材与参数的Godot适配，不代表Riot内部粒子求解器、RTPC或所有随机分支的完全复现。普通范围攻击提示沿现有splash_circle，眩晕提示沿通用状态表现。命中特效只由真实命中回执创建，不替代通用眩晕提示。

来源、图层及已执行验收见[交付记录](../../deliveries/2026-10-19_武器大师新卡.md)。


结束组织是“持续系统软停止退场＋结束系统同时播放”，不能在2秒时整体隐藏buf，也不能将cas的内部冲击环当成整个技能唯一边界。采样包含2秒stopAt及各层原始linger；原始cas网格与采样文件保留，运行时统一缩放粒子尺寸。表现尾段不延长免疫或改变伤害时刻。

原版画面依据：[Riot官方Jax页面](https://www.leagueoflegends.com/en-gb/champions/jax/)中的E演示。按持续圈直径比较可见爆发，原版与当前实机选定帧都约为0.94；检查同时覆盖烟圈与中心高度。这个近似图像比例不是游戏逻辑边界，伤害仍按150圆形判定。

实际格挡普通攻击时，身体中央快速浮现淡金色“免疫”，约0.48秒内轻微上浮5像素并淡出。连续格挡刷新同一提示，免疫计数封顶后仍提示；技能命中和仅开启技能不显示。通过既有权威表现事件同步客户端，不改变战斗判定。
