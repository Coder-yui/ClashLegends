# 庇护清泉特效

[返回庇护清泉](../pool_of_reflection.md)

来自只读Hwei.wad.client基础皮肤W_W_AoE（11层）、W_W_AoE_Red（2层）、W_W_Shield（9层）、W_W_Shield_Break（7层）。敌方附加原版红圈，以观察方阵营判断。原始ZoneRadius=350对应项目110像素，保留XYZ同比例，不压平、不补偿相机角度。护盾采用0.0125原生统一缩放；空军使用项目统一飞行高度。

保留纹理原路径目录、网格、颜色/调色板、UV、侵蚀、软粒子、排序和每层深度标志；素材库内保存原定义和加工脚本，assets仅保留接入资源。区域120Hz采样6秒，3秒停发后自然消散；护盾前5秒原生采样，长时间维持时循环1—5秒持续段，丢失权威护盾状态后播放原破盾粒子。采样渲染不等于LoL客户端逐帧复现。

卡面使用内置imagegen，根据WW原图标生成青蓝水墨护罩与金色清泉；原版WW图标直接DDS解码，无重绘。卡面提示词与原图保留在本机素材库。
