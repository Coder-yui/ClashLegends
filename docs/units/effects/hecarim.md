# 战争之影Q与恐惧之灵特效

[返回战争之影](../hecarim.md) · [美术流程](../../ART_PIPELINE.md)

从Hecarim基础皮肤的原始W_AoE、W_cas重建26层粒子，保留原纹理、网格、颜色、发射与生命周期采样，120fps采样到5秒；持续层在4秒停止发射并保留短尾迹。W_eff_02源系统没有发射器，仅在制作源件保留。

W以脚底XZ为中心，地面层抬高0.04世界单位。范围以W_AoE/Temp_Mesh绿色细圆线为准，不再以烟雾或CIRCLE2亮边估算：指示网格内外平均半径84.342672/91.819264，指示贴图径向亮度中心UV=0.26173765，经源缩放6得到517.797467源单位；整组等比缩放0.00579377110后圆线中心半径为120像素。阵营颜色直接覆盖同一网格、同一纹理的圆线，己方蓝、敌方红，使用透明混合避免与绿色相加变黄；不再另外画2D圆圈。外围烟雾保留自然渐隐，权威范围仍为120像素。

这是项目内采样重建，不等同Riot运行时：随机采样固定，未实现W逐目标吸取连接与受击附着层，原生常驻头尾粒子另见动画页。回血及眩晕使用项目通用提示，不自建提示。

## 普通攻击Q

接入基础皮肤原始Q_Cas（11层）、Q_buf（8层，包含3层模型附着材质）及Q_tar（5层）。使用原纹理、SCB网格、曲线和120fps采样，保留三维比例；Q动画仍为Hecarim_Spell1_anm，粒子按同一归一攻击时钟播放，冲刺攻击不触发Q。Q_Weapon_01源定义没有发射器。命中粒子由真实命中事件触发于主目标落点；范围内其他目标不单独派发该粒子。随机采样及源子发射系统不等同Riot运行时。

Q施放刀光原始半径199.741345×1.6=319.586153源单位；独立缩放0.00664922426后半径85像素。XZ中心保持脚底中心，仅高度跟随模型上身root骨骼，保持水平旋转，不随骨骼倾斜。原接入地面高度及共享0.005缩放已纠正。此挂点为本项目按模型动作的适配：本机BIN不提供服务器脚本的完整粒子出生挂点，不能将它宣称为已证实的LoL脚本挂点。Q_tar仍使用独立命中点与局部命中尺寸，不以AOE半径扩大受击火花。

Q_Cas的trail_flourish_skin没有源贴图，旧播放器将空采样器绘成白色矩形；现在不绘制无贴图且无网格的层，源定义保留，其余刀光与附着层不变。已用单层隔离和同场景前后截图确认白块来源及消失。

Q仅在charge_strike动作剩余时间大于0时抑制；动作名作为最近一次事件保留，不代表动作仍在播放。冲刺结束后的每次普通攻击继续读取攻击序号和归一时钟，W使用独立领域时钟，两者可以同时显示。

## 武器轨迹与拖尾重建

Q_buf的普通粒子改由原版Hecarim_Spell1_anm中的BUFFBONE_GLB_WEAPON_1挂点驱动；120fps烘焙轨迹保存在q_weapon_path.json。去掉原形状中的静态武器偏移，以真实骨骼位置接替；bindWeight=0使用出生时挂点，bindWeight=1使用当前挂点。

trail_flourish_skin不再停用，也不再当独立面片绘制。按原粒子定义使用120Hz粒子、0.7秒寿命、原宽度和颜色曲线、800源单位纹理平铺与1050源单位截止长度。粒子按出生序连接三角带，使用相机朝向展开、7点平滑和拐角平分。原烟雾纹理及加法混合保留。每次普通攻击按归一时钟重建，不累积上次攻击的尾迹。

实现参考本地ltk-manager的粒子定义解析和ribbon.ts算法；它是第三方复现，不是Riot引擎源码。现有WAD没有完整的服务器粒子挂载脚本，因此武器挂点选取、动画混合期间的烘焙轨迹及渲染器差异仍属项目适配，不能宣称逐像素等同原版。Q_Cas无纹理的拖尾层仍不绘制，避免恢复白块。

## W起手层核查

紫色圆环来自此前额外叠加的Hecarim_Base_W_eff（circle2/test/yell，common_Hunterscall01及common_color-hunterscall2），确属原包资源，但未证实为当前W起手绑定。逐层对照确认后移除该层及预加载声明，源件保留在制作中/战争之影/未采用W_eff。青绿色W_cas及W_AoE保留。

120fps采样中，范围主要层及起手层在首个采样步1/120秒已有粒子；AoE的Temp_GroundGlow1约0.2秒、cas的CIRCLE1约0.5秒延迟。这是粒子内部时间，不代表服务器施法延迟。原动画仅含嘴部事件，W表的Spell3/0.43935秒字段与Spell2_Upperbody不一致，缺少可执行技能脚本，不能断言原版W在0.43935秒释放。后续按用户选择，W起手0.44秒后领域生效，届时启动原粒子时间轴；此为本项目设计值，不声称已证实为LoL原版延迟。
