# 沙漠玫瑰原版R特效

[返回沙漠玫瑰](../samira.md) · [美术接入](../../ART_PIPELINE.md)

读取本地基础皮肤Samira_Base_R_Cas，包含21个启用层：旋转网格、风纹、火花、烟影及角色附着层。源定义、依赖与确定性采样留在开发素材库制作目录；运行只保留采样JSON、原纹理、原网格和播放器。

沿用既有原版粒子采样流程与共享Shader，三轴同比缩放0.0075，不做相机补偿或高度压平。逐层保留混合方式、深度标志和排序；6个miscRenderFlags=1层使用no_depth变体，其他层保留深度测试。21层深度映射检查通过，实际有地面、双阵营渲染已检查。

粒子仅按同步的inferno动作剩余时间采样；新增通用active_action表现状态源，冻结取消、死亡与清场时停止。权威范围独立配置180像素；当前复现施法主粒子，不宣称完整复刻LoL客户端独立R导弹、摄像机后处理或实时Wwise效果。远程普攻使用基础皮肤 `Samira_Base_BA_Mis` 的原版弹头及发光主体四层（Bullet2、bullet_core、bullet_core1、Bullet3），保留原网格、纹理与材质曲线，采用0.0102三轴比例，从本帧真实枪口沿权威弹体轨迹播放（源到用户GLB的0.0085乘模型包装1.2）。未接入源系统其余烟雾、弹壳等层，不宣称完整26层复刻。

黄色动态内圈是通用2D持续范围提示，并非源粒子；莎弥拉已移除该内圈，保留红蓝作用范围边缘；边缘在完整2秒施法期间保持可见并跟随移动，结束或取消时消失。

上升黄色团块曾由错误采样产生：R内的子系统`11.0`中`Basic`使用原生`Samira_Base_Q_Embers`火星纹理，但导出器误按局部编号0读取主系统粒子，套入主层655宽度与向上朝向。现在按`source_path`读取各子系统自己的粒子池、时钟和变换；`11.0:0`火星宽度最大120，正常短促火星保留。子系统`8.0`及`11.0`四层一并修正，原主层17层不变。已实际隔离图层确认黄团来自该错误；源文件包含火星不等于已逐帧核对官方客户端，本次没有做该项核对。

## 组织核对与180像素适配

对照本地`skin0.ritobin`解析后的完整主子系统：主系统17层，`8.0`子系统1个启用层、`11.0`子系统3层，合计21层；`8.0:0`按源禁用标记排除。全部启用层的原始字段、纹理与网格依赖已逐项核对。源`Avatar`为透明混合（blendMode=1），已纠正此前误用的加法混合，并接入源红色Fresnel边缘光（指数0.015）；该层使用当前帧采样，与主粒子同步，隐藏时同帧关闭。

最终按用户指定取180像素。以本地SamiraR的`castRangeDisplayOverride=600`作为原始显示范围基准，180÷600÷40=0.0075；主子系统位置、网格与粒子尺寸三轴统一应用该系数，模型包装仍为1.2。角色附着层沿骨骼模型保持源1.01相对膨胀，不按范围系数缩小身体覆盖层。红蓝范围提示和权威伤害均读取180。源施法主粒子的烟影与旋转网格本来位于范围内侧，不将这些内层单独拉伸到范围边缘。

本次核对的是本地原始资源组织及其接入，不是官方客户端逐帧截图比对；独立R导弹、残影、场景后处理仍不在当前施法主粒子实现范围内。


## 悍勇本色满层

使用源基础皮肤 `Samira_Base_P_Ult_Ready`，16个启用层（包含子层），保留原风纹、火星、地面光与角色附着效果，三轴比例0.0102匹配模型。Fresnel只附着Body，Gun1/Gun3/Gun4只附着Pistol、Revolver、Sword，保留原混合方式及滚动/叠乘纹理；不把武器火焰铺满全身。附着网格读取同一Skeleton姿态，不驱动战斗。原始关闭层继续关闭。

表现使用已同步的满层状态：普通槽同样显示，消耗或4秒到期后停止，死亡隐藏。确定性采样保留8秒，超过8秒的持续满层复用后4秒稳定段；本项目4秒层数期限由权威管理，特效不会维持层数。R与满层共享一个表现入口，分别启停各自粒子与附着材质。

武器层没有源反射定义时跳过Fresnel计算；有反射定义的身体层在背向镜头时显式使用零底数的极限值，避免GPU零指数幂运算产生白斑。保留原纹理、颜色和叠加方式，双方四朝向已实际渲染核对。
