# 璐璐 · 特效

[← 返回璐璐](../lulu.md) · [总索引](../README.md)

普通攻击发射深紫色法球（RGB 0.54/0.18/0.86），视觉半径为原来的1.4倍，带同色短拖尾与淡紫核心；权威碰撞半径仍为4。皮克斯为浅紫色小光弹（RGB 0.83/0.56/1.0），两者以颜色深浅和大小区分。周期召唤使用两道带光点拖尾的紫光，从璐璐身体向左右落点飞行0.25秒；落点高度按本机相机投影到皮克斯飞行平面，支持红方翻转。粒子不参与生成结算，来源受控或死亡不取消已发出的特效。狂野生长播放原版Spell4，成功获得时将目标模型放大30%，血条按新生命上限显示，并播放自制气浪与8片加大的浅绿色翻滚飘叶：以受益目标为中心，0.55秒向外扩散更亮、更宽的淡白紫色气浪，空中目标在飞行平面、地面目标贴近脚边。该事件复用可靠skill_fx去重，来源后续受控或死亡不撤销已经成功的获得特效。没有合法目标时不显示获得反馈，施法起手音不代表效果成功。

击退由权威位置表现；不增加击飞、眩晕或减速。按用户确认采用自制特效，不接入LoL原版粒子。已找到的原版素材清单保留在本地候选目录，仅作历史研究记录。回血、减速和硬控沿用通用受影响对象提示。

获得增益的存活单位脚下保留带淡紫填色的五瓣花朵与浅绿叶片，静态半透明，无持续光罩和整身染色。纹样位于3D脚下平面，开启深度测试，身体可以正常遮挡；花瓣外缘适度扩展，避免完全藏在模型及阵营标记下面。纹样跟随当前位置及空地高度，只读快照中的成长倍率，死亡或成长状态清除后消失，凝滞窗口内隐藏。
