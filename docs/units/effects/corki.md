# 库奇导弹特效

[返回库奇](../corki.md) · [美术接入](../../ART_PIPELINE.md)

使用基础皮肤原版corki_base_r_missile.scb网格（82顶点、135面），保留UV，分别使用普通与超级导弹原版纹理。网格以本项目镜头方向投影绘制，超级导弹放大25%。爆炸组合原版冲击环与火焰图集，使用独立加法混合画布，避免黑底；不将UV图集误当导弹精灵。

这是原版素材在本项目中的适配，并非LoL全部粒子层的逐层复刻；未接入原版地面碎屑、扭曲与完整烟雾发射器。原模型与贴图路径及处理见assets/effects/corki/README.md。无伪造命中，落空没有爆炸。主机真实碰撞发布既有可靠爆炸事件，客户端弹体由快照插值，表现不驱动伤害。

普攻使用原版`corki_base_ba_bullet.tex`解码的金黄色细长曳光，亮端朝飞行方向，拖尾反向；独立加法混合，无黑底。普通导弹爆炸保留金橙色，第三枚超级导弹改为红色冲击环与红橙火焰。逐次爆炸样式仅属于visual域，通过既有可靠命中特效事件传递，不改变范围和伤害。

技能弹道指示沿300像素射程保持12像素等宽；普通和超级导弹使用同一宽度，不再绘成远端扩张的扇形。此轮廓只提示飞行方向，55像素爆炸半径和首碰判定仍由战斗逻辑决定。
