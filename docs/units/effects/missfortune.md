# 赏金猎人 · 特效说明

[← 返回赏金猎人总览](../missfortune.md) · [总索引](../README.md)

## 画面中会出现什么

普攻发射枪弹；大步流星期间使用加速跑步动作。对新目标的首次攻击有独立声音，不能把声音播放次数当成额外伤害次数。

## 观看要点

在工作台实战页连续观察效果开始、持续和结束，确认没有残留、重叠或突然跳变。

## 主动技能特效

大步流星接入基础皮肤 W 的左右武器原生粒子（各6层），随枪骨骼运动；3秒技能结束后播放左右结束粒子（各3层），最多2.1秒。原版 W_buf 身体5层全部禁用，保持禁用；不混入被动移速满层 W_Max。持续与结束只影响表现。
