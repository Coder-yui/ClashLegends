# 腐蚀法术 · 特效

[← 返回腐蚀法术](../corrosion.md) · [总索引](../README.md)

使用莫甘娜基础皮肤 `Morgana_Base_W_Tar_Update` 的11层原版地面粒子，包含暗色底光、两层火焰波、小涟漪、环形填充、发光边环、两层余烬、模糊边环、裂地和能量裂纹。16项原版纹理与网格依赖全部随项目保存。

原版5秒曲线直接匹配5秒区域；贴地层与人物共享深度，原版紫黑配色保留。特效本体按原版边环实际半径284.64396（网格499.37537×缩放0.57）映射到110像素；画面使用逆投影校正圆形范围，蓝红细圈标明施法阵营和实际判定半径。通用减速提示跟随快照状态，特效不结算伤害。

2026-10-08 重新核对原版定义：保留源 pass 顺序并映射为 Godot 可用的独立优先级；余烬按原版随机出生曲线散布，网格遵循原版等比缩放。最后0.4秒将源侵蚀尾曲线映射到区域结束前，并淡出全部粒子，5秒到期不残留假伤害区域。

当前移植复用现有原生粒子采样器支持的材质/曲线子集，属于Godot适配，不能等同于LoL引擎逐像素重现；未加入角色施法动作和W命中人物附着子系统。来源与加工见[素材记录](../../../assets/effects/corrosion/README.md)。
