# 火药桶 · 爆炸特效

[返回火药桶](../powder_keg.md) · [总索引](../README.md)

使用船长原皮 `Gangplank_Base_E_Explosion` 十层原始系统：外环、闪光、木屑、地面火环、火星、尖刺、烟雾、云序列、地面闪光与焦痕。120Hz采样2秒，保留原生XYZ比例；场景仅定位到权威爆炸中心，不按镜头拉伸或压平。

焦痕层原始 miscRenderFlags=1，映射关闭深度测试的着色器；其他九层保留深度测试。预加载与运行共用选材接口，深度检查10层零错误。原版混合、贴图、颜色/尺寸/旋转曲线沿采样播放器；不声称与LoL客户端逐帧完全一致。

普通死亡与主动引爆共用效果，斩杀没有另加粒子。模型死亡动作与独立爆炸同时开始，死亡后粒子继续；暂停与清场走现有固定区域表现生命周期。

## 范围提示与爆炸尺寸

存活时用项目自绘红蓝边线显示140像素权威半径，不铺底色、不加载原版AoE标识。死亡或清场即移除。敌人身体与范围相交仍可受伤，边线表示爆炸区域，不要求敌方中心入圈。

爆炸按用户确认固定统一XYZ缩放0.0125，不随伤害半径变化；当前伤害和红蓝边线半径均为140像素。原版标识网格推导的缩放已撤回，0.0125是用户指定的表现参数，不宣称由LoL客户端真实范围反推。
