# 牧魂人特效

[返回牧魂人](../yorick.md) · [总索引](../README.md)

原版Yorick_Base_Cape_test包含Hair_Avatar_4与Hair_Avatar_5两层无限寿命AttachedMesh，均绘制Yorick_cape、双面、局部朝向；共用Yorick_Base_idle_cape_tex与Yorick_base_cape_color纹理，纵向滚速分别-0.15、-0.35。两层各自按出生UV偏移的V概率表取0～1相位，实例化和对象池复用时重新取样；采用独立表现随机源，不消耗战斗全局随机序列。模型表面覆盖两遍ShaderMaterial，使用独立实例与表现时钟，暂停不自行推进。资源通过模型场景直接依赖预加载。

已复用原版网格、蒙皮与纹理，不将静态实体披风叠在特效外。现已加入三条历史路径骨链修饰（下述为源数据约束下的Godot重建）；附属项链光和地面雾不属于本次披风双层，不冒称完整LoL角色特效复刻。

每次真实命中通过已有可靠命中表现事件绘制红色35像素范围圈，持续0.3秒；使用固定范围、不扩张范围动画，客户端不自行判伤。回血使用公共治疗表现。Q使用原版Spell1动画和声音，未额外移植原版Q武器粒子。

## 路径拖曳来源与适配

原始依据位于本地制作目录`ClashLegends-开发素材库/03-制作中/牧魂人/core/data/characters/yorick/`：

- `skins/skin0.ritobin`：三组ConformToPathRigPoseModifierData，分别从CapeUpper_M2/L2/R2_Ground到M5/L5/R5_Ground，mMaxBoneAngle均120°。
- `animations/skin0.ritobin`：101项遮罩0x125c4354与源GLB skin joints顺序对应。起点2、桥骨2_3、3、桥骨3_4、4、5依次为0.5、0.7、0.8、0.9、1、1；右侧桥骨2_3为0.6。FullAnim遮罩全零。
- Attack1/2进入FullAnim的混合0.5秒，Attack3为0.75秒，三者退出0.25秒；Spell1与Death进入0.5秒，IdleIn进入1秒，Idle1未指定时长。Run_Base没有CAPE事件。

`cape_path.gd`在动画采样后修改渲染骨架：记录世界水平移动折线，按原骨骼距根部的距离采样历史路径方向，按遮罩权重及120°上限转动骨链，保留原蒙皮、骨长、高度起伏和附属骨。非移动动作恢复作者姿态，事件混合时长随原片播放倍率映射；待机以至少0.45秒退回作者姿态，避免停步突变。

历史最多192点；初次出现用当前朝向补齐缺失历史，超过4个模型单位的跳变重新播种。回收模型清空历史、动画混合和材质时钟。只影响表现，不访问战斗随机数，不改变权威移动/碰撞/伤害，也不增加网络字段。

披风与武器修饰器仅在当前动画采样有效且片段仍存在时读取播放位置。暂停保留有效姿态与修饰；预热结束停止播放、移除动画库后跳过修饰，不把保留的片名当作仍有当前动画。

源资源没有Riot引擎求解实现。按弧长采样、水平旋转、初始化/跳变阈值及遮罩事件的解释是本项目适配，不能声称与LoL逐帧完全一致；未加入布料物理、地形贴合或额外地雾。

## 蒙皮尺寸与受击覆盖

披风直接使用源GLB的Yorick_Cape表面，原顶点、UV、骨骼权重、Skin、骨架路径及局部变换保持一致，角色包装统一缩放1.25，披风与身体同比缩放，无披风独立倍率。为单独控制受击覆盖，包装将Body/Cape两个表面分到两个渲染节点，仍绑定同一骨架；两层流动材质绘制在披风表面。披风标记exclude_hit_flash，只跳过受击白光，保留冰冻、凝滞等公共状态表现。

## 自身避让、转向拖曳与停步回稳

仅牧魂人自己的骨架与世界变换参与。三条骨链保留世界朝向历史，近身到尾端采用0.185～0.28秒的指数跟随响应；程序偏转变化率上限5弧度/秒，防止掉头跨过正负180°时翻边。移动路径影响以0.22秒响应衰减，停步后目标方向回到角色背后，不继续被旧路径牵引。待机原地转向也触发短暂滞后，转身结束自动回稳。

防穿插采用模型空间内Pelvis至Spine3的水平投影胶囊（半径0.38模型单位，含安全余量）。对程序修正后的披风骨链线段扫描，临近身体时缩小偏转并细化边界；身体投影跟随原动画，随整体1.25缩放自动同比变化。保持原蒙皮、骨长与片内起伏，不加入世界物理查询、地形、其他单位或披风布料自碰撞。这是自身躯干简化避让，不保证逐顶点或每个肢体的精确布料碰撞，原片自身穿插不由该约束重做。

动画暂停时惯性与回稳暂停；初生、跳变与对象池复用清空方向惯性和路径。上述响应、避让形状和停步行为是本项目适配参数，不声称来自Riot内部求解器。

## 披风模板、UV与材质核对（2026-10-15）

模型里的披风模板是带蒙皮的承载网格，不是程序生成的布料：源GLB的Yorick_Cape索引引用466个顶点、736个三角形，原UV范围约U=0.00089～0.99997、V=-0.00111～1.00198。包装直接保留这些UV，既不重新展开，也不按世界坐标投影。材质用原UV采样流动纹理与乘色纹理；主纹理的V坐标增加出生相位与时间×滚速，乘色纹理保持原UV，两者RGBA相乘。Alpha控制虚化和缺口，两遍绘制形成不同速度的流动。

源skin0明确initialSubmeshToHide和initialSubmeshShadowsToHide均为Yorick_Cape，GLB材质extras.visible也为false。普通披风表面由AttachedMesh特效替代，运行披风节点关闭投影；不继承身体的投影设置。原版birthUVOffset的V概率表从(0,0)到(1,1)，此前固定偏移1在重复采样下等于0，丢失了出生相位差异，本次已恢复各层独立出生采样。

披风形状由蒙皮骨架驱动：该网格权重连接Spine3和九个CapeUpper_*_SKN关节，Idle1、Run_Base、Attack1、Spell1均含108条披风相关变换轨道；另有三条Ground控制骨链的ConformToPath修饰。因此贴图滚动与几何摆动是两个独立过程。当前路径拖曳、转向缓动、自身避让仍是上文明确标注的项目适配，本次不重写运动算法。

辅助字段语义参考[LTK VFX参考](https://wiki.leaguetoolkit.dev/editor/vfx-editor/reference/)；具体层数、纹理、速率、隐藏设置与骨链以本地Yorick原始资源为依据。该参考是工具文档，不代表Riot内部渲染/求解实现。
