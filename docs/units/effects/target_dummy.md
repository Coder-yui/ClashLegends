# 训练木桩 · 余震表现

[返回建筑卡](../target_dummy.md) · [总索引](../README.md)

技能图标直接解码原版veteranaftershock纹理。增益期以原版 `perks_aftershock_avatar_mult` 纹理覆盖身体网格，叠加绿色流动与边缘亮度，并保留绿色原版余震环；实际爆炸事件绘制原版地裂纹理和扩散环，使用加色混合消除原生粒子贴图黑底。

本版是原版纹理在Godot中的适配，不宣称完整复刻LoL粒子系统。增益读取现有权威/快照标记，凝滞隐藏、解除后显示未到期状态；爆炸只消费实际到期事件，不由特效结束触发伤害。来源死亡不生成爆炸，清场移除表现。
