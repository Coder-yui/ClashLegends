# 狂战士 W 特效

[狂战士](../olaf.md) · [单只对象](../olaf_single.md) · [总索引](../README.md)

采用本地 LoL 基础皮肤 W_cas、W_shield、W_buf_glow 和 W_buf_blood 的原始纹理、网格与 120Hz 粒子采样。运行接入为 `visual_active_buff_scene` → `ActiveBuffVisual3D`，由模型代理提供权威增益时钟与护盾状态，不驱动战斗。

## 挂接与尺寸

原版 Scripts.wad.client 的 OlafFrenziedStrikes 明确声明两份 W_cas 分别绑定 L_BUFFBONE_GLB_HAND_LOC、R_BUFFBONE_GLB_HAND_LOC；两份 W_buf_blood 声明 BUFFBONE_CSTM_WEAPON_4、BUFFBONE_CSTM_WEAPON_2。后者实际只有 AttachedMesh 发射器，项目将其合并为一次目标蒙皮叠加，避免把全身染色叠两遍；这是适配，不宣称还原原引擎的材质选择规则。

护盾使用模型根位置上方的稳定中心，源 ground_sub 自带 -100 高度偏移，因此整体抬高 100 个对应缩放单位，内部层次保持原值。武器持续粒子绑 L_weapon/R_weapon，并将源 +Y 轴映射到模型斧柄 -X 轴，随骨骼旋转。护盾和武器持续光效的原版调用挂点仍缺直接证据，这两处为项目适配。

模型源 SKL 的根平移 (3.079623, 74.204971, -13.385173) 与 GLB 根平移 (-0.026177, 0.630742, -0.113774) 对应 X 镜像与 0.0085 单位比例。每帧读取模型骨架世界缩放，不再写死粒子尺寸；当前包装为 1.42。紧凑适配系数：双手闪光 0.6、护盾 0.75、双斧粒子 0.5，得到 0.007242 / 0.0090525 / 0.006035；护盾中心高 0.90525。护盾的两层起手蒙皮闪光保留原版时间曲线与透明度，不降低起手亮度。

## 播放顺序

- 激活时同时启动双手闪光、护盾和增益层；各系统内部沿源采样播放，不额外插入施法动作或人为串行延迟。
- 施放闪光自然消退；护盾层持续到护盾提前耗尽或 2.5 秒自然到期。
- 武器光效与单份蒙皮增益持续到 5 秒；buf_blood 的发射器寿命 0.1 秒不代表粒子寿命，其粒子为 -1，跟随系统存续。
- 暂停沿权威时钟停住；凝滞隐藏粒子及蒙皮叠加，恢复按已有年龄显示，不重播施放；死亡和增益结束关闭全部层。

## 已知边界

W_buf_glow 的 axe_glow 为 quadType 6 Beam，现有采样没有原版运行时端点，播放器不再将它错误画成普通面片；其余五个武器发射器保留。W_shield_child 与 W_heal 仍只有资源证据，没有可确认的触发调用，不凭名称补造破盾或回血时序。回血沿用通用提示。资源提供者继续声明完整依赖，纳入公共预热。
