# 潘森特效

[返回潘森](../pantheon.md) · [总索引](../README.md)

2026-09-27用户确认当前特效定稿。只接入大招落地段，不接蓄力、起跳、升空及起跳提示。当前登场使用LoL原版长矛、fly/slide骨骼代理、纹理和七组粒子数据，由Godot适配播放。当前文件职责、112层/67项资源清单、坐标、时序和支持边界统一见[落地素材与接入设计](pantheon_arrival_resources.md)。

以下时间从预部署动画开始计，不包含普通下牌的0.5秒命令缓冲。

| 阶段 | 表现 |
| --- | --- |
| 0–0.2秒 | 长矛从己方侧斜落至下牌点，保持斜插 |
| 0.2–0.65秒 | 人物与彗星俯冲到长矛后方三格 |
| 0.65–1.3秒 | 人物沿权威缓出轨迹滑向长矛；罩体跟随，火星/碎石脱离，拖痕留地 |
| 1.3秒后 | 下牌点生成真实潘森并拿矛收势；1.35秒冲击罩消亡，从其位置和朝向接出原有余波组合，至2.25秒消散 |

重构后的适配配置独立于原版转换数据；逐层登记附着、游离、地面和轨迹用途，项目修正不再混入原曲线。固定表现采样支持跳帧、迟到快照和倒拖重播；乘色出生滚速、偏移与拖尾平铺长度已从原定义补入。地面波缘与碎屑流动朝向行进轴，两层空气线保留上一版-125/+125居中组配置。

登场伤害仍由权威20Hz预部署扫掠结算，半径90、100点地面伤害，每个敌人含建筑一次；不伤友军与空军。到点才创建单位，拿矛不补第二次伤害。长矛视觉倾角、中体型比例与既有登场音轨保持。清场/终局释放表现节点。未完整复刻LoL粒子引擎，不把未支持的折射、导航遮罩等写为完成。

满四层红怒参照Pantheon_Base_P_enraged：长枪和盾牌使用原版P_Weapons_Glow及Q_Nebula_Streak_Mult_Vertical叠加滚动橙红光，身体、手臂和头盔使用深红边缘脉冲。原版Enrage_Flare纹理参与身体脉冲。未满层关闭，施法耗怒/资格移除/死亡/回收立即清理；冻结骨骼不停止已有红怒材质时钟。状态从Unit已同步资源比例读取，客户端不计算获得或消费。

未满层条为白色，4层为RGB(0.65,0.045,0.07)的暗深红。蓝红阵营共用效果，不使用队伍颜色替代怒气颜色。

当前简化：长矛只保留本体落下，飞行光焰/轨迹与长矛插地特效已停用；人物俯冲、撞地、滑行及收尾保留。43项“不要”已应用；当前启用5系统69层，审查包保留原编号和已确认清单。部署时序与伤害几何见[潘森手册](../pantheon.md#部署时序与登场伤害)。
