# 潘森特效

[返回潘森](../pantheon.md) · [总索引](../README.md)

[落地素材、方向与时序清单](pantheon_arrival_resources.md)记录各组原版坐标、锚点和使用顺序。

当前登场使用 LoL 原版长矛、fly/slide 骨骼代理、纹理、特效网格和六组粒子定义，由 Godot 播放器适配。

| 阶段 | 当前表现 |
| --- | --- |
| 0–0.2秒 | 长矛沿己方朝敌方的正方向从空中斜落，枪尖落到下牌点 |
| 插地等待 | 同一把长矛保持倾角，枪柄向己方侧上方延伸，不切换直立长矛 |
| 0.2–0.65秒 | 带深色人物剪影的火焰彗星斜落到长矛后方3格 |
| 0.65–1.3秒 | 彗星沿权威缓出轨迹继续滑向长矛，弧形冲击波在前，火焰和火星拖在后方 |
| 到达长矛（1.3秒） | 移除代理，创建真实潘森；收尾余波从固定到点位置向前消散，实体接拿矛和收势动画 |

当前俯视镜头接近世界45°，严格同角度会把蓝方长矛压成一个点，因此采用高度/地面距离0.5的表现倾角（约26.6°），蓝红双方统一；枪尖落点、地面朝向和后方3格不变。飞行与插地使用同一倾角，屏幕投影必须仍从己方侧向敌方正向推进。

六组系统为 Spear_Impact、update_missile、Sliding_Comet、Damage_Mis、Update_Impact、Ending_Shockwave，共98个原版发射器定义、64项实际依赖资源。长矛独立保持斜插，剔除重复的直立长矛发射器。人物代理使用原版星空纹理及原版橙红色参数。

出生偏移按三维向量及各轴概率曲线读取；飞行/滑行特效的局部 +Y 映射前进方向、+Z 映射上方；Ending_Shockwave独立使用 +X 前进、+Y 向上，使原版火光、拖尾和掀土波沿滑行方向移动。模型缩放由1.3改为1.05；长矛、代理和附属粒子比例同步缩小至原来的80.77%，三格路径与伤害半径保持权威尺寸。

自制热浪已移除；未完整复刻 LoL 的软深度、导航遮罩及 FlexShape。每系统最多220个存活粒子，到部署点清理预部署代理；收尾波通过实体已有部署表现接口运行0.9秒后清理。世界重力不经过局部轴变换；地裂和地面光强制贴地。撞地半弧网格按原始+X前沿单独对齐，碎石保留原版左右随机散射。

登场伤害仍由权威20Hz预部署扫掠结算，半径90、100点地面伤害，每个敌人含建筑一次；不伤友军与空军。纯表现不驱动模拟，到点才创建单位，拿矛不补第二次伤害。清场/结束移除整个表现节点。

来源和哈希见[原版资源记录](../../../assets/units/pantheon/r_original/source_manifest.json)。上一版程序火焰已退出运行并归档，原版登场声音保持现有时序。

满四层红怒参照Pantheon_Base_P_enraged：长枪和盾牌使用原版P_Weapons_Glow及Q_Nebula_Streak_Mult_Vertical叠加滚动橙红光，身体、手臂和头盔使用深红边缘脉冲。原版Enrage_Flare纹理参与身体脉冲。未满层关闭，施法耗怒/资格移除/死亡/回收立即清理；冻结骨骼不停止已有红怒材质时钟。状态从Unit已同步资源比例读取，客户端不计算获得或消费。

未满层条为白色，4层为RGB(0.65,0.045,0.07)的暗深红。蓝红阵营共用效果，不使用队伍颜色替代怒气颜色。
