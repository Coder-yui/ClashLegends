# 爆破鬼才：原版粒子

[返回单位](../ziggs.md) · [返回总索引](../README.md)

普通弹体使用 `Ziggs_Base_BA_mis` 及其 `Ziggs_Base_BA_Fuse_Trail` 子系统；强化三段分别使用 `Ziggs_Base_Q_mis_01/02/03` 的炸弹网格与 `Ziggs_Base_Q_Fuse_Trail` 子系统；每次落地使用 `Ziggs_Base_Q_explosion`，不再叠加弹跳接地层。引信通过原始childSet模拟器生成，保留原生旋转、颜色与纹理，不用静态圆球替代。

粒子保留原生XYZ比例，弹体缩放0.014；普通落地爆炸按半径30像素等比缩放0.00375，强化每次落地按40像素等比缩放0.005。轨迹高度仅影响表现。地面、透明排序和深度开关逐层映射到共用粒子渲染策略，50层深度检查无错误。

`BallisticAttack`只在服务器/单机20Hz推进固定落点；3D代理消费位置、弧高、外观ID和可靠落地事件。客户端不模拟伤害或弹跳次数，不添加节点引用到网络载荷。资源由卡牌效果依赖声明预热；弹体/每段结束停止发射并让既有脱离烟尘自然结束，爆炸保留完整采样尾段（源最后可见粒子约2.27秒）；清场释放在途、尾迹、爆炸及引信。

来源为本机只读 `Ziggs.wad.client`，提取、解析、采样与实际截图在开发素材库爆破鬼才任务目录。

强化待发采用原版 `Ziggs_Base_P_buf` 的4层粒子，绑定模型 `Bomb` 骨骼，世界等比缩放0.014。首次激活播放闪光，持续阶段循环稳定段；火星按源bindWeight寿命曲线跟随/脱离移动，而非始终粘在骨骼；由同步的强化待发状态控制，次数耗尽、死亡或清场时移除，凝滞隐藏并暂停。骨骼绑定为项目模型适配，未声明复现原版脚本绑定。

项目改编保留：普通攻击同样采用Q地面爆炸来表现范围伤害，未改回原版BA_tar单目标闪光；强化每次落地均爆炸，取消原版Q接地粒子和接地音。此处是用户指定玩法与表现，不宣称完整复刻原版技能。
