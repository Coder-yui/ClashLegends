# 灵魂触手 · 特效

[← 返回灵魂触手](../soul_tentacle.md) · [总索引](../README.md)

触手外观使用原生P_TentacleAvatarDormant/Active附着网格层，保留纹理、滚动、透明度、白色反射贴图对应的视角项及源深度标志。原模型的亮色基础贴图不直接作为最终外观；原版MatOverride层由透明基础材质替代，光边与主体来自附着层。

部署使用P_TentacleSpawn；拍地节点播放P_TentacleCas；强化期间使用P_TentacleBaseActive及起始R_TentacleBurst。模型及上述粒子保留原生XYZ比例，按原版拍击宽200映射到2格，统一缩放0.01。采样播放读取攻击进度。

范围预警使用独立原版P_IndicatorBLU/Red系统，各保留GroundLines、Side1、Side2三层，蓝红贴图与侧边颜色分别来自源件。按本地观察方显示友军蓝、敌军红，翻转视角随之切换。提示方向在起手锁定，拍击后消失。

按用户指定范围独立适配为宽2格、长9格（权威80×360像素），不再绘制项目纯色矩形。原GroundLines蓝方半尺寸120×506、红方140×540.5，中心Z=460；分别将完整地面矩形缩放并平移至X=[-1,1]、Z=[0,9]。侧边粒子跟随同一映射，Y保持0.01等比高度；没有相机压平。原生纹理边缘有透明和光晕，不作为碰撞依据。原版逐帧视觉等价及主观观感仍需用户对照确认。

附着层从稳定采样帧延续原版乘色UV滚速0.1/秒，不再把1～4秒采样硬循环。透明模型不投射实体阴影，避免不可见基础材质产生不匹配的摆动阴影。
