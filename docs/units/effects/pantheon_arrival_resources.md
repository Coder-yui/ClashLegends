# 潘森大招落地：素材与接入设计

[返回特效说明](pantheon.md) · [返回潘森](../pantheon.md)

2026-09-27用户确认当前特效定稿，后续不再继续本轮外观迭代。当前只播放落地段，使用用户已选用的素材。43项“不要”保持停用；登记7系统112层，实际启用5系统69层，另有独立长矛和两段骨骼剪影。原始转换数据和项目编排分开维护。

## 当前约定

- **空中俯冲 update_missile、滑行彗星 Sliding_Comet**：选用层恢复原版相对偏移、旋转、缩放和曲线；撤销L024/L025单独转向、L040–L043按脚骨重排。地面投影及坐标轴转换仍由Godot适配层处理。
- **两段剪影**：空中使用原版Temp_Mesh4与pantheon_spell4_fly，偏移(0,-50,-250)、统一缩放0.8；滑行使用PantheonSllide与pantheon_spell4_slide，偏移(0,-100,-70)、统一缩放1。两者都在所属彗星坐标系中，读取各自颜色曲线、UV、绘制优先级；不另加模型高度补偿或独立放大，不把骨骼动画挤压到整段时长。glTF已转换到Godot坐标，统一坐标映射后播放。
- **滑行冲击波 Damage_Mis、余波 Ending_Shockwave**：保留上一版所有逐层配置、选用项、偏移、朝向、缩放，仅修正两者衔接。Air Streak仍为-125/+125组中心适配，center_mesh_z保留；余波地面波缘仍保留ground_front等已确认的方向配置。
- **下牌点**：是正式潘森出现的位置，也是独立长矛标记的枪尖落点。长矛恢复原来的斜落/斜插网格与角度，取消按Spell4_Hit第0秒烘焙的枪位适配。长矛轨迹与插地粒子保持停用。

## 冲击罩到余波

原文件Damage_Mis/Temp_Mesh1声明childEmitOnDeath，子效果为Pantheon_R_Ending_Shockwave。父粒子寿命0.7秒，出生偏移(0,-450,0)，不是在单位出生点另放一组余波。

预部署0.65秒开始播放冲击波，父粒子应在出牌后1.35秒消亡。正式单位仍在1.3秒出现：单位表现承接尚未到期、绑定系统的单粒子罩体层，补完剩余0.05秒；父罩体消亡时记录其世界位置和正交朝向，子余波从该变换开始播放原来的组合。继承不包含父网格的6/4/4.5缩放，子层保留自身原始尺寸。节点所有者冻结这一交接点，后续单位移动、转身或推挤不拖动余波。没有任意递归子效果图，也不由粒子控制单位生成或伤害。

| 时间 | 表现 |
| --- | --- |
| 0–0.2秒 | 独立长矛落到下牌点；无长矛轨迹、插地粒子 |
| 0.2–0.65秒 | 空中彗星＋第一剪影fly |
| 0.65–1.3秒 | 滑行彗星＋第二剪影slide、既有滑行冲击波 |
| 1.3秒 | 潘森在下牌点出现并播放拿矛动作；独立标记长矛回收 |
| 1.35秒 | 冲击罩达到原版寿命，触发子余波 |
| 至2.25秒 | 余波原组合推进消散 |

1.3秒预部署和当前滑行距离不是后续动画调整的硬约束。本轮未改权威数值：20Hz、后方120像素滑行、90半径、100地面伤害一次；拿矛收势1秒。若以后调整时序，应同时更新权威轨迹和表现配置。

## 文件职责

所有资源路径相对于assets/units/pantheon。

| 文件 | 职责 |
| --- | --- |
| r_original/source_manifest.json | 67项原始纹理、网格、骨骼代理的来源与哈希 |
| r_original/systems.json | 112层转换数据与曲线，保持源数据 |
| arrival/native_composition.json | 从原版定义提取两段骨骼发射器及明确的父子关系 |
| arrival/integration.json | 系统阶段、已选/停用层及项目适配；enabled:false不创建发射器 |
| arrival/profile.gd | 读取配置，统一坐标映射 |
| arrival/particle_player.gd、particle_*.gdshader | 粒子与世界拖尾采样；消亡时报告该粒子最终姿态 |
| arrival/original_comet.gd | 预部署系统组合 |
| pantheon_arrival.gd | 长矛、fly/slide代理、只读权威轨迹 |
| pantheon_view.gd | 单位出现后承接冲击罩，消费父粒子消亡事件并播放子余波 |
| visual_metrics.gd | 项目表现标尺，不调整权威范围 |

120Hz固定表现采样使低帧率、迟到快照和倒拖重播保持出生/轨迹稳定，不构成第二套战斗模拟。动画与粒子不驱动伤害、生成、移动或网络状态。

## 复现与审查

原版定义在本地ClashLegends-开发素材库/03-制作中/潘森/大招落地研究/definitions；制作入口仍为同卡的落地接入重构目录。起跳蓄力cas、砸盾Cas_Shield_Slam、起跳冲击Cas_Jump_Shockwave及起跳提示不进入运行组合。共享资源即使文件名带cas，只要落地层实际引用就保留。

网站保留L001–L112、G01–G07、P01–P03编号。“空中俯冲”和“滑行彗星”组合卡包含对应剪影，P02/P03可单独查看。用户勾选保存到当前审查包selections.json，不直接修改游戏或已录视频；应用后显示“已在游戏中停用”。旧停用层视频保留作对照，生成新包时保留用户清单。

## 支持边界

这是Godot适配，不是完整LoL粒子引擎。原生软深度、导航遮罩、FlexShape、折射、纹理寻址、逐帧图集、基于速度的发射及通用子效果图仍未完整实现。只支持这里明确的冲击罩消亡→余波关系；纹理、原网格和骨骼动画来自已有转换素材。当前特效观感已由用户确认；上述原引擎能力边界仍保留。
