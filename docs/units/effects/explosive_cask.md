# 爆破酒桶 · 特效

[返回卡牌](../explosive_cask.md)

使用更新本地资源库的 Gragas 基础皮肤 R。飞行 Mis 5 层、落点爆炸 End 19 层、真实命中 Tar 5 层，源定义禁用的发射器保持禁用。

落点爆炸采用独立复现结果的三维采样：直接读取原始 BIN 组织、TEX 和 SCB，保留出生数量/延迟、随机参数、完整运动与外观曲线，以 120 Hz 采样交给专用 Godot 播放器。运行中使用原始三维网格及相机朝向面片，不是平面爆炸视频。网格顶点透明度、背面剔除、双纹理 UV、侵蚀、软粒子和绘制顺序独立适配，不再经过潘森的简化 End 播放路径。最晚地面余迹延迟 0.3 秒、持续 1.8 秒，整体保留 2.15 秒后释放。

原始 11 层的关闭深度测试标志已执行，另 8 层保留深度遮挡。爆炸按原始 350 单位参考半径映射为法术 105 半径，并补偿战场相机的地面投影；主扩散范围与落点圈对应，碎屑、偏心纹理和淡出软边沿用原始形态。相机朝向粒子保持原比例。具体空间分配遵循[法术投影约定](../../reference/SPELL_EFFECT_PROJECTION.md)，中心分布与本体形状分别变换。

从己方水晶向固定落点抛出，105 半径圆圈只提示范围。权威抵达事件切换爆炸，真实命中回执才触发受击层；被法术盾抵挡、凝滞或未命中不伪造受击。客户端通过可靠飞行、抵达和卡牌事件复现，特效不决定伤害或击退。Mis 保留原五层素材与连续 CameraTrail，使用独立飞行时钟按出生位置重播；Tar 沿用目标位置上的独立等比表现。

已核对原始值树和 43 个依赖哈希，完成 Godot 实际战场渲染、暂停与清场检查。采样固定 seed 79，因此每次爆炸的随机图案一致；原引擎无贴图 palette 缺省行为仍未确认，屏幕扭曲的背景分组与 Godot 有差异，不宣称逐像素还原。骨骼绑定、场景光照不属于本轮要求。

来源、生成方法与精确边界见 [爆炸适配说明](../../../assets/effects/explosive_cask/native_end/README.md)，其他阶段见 [素材说明](../../../assets/effects/explosive_cask/README.md)。

## 本卡的投影分配

| 原版层 | 适配方式 |
| --- | --- |
| Pool、PoolDark、Flame_Shockwave、fireRing、floordarlk | 地面范围形状随 XZ 补偿 |
| DistortFAST、shadow | 虽未标 groundLayer，仍为近平地范围面；XZ 补偿，保留原始 10/3 单位高度 |
| PierceBubble、Ring_、mesh | 中央泡状穹顶、圆柱及锥形网格底座随 XZ；保留原始 Y 尺寸与位置曲线，不因 groundLayer 强制压平 |
| Sand_Burst | 散射中心与水平运动随范围；贴片本体不拉伸，保留任意四边形朝向，继续贴地 |
| Verticalline | 中心随范围，射线方向、宽度与长度不套地面拉伸；朝相机求射线侧向 |
| BigLensFlare、CenterFlare、EnergySpray、Splashes_IN、Splashes_IN1、flash_Add、wood | 中心随范围，Billboard 尺寸保持原比例；定向粒子跟随映射后的运动方向 |
| Mis：barrel、BarrelGlow | 独立等比换算 0.00365 世界单位/源单位，酒桶与随身光晕本体额外放大 2 倍，不随法术半径变化；弧高 140、起始高 45 为独立屏幕像素参数，经通用入口换算为世界 UP 高度 |
| Mis：Trail_Boost、Trail_Glow、spray2 | 按原始 bind=0 保存各出生时刻的世界位置；两条拖尾仍为连续带状几何，抵达停止发射后保留最长 0.4 秒余迹 |
| Tar 五层 | 以真实命中回执位置定位，独立等比换算 0.008，不做 AOE 拉伸；本轮不加骨骼跟随 |

权威半径仍为 105。实际范围参考必须读 `play_card()` 吸附后的权威落点，不能把请求坐标当作最终落点。当前实现未更换原始 19 层采样或纹理；空间分配是本项目的投影适配，不代表 LoL 的完整坐标合同。

本局卡组包含此法术时，纹理由MatchResources提前收集，加载阶段通过SpellEffectWarmup实际绘制完整时序样本，保留材质/网格后清理样本；原生JSON进入导出包。见[加载职责](../../MAINTENANCE_ARCHITECTURE.md#法术加载与绘制准备)。
