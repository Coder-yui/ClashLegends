# 金克丝特效

[返回金克丝](../jinx.md) · [轻机枪](../jinx_minigun.md) · [总索引](../README.md)

火箭使用原版Jinx_Q_Rocket.scb的161顶点、292三角面和原UV纹理，投影为项目2D弹体；尾迹使用Jinx_Base_Q_Trail01。机枪继续使用金克丝原版Jinx_Basic_Bullet贴图，独立于库奇弹体；此次按用户确认保留现状。爆炸使用原版Jinx_Explosion_Smoke与Jinx_Explosion_Flat的2×2图集，按命中事件播放0.38秒。

罪恶快感使用原版overdrivelines_iblitz拖线与Jinx_Base_P_Buf笑脸，随权威/快照状态显示。保留原版出生分布与负Z速度，在单位根挂载上增加(0,-50,-90)源单位校正，使新线位于躯干略后方（局部Z=-0.0952，高度0.476–1.428，外层再随模型放大1.1倍），不从身前发射。新线跟随单位根朝向，已发粒子保留世界空间运动，原版负Z初速映射为后向速度。任意四边形在Godot中将长轴对齐运动方向。

发射密度按6秒被动剩余时间衰减，再触发时随新的6秒窗口恢复；层数增加不会叠出多套速度线。切枪保留实例，凝滞隐藏并清理粒子但计时继续，恢复不重播笑脸，结束或死亡清理。

原版可核对的直接证据为本地 `shared-bins/12d22b526a64fe59.ritobin` 中 `Jinx_Base_Passive_Buff`。官方参考：[金克丝技能页](https://www.leagueoflegends.com/en-us/champions/jinx/)及其中的[被动演示](https://lol.dyn.riotcdn.net/x/videos/champion-abilities/0222/ability_0222_P1.mp4)。素材包未提供完整特效挂点调用脚本，尚不能证明其绑定到哪一根角色骨骼；目前采用单位根变换与原版发射器参数适配，不宣称完整复现LoL调用链。

火箭爆炸在真实命中中心播放，主火焰约0.095秒展开到45像素最大半径，烟雾柔和扩散且外沿不超过45像素，0.38秒内淡出。两层均有圆形软边约束，烟雾使用正常透明混合、火焰使用加法混合。与目标身体圆相交的伤害判定保持原规则；临时验收范围圈不进入游戏表现。

这些是原版资源在Godot中的适配重建，不是LoL完整粒子系统逐层移植：原版爆炸的扭曲、球体网格、多层能量与随机烟羽未全部还原。权威范围45像素，与纹理尺寸、粒子运动无关。仍需用户确认适配后的观感是否满足原版效果要求。

2026-10-07调整：加速线尺寸、位置和速度保持SKL→GLB的0.0085换算，再随模型缩放；在此基础上宽度增加20%、发射率24→0、蓝白亮度略增，出生点仍在躯干后方。火箭爆炸按用户选择恢复烟雾与火焰2×2图集、0.38秒及45像素范围适配；撤回试验的三层命中效果。

范围校准：火焰采样图集每格中心82%的区域，烟雾采样90%，补偿原图留白；圆形软边从半径90%处开始，半径外完全透明。火焰约0.095秒展开，烟雾约0.171秒达到45px外沿，保留0.38秒烟火寿命与风格。权威判定是目标身体圆与45px爆炸圆相交，目标中心在圆外但身体触边仍可受伤，不因此扩大特效半径。
