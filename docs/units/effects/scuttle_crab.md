# 峡谷迅捷蟹：特效

[返回单位](../scuttle_crab.md) · [总索引](../README.md)

死亡治疗区复现基础河蟹`SRU_Crab_Base_Z_VisionRing_Green/Red`，各5层：两层河岸水纹、阵营边界、光点、流动水纹。源Team_Indicator网格半径250.156映射权威110像素；己方使用Green、敌方Red，按观察者阵营选择。源区域原用于视野/加速，在本项目仅表现死亡治疗区，不附加视野或加速规则。

谦卑复现`Items/3143/Particles/3143_Active_Cas`的13层施放特效，保留原纹理、网格、时间及颜色曲线；源500半径标尺映射项目130像素，播放3秒。受影响对象使用项目通用减速、减攻速提示，不重复叠加兰顿Debuff粒子。

资源采样120fps，播放由可靠区域事件时钟驱动，不参与权威判定。卡牌与技能分别声明基础区域/兰顿资源依赖，双方原数据、材质及纹理纳入资源预热。生命周期实际渲染检查覆盖出现、持续与清场；原文件、转换和来源哈希保存在本地制作目录及正式来源清单。

区域中心触角由死亡视觉代理的同一骨骼连续播放：burrow → ward_run_toground → ward_spawn → ward_idle → ward_tohide，沿用单位0.91缩放及死亡朝向，不再切换独立Ward模型。第2秒开启光圈、antenna_wake和形成声音，第4.8秒才开始6秒治疗；第8.5秒开始收起触角，第10.8秒治疗、光圈与触角一起结束。清场/终局取消整段。

按用户反馈停用原版 Ward Shadow 黑影层，仅保留圈、中央波纹和蟹耳朵。
