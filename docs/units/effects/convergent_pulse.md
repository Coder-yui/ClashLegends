# 聚合脉冲特效

[← 聚合脉冲](../convergent_pulse.md) · [总索引](../README.md)

来自本地Orianna.wad.client基础皮肤的 `Orianna_Base_R_VacuumIndicator`（19层）与 `Orianna_Base_R_VacuumIndicatorSelfNoRing`（12层），组合为范围提示、向内冲击、中心蓄能与收束爆发。120Hz离线采样保留原始贴图、网格、颜色及生命周期；两种范围以 `Indicator_OuterRing_Core` 的亮线半径378.684694原生单位校准，等比例缩放XYZ；把该层原生Y=-30平面对齐地面，整体平移并保留层间高度，不抵消54°镜头投影。

逐层miscRenderFlags映射深度测试，复用太阳耀斑已接入的原生粒子着色器；保留混合、软粒子、侵蚀和扭曲参数。双方使用同一原生主效果；未叠加独立的ally附加圈。按需求不接入命中单位身上的受击特效；逐目标命中音效保留。素材与源定义保存在开发素材库的05-已完成/聚合脉冲/源件与过程记录目录。源数据还原不代表已逐帧对照原版客户端。

卡面为内置imagegen生成的机械球向心脉冲插画，正式图616×1120；强化图标取原版OriannaR.dds，来源及哈希见assets/skills/source_manifest.json。

## 原生图案、边界与时序复核

`ADDmAZE` 使用原始 `Orianna_Base_R_Decal`：贴图内的偏置圆弧和小圆本来不中心对称；另乘滚动的 `Orianna_Base_R_Noise` 与原始侵蚀贴图，因此局部亮度也不对称。没有替换图案、加镜像对称或挪动这一层。原始平面、90°朝向、统一400缩放、UV与逐帧变换均与提取采样一致。

核心圈的 `Donut03_Thin` 网格顶点alpha=255亮线半径约23.667793，乘原生统一缩放16得到378.684694；网格外缘409.266是透明衰减边，不作为范围边界。以前用技能数值415做缩放分母会使105/130px作用范围对应的亮线只有95.812/118.624px。修正仅调整表现缩放与原生地面锚点，105/130px玩法与预览半径不变；身体圆接触即命中的规则也不变。

源定义核心圈与ADDmAZE在0.2秒开始，粒子寿命分别0.45/0.5秒；范围爆发与中心爆发源延迟均为0.65秒，对应权威13Tick。120Hz模拟采样的首次可见帧与源延迟有最多约1帧差异；不另加0.25秒、不把完整粒子片段整体变速。两个系统无额外源transform/buildUpTime。校准的是本项目固定落点法术；原版跟随魔偶、持球英雄及运行时挂接行为未做客户端逐帧验证，不将独立素材预览当成完整LoL实机复刻。

## 阵营分支核查

本地原包的现代 `R_VacuumIndicator` 与 `R_VacuumIndicatorSelfRing` 核心环均为蓝色（RGB 0.20392157/0.5882353/1）；未找到R的red/enemy独立系统或已确认的运行时敌我颜色映射。`R_VacuumIndicator_ally` 是不同的旧层结构，且引用Dissonance（W）音效，不能据此认定为现代R阵营分支；W的red/green资源不用于本卡。目前双方共用原版蓝色R。此结论仅覆盖已检查的本地资源，不宣称已完成LoL客户端敌我视角对照。
