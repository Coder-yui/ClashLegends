# 中型雷电法术特效

[返回卡牌](../medium_lightning.md) · [返回总索引](../README.md)

使用Volibear基础皮肤原始系统、纹理与网格，120Hz固定种子采样保留颜色、UV、粒子运动、混合与深度标志。完整来源与SHA-256见[资源清单](../../../assets/effects/medium_lightning/source_manifest.json)。

| 阶段 | 原系统 | 当前组织 |
| --- | --- | --- |
| E施法方预警 | E_AOE_Warning（12层） | 0秒开始，保留原生尾迹 |
| E敌方预警 | E_AOE_Warning_Enemy（5层） | 1秒开始，仅敌方显示 |
| E落雷 | E_AOE（16层） | 2秒触发，与伤害同一权威事件 |
| R塔命中 | R_towerHit_01 / R_towerHitCrack_01（共4层） | 真实命中存活防御塔时，附着闪光与空间裂纹共同开始 |
| R塔失效 | R_disabledTower_A（8层） | 暗化、电流、开始闪光；持续2秒后停止，尾迹保留至2.3秒 |

敌我差异按观看者本地阵营判断，不固定绑定蓝方或红方：换到红方视角，红方施法显示完整己方预警，蓝方施法显示敌方预警。敌方预警呈红橙色：原版E_AOE_Warning_Enemy的Static、WarningAddA/B/BG四层使用Volibear_Base_colorGrad的索引15（第16行）。Shader按原始亮度权重查色表、替换RGB并保留透明度，再计算其他纹理与粒子颜色；此前遗漏该步骤导致红圈缺失，现已修正。E落雷与R塔失效共用原版系统；当前仅对WarningAddA/B/BG三个范围圈层启用该映射。上次扩展到Static、烟雾、旋流、落雷与塔体层后出现明显外观回归，已撤回这些额外层的色表映射，恢复修改前表现；其他层的完整原版色表复现未验收。

EndFlash_A在源资源中为5.9秒延迟发射，并非停止事件自动触发。本卡使用2秒失效窗口，因此只将结束闪光发射时间平移至1.9秒，保留其0.25秒粒子曲线；不整体压缩R的开始、持续与结束速度。重复施法替换同塔附着链，塔死亡立即清除，结束后恢复原材质。

E以325源单位校准到100权威像素，XYZ统一缩放，不抵消54°镜头投影。R附着层复用塔体几何与表面裁切，空间层以塔体半径校准。护盾血条与减速状态提示沿用通用入口；防御塔失效自身只显示原版塔体失效特效，不产生眩晕标识；叠加其他眩晕时正常显示其标识，控制逻辑保持不变；本法术没有狗熊角色，因此不挂载英雄手部E_cas或整套R跳跃/落地动画。未取得LoL客户端逐帧对照，源资源适配不等于完整客户端复刻。
