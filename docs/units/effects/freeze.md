# 冰冻 · 特效说明

## 画面中会出现什么

冰冻区域使用冰脉护手装备的 `6662_Slow_Field` 原版粒子系统，含冰面、外圈、冰晶和起手扩散。半径 110，持续 3 秒。地面与人物共享深度检测，冰面不盖住人物；边界按施法阵营显示蓝色或红色，内部保留原版颜色。冰面与减速地面均按贴图可见外沿校准缩放，补偿透明留白，使本体覆盖到各自作用边界。

强化冰冻在施放当刻同时生成巨魔基础皮肤 W 的地面特效 `Trundle_Base_W_ground`：裂纹、扩散和冷雾（按要求去掉暗底）。减速区域半径 137.5，为冰冻半径的 1.25 倍，总计持续 5 秒。前 3 秒重叠的内圈被冰冻效果遮住，外侧可见减速场；冰冻结束后露出完整减速场，再持续 2 秒后移除。区域内敌军移速与攻速各降低 30%；离开后停止续期，短暂状态到期恢复。

受到冻结的人物、建筑卡主体与自带基座保留淡蓝模型覆盖；防御塔仅覆盖塔身，已脱离碎块保持原色。水晶免疫冰冻。解冻后的双减速不保留冰冻模型覆盖，沿用通用状态提示。强化技能图标仍使用冰脉护手装备图标。
