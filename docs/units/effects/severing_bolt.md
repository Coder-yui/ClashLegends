# 攢聚雷特效

[返回攢聚雷](../severing_bolt.md)

本机只读Hwei.wad.client基础皮肤的Q_W_warning和Q_W_AoE：预警19层、爆炸17层、受击5层，120Hz采样到5秒。源单位225对应权威65像素，XYZ统一缩放，不为54度相机压平或拉伸。预警主体、爆炸、受击共用原版配色；敌方另外叠加原版Q_W_warning_red的1层红圈。敌我是相对当前观察方，不把固定team=1永远当敌人。

保留网格、贴图、UV、颜色、尺寸、侵蚀、软粒子、排序与逐层深度标志；材质和预热共用Shader路径。粒子采样器并非LoL完整运行时，本组没有减色层、定制材质、子发射器、反射、拖尾或Beam。独立受击Q_W_Tar的5层在真实命中回执结算后于命中位置播放；法术盾拒绝时不产生，地面落雷空放仍显示。

卡面由imagegen根据QW原图标的橙金雷霆、紫黑墨迹概念生成，本轮加宽橙金色主体笔触、强化粗细和尖端收束变化，正式尺寸308×560；强化图标为原版HweiQW.dds解码PNG。源定义、提取脚本、原图与音频计划在本机开发素材库本卡目录；正式粒子和哈希见assets/effects/severing_bolt/source_manifest.json。

## 调色与敌我版本核对

2026-10-26修正第一版遗漏：9层预警、6层爆炸、1层受击声明了Hwei_Base_Gradient02调色板，旧播放器虽保存元数据却未采样，导致灰白源贴图直接呈白色。现按原始通道混合值、4行选择和发射器相位U/V曲线重新采样；仅替换贴图RGB并保留alpha，再按原顺序应用颜色渐变、乘纹理、侵蚀和粒子颜色。没有全局强染黄色，也没有把本来白色的高光统一改色。

皮肤资源映射明确包含Hwei_Q_W_warning_red，实际定义位于WAD链接共享BIN，只有Ring_A红色网格圆环；不能仅搜索skin0正文就断言没有敌方版本。该红圈作为附加预警，爆炸及受击未发现独立敌方映射。双方卡组预热都声明共用三组和敌方红圈。

修正翻页贴图在单个图集格内寻址，支持原始透明边界模式；源FB_Elec_Impact两层的depthBiasFactors按坡度与D24单位近似映射，不抬高整组。42层深度测试按源miscRenderFlags逐层选择，16层调色板均有真实纹理和逐帧参数；本地palette-audit.json列出逐层检查。

Godot屏幕扭曲与深度偏移仍有跨渲染器近似，未声明与LoL客户端逐帧完全等价。实际54°战场、分层和有/无地面检查见本次交付记录。
