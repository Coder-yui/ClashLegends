# 永恒梦魇特效

[返回永恒梦魇](../nocturne.md) · [单位索引](../README.md)

原版基础皮肤P_cleave_AoE的8层用于主动强化攻击真实命中；W_Shield_01的10层用于护盾存续，W_spellblock_01的4层用于成功抵挡。使用现有原生粒子播放器，34项纹理/网格依赖及来源清单在assets/effects/nocturne/native。

导出遵守isUniformScale，P与W/抵挡分别按范围和模型体量校准粒子缩放。持续盾和瞬态粒子复用模型胸部/可见网格中心挂点，跟随飞行高度；不读取或修改战斗数值。持续状态复用active_buff快照，护盾消费/到期关闭发射，尾粒子独立淡出。P由命中表现事件启动，不用动画计时猜命中。

此为原版定义的项目播放器适配；没有宣称完整复现LoL渲染器。实战截图已检查主体、护盾挂点和原生统一缩放；不支持的LoL动态绑定/专有渲染差异仍可能影响细节。

P按70权威半径单独校准，粒子换算系数0.007；W与抵挡按1.8模型体量校准，系数0.0105。范围旋斩与贴身护盾不共用缩放。

每次effect_shield:start重新创建W播放器，覆盖工作台护盾未结束时再次施放；旧播放器停止发射并回收尾粒子。W持续主体层使用原始1.5秒粒子寿命，对齐当前1.5秒护盾；P和抵挡层不受影响。
