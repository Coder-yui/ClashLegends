# 凛冬之柱特效

[返回单位](../pillar_of_ice.md) · [总索引](../README.md)

基础皮肤E的PlagueBlock系统按用户勾选保留7层：实体柱体、升起喷溅、地面冰裂纹、常驻冷雾、柱身光束、底部蓝光和地面暗底。雪屑、暗色喷溅、持续落冰和射出碎石已移除。外圈复用项目范围圈着色器，己方蓝、敌方红；基础110、主动200，保持圆形世界几何，经项目相机自然投影为椭圆。

粒子按120Hz离线采样，保留逐层混合、UV、颜色、深度测试及深度偏移。0号加法混合使用预乘后的纯加法，1号透明混合、3号不透明写深度、4号alpha加法分别处理。地面冰裂纹按330源单位半径、冷雾按400源单位分布半径分别校准到110/200；暗底独立按425源单位可见半径校准到110/200（贴图非透明边缘实测420.43，预留双线性过滤余量）；保留原生XYZ比例，柔和雾边不是硬判定边界。柱体、升起喷溅、柱身光束与底部蓝光保持0.009模型比例，不跟着主动范围变大。

受影响对象的移动减速和减攻速提示复用通用状态特效与快照。原生反射立方体字段已留在来源清单，但当前采样播放器未还原环境反射；不是完整LoL光照复刻。LoL实时导航遮罩亦未模拟。

资源：[来源清单](../../../assets/effects/pillar_of_ice/source_manifest.json)。

升起保留所选喷溅层的原速时序、速度、尺寸曲线。常驻烟雾、光束延长发射，保留粒子自身寿命与运动曲线；不再整体回放1～3秒。裂纹、地光和暗底保留原始渐入，再停留于源4秒的稳定外观。

为支持治疗延寿，连续粒子按源4～24秒的出生批次循环；跨周期仍存活的粒子使用其后续原始轨迹接续，不重置、不交叉淡化。源24秒后进入20秒周期。原版禁用的pillar_smoke、Splash_down、ghosts保持禁用。效果不读取导航/碰撞来驱动玩法。
