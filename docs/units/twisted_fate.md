# 卡牌大师

[← 返回总索引](README.md)

## 总览

可在河道之外的全图合法地面位置部署的远程单位。每第五次普攻更强；万能牌会发出三张穿透牌，适合打击排列在路径上的敌人。

## 被动与特殊规则

**远距离部署：**先等待 1.3 秒，再出现并部署 0.45 秒，总计 1.75 秒。**第五击：**伤害提高到 150%，当前为 93；仍是一张普通攻击弹体。

## 主动技能

### 万能牌

朝前方扇出 3 张穿透牌，飞行命中地面或空中敌人时造成伤害；同一敌人每次施法只受伤一次。
