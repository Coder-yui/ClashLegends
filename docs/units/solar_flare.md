# 太阳耀斑

[← 返回总索引](README.md)

2费纯控制法术，改造自曙光女神R。公共出牌延迟后，正式施法0.9秒落光；按落光瞬间位置判定。

| 项目 | 数值与规则 |
| --- | --- |
| 外圈 | 半径100像素，2.5格 |
| 中心 | 半径40像素，1格；中心优先，身体圆接触即命中 |
| 控制 | 中心眩晕1.75秒；外围移速降低80%，持续1.75秒 |
| 伤害 | 基础版0 |
| 目标 | 敌方地面及空中普通单位；中心眩晕也影响建筑卡、防御塔；水晶免疫控制；外围减速不影响建筑，日光可作用于建筑卡、防御塔和水晶 |
| 主动日光 | 额外1费，每次法术一次；命中附加2.5秒标记 |
| 日光触发 | 后续首次有效正伤害追加100伤害（防御塔和水晶按30%结算，为30伤害），随后消耗；护盾可吸收，减伤生效 |

日光重复施加只刷新；零伤害、凝滞拒绝及法术盾挡下的伤害不消费。伤害被普通护盾吸收仍算有效命中。同Tick多个伤害仅首个消费；落光同批伤害先结算，标记随后建立。凝滞中隐藏且继续到期，不补发伤害；死亡清理。控制免疫不阻止独立日光标记，法术盾抵挡整次法术。
