# 拉亚斯特

[返回单位索引](README.md)

由凯隐累计命中近战敌军6次解锁，不能直接放入卡组。后续4费凯隐卡部署拉亚斯特；旧凯隐保留。普攻命中固定回复35生命，附加敌方最大生命3%伤害；防御塔与水晶附伤固定35，建筑卡仍按最大生命比例。

| 数值 | 当前配置 |
| --- | --- |
| 费用／生命 | 4金币／950 |
| 普攻／间隔 | 80／1.1秒 |
| 普攻前摇 | 0.16秒，随攻速缩放 |
| 表面射程／目标 | 32px／地面单位、建筑、塔与水晶 |
| 移速／身体半径 | 68px/s／18px |
| 进入地形回复 | 70生命 |

穿地形、出地形普攻与成长资格共用[凯隐规则](kayn.md)。

## 巨镰横扫（Q）

2金币，6秒冷却，每次部署2次。正常移速68px/s时突进0.43秒，总时长1秒。路径与旋转各90基础伤害，分别附加目标最大生命3%（塔、水晶固定35）；每段至少命中一人回复50生命，多人不增加本段回复，空放不回血。共同距离、阶段、碰撞、受控取消和已提交结果的规则只在[凯隐Q](kayn.md#巨镰横扫q)维护。
