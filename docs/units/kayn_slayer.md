# 影流之镰·红凯

[返回单位索引](README.md)

由普通凯隐累计命中近战敌军6次解锁，不能直接放入卡组。后续4费凯隐卡部署红凯；旧普通凯隐保留。普攻命中固定回复35生命，附加敌方最大生命3%伤害；防御塔与水晶附伤固定35，建筑卡仍按最大生命比例。

| 数值 | 当前配置 |

| 费用／生命 | 4金币／950 |
| 普攻／间隔 | 80／1.1秒 |
| 表面射程／目标 | 32px／地面单位、建筑、塔与水晶 |
| 移速／身体半径 | 68px/s／18px |
| 进入地形回复 | 70生命 |

可穿越河流和双方存活建筑、塔、水晶；桥面视为普通地面。仍受战场边界及同层普通单位碰撞约束。完整圆柱进入地形时回复，连续留在或跨越相连地形只触发一次，完整离开后才能重触发。在地形里不能普攻：先挪到不与地形和单位重叠的合法点，下一权威步重新检查目标、射程和前摇；附近完全无空位则等待。

## 巨镰横扫（Q）

2金币，6秒冷却，每次部署2次。沿施法开始时的朝向突进120px，持续0.3秒；路径碰撞宽40px，对穿过的每个地面敌人造成90伤害。开始后0.5秒，以自身为中心旋转，半径65px，再造成90伤害。总施法0.7秒。红凯每段附加目标最大生命3%伤害（塔、水晶固定35），每段至少命中一人回复50生命；命中多人不增加本段回血，空放不回血。

Q可在地形里使用。突进不推开单位，全程可受伤；结束先寻找不与普通单位重叠的落点，地形仍可进入，再结算旋转。冰冻取消剩余突进和旋转；眩晕不取消已开始Q；击退接管位置、停止剩余突进，旋转仍按原时间在新位置执行。死亡和清场清除后段。

落点使用连续几何查询：比较地面/桥面边界投影、圆柱边界投影及交点，选择最近合法点；同距按阵营前方及横向固定排序。保留0.002px浮点安全余量，无解则等待，不冒用非法落点。
