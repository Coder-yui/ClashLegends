# 皮克斯

[← 返回总索引](README.md)

## 总览

一张卡同时部署五只小型飞行单位，近距离发射紫色光弹。主动技能让这一批仍存活的皮克斯持续吸血，允许生命超过平时上限。

## 被动与特殊规则

**五只一组：**一次出牌生成 5 只，编队间距 36。技能归属这一批存活成员；持有者死亡后资格会交给同组成员。再次出牌不会移除上一批已经获得的吸血。

## 主动技能

### 仙灵汲取

使这次部署中仍存活的所有皮克斯此后的每次普通攻击命中都回复该次实际扣除生命值25%的生命（不含护盾和过量伤害）；可溢出生命上限，最高达到150%。

| 项目 | 当前数值 |
| --- | --- |
| 技能费用 | 1 |
| 最多使用 | 1 次 |
| 冷却 | 0 秒 |
| 吸血比例 | 25% |
| 生命溢出上限 | 150% |
