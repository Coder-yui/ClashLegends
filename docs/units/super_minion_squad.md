# 攻城部队

[← 返回总索引](README.md)

## 总览

一次出牌生成2只超级兵，横向并排站位，中心间隔2.5格（100像素）。每名超级兵为稍大体型、身体半径21。两名成员是独立单位，共享本次部署的主动技能资格。

[查看3D摄影卡面](../../assets/cards/super_minion_squad_loading.png)

## 男爵之力

消耗2金币，可用1次，冷却7秒。施放后为这次下牌中仍存活的两只超级兵分别施加超级兵男爵之力：移速135%、伤害135%与140点护盾，持续5秒。队长阵亡后，主动技能资格转交仍存活的另一只超级兵。
