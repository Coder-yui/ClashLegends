# 正义天使（远程）

[← 返回总索引](README.md)

对地、对空的飞行单位。卡组中只有“正义天使”一张卡；提交出牌时，金币达到6便花6金币部署远程形态，不足6但达到3便花3金币部署近战形态；不足3不能出牌。形态在付款时锁定，部署等待和此后金币变化不会改变已有单位。

## 数值

| 项目 | 当前试玩值 |
| --- | --- |
| 费用 | 6金币，由正义天使自动选择，不能单独组入卡组 |
| 生命 | 820 |
| 普攻伤害 / 间隔 | 105 / 1.5秒（满层约1.07秒） |
| 射程 / 出手前摇 | 190像素 / 0.18秒（创建弹体） |
| 移速 / 身体半径 / 质量 | 60像素每秒 / 18像素 / 4 |
| 部署 | 命令等待0.5秒，生成后部署1秒 |
| 目标 | 空中、地面、建筑 |
| 光剑与焰浪速度 | 420像素每秒 |
| 焰浪伤害 / 起始总宽 | 55 / 1.2格（48像素） |
| 焰浪扩宽 / 延迟 | 横向缩放1→2，按最大合法行程线性增加 / 光剑创建后0.1秒 |
| 焰浪终点 | 出手瞬间目标位置后1格，创建光剑时即锁定 |

光剑追踪主目标，单体造成105伤害，无溅射。每次远程普攻另发一道焰浪，锁定出手方向，由近到远逐渐扩宽，穿过敌人继续飞行；焰浪同时伤害路径内的空中单位、地面单位、建筑、塔和水晶，每对象55伤害一次，不随主目标的空地属性筛选。主目标可叠加160伤害。光剑命中即销毁。光剑创建瞬间，以光剑2D起点及当时目标位置确定焰浪轴线；焰浪晚0.1秒从同一起点创建，终止于该目标旧位置后1格并淡出。目标移动、死亡或光剑拐弯/提前消失均不改变焰浪路径。190像素普攻范围不变；只有攻击合法目标时产生的余波能波及其后方敌人，不获得更远索敌能力。3D表现从天使模型处发出，光剑追踪目标模型，焰浪按锁定路径投影。波前扫掠形成逐渐扩宽的梯形，目标身体接触即可命中，不提前用远端宽度伤害近端侧方。不伤友军，来源死亡不取消已发射光剑或焰浪。

横向缩放初值为1（48像素宽），以当前目标在最大合法出手位置时的行程（含末端1格余波）为标尺，线性到2（96像素宽）；近目标的焰浪提前结束时不到2倍。射程按身体边缘间距判定，标尺计入双方身体半径和光剑出生偏移。只改变横向宽度，不把纵向厚度同时翻倍。

## 共用被动与主动

[近战形态](kayle.md)统一维护登神之阶及星界恩典：真实普攻命中叠10%攻速，最多4层，最后命中后3秒整体到期；焰浪不重复叠层。W为0金币、2次、6秒冷却，回复自身160生命并加速30%持续1秒，施法0.6秒。控制、凝滞抑制、收益和声音按共通规则，不另设远程版本。

两形态共用GLB，工作台“正义天使”可切换部件、材质与动画。
