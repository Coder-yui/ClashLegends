# H-28G进化炮台

[← 单位总索引](README.md)

4费防守建筑，对地对空，单发炮弹造成单体伤害。

| 属性 | 数值 |
| --- | --- |
| 生命 | 720 |
| 伤害 | 70 |
| 攻击间隔 | 0.8秒 |
| 发射前摇 | 0.21秒，20Hz下向上对齐 |
| 射程 | 220像素（5.5格），按双方表面距离 |
| 体型 | 稍大，权威半径21像素 |
| 占地 | 2×2格 |
| 衰减基准时间 | 24秒，每秒自然衰减30生命 |

射程内没有可攻击敌人时收缩待机，敌方不可选取，也不能直接对其结算伤害或控制。敌军进入射程后立即恢复可选取与攻击资格；凝滞、隐身等当前不可攻击目标不触发展开。收缩与展开动画只表现状态，不额外延长保护或阻挡攻击。友方治疗和已有附着效果继续，待机不暂停寿命。

**海克斯修复**：1费，两次，冷却8秒，即时回复240生命，最多回到最大生命；保持每秒30生命的自然衰减，治疗可延长实际存活时间。重伤按通用规则阻止治疗。技能图标为大发明家原版被动图标。
