# 影流刺客

[返回单位索引](README.md)

由凯隐累计命中远程敌军4次解锁，不能直接放入卡组。后续4费凯隐卡部署影流刺客；旧凯隐保留。

| 数值 | 当前配置 |
| --- | --- |
| 费用／生命 | 4金币／650 |
| 普攻／间隔 | 110／0.85秒 |
| 普攻前摇 | 0.12秒，随攻速缩放 |
| 表面射程／目标 | 32px／地面单位、建筑、塔与水晶 |
| 移速／身体半径 | 88px/s／18px |
| 进入地形回复 | 120生命 |

穿地形、出地形普攻与成长资格共用[凯隐规则](kayn.md)。影流刺客每次完整进入地形另获1秒30%移速加成。

## 巨镰横扫（Q）

1金币，6秒冷却，每次部署2次。正常移速88px/s时突进约0.332秒，总时长约0.902秒；路径与旋转各90伤害。共同距离、阶段、碰撞、受控取消和已提交结果的规则只在[凯隐Q](kayn.md#巨镰横扫q)维护。
