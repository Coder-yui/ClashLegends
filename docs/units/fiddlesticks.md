# 远古恐惧（衍生单位）

[返回总索引](README.md)

[草间人](scarecrow.md)的移动形态，在工作台“衍生 / 形态”中独立展示，不进入选卡池。最大生命1200，稍大体型（半径21），移动速度44。

对地对空，射程180、视野250；每目标每秒60持续伤害，回复实际伤害的50%，最多回复到生命上限。攻击时停止移动，没有原版W末跳爆发。由草间人变来时保留当前生命，没有自然衰血，也不恢复主动次数。

每轮开始时锁定射程内全部合法目标，连续汲取2秒，再停0.75秒。目标失效或离开射程即断线，重新进入也须等下一轮。全部断线时提前进入停顿。远古恐惧在停顿时可以立即向圈外目标移动。
