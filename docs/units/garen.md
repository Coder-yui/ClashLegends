# 盖伦

[← 返回总索引](README.md)

## 总览

高生命的前排战士，只攻击建筑。主动技能可选择强化下一击的“致命打击”，或边移动边旋转伤害周围地面敌人的“审判”。

## 主动技能

备战时从以下技能中选择一个携带。

### 致命打击

强化下一次普通攻击，使其造成双倍伤害；强化尚未打出时移动速度提高两档。技能不会重置或延后当前攻击节奏。

| 项目 | 当前数值 |
| --- | --- |
| 技能费用 | 1 |
| 最多使用 | 2 次 |
| 冷却 | 6 秒 |
| 强化普攻伤害 | 200% |
| 强化待发时移速 | 136.36% |

### 审判

作用目标：地面敌人。

旋转 3 秒，对当前身边的地面敌人每秒造成 60 点伤害；施放期间只锁定攻击，仍可移动和改变朝向。

| 项目 | 当前数值 |
| --- | --- |
| 技能费用 | 2 |
| 最多使用 | 1 次 |
| 冷却 | 10 秒 |
| 持续时间 | 3 秒 |
| 基础伤害 | 60 |
| 作用半径 | 90 |
| 效果执行延迟（配置） | 0 秒 |
| 施法总时长 | 3 秒 |

施放期间：暂停普通攻击，可以继续移动和转向。
