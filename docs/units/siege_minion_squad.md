# 炮车部队

[← 返回总索引](README.md)

## 总览

一次出牌生成3只炮车兵，站在三角形的3个顶点，三角形边长1.5格（60像素）。每名炮车兵为中体型、身体半径18。三名成员是独立单位，共享本次部署的主动技能资格。

[查看3D摄影卡面](../../assets/cards/siege_minion_squad_loading.png)

## 男爵之力

消耗3金币，可用1次，冷却8秒。施放后为这次下牌中仍存活的炮车兵分别施加炮车兵男爵之力：伤害150%，持续5秒。队长阵亡后，主动技能资格转交仍存活的炮车兵。
