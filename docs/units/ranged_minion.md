# 远程兵

[← 返回总索引](README.md)

## 总览

低费用远程兵，可攻击空中与地面目标。适合跟在前排后面持续输出。蓝红双方使用各自模型，战斗数值相同。

[查看卡面原画](../../assets/cards/ranged_minion_loading.png)
