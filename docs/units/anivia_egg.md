# 冰鸟的蛋

[← 返回总索引](README.md)

## 总览

冰鸟第一次被击败后留下的地面形态，不能从卡组直接部署。蛋不移动、不攻击；守住 3 秒即可孵化，被击破则复活失败。

距离采用游戏内统一单位；一格为 40。表中为基础值，技能增益另列。

## 被动与特殊规则

**孵化：**3 秒后变成 620 生命的冰鸟，复活次数用尽。165 生命相当于未受增益影响的防御塔 3 次普攻。蛋被击破立即停止孵化；成功孵化不会播放死亡动作。
