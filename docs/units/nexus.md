# 水晶

[← 返回总索引](README.md)

## 总览

双方各有一座水晶，是需要保护的核心建筑。水晶不攻击，拥有完整的出生、持续运转和摧毁表现。蓝红外观不同，生命相同。

## 控制与生命周期

水晶不攻击；眩晕不打断升起、环境运转或爆炸动画。水晶免疫冰冻和凝滞，不能与双方防御塔混为同一种目标。统一边界见[表现合同](../status/PRESENTATION.md#防御塔与水晶的生命周期动画)。
