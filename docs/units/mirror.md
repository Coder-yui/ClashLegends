# 镜像法术

[← 返回总索引](README.md)

复制自己上一张成功使用的卡牌。失败、缺费、非法落点和被主机拒绝的请求不会改变复制目标；双方各自记录。联网客户端有原卡请求尚未确认时，镜像暂不可选，确认或拒绝后恢复，避免按旧目标预览却复制新目标。镜像自身沿用这份已解析目标，不递归复制镜像。

| 项目 | 当前规则 |
| --- | --- |
| 费用 | 上一张卡实际部署形态的基础费用；不包含主动法术额外费用 |
| 复制内容 | 完整单位、建筑、编队或法术；不是复制场上残血状态 |
| 部署位置 | 继承原卡区域、地形、占地及额外部署等待 |
| 开局手牌 | 八张随机洗牌，镜像限定在后四张等待队列中 |
| 默认技能 | 复制体不携带主动；被动与原有形态规则仍正常运行 |

例如上一张为6费远程正义天使，镜像固定为6费远程形态，之后金币减少不会变回3费近战。镜像在命令接受时固定目标，后续出牌不会改变已付款的镜像。

## 主动：完整镜像

将镜像放在备战前两个主动席之一，可复制所有席位预先选定的技能。原卡不必位于主动席；在备战卡牌信息中选择它的技能即可。复制体使用原技能费用、次数与冷却，占镜像自身的左/右技能槽。

再次成功使用镜像立即收回旧复制体的未用技能资格和待释放请求，已开始的技能与持续效果沿用原规则。旧单位仍存活。新的复制体部署完成后可以使用技能；较早镜像即使更晚完成额外部署也不能夺回槽位。全场始终最多两个可操作技能槽。

复制法术时使用备战选定的强化规则，当次施放直接生效，不创建单位技能按钮，并清空旧镜像单位的槽位。镜像仍只支付原法术基础费用。较新的镜像入队不会取消较早已付款法术的强化效果。
