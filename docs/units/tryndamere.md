# 蛮族之王

[← 返回总索引](README.md)

## 战斗狂怒

初始0点怒气，每次普通攻击正式出手增加1点，最多2点。满怒下一次攻击造成360伤害，消耗2点且不产怒，形成普通、普通、暴击循环。怒气不随时间衰减，不依赖主动槽；再次部署使用独立怒气。

前摇取消不消费，解控后重新完整起手。致盲出手沿用普攻消费规则：普通出手产怒，暴击出手耗怒，但落空不造成伤害。模型和声音使用同一个权威攻击段。

每刀由0.4秒保持对应动作首帧、1.07秒原攻击动作、0.23秒保持末帧组成。没有圈内下一目标时，只可跳过最后保持段；攻击动作本身的收招必须完成。攻速变化时各段同比缩放。

## 无尽怒火

3金币、每次部署1次、冷却15秒。正式施放立即满怒；之后4秒生命最低为1，暴击不消耗怒气。结束时不治疗、不自动死亡，留下的满怒仍供下一次暴击使用，后续伤害可正常致死。

除了凝滞，冰冻、眩晕、击退期间均可开始此技能；原控制不解除，冻结姿势保持，不能趁机攻击或移动。部署未完成、死亡或没有使用资格仍不能施放。请求有公共0.5秒缓冲，执行时处于凝滞则取消退款、不扣次数。技能本身无施法动作锁；满怒会刷新旧普攻，从完整暴击前摇重新开始。

4秒由20Hz推进，暂停不计时；凝滞抑制增益但计时继续，离开时只恢复未到期部分。保护在护盾抵挡后钳制生命，同批多刀仍最低1；不改变其他对象的死亡规则。
