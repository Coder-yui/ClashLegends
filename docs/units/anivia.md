# 冰鸟（艾尼维亚）

[← 返回总索引](README.md)

**风暴与复生：**已创建的固定风暴按自身寿命继续，不因冰鸟受控或死亡消失；创建前被冰冻则取消该次技能后段。复生的新实体不继承旧控制。

## 总览

能攻击地面和空中的远程飞行单位。普攻发射冰锥，冰雪风暴能压制一片区域；首次被击败后留下蛋，保护好蛋就能让冰鸟满血回到战场。

## 被动与特殊规则

**复活一次：**第一次被击败后生成 165 生命的蛋。蛋存活 3 秒后变回满血冰鸟；复活后的冰鸟不再生蛋。风暴已经落地后，即使冰鸟死亡也会继续存在到结束。

## 主动技能

### 冰雪风暴

在身前创造冰雪风暴；落地造成伤害，区域持续 3 秒并周期性造成伤害与减速。施法期间锁定攻击、移动和朝向。
