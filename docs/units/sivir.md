# 战争女神

[返回单位索引](README.md)

5金币范围伤害后排，使用往返穿透的回旋镖攻击地面和空中敌人。单次攻击去程、回程都命中时合计造成140伤害。

| 项目 | 当前数值 |
| --- | --- |
| 生命 / 体型 | 560 / 中，身体半径18 |
| 普攻伤害 | 每程70，每目标每程最多一次 |
| 攻击距离 / 视野 | 160（4格）/ 240 |
| 飞行距离 / 弹速 | 去程200（5格）/ 每秒400 |
| 弹体碰撞半径 | 12 |
| 出手前摇 / 基础动作间隔 | 0.25秒 / 1秒；仍须接住后才能再次起手 |
| 移动 | 地面，中速60 |
| 部署 | 单只，默认1秒 |

去程在发射时锁定方向，不追踪敌人；回程朝来源当前位置飞回。两程分别去重，不因触碰敌人消失。来源受控不取消在途弹体；来源死亡后回到发射点结束。回旋镖尚未接回时不能起手下一击，超出射程仍可追击。

**法术护盾**：1金币，2次，冷却8秒。立即获得1.5秒的一次效果护盾，成功抵挡后回复120生命，不能超过生命上限。阻挡一次敌方攻击、技能或法术及其同次附带效果；已有持续伤害不消耗盾，友方效果不消耗盾。自然到期不治疗，开盾不打断普攻。
