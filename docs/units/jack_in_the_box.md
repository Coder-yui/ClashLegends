# 惊吓魔盒

[← 返回总索引](README.md)

5金币的埋伏建筑，部署时已隐身。部署完成后首次发现攻击范围内的合法敌人，永久破隐并使范围内敌方单位眩晕1秒。此后持续齐射范围内所有合法敌人，只有一个目标时伤害翻倍。

| 项目 | 当前数值 |
| --- | --- |
| 生命 / 存续 | 800 / 30秒标称自然衰血 |
| 伤害 / 间隔 | 群攻每目标50，单目标100 / 1秒 |
| 攻击距离 / 目标 | 160像素（4格，表面距离） / 地面、空中及建筑 |
| 部署 / 占地 | 1秒 / 2×2格 |
| 体型 / 身体半径 | 稍大 / 21像素 |
| 前摇 / 弹速 | 0.33秒（20Hz首次发射量化至0.35秒） / 520像素每秒 |

主动 **惊吓**：1金币，每次部署2次，冷却10秒；使攻击范围内敌方单位眩晕1秒，无伤害。范围按自身21半径加160射程，再与目标身体圆判断，和普攻边界一致。建筑单位可受眩晕，防御塔不受本技能眩晕。

部署未结束、冰冻、眩晕或凝滞期间不触发被动，解除后仍可激活。受伤不破隐；已破隐不会重新进入隐身。隐身复用当前图奇式公开玩家视图：双方可见虚化模型，敌方单位与塔不能新锁定，仍可受范围伤害。

齐射在发射时锁定合法目标集合与伤害倍率；每目标一个追踪弹体，后续新增目标不改变已发弹体伤害。隐身、凝滞和不可选取目标不计入齐射数量；致盲取消整次齐射，只消耗一次。眩晕属于范围效果，不要求目标可被普攻锁定，仍服从凝滞和来源保护。

寿命按最大生命÷30秒自然衰血，治疗可延长实际生存，凝滞暂停自然衰血。主动沿用正式请求、扣费和命令延迟。
