# 女王巢穴

[← 返回总索引](README.md)

4金币建筑，600生命，不攻击、不移动，身体半径25像素，占地3×3格。部署1秒，完成后每秒自然衰减24生命，基础存续25秒。被击杀或自然衰血死亡后在原位置释放一只满血雷克塞，部署1.1秒。凝滞暂停衰血，眩晕和冻结不暂停。

女王之怒：1金币、1次、冷却15秒，雷克塞立即从洞口前方50像素出巢，巢穴保留当前生命和3×3占地，继续原自然衰血。空巢不再显示Zzz，也不再触发死亡召唤。
