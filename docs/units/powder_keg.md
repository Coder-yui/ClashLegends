# 火药桶（建筑卡）

[返回总索引](README.md) · [动画](animations/powder_keg.md) · [音频](audio/powder_keg.md) · [特效](effects/powder_keg.md)

4费防守建筑，不移动、不普攻，用生命承伤，死亡爆炸。模型与训练木桩接近同档，桶体更矮宽。

| 项目 | 数值 |
| --- | --- |
| 生命 / 费用 | 750 / 4 |
| 占地 / 身体半径 | 2×2格 / 20像素 |
| 部署 / 存续 | 1秒 / 部署结束后20秒 |
| 自然衰减 | 每秒37.5生命，按整数余量累计；护盾、减伤不抵消 |
| 死亡爆炸 | 300伤害，半径140像素（3.5格），按目标身体边缘检测 |
| 爆炸目标 | 敌方地面单位、建筑、防御塔与水晶；不伤友军与空军 |

被击杀、自然衰减归零和主动引爆均产生一次爆炸。清场直接销毁不触发。爆炸普通伤害遵守护盾、减伤、凝滞及效果盾；可引发敌方火药桶死亡爆炸，不会引爆友方桶。

## 被动：击杀奖励

同一次爆炸击杀任意敌方目标，获得1金币，多杀仍只给1金币。原金币提示显示在火药桶位置；沿用金币上限。死亡替身、死亡形态与复生不算真正击杀。伤害完全被阻挡、只消耗护盾或没有击杀时无奖励。

## 主动：烈性火药

0费，每次部署1次，冷却10秒。沿用公共技能请求及0.5秒命令缓冲；正式执行时立即引爆，无额外前摇。

先结算300爆炸伤害，再检查实际受到生命伤害的敌方单位：剩余生命严格低于最大生命15%时斩杀，恰好15%不斩杀。斩杀不作用于建筑、防御塔和水晶，不突破拒绝死亡；死亡替身/复生沿原规则处理。自然死亡的普通爆炸没有斩杀。受控释放权限沿用普通主动技能。

数值为本项目初始平衡选择。卡面使用用户2026-10-25摄影棚成片；技能图标使用船长原版E。
