## 旋斩与毁灭冲锋

普通攻击以自身为圆心，同时伤害范围内的前后敌人，边界计入目标身体半径，不伤空军或友军。旋斩属于普通攻击，受到致盲与普攻免疫约束。

连续自主移动实际累计140像素（3.5格）后进入冲刺，移速提高50%至114像素每秒，普通移动Run切换为Spell3run。按自主实际距离累计，碰撞推挤、击退和攻击位移不计入。停下、开始普通攻击或受到硬控都会清空积攒与冲刺就绪；发动冲刺攻击则把资格消费为正在执行的攻击。

蓄满后的下一击可在表面距离80像素（2格）内起跳，播放Spell3。前0.4秒接近目标，近距离也保留完整前段；接近速度上限420像素每秒，目标追踪有距离上限，不无限追赶。到0.4秒节点且仍接触目标（前侧落点预留2像素，命中容差4像素）才造成80伤害，普通地面单位同时沿原冲刺方向击退0.5秒并眩晕1.5秒。击退基准40像素，乘以 clamp(4/质量, 0.35, 1.4)，遵守普通击退碰撞规则。建筑受伤但不被本次攻击击退或眩晕。

踢击后解除目标绑定，沿原方向再减速前冲最多24像素（0.6格），后0.67秒完成落地收势。整段动作约1.07秒；20Hz模拟在下一个Tick完成落地，最多约30毫秒对齐误差。落地立即清除本次攻击冷却并允许下一次普通攻击起手，仍需正常0.15秒前摇。目标死亡或继续被击退不改变人马终点，不保证最终站在目标身后。

整个起跳至落地过程不参与碰撞，仍可被选取、受伤和受控。起跳前检查接触点合法性，命中时检查固定续冲终点，结束或中断时再做合法落点恢复；建筑、地形和边界会缩短续冲，无合法恢复位置时禁止攻击并继续恢复检查。

| 情况 | 处理 |
| --- | --- |
| 眩晕发生在积攒/就绪时 | 清空并停止；结束后重新积攒 |
| 眩晕发生在起跳后 | 保持踢击及落地；眩晕正常计时，落地后剩余眩晕继续限制攻击 |
| 冰冻、凝滞、禁锢、击退 | 取消未完成攻击/位移，合法收尾；已造成的伤害与控制不撤销，不续播补打 |
| 起跳后目标死亡、凝滞或不可选中 | 不换目标，沿最后有效轨迹踢空并合法落地，消费冲刺机会 |
| 目标超出有限追踪范围 | 不无限追逐，踢空落地 |
| 致盲 | 保留起跳、续冲和落地；消费一次致盲，不造成伤害、击退或眩晕 |

此击是单目标强化普通攻击，不同时旋斩，遵守普攻免疫。死亡/清场终止自身所有未完成动作。

## 恐惧之灵

2金币、1次、冷却15秒。W上半身起手0.44秒期间只锁攻击，移动脚步不变；随后开启4秒的随身领域，半径120像素（3格）；每0.5秒造成20伤害，共8次，首次在第0.5秒。攻击地面敌军和建筑。

领域与普通攻击按实际造成生命伤害的30%治疗自身；护盾吸收、过量伤害及无效命中不增加治疗，遵守公共整数规则。仍可移动及普攻，生效后的W上身动作可直接被普通攻击或冲刺踢击接管，不需等待动作播完。冰冻取消领域和本次限时吸血，死亡或清场停止，不产生死后治疗。
