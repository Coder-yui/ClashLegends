# 提莫

[← 返回总索引](README.md)

## 总览

移动灵活、能够对空的远程单位。主动技能把下一针变成致盲攻击，让被命中的敌方单位接下来的两次普攻无法造成伤害。

## 主动技能

### 致盲

强化下一次普通攻击；命中单位后使其接下来的两次普通攻击（包括强化普攻）不造成伤害。技能不改变攻击间隔。

| 项目 | 当前数值 |
| --- | --- |
| 技能费用 | 0 |
| 最多使用 | 2 次 |
| 冷却 | 4 秒 |
| 强化普攻伤害 | 100% |
| 致盲攻击次数 | 2 |
