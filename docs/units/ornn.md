# 奥恩

[← 返回总索引](README.md)

## 被动：锻造脉冲

部署完成4秒后发出第一把锤子，之后每8秒发锤一次。每次提前3.6秒开始播放完整锻造音效。每次从全场存活、尚未增幅的友方普通单位中选择一名，永久提高其普通攻击伤害20%；奥恩本人也可成为目标。费用高的单位优先；同费用时距离奥恩更近的优先；完全相同时按战斗出生身份稳定排序。建筑、冰鸟蛋、复生等待、凝滞及对友方也不可选中的单位不参与选择；格温仅对敌方生效的隔离不影响增幅。

增幅只进入普通攻击倍率，不改变技能伤害或攻击速度。伤害乘倍率后沿普通攻击原有数值边界四舍五入，例如奥恩获得增幅后，`104 × 1.2 = 124.8`，结算为125点伤害。

发射后，一把小橙色锻造锤从奥恩飞向目标并留下橙色轨迹；锤子抵达后才赋予增幅并在目标血条左侧显示柄加粗、倾斜45度的橙色锻造锤标记。飞行耗时按发射距离为0.35–2.5秒，跟随移动目标；目标死亡（含赛恩进入复生、冰鸟旧实体死亡变蛋）沿现有生命周期取消；抵达时再检查友方选取资格，死亡、凝滞或对友方也不可选中则不增幅、不播抵达声。成功抵达在目标处播放LoL购买装备成功音效。奥恩死亡或受到控制不撤回已发出的锤子。飞行中的目标会被预留，避免多个奥恩重复选中。奥恩不会在每次脉冲时停下锻造。

眩晕、冰冻、凝滞会截断当前锻造音频；发锤前被打断，在所有这类控制解除后重新锻造完整3.6秒再发锤。发锤后的声音尾段可以被截断，不影响已发出的锤子。普通击退不打断锻造。凝滞与通用不可选中目前仅有状态规则及奥恩准入检查，项目尚无完整通用施加链路（见[实现现状](../status/IMPLEMENTATION.md)）。

## 主动技能：熔铸冲锋

先蓄力0.35秒，再向锁定朝向冲锋0.5秒，移动速度固定，不受奥恩基础移速影响。沿途每名敌人每次冲锋受到32点伤害；撞到建筑、河流或场地边界时停下，以障碍表面接触点为中心对半径82内敌人造成135点伤害和1.5秒眩晕。被撞到的建筑不吃路径伤害，但会承受停止点范围伤害。冲完整段距离而未碰到障碍时，不造成终点范围伤害或眩晕，收势0.2秒直接回到常规动作。碰撞时立即进入0.55秒撞击/收势窗口，显示固定橙色范围标识。

## 主动技能与控制

- 眩晕：不能开启新技能，已开始的蓄力、冲锋和碰撞结算继续；技能结束后仍受剩余眩晕限制。
- 冰冻：取消技能剩余阶段，解除后不续冲；已经结算的伤害与眩晕不撤回。
- 普通击退：外部位移接管；冲刺阶段检查到仍有击退行动锁时，停止冲刺并进入0.2秒未碰撞收势，不额外触发撞墙爆发。蓄力期间若击退已结束，之后仍可冲刺；收势阶段不会撤回既有爆发。
- 凝滞、禁锢、嘲讽、强制推拉：通用生产链尚未完整接入，不能把设计规则当作当前技能已支持的效果。

突进移动后清除旧寻路缓存，结束时从当前位置重新计算通往目标的路径，避免追赶身后的旧路径点。
