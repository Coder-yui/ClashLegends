# 远古恐惧（衍生单位）：声音

[返回单位](../fiddlesticks.md) · [返回总索引](../README.md)

共享远古恐惧原皮W起音（3变体）、W汲取持续音（2变体）、死亡音效与中文死亡语音（3变体）；部署使用客户端原版中文选人语音。所有事件保留原增益。死亡超过1.5秒时保留前1.5秒，末0.5秒线性淡出。

持续音随攻击、控制、死亡和清场停止；暂停由通用音频管理器处理。没有末跳爆发，不接原版W最后一跳音效；变形没有独立匹配事件，暂不添加变形音。来源见[音频清单](../../../assets/audio/units/fiddlesticks/event_manifest.json)。试听验收见交付记录。
