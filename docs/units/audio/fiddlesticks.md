# 远古恐惧（衍生单位）：声音

[返回单位](../fiddlesticks.md) · [返回总索引](../README.md)

两种形态共享原皮W起音3变体、W汲取持续音2变体。每轮吸血开始播放起音和持续层，停顿、目标全部失效、控制及死亡时结束持续层，下一轮重新启动。源TXTP重新解码后，5个正式W音频的PCM均与源事件一致。

两种形态均取消deploy:voice。建筑草间人的respawn另播放原版Respawn3D_buffactivate，按4.3秒动画缩放到2秒的比例进行2.15倍保调变速，音频含尾音约2.05秒。

死亡统一使用Death3D_effigies的2个随机变体，与death_effigies动作配套。建筑保留完整摧毁声约2.15秒，移动单位按项目规则保留前1.5秒并在1–1.5秒淡出。原英雄死亡音效及死亡语音已从运行配置移除，旧文件与来源保留素材库。

原版W末跳声属于未启用的末段爆发。主动“巫骇草人”成功起手播放用户选定的ScarecrowEffigy_OnHitLocation试听版本，固定一个变体，截取前3秒，前2.5秒保持原PCM，最后0.5秒线性淡出。换形后的音频表也保留该起音，覆盖快照先到、声音事件后到的情况。所有声音保留原事件增益，部署变速与死亡包络单独记录。来源见[音频清单](../../../assets/audio/units/fiddlesticks/event_manifest.json)，实际混音录音与检查结果见[交付记录](../../deliveries/2026-11-03_草间人新卡.md)。
