# 未来守护者声音

[远程](../jayce.md) · [战锤](../jayce_hammer.md) · [总索引](../README.md)

部署使用本地中文客户端126号选人语音，播放补偿-8dB。锤炮形态各自使用基础皮肤两套普攻出手和命中事件；炮形态单独按实际弹体创建播放发射声，命中声等真实命中。转换分别使用HtG/GtH原事件。超能电荷在主动效果执行时派发开始音，末次强化收招结束或4秒到期时派发一次结束音；开启音轨由增益持续层持有，到期/耗尽停止，换形保留同一播放器。

死亡同时播放基础皮肤死亡音效与中文Death3D语音；超过1.5秒的文件保留前1.5秒并在末0.5秒线性淡出。事件池最多3变体，保留原事件增益，不归一化。首击使用PassiveMeleeAttack/PassiveRangedAttack的出手、发射与命中事件；远程W使用HyperChargeRangedAttack专属出手、发射和命中事件。锤W使用StaticField起手、持续和结束事件，持续层按电场时钟停止并短淡出，换形保留音轨。首击优先于W攻击声。走路无音频。完整Wwise RTPC与材质条件未复刻。

来源和PCM加工见assets/audio/units/jayce/event_manifest.json。运行时试听与清理验收见本次交付记录。

两种换形继续使用已导入的原版GtH/HtG OnCast事件：入锤为GtH，入炮为HtG，在同步transform动作开始时各播放一次。两段约3.164秒，保留原始声音尾部，不按0.3秒动作窗口截断。无新增换形语音；本地本次可用中文TXTP只含死亡事件，未用其他语音替代。
