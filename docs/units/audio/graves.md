# 法外狂徒：声音

[返回单位](../graves.md) · [返回总索引](../README.md)

接入原皮霰弹出膛与真实命中各3个变体、换弹打开/关闭各1个、E施放3个、中文死亡语音3个、三句中文部署语音。部署池为“把头埋地。”（移动语音第8条）、“我与死亡同行。”（中文客户端104号选人原声）和“我可没时间胡闹。”（移动语音第6条）。客户端选人句的文件保留原始OGG，播放时衰减18dB以匹配两条移动语音。每枪只有一次发射声，命中按实际弹丸事件经过通用并发预算播放。

换弹开始播放reload_open，补满时播放reload_close；取消换弹不会假播完成。主动动作开始播放GravesMove_OnCast。没有额外的挥枪前摇声，也没有找到独立匹配的死亡SFX，不用无关事件补齐；死亡仅播放原版Death3D语音。

保留Wwise原事件增益，不做归一化。死亡超过1.5秒时截为1.5秒，末0.5秒线性淡出。命中使用源事件首个明确Switch分支，未知分支不臆称材质类型。换弹音时机映射到本项目开始/完成，未声称复现原动画图的所有中间音节点。
