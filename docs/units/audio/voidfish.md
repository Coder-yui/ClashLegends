# 虚空鱼音频

[返回单位](../voidfish.md) · [单位索引](../README.md)

声音来自本地只读 `Belveth.wad.client`，经既有TXTP工具还原事件。来源与加工见 [清单](../../../assets/audio/units/voidfish/source_manifest.json)。统一48kHz单声道PCM16，不逐文件归一化。

- 部署：原版虚空鱼出生效果，单只音量-23dB；八只同点同时出生会叠加，按整批出生层调低18dB，避免掩盖女皇死亡声及总线削顶。
- 普攻：近战虚空鱼攻击，出手与真实命中分别触发，均-7dB。
- 死亡：虚空鱼死亡变体，-5dB。


使用通用短音预算、暂停恢复与清场生命周期。当前无部署语音；已准备中文语音银行但尚未核实适合部署的台词，不使用不相关台词替代。实际场景录音保存在本地素材库，主观听感尚待用户确认。
