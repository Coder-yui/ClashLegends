# 卑尔维斯音频

[返回单位](../belveth.md) · [单位索引](../README.md)

声音来自本地只读 `Belveth.wad.client`，经既有TXTP工具还原事件。来源与加工见 [清单](../../../assets/audio/units/belveth/source_manifest.json)。统一48kHz单声道PCM16，不逐文件归一化。

- 部署：原版复生效果，音量-5dB。
- 普攻：慢速攻击挥击变体，出手与真实命中分别触发，均-7dB。
- 死亡：原版死亡效果，-5dB。
- 主动：Q施放-4dB，路径实际命中-5dB；不播放旋转事件。

使用通用短音预算、暂停恢复与清场生命周期。当前无部署语音；已准备中文语音银行但尚未核实适合部署的台词，不使用不相关台词替代。实际场景录音保存在本地素材库，主观听感尚待用户确认。
