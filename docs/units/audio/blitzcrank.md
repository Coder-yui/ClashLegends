# 蒸汽机器人声音

[返回蒸汽机器人](../blitzcrank.md)

已接入两段普攻出手/命中、Q起手/命中、E准备/出拳/命中、死亡音效及中文死亡语音。部署使用中文客户端原版选人语音，播放补偿-8dB；其余保留原始事件增益，无逐文件归一化。每池最多3个变体；两套普攻解码后相同的6个WAV已合并引用，保留独立动作语义与原事件来源。

死亡音效及三段中文死亡语音均核对1.5秒上限；超长素材前1秒不改、后0.5秒线性淡出。死亡语音不再继承被冰冻取消的旧动作身份。Q瞄准期间静默，正式释放独立弹体时播放原版起手音，拉取实际生效后播放命中音；没有额外配置循环飞行声。走路不加声音。

已录制真实工作台双方部署、Q、连续普攻、E、冻结恢复、死亡和清场混音，并在本机播放复核。源事件、变体、哈希与加工见[来源清单](../../../assets/audio/units/blitzcrank/event_manifest.json)。Wwise运行时RTPC、材质分支与所有嵌套随机未完整复现。
