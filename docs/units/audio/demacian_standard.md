# 德邦军旗：音频

[返回军旗](../demacian_standard.md) · [总索引](../README.md)

部署起始使用原版皇子E DemacianStandard_fall的3个随机变体，部署0.5秒时通过deploy:release播放DemacianStandard_hit的3个随机变体；黄金圣盾施放使用GoldenAegis_OnCast的2个变体。全部由本机JarvanIV基础皮肤SFX银行解析，wwiser主增益0dB，重新解码后保持原事件增益。素材和哈希见[清单](../../../assets/audio/units/demacian_standard/event_manifest.json)。

军旗不攻击，未添加英雄语音。未发现独立军旗摧毁事件，死亡无声；没有把皇子本人的死亡声移给建筑。攻速光环与盾持续声暂未接入，避免将W原始循环事件作为一次性声音播放。试听与实战验收状态见任务记录。
