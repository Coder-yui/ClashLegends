# 浪潮法术音频

[返回浪潮法术](../tidal_wave.md) · [返回总索引](../README.md)

公共出牌延迟结束后播放娜美基础R的 `Play_sfx_Nami_NamiR_OnCast`（3个随机分支）。按原版NamiR的 `mCastTime=0.5`，再经过10个权威Tick生成浪潮，同时播放 `Play_sfx_Nami_NamiR_missilelaunch`（2个分支）。施法声自然保留尾音，与发射声重叠，不等待音轨结束。原版客户端逐帧同步尚未验证；0.5秒来自本机原始技能配置，三事件来自基础声音银行。

实际敌方命中结算成功后播放 `Play_sfx_Nami_NamiRMissile_hit`（接入前3个分支，遵循项目单池最多3变体；第4个保留在试听台），每目标每道浪潮一次；空军、友军、免疫或法术盾抵挡不播放命中声。建筑的有效命中也播放。所有事件沿统一卡牌表现RPC发送，客户端不计算命中。

wwiser显式`-gv=0dB`、vgmstream重新解码；施法与命中保留完整音轨，发射保留前1.4秒原音，加0.25秒淡出，总长1.65秒，对应11格浪潮的28Tick推进。保留原事件增益，无归一化，运行补偿0dB。未添加角色语音或友方加速提示音。暂停/清场遵循公共音频生命周期，待生成浪潮在清场时取消。

来源与哈希见 `assets/audio/spells/tidal_wave/event_manifest.json` 和全局原增益清单。实际播放证据见本次交付记录，不将自动事件检查视为主观听感通过。
