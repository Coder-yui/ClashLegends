# 狂战士音频

[狂战士](../olaf.md) · [单只对象](../olaf_single.md) · [总索引](../README.md)

基础皮肤两套普攻分别映射原版BasicAttack、BasicAttack2的出手和真实命中声；Attack3仅用于诸神黄昏，使用与原BasicAttack3事件PCM相同的已有普攻资源；每池最多3个变体。W开始使用OlafW_OnCast，持续使用OlafW_OnBuffActivate，随增益结束、死亡和清场停止。死亡使用中文Death3D，超过1.5秒按公共包络裁剪。

事件图显式用wwiser -gv=0dB生成，每次从TXTP重新解码，保留原节点增益。来源与精确变体见assets/audio/units/olaf/event_manifest.json。部署从原选人语音、“掠夺吧。”、“杀戮的欲望正在高涨！”三句中随机播放一句，沿用公共声音池的不连续重复规则。同次下卡的两只共享一次语音，下一批独立触发；单只工作台对象也只播一次。两句新增语音来自中文原包的 Move2DStandard 第2/5分支，保留事件节点 -13 dB 增益。选人OGG不重编码，播放时单独 -12 dB，匹配混合声音池的响度；原基础皮肤事件列表未见独立死亡音效，死亡语音已接入。实际试听待验收。

## 诸神黄昏

激活使用原基础皮肤OlafR_OnCast，持续使用OlafR_OnBuffActivate。持续声跟随单位，按原媒体0–277874采样点（44100Hz）循环；6秒窗口结束或死亡触发原停止事件的0.75秒线性淡出，清场立即停止；施放单次轨保留原始尾音。两条素材由原银行以wwiser -gv=0dB重新生成事件并重新解码，事件增益分别为-11dB/-20dB，不添加后期增益或归一化。

R Attack3的出手/命中事件与原基础普攻对应变体PCM相同，复用已有文件，每池三变体；真实伤害命中时才播放命中声。R与W状态音轨按免控窗口切换，不混播W施放声。现版本未额外接入R中文技能语音；音效均来自原版事件。两条R音效及六个Attack3出手/命中变体均已重新解码并通过逐样本PCM一致性比对；素材播放和双阵营实战录音已执行，主观听感由用户最终验收。
