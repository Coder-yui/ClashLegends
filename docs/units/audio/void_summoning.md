# 虚空召唤声音

[返回卡牌](../void_summoning.md) · [返回单位索引](../README.md)

法术使用虚空女皇基础皮肤的大招施放、变身激活和形态持续声，已经移除装备虚空献祭声音。声音由落地区域独立持有，共8秒；虚空鱼出生、攻击、死亡继续沿用[虚空鱼音频](voidfish.md)。

| 时间 | 原始事件（前缀 `Play_sfx_Belveth_`） | 处理 |
| --- | --- | --- |
| 0秒 | `BelvethR_OnCast` | 完整施放声，节点-14dB |
| 1秒 | `BelvethR_transform` | 完整变身声，节点-19dB |
| 1秒 | `BelvethR_buffactivate_other` | 世界位置激活声，3个随机变体，节点-16dB；不叠加自身视角版本 |
| 1至8秒 | `BelvethR_buffactivate_loop` | 原始单圈循环，节点-25dB，到期停止 |

按施放、变身激活、持续的动作阶段衔接，各段尾音自然重叠；不会等待一个文件全部播完才开始下一个。**源Spell4施法时间为1秒，但客户端Lua不含完整运行时声音回调，因此1秒处的激活/循环衔接属于项目适配，未证明为原版逐帧时序。** `BelvethRSteroid_cast`实际属于强化普攻，未接入；也不加入珊瑚目标、伤害命中或中文语音。

从显式wwiser `-gv=0dB` 的TXTP重新解码，保留节点增益。原循环以 `vgmstream -i` 解码一圈再重复，未使用试听台的双圈加淡出文件。浮点混合不归一化，48kHz PCM16，3条成品各8秒，峰值约0.428、0.435、0.450，无削波；运行音量0dB。

`spell:zone_sustain`使用3条预合成序列，配置`natural_tail=true`防止文件结束后重播大招开头；文件与区域均为8秒，不延长声音。暂停冻结播放和计时，恢复继续；清场、终局和预算淘汰停止整个序列。既有可靠区域音频事件同步双方，事件ID去重。调整区域持续时间时必须同步重建音轨。

逐文件来源、TXTP哈希、输入PCM哈希及混合参数见 `assets/audio/original_gain_manifest.json`。本地制作配方与原始输入在素材库 `03-制作中/虚空召唤/audio-belveth-r/`。实际播放录音与自动检查不替代用户最终听感验收。
