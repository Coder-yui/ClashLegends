# 凛冬之柱音频

[返回单位](../pillar_of_ice.md) · [总索引](../README.md)

| 时机 | 来源与行为 |
| --- | --- |
| 部署开始 | E冰柱`TrundleCircle_buffactivate`第1条的0～3.25秒：升起与碎冰尾音；立即播放一次，不拉伸到1秒部署时长 |
| 部署完成至死亡 | W `TrundleDesecrate_buffactivate`第1条原生约5秒循环；0.1秒淡入，死亡时0.15秒淡出 |
| 死亡 | 同一条E的4.5～8.105秒：落下／坍落声及自然尾音；死亡立即开始，模型退场后仍允许尾音自然结束 |
| 冰封领域开启 | W `TrundleDesecrate_OnCast`第1条，播放一次；冰柱死亡时停止尚未播完的声音 |
| 移除与清场 | 单位归属的短音停止，循环层清理；终局清场停止全部战斗音 |

每个事件只有一条音频，不使用随机变体。升起与落下来自同一原始E粒子音轨，不使用上一版叠合了英雄OnCast的成品。源模型升起在0～0.36秒、下沉从5.625秒开始；音轨后段在约4.5秒已有坍落起音，因此从4.5秒保留完整声响，不机械截掉起音。两段保持原速与原增益，起点加5毫秒防点击包络、末尾150毫秒淡出，无归一化。落下片段约3.605秒，属于建筑摧毁声，不套普通单位1.5秒截断。

W循环保留原事件音频；W开启声与E升起声使用`owner: unit`绑定存活单位，死亡和移除时停止。死亡结果声独立持有，不因模型0.8秒后消失而截断。声音不会驱动建筑部署、死亡或主动技能计时。
