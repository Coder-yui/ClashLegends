# 德莱厄斯原生音频

[返回德莱厄斯](../darius.md) · [总索引](../README.md)

全部来自本地LoL基础皮肤音频包，部署语音使用中文语言包，未使用其他英雄或皮肤声音。

| 实际时机 | 声音 |
| --- | --- |
| 部署随机一句 | “诺克萨斯即将崛起。”、“懦弱之举，我绝不姑息。”、“我将死战不休。”；三句同池随机 |
| 两段普通攻击 | 对应BasicAttack/BasicAttack2出手及真实命中变体 |
| 断头台 | Execute出手、真实命中及击杀事件 |
| 血怒获得 / 持续 | HemoMax获得声与循环音；刷新不重播获得声 |
| 死亡 | Death3D原版声效 |

血怒音轨归Buff所有，随身移动，硬控不打断；到期、死亡和清场停止。挥舞音归攻击，取消时停止；命中音只由实际命中派发。未使用Q/W/E及走路声音。普通流血不额外播放逐Tick音效，避免持续伤害高频叠音。

34个正式音频文件，SFX统一衰减2.838dB保留变体间响度并防PCM16削波，语音不归一化；运行中按事件音量混音。三句台词通过公开文字事件目录及本地转写匹配，未冒充用户人工确认。来源、哈希与加工见[音频记录](../../../assets/audio/units/darius/README.md)。

实际渲染已记录双阵营混音，断头台命中/斩杀、血怒循环及死亡均有事件证据；暂停、硬控和结束清理有回归。最终主观听感仍待用户确认。
