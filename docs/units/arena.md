# 竞技场

[← 返回总索引](README.md)

## 总览

对战发生的地图，也是比赛时长、兵线、金币节奏和全局声音的归属入口。当前正式对战仍使用峡谷背景图，另有独立的 3D 峡谷候选场景。

## 数值

| 项目 | 当前数值 |
| --- | --- |
| 战场大小 | 720 × 1280 |
| 网格 | 18 列 × 32 行，每格 40 |
| 窗口大小 | 720 × 1400，底部 120 为操作区 |
| 河道 | 纵坐标 600～680 |
| 两座桥中心 | 横坐标 140、580 |
| 桥宽 | 120 |
| 正常比赛 | 185 秒 |
| 加时 | 120 秒 |
| 起始金币 / 上限 | 5 / 10 |
| 基础回复 | 每 2.8 秒回复 1 金币 |
| 双倍回复 | 正赛最后 60 秒；加时前 60 秒 |
| 三倍回复 | 加时最后 60 秒 |
| 首波小兵 | 开场 5 秒 |
| 普通兵线间隔 | 45 秒 |
| 双倍阶段兵线间隔 | 30 秒 |
| 同波出兵间隔 | 0.5 秒 |

## 当前画面

正式对战使用二维峡谷背景。3D 峡谷已单独存放供预览，尚未作为正式地图启用；预览图不能当作正式对战效果。
