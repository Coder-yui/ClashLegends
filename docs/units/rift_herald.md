# 峡谷先锋

[← 单位总索引](README.md)

## 总览

8金币、极大体型的推进坦克。只锁定建筑，每条生命首次攻击以冲撞代替，之后正常近战。冲撞受地形约束，桥面允许通过，不能越过河水。

## 被动：虚空冲撞

- 建筑进入5格（200px）表面距离后，在可直线到达建筑的合法位置停下准备2.5秒。当前位置不合法时，沿现有导航寻找步行路线最短的合法候选点，途中每步重新检查能否直接冲撞；桥面允许，水域禁止，身体半径同样参与检查。
- 准备期间不受普通接触推挤；冰冻、眩晕、击退均可打断准备，动作与准备声音同时停止。解除后从当前位置重新检查路线并完整准备2.5秒，不消耗首次冲撞机会。准备阶段目标死亡时重新索敌，不消耗次数。
- 冲撞速度400px/秒。冲撞期间拒绝现有冻结、眩晕、击退、减速、减攻速和致盲；仍会受到伤害。
- 沿路每只地面敌軍受100伤害，按所在侧朝两旁击退48px基础距离、持续0.2秒；实际距离沿用质量衰减和地形限制。友军、空军不受伤。
- 撞击建筑造成500伤害，然后直接扣除自身当时当前生命的30%（整数四舍五入），护盾不能抵消这项生命代价。
- 从碰撞点爆发6只[虚空蠕虫](voidmite.md)，向六个方向短距离散开；合法出生与位移均遵守建筑和水域阻挡。
- 撞击后收势0.65秒再正常普攻。开始冲撞即消耗唯一机会；途中死亡或目标死亡时空撞，不返还次数、不孵化；新敌方建筑拦截且成功承受伤害时正常孵化。

## 主动技能：旋转重拳

1金币，每次部署最多2次，冷却6秒。施放3.00秒，在1.57秒对身体前缘起算、半径2.5格（100px）的180°半圆内地面敌军及建筑造成210伤害。施法锁移动、普攻和朝向；冻结/眩晕沿用技能暂停恢复规则。冲撞准备、冲撞及收势期间不可施放。
