# 治疗术

[← 返回总索引](README.md)

## 总览

恢复友方普通单位生命的法术，对建筑、水晶和防御塔不回血。放入主动槽后，治疗改为覆盖全图友方单位，并为落点附近友军加盾。

[查看卡面原画](../../assets/cards/heal_loading.png)
