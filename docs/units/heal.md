# 治疗术

[← 返回总索引](README.md)

## 总览

恢复友方普通单位生命的法术，对建筑、水晶和防御塔不回血。放入主动槽可在“强化治疗”和“过量治疗”之间选择。

[查看卡面原画](../../assets/cards/heal_loading.png)

## 数值

| 项目 | 当前数值 |
| --- | --- |
| 费用 | 2 |
| 施放位置 | 全图选点 |
| 作用半径 | 110.0 |
| 普通治疗 | 200 生命，不超过正常上限 |
| 光圈显示 | 1.2 秒，治疗在施放时立即完成 |
| 主动槽总费用 | 3 |
| 强化治疗 | 全图友方普通单位回复 200；落点范围内回复 300（治疗量提高 50%），不增加护盾 |
| 过量治疗 | 范围内友方普通单位回复 300（治疗量提高 50%） |
| 过量转盾 | 过量治疗溢出量的 50% 转为护盾，持续 3 秒；建筑、水晶和防御塔不受治疗影响 |
