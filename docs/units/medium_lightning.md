# 中型雷电法术

[← 返回总索引](README.md)

4金币单次范围落雷，用于清理单位群和短暂压制防御塔。全场选择落点，公共0.5秒出牌延迟结束后，蓄雷2秒再一次结算；不追加第二次伤害。

| 项目 | 当前数值 |
| --- | --- |
| 普通费用 / 主动槽费用 | 4 / 5金币 |
| 落雷前摇 | 2秒（40Tick）；敌方仅最后1秒看到预警 |
| 作用半径 | 100像素（2.5格），包含目标权威身体半径接触 |
| 伤害 | 240，对敌方地面、空中单位和建筑卡全额生效 |
| 防御塔 / 水晶伤害 | 72（30%） |
| 防御塔失效 | 2秒（40个20Hz权威Tick），复用眩晕 |

E的2秒落雷与敌方最后1秒预警对应[Sky Splitter时序说明](https://leagueoflegends.fandom.com/wiki/Volibear/LoL)，并与本机基础皮肤预警资源时间轴交叉核对。

失效只作用于命中后仍存活的敌方防御塔，水晶和建筑卡不受该控制。友方不受伤害。凝滞、法术护盾和其他交互准入沿用通用规则，普通吸伤护盾不阻止命中附带的状态。

## 主动技能：霹天雳地

放入主动槽时随本次出牌强化，额外1金币，总费用5；每次出牌生效一次，冷却0秒。

- 落点范围内友方非建筑单位（含空军）获得180点护盾，持续3秒，不自然衰减。
- 命中的敌方非建筑单位（含空军）减速30%，持续2秒。
- 建筑卡、防御塔、水晶不获得强化护盾或移动减速；凝滞友军不获盾。
- 多次施法按通用独立盾层和最强减速聚合，不按视觉电弧结算。
