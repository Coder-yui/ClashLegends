# 单位与竞技场手册

这里是面向阅读和观看的总入口。点开一个对象，就能看到它的定位、当前数值、被动和技能，再从页面进入动画、音频或特效说明。

## 怎么使用

- 想了解强弱与玩法：先看对象总览里的数值、被动和技能。
- 想了解动作怎样接入：进入该对象的动画页，查看动作表和衔接说明。
- 想听声音：进入音频页，点击试听，再看触发时机与缺项。
- 全局播报和共享声音：[竞技场音频](audio/arena.md)。
