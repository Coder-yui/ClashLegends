# 聚合脉冲

[← 返回总索引](README.md)

3费范围伤害与聚拢法术，改造自发条魔灵R。全场施放，可覆盖建筑；公共0.5秒出牌延迟之后再蓄能0.65秒，以结算瞬间的位置查询目标。

| 项目 | 普通版 | 强化脉冲（额外1费） |
| --- | --- | --- |
| 伤害 | 180 | 270 |
| 半径 | 105像素（2.625格） | 130像素（3.25格） |
| 防御塔、水晶伤害 | 54 | 81 |
| 强制位移距离 | 80像素（2格） | 100像素（2.5格） |
| 基础位移时间 | 0.4秒 | 0.5秒 |

伤害影响敌方地面、空中和建筑，身体圆接触作用圆即命中。建筑不被拉动。可移动敌方单位朝结算时的中心方向强制位移，普通版80像素/0.4秒，强化版100像素/0.5秒，两者基础速度均为200像素/秒，距离不受质量影响。途中不参与碰撞，可以相互穿过、越过中心、河道和建筑；完整身体仍受场界限制。终点复用通用合法落点校正，建筑和地形需要避让，普通单位在结束后恢复自然分离；落点延长时按原速度增加实际控制时间。中心目标只受伤，不产生任意方向位移。

法术盾阻止同一次法术的伤害与拉拢；凝滞拒绝命中，位移免疫按通用控制规则处理，护盾吸收伤害不自动免疫位移。每次法术对各目标只结算一次；清场取消尚未结算的脉冲。强化每次出牌使用一次，没有独立冷却。
