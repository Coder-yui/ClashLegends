# 藤蔓鞭击者

[← 单位总索引](README.md)

3金币近战建筑，仅攻击地面敌人，每次命中使敌人减速30%，持续2秒。同源重复命中刷新时间，不叠加减速强度。

| 属性 | 当前数值 |
| --- | --- |
| 生命 / 攻击 | 720 / 100 |
| 攻击间隔 / 首次命中 | 1.25秒 / 0.31秒（20Hz约0.35秒） |
| 射程 | 100像素（2.5格），双方表面距离 |
| 体型 / 身体半径 | 稍大 / 21像素 |
| 占地 | 2×2格 |
| 自然生命衰减 | 24秒基准，每秒30生命；强化中每秒45生命 |

**缠绕之根**：2金币，最多2次，冷却14秒；持续6秒。最大生命提高50%至1080并获得新增360生命，模型与碰撞增大25%（半径26.25像素），攻速提高60%（周期约0.78125秒，实际按20Hz结算）。刷新不重复补血。到期恢复上限与体型，仅裁剪溢出生命，不额外扣血。强化不刷新寿命，也不附带大招范围伤害或击飞。

需求未填的生命、伤害、攻击间隔与强化持续时间采用以上项目调优值。卡面使用用户摄影原图`藤蔓鞭击者_20261103_002724.png`，技能图标使用婕拉E原图。
