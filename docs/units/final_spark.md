# 终极闪光

[← 返回总索引](README.md)

3费直线爆发法术，改造自拉克丝R。仅在己方初始半场合法格释放（不含河道、桥）；方向朝向敌方，建筑不阻挡部署。公共0.5秒命令缓冲后开始1秒预警，在第20个权威Tick按目标当时位置一次结算。

| 项目 | 数值 |
| --- | --- |
| 长度 / 宽度 | 800 / 40像素（20 / 1格） |
| 伤害 | 300 |
| 防御塔与水晶伤害 | 90（30%） |
| 目标 | 敌方地面、空中单位和建筑 |
| 余光 | 起手后2.5秒结束，无持续伤害 |

身体圆接触直线矩形即命中，端点按圆与矩形最近距离判定。友军不受影响，光束不被前排阻挡。

主动「夺目光辉」额外1费，每次出牌一次，无独立冷却：命中的敌方非建筑单位获得1次致盲，使下一次普通或强化攻击落空，仍消耗攻击；技能不受影响。重施取剩余次数最大值，不叠加；无攻击不自然消耗。复用通用致盲提示与免疫规则。法术盾拒绝整次伤害与致盲，凝滞拒绝命中，护盾吸收伤害不自动阻止致盲。
