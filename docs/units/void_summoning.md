# 虚空召唤

[← 返回总索引](README.md)

5金币法术，公共出牌延迟0.5秒后建立半径4格（160像素）、持续8秒的区域。区域建立0.5秒后首次生成（正常出牌至第一只生成合计1秒），此后每0.8秒分散生成一只[近战虚空鱼](voidfish.md)，共10只；第一只在0.5秒，最后一只在7.7秒，区域到8.0秒结束。可以全图选点，不造成直接伤害。生成后的鱼持续存在，法术结束不销毁它们。

落点使用独立固定种子223069与固定候选数的分散采样，呈不规则分布；相同位置重复施法得到相同基础落点，不消费全局随机流。边缘区域只从地图内且圈内的候选点选择，避免多个越界点挤到同一个边界点；最终生成查询仍同时约束地图、范围圆与不可推动占位。虚空鱼是空军，可以出现在河道上方。死亡转化优先保留死亡位置，受边界或凝滞占位阻挡时寻找圈内最近合法点；完全无解时拒绝非法生成。

每只鱼的出生等待为0.8秒：原版出生最后一层约0.78秒结束，向上取整到固定Tick。完成后可以移动、索敌和攻击，不再等1秒。出生期间实体可受伤；控制效果仍遵守通用规则。只覆盖本法术基础与转化召唤，不修改其他虚空鱼来源。

## 虚空献祭

沿用法术主动槽强化：放入主动槽时随本次出牌自动启用，总费用6金币。定义费用1、次数1、冷却10秒；法术沿用项目既有强化出牌规则，不创建独立单位主动按钮。

在区域生效的8秒内，死亡中心落在圈内的敌我非建筑、非近战虚空鱼单位真正死亡时，在死亡位置生成一只施法方的近战虚空鱼，同样等待0.8秒。近战虚空鱼排除；远程虚空鱼（普通编队、大军、单只）均允许转化；塔、水晶和建筑排除；替身与孵化不算真正死亡。每个区域对同一死亡只触发一次，重叠区域分别结算。到期Tick起不再转化。

## 素材与设计依据

- 半径4格、8秒、0.8秒间隔、10只及强化1金币遵从用户追加需求。
- 范围采用原版装备223069的 `223069_Indicator_On`，保留20层及各层深度标志；范围与项目圆形落点做投影适配。到期立即清理。
- 技能图标保留原版 `223069_kiwi_voidimmolation.dds`。法术卡面由内置 imagegen 参考既有虚空鱼卡面生成，保留金色面甲与紫色嘴部，以多处传送阵体现召唤；提示词及来源记录在卡面清单与素材库。
- 区域声音使用虚空女皇大招施放、变身激活与形态循环，8秒停止；1秒衔接点属于项目时序适配，详见[音频页](audio/void_summoning.md)。出生、攻击、死亡沿用虚空鱼声音。
- 原始资源、采样与音频来源见素材库 `03-制作中/虚空召唤`，正式特效清单见 `assets/effects/void_summoning/source_manifest.json`。
