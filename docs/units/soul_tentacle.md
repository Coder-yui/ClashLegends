# 灵魂触手

[← 返回总索引](README.md)

4费地面防守建筑，改造自俄洛伊的独立触手。占地3×3格，碰撞为稍大（半径21像素），不会自主移动。

| 项目 | 数值 |
| --- | --- |
| 生命 | 1000 |
| 伤害 | 180 |
| 索敌攻击距离 | 表面距离160像素（4格） |
| 拍击范围 | 从自身中心向前360像素长、80像素宽（9×2格）矩形 |
| 攻击间隔 | 2.65秒 |
| 前摇 | 0.75秒 |
| 自然寿命 | 25秒，每秒自然减少40生命 |

只攻击地面敌军，也可伤害建筑、防御塔与水晶。起手根据目标所在位置固定朝向；之后目标移动、死亡或失去可选取性都不会重新瞄准。拍下时查询矩形与目标身体圆是否相交，可以拍空，也可以命中后来进入范围的敌军。致盲使整个拍击无伤害；拍地声仍播放。控制打断沿用普通攻击规则。

**过界信仰**：3费、一次、冷却10秒。即时获得8秒不可选取，期间暂停自然寿命和生命衰减，攻速提高50%；不暂停自己的攻击。满血且没有外来伤害时，使用完整强化可将自然存续时间延至33秒。强化不回满生命，也不移除已有附着效果。

峡谷先锋不会新选不可选取触手；已经锁定的冲撞继续接触并收招，碰撞无伤害、不支付生命代价、不生成蠕虫，与撞击凝滞建筑一致。
