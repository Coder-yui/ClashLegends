# 武器大师

[返回单位索引](README.md)

5费单体地面近战，以范围普攻清理密集敌人。持续命中积累攻速，反击风暴用于抵挡普攻并在结束时反击。

## 无情连打

每次普攻有效命中增加一层，每层提高10%攻速，最多5层（50%）。再次命中刷新全部层数4秒；溅射多人只加一层，空挥和被免疫的攻击不加层。

## 反击风暴

消耗2金币，每次部署可用2次，冷却8秒。立即建立2秒普攻免疫窗口，仍可移动和攻击；普攻不会消耗生命或护盾，也不触发攻击者命中收益，技能伤害正常结算。

窗口自然结束时，对自身周围159.38圆形范围内地面敌人造成150伤害，并眩晕1.5秒（建筑沿通用控制准入）。每免疫一次普攻增加20%伤害，最多计5次，即最高300伤害。冰冻和眩晕不取消已建立的窗口；死亡取消结果，凝滞中到期不爆发，也不在解除后补发。没有提前结束按钮。

需求未填写的基础数值、2秒持续时间、150基础技能伤害、原生地面范围和每次20%增幅由本次接入补齐；被动层数与部署时间沿后续调整，其他费用、持续时间和眩晕时间沿需求。
