# 狂暴赛恩

[返回赛恩](sion.md) · [返回总索引](README.md)

不能单独出牌，由赛恩首次致死后2秒进入。满血2400，不再只攻击建筑，可攻击地面单位及建筑，普攻不能对空。

| 项目 | 数值 |
| --- | --- |
| 生命 / 伤害 | 2400 / 180 |
| 普攻间隔 / 前摇 | 0.6秒 / 0.12秒 |
| 移速 / 半径 / 质量 | 76（快）/ 27 / 12 |
| 射程 / 视野 | 40 / 240 |
| 普攻吸血 | 实际造成生命伤害的50%，最高回复至2400 |
| 自然衰血 | 每秒480，即最大生命的20%；无回血无受伤时5秒死亡 |

吸血只基于实际掉血，护盾吸收、空挥或被拒绝命中不回血。回血能够延长存活时间；这不是固定5秒倒计时。衰血绕过护盾，不视为受击，硬控不能暂停。不能使用主动技能，死亡后不会再次复生。
