# 庇护清泉

[← 返回总索引](README.md)

3费范围护盾法术，由慧WW改造；全场合法落点施放，忽略建筑占位。

| 项目 | 数值与规则 |
| --- | --- |
| 清泉持续 | 3秒（60个权威Tick） |
| 范围 | 半径110像素／2.75格，按身体边缘接触 |
| 目标 | 友方地面和空中单位；不包括建筑卡、防御塔、水晶 |
| 护盾补充 | 每秒60，每Tick3，不设上限；单次完整持续提供180 |
| 离圈与结束 | 已有清泉盾保留1秒，留圈持续刷新寿命 |
| 渲浓 | 额外1费，落地立即提供120盾 |
| 叠加 | 重叠清泉不加快补盾；多次强化的初始盾可累加 |

清泉盾独立于其他来源护盾，可通过连续施放继续累加。凝滞拒绝新护盾；死亡清盾。暂停停止模拟，清场取消区域。法术主动槽随本次出牌强化，无独立重复释放按钮。
