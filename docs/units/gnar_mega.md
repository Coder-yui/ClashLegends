# 大纳尔

[← 返回总索引](README.md)

**控制与变形：**冰冻中达到第4次真实命中，只保留一次待变形，解冻后先变小；眩晕不阻止变形。换形后不继承旧形态弹体的命中计数。变形锁正常计时，冰冻解除不续旧变形动画。

## 总览

纳尔变大后的近战形态，生命、体型和单次伤害更高，但移动更慢，无法对空。继续命中敌人后会变回小纳尔，不能把大纳尔作为另一张卡单独部署。

## 被动与特殊规则

**变小：**4 次有效命中后恢复小纳尔，还原期间锁定 1.33 秒。最大生命回到 430，当前生命超过 430 的部分会被截掉。变形不会刷新技能次数。

## 主动技能

### 怒气爆发

作用目标：地面敌人。

小纳尔先变大再释放前方重击；大纳尔直接释放。命中时造成伤害并眩晕地面敌人。

| 项目 | 当前数值 |
| --- | --- |
| 技能费用 | 2 |
| 最多使用 | 1 次 |
| 冷却 | 8 秒 |
| 基础伤害 | 120 |
| 向前距离 | 140 |
| 区域宽度 | 60 |
| 效果执行延迟（配置） | 0.8 秒 |
| 施法总时长 | 1.2 秒 |

施放期间：不能移动、不能普攻，也不能转向。
