# 近战兵小队

[← 返回总索引](README.md)

## 总览

一次出牌生成4只独立近战小兵，站在正方形的4个顶点。成员沿用近战兵的战斗数据、模型、动作和阵营表现，但共享本次部署的主动技能资格。

[查看3D摄影卡面](../../assets/cards/melee_minion_squad_loading.png)

## 男爵之力

消耗1金币，复用近战兵男爵之力：为这次下牌中仍存活的近战兵提供移速135%与伤害125%，持续4秒。技能沿用近战兵的2次使用与5秒冷却；队长阵亡后，主动技能资格转交同编队中仍存活的小兵。
