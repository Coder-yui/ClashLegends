# 空投熊

[单位索引](README.md) · [提伯斯](tibbers.md) · [特效](effects/airdrop_bear.md) · [音频](audio/airdrop_bear.md)

4费法术，只能在己方半场使用，敌塔被摧毁也不会开放敌方落点。正式出牌经过公共0.5秒命令缓冲后，显示1秒范围预警，再用0.5秒从空中落地；总计2秒。工作台只跳过公共缓冲，仍保留1.5秒预警与下落。预警维持到落地，落地同时伤害并召唤可立即行动的提伯斯，不播放出生动画。

落地时对半径100像素（2.5格）内敌方地面、空中和建筑造成160伤害；防御塔与水晶为48伤害。以目标身体与圆形范围相交判断命中。中心召出一只提伯斯，非法地形或结构占位由通用召唤入口寻找最近合法位置；伤害仍以原落点结算。

放入主动槽时总费用6：落地额外眩晕1.5秒（水晶免疫）；此次召出的提伯斯获得永久灼烧与5秒50%攻速加成。攻击速度加成自落地出生开始计时，无部署等待；常驻火圈不随5秒到期消失。

灼烧每0.5秒对熊周围100像素（2.5格，与落地一致）内敌方地面、空中和建筑造成20伤害。首次在出生0.5秒后触发。眩晕和冰冻不取消灼烧；凝滞抑制当前脉冲且不补发，死亡或清场结束。多个熊各自结算，不共享冷却。

法术盾可抵挡同次落地伤害与控制，不阻止召熊。普通护盾只吸收伤害。法术卡面为AI原创，技能图标使用安妮原版R；提伯斯卡面使用用户在项目摄影棚拍摄并确认的照片。
