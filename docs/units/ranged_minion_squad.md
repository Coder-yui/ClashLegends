# 远程兵小队

[← 返回总索引](README.md)

## 总览

一次出牌生成3只独立远程小兵，站成紧凑三角形：1只在前、2只在后。成员沿用远程兵的战斗数据、模型、动作和阵营表现，但共享本次部署的主动技能资格。

[查看3D摄影卡面](../../assets/cards/ranged_minion_squad_loading.png)

## 男爵之力

消耗1金币，复用远程兵男爵之力：为这次下牌中仍存活的远程兵提供攻速125%与伤害125%，持续5秒。技能沿用远程兵的2次使用与5秒冷却；队长阵亡后，主动技能资格转交同编队中仍存活的小兵。
