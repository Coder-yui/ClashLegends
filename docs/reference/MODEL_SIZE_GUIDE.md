# 单位体型与模型大小参考

[返回美术接入](../ART_PIPELINE.md) · [新卡清单](../NEW_CARD_CHECKLIST.md) · [卡牌机制](../CARD_DESIGN.md)

## 目标与适用范围

**同一体型的单位应有相近的身体体量观感，不要求模型等高、等宽或包围盒相同。** 保留矮壮、细长、人形、兽形、飞行等形态差别。相邻档位允许视觉尺寸重叠；体型档位不等于一组互不相交的外观尺寸区间。

本页用于新单位选体型和校准模型，不包括建筑、地图、弹体和技能特效。红蓝方合并参考；独立变形分别判断。编队以单个成员判断，不能拿整组队形套一个身体体型。

权威 `size_tier` / `radius` 与模型大小分开维护。新卡先结合玩法和角色形态确定体型，再校准模型；已有卡纯美术调整不得自行改碰撞。用户明确要求调整体型时，同步逐卡定义、提示半径、相关编队/形态、文档与回归。`visual_radius` 不是模型测量结果。

## 七档参考

下列模型是当前项目的比较样本，不是严格标准件。尺寸为2026-09-26校准批次的**完整可见轮廓宽×高近似值**，包含装备与附属物，供重现比较；不是单独测量出的躯干尺寸、实际三维体积或必须达到的范围。

| 体型 | 标准碰撞半径 / 直径 | 主体观感 | 优先参照模型及轮廓大小（约px） |
| --- | --- | --- | --- |
| 极小 | 9 / 18 | 很小的精灵、伴生物，身体体量显著小于普通小兵 | 皮克斯46×27；多数宽度来自翅膀，不能以46作为极小身体宽度 |
| 小 | 12 / 24 | 小而紧凑的小兵、小怪 | 远程兵34×33、小鬼38×33；较宽的近战兵49×43；冰鸟蛋33×26 |
| 稍小 | 15 / 30 | 比普通小兵饱满一档的小型角色 | 小纳尔62×57、提莫50×74；耳朵、帽子拉开轮廓差异 |
| 中 | 18 / 36 | 常规人形或同等体量的异形单位 | 艾希69×74、女枪70×69、卡牌大师52×87；异形参照炮车62×85、龙王53×71；格温119×71中的宽度主要受剪刀影响 |
| 稍大 | 21 / 42 | 更结实、宽厚或高大的主体 | 德莱厄斯80×104、腕豪57×108、超级兵108×88；冰鸟120×60为飞行展开形态参照，当前保留自定义半径20 |
| 大 | 24 / 48 | 厚重的战士或宽厚大型兽体 | 盖伦106×118、大纳尔93×84；大纳尔蹲伏，所以明显矮于盖伦仍可同档 |
| 极大 | 27 / 54 | 显著厚重、占画面较多的大型主体 | 赛恩124×132、峡谷先锋132×148；狂暴赛恩103×110是姿态与武器表现变化，不据此另降档 |

这里的px按标准720×1280战场、40px/世界单位的正交投影尺度换算，不是显示器物理像素。取景为45°俯角、固定模型朝向、待机约0.3秒。图像尺寸或相机倍率变化后需先换算到同一尺度；不同动画姿态不能直接当作模型缩放差异。

没有覆盖所有形态的统一“人体高度”：例如大纳尔较矮但身体宽厚，龙王较长但细，冰鸟翼展大但躯干窄，不能只凭一个方向的最大值分档。

## 怎样使用参考

1. **选相似形状的样本。**人形优先与人形比，矮壮角色与矮壮角色比；跨形状时至少再选一个同档样本，避免只比高度。新卡是中体型时，可先以艾希/女枪/卡牌大师作为常规人形的起点。
2. **固定镜头、同场并排。**使用相同正交倍率、俯角、地面位置和朝向。普通模型预览会自动适配每个模型，单独窗口看起来同样大不能证明实际尺寸相近。候选仍放素材库，用通用模型展台/摄影棚；需要实战时按工作流建立联调副本。
3. **先看身体。**比较头、胸腹、躯干、四肢和主体装甲共同形成的体量，再看整体轮廓。不要把细长武器、张开的翅膀、尾尖、头冠或透明特效算成同等厚重的身体。厚重肩甲、机械底盘与宽躯干属于主体观感，应纳入判断。
4. **允许自然差异。**可把最相似样本的主体线性观感上下约20%作为初次试调的宽松参考，不作为验收硬阈值或自动缩放公式；这不是体积±20%。一个方向更长时应综合另两个方向与姿态，不能要求每个轴都落在同一范围。差异大到像隔了一整个体型档位时再复核。
5. **再看动态与邻档。**检查正面、侧面、背面，以及待机、移动、普攻/技能中的常见姿态；与同档、邻档各一个样本并排看。一次挥剑、展翼、蹲伏或死亡姿态的最大包围盒不作为缩放基准。
6. **验收整体效果。**同档一起出现时，身体体量应大致属于同一组；放进标准战场后仍清晰可辨、不过分挤压其他单位。允许武器与附属物伸出碰撞圈，不要求模型轮廓被碰撞圆完全包住。

## 缩放与关联检查

- 各源模型的单位制、骨骼和原始尺寸不同，不能横向比较包装场景的 `scale` 数字，也不能把一个英雄的缩放常数直接复制给另一英雄。
- 先使用统一XYZ缩放保留原比例；不得为了凑宽高把正常模型压扁或拉长。仅调整包装与必要的落脚校正，不让模型驱动权威逻辑。
- 放大/缩小时同步核对脚底偏移、血条/状态挂点、弹体/吐息起点、跟随特效、变形/复生/死亡后续模型。优先使用已有骨骼挂点及自动投影，不新增重复的固定偏移。
- 空军仍按统一网格底部离地高度处理；离地更高不是模型更大，调试时应分开判断。
- 模型变化不等于攻击距离、技能范围、弹体碰撞或伤害随之改变。只有明确的玩法调整才修改这些权威数据。
- 更新模型时重新与本文的同档参照比较；参考样本本身若发生明显变化，需要更新本页的近似尺寸和参照说明，不保留过时数值当作永久硬标准。
