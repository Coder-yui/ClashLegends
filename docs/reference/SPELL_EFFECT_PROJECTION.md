# 法术特效的范围与空间投影

[返回表现合同](../status/PRESENTATION.md) · [凝滞实例](../units/effects/stasis.md)

本项目的权威战场是720×1280逻辑平面；相机为斜俯视正交相机。圆形法术判定在逻辑平面中完成，展示也必须是对应的屏幕圆。3D高度只是表现，不参与范围查询。以下是项目适配约定，不是对LoL引擎坐标合同的完整复刻。

## 按语义分配变换

| 原版层的职责 | 位置 | 形状与朝向 |
| --- | --- | --- |
| 地面范围圈、范围内的地面光晕 | 反投影权威位置至地面 | XZ补偿，使屏幕轮廓与权威圆一致 |
| 以范围为底座的柱体、穹顶 | 底座与同一范围对齐 | 底座XZ随范围补偿；Y保留原版相对比例和真实世界竖直 |
| 范围内散布的符文、火花、上升粒子 | 出生分布和水平运动映射同一范围；Y保持原尺度 | 不把范围拉伸继续施加到小粒子本体；保留原版网格/任意四边形/定向方式 |
| 面向相机的光点 | 中心按所属系统定位 | 保持原版Billboard与局部尺寸；不二次补偿圆形光点 |
| 飞行弹体 | 权威起终点和时长驱动表现轨迹 | 独立等比尺度，不随AOE半径变大，不套用地面范围拉伸 |
| 拖尾与出生后独立粒子 | 按原版bindWeight和出生时刻定位；未绑定粒子不能随当前弹体平移 | 原Trail用连续带状几何；沿用纹理、宽度、颜色和寿命，不能当普通贴片 |
| 附着角色/塔的金身等 | 模型或骨骼挂点 | 使用模型自身变换，不再做AOE投影 |

不能仅靠“3D / 2D”“是否isGroundLayer”决定变换。需同时检查primitive、绑定、出生偏移、速度、粒子尺寸和这层实际承担的意义。原定义有些贴地四边形未标记groundLayer；也有范围内粒子的位置需要映射，而自身形状不需要。

## 实现入口

通用入口为 `scripts/presentation/spell_effect_projection.gd`：

- `ground()` 将逻辑坐标反投影到地面。
- `footprint_basis()` 建立屏幕X/Z等长的地面基底，Y始终为世界UP；高度不乘反俯视系数。
- `flight_position()` 将调用者指定的起始高度、弧高与进度变为世界位置。弧高是独立艺术参数，不由命中半径推导。

粒子渲染要分离“中心/分布变换”和“本体形状变换”。凝滞播放器的projection_basis作用于中心；shape_basis只对范围平面和柱体底座启用，其他小粒子为单位矩阵。Billboard保持面向当前相机。

单位换算必须明确源尺寸和项目目标尺寸。范围系统按可见边界校准；飞行系统使用独立的源单位换算。不是给所有法术套同一数值，也不改写原纹理或颜色来掩盖坐标错误。当前基础针对正交相机；若未来改透视，需重新处理位置相关缩放与投影，不能沿用当前仿射假设。

## 后续法术的验收

先列原系统/发射器的职责与变换分配，再检查范围四向和斜向、不同战场位置及双方视角。检查柱体底座、上升高度、小符号形状、飞行中段、原地停留与拖尾，最后检查抵达、暂停和清场。自动验证圆的投影与绑定语义，实际渲染确认素材朝向/大小/层叠；既有法术不因本约定自动批量修改。
