## 路径兼容与恢复

[84项前后映射](material_archive_2026-10-02.json)是2026-10-02迁移清单。每项为同卷rename，原目录位置保留相对符号链接：旧交付、来源manifest、加工配方和绝对路径继续指向同一份文件。另为潘森源件转换脚本保留一个父目录相对寻址链接，列于同一映射文件的 compatibility_links。没有复制第二份源件，也未改写来源元数据；新任务从05目录访问，旧链接不是新的制作任务。暂保留链接以免破坏历史路径，不能把链接指向的内容作为重复文件删除。

本地执行/校验/恢复脚本与文件清单位于 `ClashLegends-开发素材库/04-中间产物/工程整理/2026-10-02/`。可执行：

```sh
python3 ClashLegends-开发素材库/04-中间产物/工程整理/2026-10-02/archive_materials.py check
python3 ClashLegends-开发素材库/04-中间产物/工程整理/2026-10-02/archive_materials.py undo
```

check核对迁移文件的inode、大小、修改时间与模式，以及待开发/地图内容SHA-256；后续正常编辑会使本轮基线校验失败，需要先判断差异。undo仅在旧位置仍为本轮链接时移回源件，不删除文件；保留空归档目录和记录。不要在素材编辑过程中执行恢复。

地图仍使用 `python3 tools/dev.py stage --arena --open`；音频/模型继续使用通用展台。联调副本可用 `stage --reuse <路径> --open` 继续，旧副本缓存可再生成，源件差异必须先核对。
