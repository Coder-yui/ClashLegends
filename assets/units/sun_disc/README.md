# 太阳圆盘组合模型

- 动态圆盘源素材原为 `待开发卡牌美术素材/沙漠皇帝 (3).glb`，已移动为 `source/sun_disc.glb`，原文件已从待开发队列移除。
- `source/princess_tower_ruin_blue.glb` 与 `source/princess_tower_ruin_red.glb` 由项目现有双方公主塔模型的 `Destroyed` 最终姿态烘焙而来，只包含一个静态 `Rubble` 表面。可用 `tools/assets/export_princess_tower_ruin.py` 重建。
- 两个包装场景把圆盘与对应阵营废墟组合。普通部署直接显示静态基座；权威生成标记 `built_on_tower_ruin` 为真时，包装脚本只隐藏自带基座，复用战场现有塔墟。
- 圆盘主体使用 `0.0172` 整体缩放，按素材包围盒计算的宽度约为废墟的 `1.03` 倍；废墟继续使用 `0.01`，权威碰撞与 3×3 占地不随表现缩放变化。
- 废墟没有部署/死亡动作：普通部署时立即出现，圆盘 `Death` 播放完的末帧才随包装移除；建在真实塔墟上时不创建或移除额外废墟。
- 圆盘可随索敌改变朝向，自带废墟会抵消父级转向并保持部署首帧方向。`Spawn` 使用世界地面高度裁切并保持正常深度关系：地下碎片不渲染，位于废墟内部的部分由废墟遮挡，升出废墟后才逐渐可见。
- 包装脚本只管理纯表现，不读取塔、不改碰撞、不改寿命。
