# 蒸汽机器人模型

用户指定的蒸汽机器人GLB，迁移后源件保留在开发素材库 `05-已完成/蒸汽机器人/源件与过程记录/蒸汽机器人.glb`；正式GLB保持源内容。单一身体网格/材质，源可见配置为true，无额外候选部件。源包围盒约1.501×1.124×1.298世界单位；包装统一1.25倍、脚底+0.005，与中体型艾希同场检查。

包装只负责Q原版粒子与电缆、E右拳粒子。R_hand挂点与同步目标端点只控制视觉，不反向驱动牵引。动作、源帧率、前摇及死亡时长见[动画手册](../../../docs/units/animations/blitzcrank.md)。
