# 德邦军旗模型

来自本机只读JarvanIV.wad.client内JarvanIVStandard基础皮肤SKN/SKL、原始纹理与summonerbeacon两段动画；lol2gltf转换，统一缩放0.01。旗杆单GLB不含旗面，运行及摄影必须使用standard_view.tscn，旗面由E CameraTrail重建。

源件与加工脚本保留于ClashLegends-开发素材库/03-制作中/德邦军旗。动画/表现说明见[手册](../../../docs/units/animations/demacian_standard.md)。
