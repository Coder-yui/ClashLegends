# 狂战士素材

使用用户指定的狂战士.glb，保留19段动作、模型比例、骨架、纹理和原顶点顺序。包装统一缩放1.42。诸神黄昏期间移动继续使用原Run，攻击使用原Attack3；不合成R移动动画。

原提供GLB没有NORMAL属性。2026-11-06从原版基础皮肤olaf.skn补回2897个顶点法线，匹配每个顶点的位置（镜像X、缩放0.0085）及UV后写入，法线只镜像X。原顶点、UV、索引、骨骼权重和动画二进制不变，KHR_materials_unlit保留；这是修复R轮廓光读取缺省法线造成整身黄光，不是改写模型形状。来源哈希与匹配误差见source_normals_manifest.json；可复现脚本和原输入保留在开发素材库03-制作中/狂战士/诸神黄昏。

卡面来自Olaf.wad.client的olafloadscreen.tex；W/R图标来自基础皮肤原图标。特效源单位0.0085乘实时骨架缩放，详细挂点、原版参数与适配边界见[特效手册](../../../docs/units/effects/olaf.md)。
