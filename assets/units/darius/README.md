# 德莱厄斯模型

正式资源：`source/darius.glb`，包装`darius_view.tscn`。来源为用户提供的项目素材库`01-待开发/卡牌模型/诺克萨斯之手.glb`，经制作中/德莱厄斯迁移正式接入；未修改原始GLB字节。依赖纹理嵌入模型。

包装统一缩放0.015、朝向偏移0，不参与战斗碰撞。Idle1、Run、Attack1/2、Spell4、Death已实际播放；部署无复活动作，回退Idle1。

卡面源包Darius.wad.client内`assets/characters/darius/skins/base/dariusloadscreen.tex`，解码到`assets/cards/darius_loading.png`；R图标同包`assets/characters/darius/hud/icons2d/darius_icon_sudden_death.dds`，PNG转换及哈希见技能来源清单。
