# 恕瑞玛卫队音频

来源为 LoL Azir 基础皮肤事件库，已复用准备好的 `card_audio_batch/azir` 事件素材，与原始 WAD 来源记录关联。共13个正式WAV：三段士兵出手各2变体、士兵命中2变体、W召唤2变体、W消散2变体、E护盾施放仅r1。

出手按三段攻击匹配，命中只在真实命中后播放；召唤/死亡按每名士兵生命周期触发，技能起手由同次出牌的技能持有者触发一次。出手、召唤和死亡-5dB，命中-4dB，技能0dB。死亡声沿用项目最长1.5秒及尾部淡出规则。

护盾生效/结束原声仍留在候选区：当前没有独立护盾结束/破盾音频入口，不将正常到期声音错误用于破盾。事件、时长、源TXTP、哈希和处理参数见 event_manifest.json。听感待用户试听确认。
