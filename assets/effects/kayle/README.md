# 天使光剑与焰浪

来自本机只读 Kayle.wad.client 基础皮肤；原始路径与提取索引见 source_manifest.json。九张 PNG 为原 TEX 解码，非重新绘画。

原生 Kayle_Base_BA_Ranged 引用子弹头与拖尾；Kayle_Base_P_Enraged_Mis_2 引用焰浪弧线、火丝、尾迹与火焰渐变。共享 bin 哈希 54b2e3967983f8cc、eb2d2fb41332e9aa。源码与解码中间件保留在开发素材库/03-制作中/正义天使/wave-native、wave-decoded。

Godot使用独立只读表现代理与加法混合shader分层重建：子弹头改为金色，焰浪为金色弧线加滚动火丝与淡出尾迹。未移植LoL粒子运行时、全部发射器或原始服务器脚本，不声称像素级还原。贴图不参与伤害计算。

原 SpellData 的 KayleEnrageConeMisUpgrade 为直线非追踪，投射到射程终点，CastOnHit，运动完成销毁；原范围850、速度2800不是本项目像素单位。本项目按用户最新要求采用扩宽波前：起始1.2格宽、横向1→2线性扩宽，最大合法射程加余波才到2倍，近目标提前结束不到2倍，光剑创建后延迟0.1秒发出，终点在出手瞬间目标位置后1格。主目标类别在出手时锁定：对空只伤空军，对地只伤地面单位及建筑，每目标55伤害一次，不额外叠攻速被动。复用现有普攻声音，本轮未新增独立焰浪音轨。

## 扩宽与尾程修订（2026-09-25）

原P_Enraged_Mis_2的Arc与Arc2发射器scale0曲线为(1,1,1)→(1.8,2,0)，支持渐扩的画面依据；这不等于伤害宽度曲线。原弹体SpellData仍为850射程并在运动完成时销毁，现有本地素材不足以证明服务器将焰浪寿命绑定光剑命中。因此“伤害波前渐扩、出手锁定目标位置后1格”明确为按用户要求自定义的项目规则，不声称完整还原LoL逻辑。最新版本不再用光剑退出时机控制焰浪。起点、方向及终点在光剑创建时锁定，延迟0.1秒实际创建；目标变化不改路径。画面使用模型胸部骨骼锚点，无合适骨骼时取可见网格中心，起点对齐天使、光剑终点对齐目标；焰浪端点冻结。视觉随快照中的权威宽度放大；停止后原地0.12秒淡出不再伤害。光剑退出即移除其表现。

## 原版层次复核与单弹体（2026-09-25）

BA_Ranged的Glow Missile Head为单个粒子，引用Caitlyn_Skin11_BA_Bullet与Flame_trail_gradient；删除先前第二层剑头。保留单剑头、原E_bigglow02光晕以及原BA_trail纹理。原Head颜色(1,.8509804,.09019608)、Glow颜色(1,.63,.03)用于Godot着色；渐变图选择金色行（索引4）为本项目金色适配，未证明与原版运行时动态调色选择完全一致。

原Trail寿命0.12秒，本项目记录0.12秒真实画面轨迹生成渐细带状拖尾，转弯时不将整条尾迹硬旋转。剑尖对齐飞行位置，主体向后展开；命中时整枚光剑及尾迹立即释放，不穿透，不保留第二剑头。全身金尘、Sharp edge随机片及减色地面层未完整移植，避免把地面投影直接套到对空飞行效果。

P_Enraged_Mis_2的Fire Trail和Fire1使用原texDiv(1,.5)，UV滚动分别为(1,.25)/(1,.1)；Arc/Arc2及火丝/尾迹继续采用原贴图。横向缩放依用户规则1→2，纵向厚度保持；这不同于LoL原动画曲线(1,1)→(1.8,2)。用户自定义空地分类与归一化扩宽不冒充原服务器逻辑。
