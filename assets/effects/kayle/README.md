# 天使远程光剑与焰浪

从本机只读 Kayle.wad.client 提取基础皮肤 `Kayle_Base_BA_Ranged` 与 `Kayle_Base_P_Enraged_Mis_2`，分别对应源 BIN `54b2e3967983f8cc`、`eb2d2fb41332e9aa`。各系统的 source_manifest.json 保存源包、依赖和哈希。

两组各7个发射器：光剑包含碎光、减色底层、光晕、轨迹带、速度线、单弹头和金尘；焰浪包含金尘、火焰拖尾、乘法火焰弧、外弧、光晕、亮弧和尾迹。保留原贴图、调色板行、双纹理遮罩、UV动画、混合方式，以及固定种子采样的粒子颜色/尺寸/旋转曲线。采样60Hz，Godot用2D多边形投影到已有模型锚点路径；真实飞行轨迹记录未绑定粒子的出生位置并连接拖尾。

这不是完整LoL运行时：原粒子的时间压缩/延展到本项目行程，Z轴层次投影到弹体平面，地面层随飞行表现投影，焰浪亮弧宽度适配权威半径，退场0.12秒。每枚弹体复用确定性采样，不重新随机模拟。光剑仍命中后立即移除。

焰浪权威碰撞改为向后弯曲的半椭圆亮弧：横向半径24→48像素（按最大合法行程增长），弧深为当前半径0.8倍，亮弧厚度6像素，16段连续扫掠，每目标一次55伤害。中央尾光不填满弧后空白，不造成额外伤害。弧形近似贴图主要亮线，不把每个火星当成碰撞对象；判定完全由20Hz权威模拟计算，不读取贴图。

原始素材、导出脚本、旧版表现与渲染证据位于本地开发素材库 `05-已完成/正义天使/源件/2026-10-08-远程弹体重做/`。
