# 德邦军旗原版特效

源：本机只读 JarvanIV.wad.client，基础皮肤。2026-11-08重新从源包提取BIN与25项网格/纹理依赖，原始解析、转换脚本、重建报告保存在开发素材库03-制作中/德邦军旗/rebuild；文件哈希见source_manifest.json。

- 部署：E_tar_green/red的Weapon（不透明网格、写深度），原生高度2000、速度−4000，0.5秒落地。配套落点圈使用各自原版颜色。落地播放E_hit_01的7层尘土/闪光，再由旗杆与E_flag_hld待机补齐1秒。E_flag_hit_01只有名为empty的黑纹理和Q命中音，不作为部署落地资源；E_mis属于投掷飞行，不代替落点下落。
- W施放：W_nova_01的5层原版网格环，按源半径153.062274和可见主扩张3.0统一缩放，主环外沿中心半径160；尾段额外扩张裁在160内，地面高度与常驻面一致。
- W自身盾：W_buf_01的6层原版盾环及spiritwheel，尺寸跟随模型0.01；源5.1秒采样按原速播放，项目3秒盾期的最后0.35秒仅淡出，盾提前耗尽立即隐藏。W_tar是目标受影响层，此项目减速复用通用提示，不重复附加。
- 采样120Hz，剔除离线模拟器首个1/60秒空步，将源事件起点置于0；并非改变原版速度。粒子局部XYZ不做相机压缩，混合与深度按各层源字段。粒子着色由本目录native提供；旗面CameraTrail复用通用trail着色器。
- 常驻范围为半径160的红蓝阵营细边，内部使用双方同色、覆盖整个圆面的低透明流动纹理，仅最后1战场像素柔和收边。范围平面与旗面网格加入presentation_fx，避免受击/冰冻/凝滞等模型叠加材质把透明载体显示为方块。
- 离线采样不模拟LoL实时导航遮罩。视觉复核证据及未验收项见同任务交付记录。

## 新版接入复核

以素材库本机基础皮肤BIN为准，Skin0/Resources明确将W_nova与W_buf映射到当前5层扩散/6层盾资源。保留新版金色扩散、原始纹理和颜色查表，不采用官网旧演示的蓝绿重染。修复项目时间适配将5.1秒整体加速到3秒的问题，入场短闪、旋转、查表均保留原速。

部署smoke的uvMode=2此前未传入材质，现补齐固定alpha轮廓、RGB独立滚动。源Dustring/smoke启用深度测试但无单独soft参数；项目另加35源单位软交界，保留深度遮挡。此软交界属于项目适配，不能据源soft为空断言LoL实机也硬截断。

旗面遵循JarvanIVStandard源root挂点，不再挂包装原点；靠杆端固定竖直缝合边，远端保留CameraTrail采样。死亡通过begin_visual_death/finish_visual_death同步旗杆下沉与清理，不按hp归零立刻隐藏旗面。
