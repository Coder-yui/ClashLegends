# 两种电击法术的原版粒子

电击法术使用装备风暴狂涌 `4646_Lightning_Bolt_Large` 的完整17层与24项依赖；大型电击使用符文电刑本体 `Perks_Electrocute_AOE` 的完整8层与7张纹理。来源见 [清单](source_manifest.json)，每套按原目录存放。

原始定义以120Hz、种子79离线采样，共享 `player.gd` 逐粒子重播位置、方向、大小、颜色、UV与侵蚀。原始混合0/1/4分别适配纯加法/透明/透明加法。固定样本和Godot混合、相机、深度差异是适配边界，不声称逐像素复刻。

地面整体尺度按风暴狂涌OutsideRing=1050、电刑Flash=550换算；电击按施法半径，大型电击单次定点特效固定90像素参考半径。天空落雷层独立伸长，根据相机投影将主雷柱高度校准为约320像素；地面圈和火花不随高度放大，雷柱横向宽度另加粗为1.8倍。原版出生时序与尾迹保持，2.1/1.1秒回收，只读取权威派发的表现事件。

两套粒子均使用禁用深度测试的材质，关闭软粒子深度淡出，渲染优先级100起保持原层顺序，避免被单位、建筑和地形遮住。雷柱地面以下部分按本地高度裁掉。风暴狂涌地面层统一压在XZ平面（含blackhole/cast_pulse），通过相机反投影的地面基向量补偿俯视压缩，使外圈投影匹配圆形权威范围。
