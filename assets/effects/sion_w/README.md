# 赛恩 W 原版特效

从只读 `Sion.wad.client` 的 `0xef0e0a255f9d3632` 提取基础皮肤 Cas、Shield、Nova 三个系统。各子目录 `source_manifest.json` 记录原始定义与依赖校验值；PNG及网格JSON保留原素材，`sampled.json` 保留120Hz原版曲线采样。

运行入口：`scripts/presentation/sion_w_effect_3d.gd`。护盾以独立W盾层的存续控制；爆炸只消费权威事件。施放与球体以285源单位映射2.6倍单位身体半径，球心抬高0.95倍表现半径；爆炸650源单位映射200像素伤害半径。球体不作地面投影拉伸。爆炸保持1.3秒表现尾迹，不延迟伤害。

采样播放器复用已验证的原生粒子材质数学。仅地面阴影与平面外环贴地，火焰网格保留高度。无被动、Q、E、R素材扩展。

W护盾持续3秒；球体采样覆盖完整3秒，持续期间纹理继续滚动，真实到期才切换爆炸。
