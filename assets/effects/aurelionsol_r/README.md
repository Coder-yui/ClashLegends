# 龙王原版星落 / 天瀑

来源：本地只读 `AurelionSol.wad.client` 的基础皮肤 `skin0.bin`。每个变体的 `source_manifest.json` 保存源包、BIN、纹理和网格哈希。运行采样30Hz，保留原始材质混合、UV、粒子颜色、缩放和网格；不使用旧版手绘星核。

- 普通：`AurelionSol_Base_R_Tell`、`R_Mis`、`R_Impact`。
- 强化：`R_Calamity_Tell`、`R_Calamity_Mis`、`R_Calamity_Impact`、`R_Calamity_Shockwave`（同一前缀）。
- 普通/强化动作约1.93/1.9秒；起手后0.4/0.25秒创建独立星辰，再飞行1.25/2秒，起手后1.65/2.25秒命中。伤害、范围、5层充能、2.8秒冲击波传播保持原规则。
- 预警原素材参考半径350、爆炸主轮廓参考半径560，分别统一缩放到权威半径92；不再让两种原尺寸不同的系统共用420的缩放基准。
- 地面按屏幕权威圆投影；坠落采用独立表现轨迹并翻转原始导弹轴。原版双层拖尾通过出生世界位置和源平铺长度构建带状网格。
- 冲击波源网格半径30.553667，原缩放约14.977777+61.333333×年龄，整体适配权威当前波头；未用粒子坐标反推伤害。
- 落地尾段最长4秒，只延续表现，不重复命中。场景退出释放节点。资源在卡牌依赖中登记并参与加载预热。

限制：本地BIN保留的三个冲击波子发射器引用（流星、星云）未解析到实际子系统，未伪造替代；其余七个主系统已接入。原版屏幕畸变通过项目Compatibility着色器近似，非LoL逐像素渲染。音频沿用已有LoL素材和权威落地事件。

可编辑源件与验证截图：本地 `ClashLegends-开发素材库/05-已完成/龙王/源件/2026-10-09-R星落天瀑/`。

时序证据：本地英雄BIN的R/R2导弹FixedTimeMovement.mTravelTime分别为1.25/2秒。动画BIN中Spell4片段为10至16帧，强化片段为6至23帧，施法粒子事件为第1帧；项目据此选用0.4/0.25秒创建点并对齐20Hz。该事件是施法粒子事件，尚不能证明LoL服务端也在此刻生成星辰。spellCastTime为0不代表动作期间可以移动；粒子生命也不能推断动作锁定时间。预警粒子按独立飞行进度采样，动作不驱动伤害或特效存续。
