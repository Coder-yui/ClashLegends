# 龙王原版 Q 吐息

来源：只读 LoL `AurelionSol.wad.client`，基础皮肤 `skin0.bin` 中 `AurelionSol_Base_Q_Beam`（16 层）与 `AurelionSol_Base_Q_Beam_End`（7 层）。两个 source manifest 记录原定义与纹理、网格哈希。

原版纹理/SCB 网格与颜色、粒子生命、UV 动画、混合模式经本地 ltk-manager 读取和采样；`sampled.json` 与 `sampled_end.json` 为 30Hz、4 秒采样。持续发射在 1–4 秒段循环，常驻单粒子 UV 按原速率继续滚动。网格光束按原 Z 轴参数化，宽度与模型采用 0.006 素材缩放，长度绑定当前嘴部和目标；螺旋长度按当前光束适配。采用独立材质文件，避免其他法术的 shader 改动影响本卡。

模型包装只消费表现状态，喷流与命中端共用启停和时间；暂停随场景暂停，退出攻击/受控/死亡关闭，模型池重置清零。空中目标保留现有身体投影锚点，地面目标保留战场落点；沿相机平面还原视觉端点，不修改权威位置、持续伤害、范围、动画或音频。

这是针对本项目视角的原素材移植，不是 LoL 渲染器的逐像素复刻；未添加 Q 爆发计时环、强化 Q 或新伤害事件。

可编辑源件、依赖、转换脚本与本次截图位于本地 `ClashLegends-开发素材库/05-已完成/龙王/源件/2026-10-08-Q吐息/`。正式观看见[龙王特效说明](../../../docs/units/effects/aurelionsol.md)。
