# 琴瑟仙女原版粒子

基础皮肤BA_Mis、W_Zone_Self、R_Missile、R_Cas；原始WAD只读，Rust读取BIN，ltk-manager模拟器120Hz采样，保留纹理、网格、颜色、混合与逐层miscRenderFlags。制作配方位于开发素材库05-已完成/琴瑟仙女/源件，W自身层与组织修订位于其特效修订子目录。

W自身系统绑定模型根部，400源单位等比对应160项目像素；R_Cas在起手绑定模型根部，导弹独立从WEAPON发射并使用原版Y前进/Z向上坐标约定。飞行结束停止发射、保留已有粒子消散。详见docs/units/effects/sona.md；玩法与受影响对象状态提示由公共系统负责。旧W_Zone不作为正式运行依赖。

R校核配方位于同级源件的“周期治疗与R校核”目录：以原生导弹姿态采样后逆变换，保留世界重力，不将静止姿态的世界加速度旋转到飞行轴。空军版本在WEAPON高度沿水平面扫掠；源目标高度字段不作为固定落差。

R左右边线和范围底纹按原版长射程制作，宽度也超出本项目光波。实战设置路径时隐藏这三层，统一使用项目320×140技能范围提示；独立素材预览仍显示源层。主体网格约130像素宽，对应每侧约5像素命中余量，原生三维比例保持。

2026-11-07 R光波重制：制作配方与独立几何比对位于素材库`03-制作中/琴女特效重制/`。R改为1280源单位/秒、640源单位路程的移动采样，记录逐粒子`birth_times`与`birth_odometer`，分别用于运行路径插值和WAKE纹理。帧坐标已扣除采样路径的绑定位移，不能再直接作为源世界坐标使用。5条arbitraryTrail沿源粒子局部X轴展开，并保留源平滑/遍历方向/截断；禁止改成相机朝向带。W、R_Cas、普攻采样未改。
