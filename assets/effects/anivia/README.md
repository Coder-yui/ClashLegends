# 艾尼维亚原版普攻与冰雪风暴

来源：本机只读 `Anivia.wad.client`，基础皮肤 `Anivia_Base_BA_Mis` 与 `Anivia_Base_R_AOE_Green`。各目录的 source_manifest.json 记录源二进制、纹理和网格 SHA-256；仅运行必需资源进入本目录。

普攻仅显示原版 IcicleSpear 网格和纹理；GoldGlow / Trail_Blend / lotus_leaves 不生成，去除辉光、拖尾和散粒。源文件中已禁用的旧冰块与雪花层不启用。弹体锚点、朝向和生命周期读取 ProjectileSystem 的可见快照；不绑定来源模型存活时间，不影响速度或碰撞。不添加专属命中特效，命中沿用通用闪白。

风暴直接使用原版第3–6秒的稳定阶段：保留12个持续层，剔除7个在该段已无粒子的扩张/闪光层。首帧即完整尺寸，按区域年龄以原速播放3秒，末0.12秒淡出；不改变技能规则。

范围校准以可见边环亮线为准，不用包含透明留白的网格外沿。原边环网格半径45.18509–75.30853对应UV的V=0.00836056–0.99155861；原纹理亮线峰值V=66.5/128，乘源尺寸6.5后得到395.5019半径，映射到项目技能当前半径（冰鸟为86）。地面投影让蓝红双方均与权威圆形范围一致。细阵营范围圈继续保留，模型死亡不结束已生成区域。

粒子由已有 LeagueToolkit 解析/采样流程导出，以60Hz采样驱动；Godot播放器只读表现时钟。保留网格、纹理、多重纹理、UV、颜色、旋转与尺寸曲线；并非LoL引擎逐像素复刻，原生环境反射未移植。着色器数学复用项目已有原版特效实现，独立封装避免改动其他特效。

制作源件、提取与采样脚本位于本地开发素材库 `05-已完成/冰鸟特效/`。采样固定种子79。正式权威规则、技能动画和音频未修改。
