# 钢铁烈阳之匣 · 太阳圆盘日耀庇护

- 来源：本地只读 LoL `Global.wad.client` 的 `items` 数据条目，系统 `Items/3190/Particles/3190_Buff_Activate`。
- 原版 12 层施放粒子、13 项直接依赖；保留原始纹理、网格、出生分布、颜色、UV 和寿命曲线。只接入施放系统，不接装备常驻光环、受击或破盾系统。
- `sampled.json` 使用现有 ltk-manager 原版粒子引擎以固定种子 79、120Hz 采样；2.8 秒覆盖全部粒子寿命（最后活跃样本约 2.717 秒）。它只驱动表现，不参与 20Hz 权威计算。
- `source_manifest.json` 记录源包、条目哈希、二进制与依赖 SHA-256、读取器版本。完整源件与构建配方位于本机素材库 `05-已完成/太阳圆盘/源件/2026-10-08-钢铁烈阳特效/`。
- 地面波纹按原版 ring 的 800 单位半径适配太阳圆盘的 260px 范围，反投影补偿战场相机俯角；竖向火花保持原比例。蓝红双方共用原版金色，翻转视角通过投影矩阵适配。
- 复用现有原生粒子网格/材质播放实现与爆破酒桶的通用采样着色器；纯加法层使用独立 shader 宏，避免将无透明通道的原版火花纹理当作普通透明贴片而产生黑块。旧手绘扩散圈已移除。
- 日耀庇护护盾数值、持续时间、目标规则、施放声音与可靠网络事件保持原规则；尾部粒子不延长护盾时间。
