# 格温与麦林炮手原版粒子

来源为只读本机 Gwen.wad.client / Tristana.wad.client 基础皮肤，逐系统的 `source_manifest.json` 保留源二进制、纹理、网格和转换结果 SHA-256。

- `mist`：Gwen_Base_W_MistArea，26个原版层；移除CornerRune_BLOOM1/2两层水平边角纹饰（此前视觉上像圈外8根针）。原速播放，固定地面中心与120权威半径；边环按源网格UV及纹理亮线峰值46.5/128校准，原版半径425.593映射到当前范围。出生的雾墙/针线有原版动画，结界判定圆不扩缩。双方保留细阵营边线。
- `missile`：Tristana_Base_BA_mis，仅显示原版bullet1弹头网格本体；SmokeTrail、BlurTrail、Sparks不生成。不添加专属命中特效，命中沿用通用闪白。绑定弹体的可见快照与朝向；弹体消失即释放。原版弹头沿系统Y轴，自旋绕该轴。
- `rapid`：Tristana_Base_Q_Buf，保留Mesh_Rings流动光环和Muzzle_Glow、Muzzle_Glow1两层贴筒流光；仅移除向外喷散的Embers火星。挂接武器骨骼Buffbone_Glb_Weapon_1，源长度按0.01转换到模型空间，继承模型缩放与全部武器动作。此挂接为项目适配，源资料未包含LoL脚本运行时完整挂接契约；不声称逐像素还原。

沿用已有LeagueToolkit定义解析/固定种子79采样流程，60Hz记录网格、纹理、多重纹理、颜色、尺寸、旋转和UV曲线；Godot只消费表现时间。没有移植LoL引擎环境反射与子系统脚本。原版Q的7秒粒子在本项目5秒Buff结束时立即隐藏。凝滞等暂时隐藏不会重启年龄；暂停不推进表现时间。结界出圈、到期、死亡和清场以权威/快照状态为准。

加载阶段收集JSON内部纹理并实际绘制三个系统的出生和持续阶段，保留材质/网格强引用。制作脚本、源件和渲染证据在本地开发素材库 `05-已完成/格温小炮原版特效/`。
