# 熔岩巨兽原版粒子

来自Malphite基础皮肤：E_cas（6层）、E_hit_aoe（8层）、P_Shield_Refresh（6层）、P_shield_break（4层）。原定义、依赖路径/哈希、采样脚本在开发素材库03-制作中/熔岩巨兽；原始WAD只读。

120Hz采样4秒。场景只读权威动作、盾存在状态与落地事件；被动粒子XYZ等比缩放约0.0121429，与模型2.50共享换算并计入源皮肤skinScale=1.75；E使用独立等比0.01，无镜头压平、拉伸。source miscRenderFlags逐层映射深度测试，材质与预加载共用resource_shader_path。

E_cas由Spell3第8帧右手挂点释放，E_hit_aoe独立置于权威落点；均脱离施法单位。护盾获得附着模型，破盾由独立表现所有者管理，源bindWeight曲线控制粒子继承位移；清场统一回收。斜视呈椭圆、正上方呈圆形，禁止为屏幕圆形补偿相机。

通用粒子着色器复用已接入的爆破酒桶播放器着色器；Avatar使用同管线附着变体。此为Godot重建，非Riot完整实时模拟器；目标双减速统一复用公共提示。

E单独采用0.01等比缩放，匹配160像素范围；被动护盾仍随2.50模型换算。E的14个启用层名称与纹理逐层匹配源定义，Skin16拳击碎石依赖由基础皮肤原文件引用，并非误接其他皮肤。通用nova枪芒不再叠加到专属原版特效。

2026-10-22 E挂点修正：按Spell3第8帧完整骨骼链采样右手位置与旋转，逐层遵循localOrientation/particleLocalOrientation，保持其他层世界重力；释放后固定世界变换。Trigger_3新增源Flame_trail_gradient调色板（红通道、9.5/16行中心），仅其已确认的常量配置；原始采样帧未重采样。新增PNG与制作源件逐字节一致，生成脚本同步保留palette_path。原生三维高度和等比缩放不变。
